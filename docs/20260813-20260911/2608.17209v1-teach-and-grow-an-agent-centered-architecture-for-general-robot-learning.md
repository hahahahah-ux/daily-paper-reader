## 摘要
端到端的视觉-语言-动作（VLA）模型与世界-动作模型为通用机器人提供了一条优雅路径，但其可靠性受限于经验证的物理覆盖范围。当陌生物体、传感器、具身形态或接触情况落在该覆盖范围之外，且不存在经验证的备选方案时，纠正失败需要新的机器人数据、策略更新和回归测试。这种反复出现的负担就是再训练税。与文本不同，具身数据往往必须通过操作机器来生成。我们提出 Teach-and-Grow Learning（TGL），一种以智能体为中心的通用机器人学习架构。在其一般形式中，一个多模态智能体将少量成功演示转化为可复用的技能块（Skill Blocks）：面向有意义子目标的闭环行为。在新场景中，智能体将这些技能块落地并组合，选择习得的或几何工具，观察物理结果，并在执行偏离意图时修正路径。技能库（Skill Library）存储可执行行为，而结构化经验记忆（Experience Memory）则传递成功、失败与修复。新任务无需任务特定的策略再训练即可获得。我们在 LIBERO 评测中达到最先进性能；受控研究揭示了技能归纳、持续复用和智能体主导的适应。最后，我们提出 Teach-and-Grow 缩放律假设：若 X 表示有效的可复用经验，则未来任务误差与教学需求应随 X 以幂律方式趋近不可约的下限。因此，该架构将部署视为持续学习阶段，其中一个任务可以让下一个任务变得更容易。

## Abstract
End-to-end vision-language-action (VLA) and world-action models offer an elegant route to general-purpose robotics, but their reliability is bounded by validated physical coverage. When an unfamiliar object, sensor, embodiment, or contact falls outside that coverage and no validated fallback exists, correcting the failure requires new robot data, a policy update, and regression testing. This recurring burden is the retraining tax. Unlike text, embodied data must often be created by operating machines. We present Teach-and-Grow Learning (TGL), an agent-centered architecture for general robot learning. In its general form, a multimodal agent turns a few successful demonstrations into reusable Skill Blocks: closed-loop behaviors for meaningful subgoals. In a new scene, the agent grounds and composes these blocks, selects learned or geometric tools, observes the physical outcome, and revises the route when execution departs from intent. A Skill Library stores executable behavior, while structured Experience Memory carries forward success, failure, and repair. New tasks are acquired without task-specific policy retraining. Our LIBERO evaluation attains state-of-the-art performance; controlled studies expose skill induction, persistent reuse, and agent-directed adaptation. Finally, we propose the Teach-and-Grow scaling-law hypothesis: if X denotes effective reusable experience, future-task error and teaching demand should approach irreducible floors as power laws in X. The architecture therefore treats deployment as a period of continued learning, in which one task can make the next easier.

## 2. 方法论：Teach-and-Grow Learning（TGL）

### 2.1 核心思想
- 以**多模态智能体（Agent）为组织智能**，居于工作流之上（而非固定流水线中的一个模块），负责语义层决策；物理层仍由机器人原生的执行器（规划器、控制器、学习策略）负责度量运动与接触。
- **非对称分工**：Agent 决定"现在哪个子目标重要、缺什么证据、上一动作是否达成意图"；执行器负责高频控制，避免语言级规划被当作运动权威。
- **学习对象转移**：学习的是**显式可执行能力**（技能库 + 经验记忆），而非任务特定策略参数。

### 2.2 关键技术组件
- **Skill Block（技能块）**，定义为七元组：
  $b_i := \langle g_i, S_i, \rho_i, \gamma_i, \Pi_i, v_i, R_i\rangle$
  - $g_i$：应发生什么变化；$S_i$：适用域（scope）；$\rho_i$：可复用策略；
  - $\gamma_i: O \to Z_i$：把观测映射为场景接地变量；$\Pi_i$：兼容执行器集合；
  - $v_i$：由动作前后观测与执行证据输出 pass/fail/inconclusive；$R_i$：有界恢复选项。
  - **不是轨迹片段回放**，而是闭环行为：语义/行为不变量保留，位姿、抓取、路径、时序、控制参数在当前场景**重新实例化**。
- **工作规划**：$\tau_t = (b_{i_{t,1}}, \dots, b_{i_{t,L_t}})$，为"接下来做什么"的动态计划，执行后可按结果保留、缩短或替换剩余路径。
- **结构化经验记忆**：
  $\mu_j = \langle task, context, blocks, outcome, diagnosis, repair, evidence\rangle$
  —— 技能库记"如何做"，经验记忆记"经验教了什么"，且人类可读、可编辑。
- **固定权重学习**：$\theta_{n+1}=\theta_n=\theta$；$(B_{n+1}, M_{n+1}) = U(B_n, M_n, D_n, \Delta H_n)$；$H_{n+1}=H_n \cup \Delta H_n$。即新任务获取不改变基础模型参数，蒸馏出的快速策略 $\phi$ 为**后续压缩**，而非任务获取机制。

### 2.3 算法流程（文字化）
1. **少样本教学**：少量成功演示被切分为围绕有意义状态变化的片段序列 $d^{(j)}=(s_1^{(j)},\dots,s_{K_j}^{(j)})$。
2. **跨演示抽象**：按"达成什么效果"对齐片段，合成共享策略 $\rho_k=\mathrm{Synthesize}(A_k)$；分离语义不变量、行为不变量与实例变量。
3. **技能块接地与验证**：在新场景中绑定当前物体与几何，选执行器执行，验证结果；成功扩展适用范围，失败收窄范围。
4. **动态组合与工具选择**：$(\mathbf{o}_{t+1}, \varepsilon_t)=\mathrm{Run}(b_{i_{t,1}}, \pi_{i_{t,1},t}, \mathbf{o}_t)$，Agent 依据证据继续、重观测、换执行器、重组路线、请求针对性教学或停止。
5. **有界探索与针对性教学**：教学给探索提供起点，交互拓宽教学集，后续指导愈发选择性。
6. **结构化成长与快速策略蒸馏**：验证过的行为入技能库、经验入记忆；成熟行为可蒸馏给 VLA/WAM 作为快速路径。

### 2.4 Teach-and-Grow 缩放律假设
- 定义**有效可复用经验**：$X_n=\sum_{h\in H_n}\omega(h;B_n,M_n)$，$\omega\in[0,1]$ 由证据可靠性、新增覆盖、可检索性、接地有效性、与已入库块的兼容性五项决定，**未来任务结果不进入该评分**。
- 预测形式：$E_{future}(X)=E_\infty+AX^{-\alpha}$，$D_{teach}(X)=D_\infty+BX^{-\beta}$。
- 成本侧预测：$C_{TGL}(K)=C_0+\sum_{k=1}^{K}\kappa_k+C^{retrieve}_{cum}(K)$，当范围与验证保持局部、层级检索满足 $O(K)$ 时，累计成本至多线性；对比端到端 $C_{E2E}=C_{collect}+C_{train}+C_{regress}$ 可能凸增长。
- 灵感来源：《学记》"教学相长"，形成循环 teach → compose → act+check → grow → teach。

## 6. 主要结论与发现

- **技能归纳可行**：少量成功演示可被抽象为范围明确、可验证的闭环技能块，并能通过保存-重载成为持久可复用能力。
- **物理反馈改变决策**：执行证据（pass/fail/inconclusive）可触发重新观测或路线重建，实现"动作层适应"之上的**任务级重组合**。
- **局部库增长改变同一执行器的能力边界**：在不改变权重、运行时与评估预算的前提下，新增 2 个块使成功率从 0/6 提升到 4/6，验证了"本地新增能力、不重写无关行为"的核心主张。
- **范围受控**：超出学习范围的场景会在缺失语义效果处停止，避免错误沿任务链传播。
- **理论主张**：提出 Teach-and-Grow 缩放律假设——随着有效可复用经验 X 增长，未来任务误差与教学需求以幂律趋近各自不可约下限；并推测显式能力新增的累计成本在局部化更新下至多线性增长，而全局耦合更新可能凸增长。
- **总体结论**：机器人应能"就地学局部经验"，部署即学习；目标不是保存所有交互，而是保留那一小部分能把"今天陌生的任务"变成"明天可复用能力"的经验。

## 7. 优点与亮点

- **问题刻画精准**："再训练税"与"局部缺口 → 全局更新"的失配分析清晰，附录 A 对覆盖组合爆炸、精度律、模态/具身税的论证有说服力。
- **架构分工明确**：Agent 只管语义状态转移，执行器负责度量控制，避免把语言规划当作运动权威；提高了可读性与失败可归因性。
- **学习对象设计有创新**：把"可执行能力"本身作为学习对象，技能块是带范围、成功判据与恢复的**契约**，支持后端替换（几何抓取 / VLA / 触觉策略）而不破坏其他技能。
- **经验与技能分离**：技能库（怎么做）与经验记忆（学到了什么）职责清晰，且均为**版本化、人类可读可编辑**的对象，便于人工纠偏与审计。
- **非破坏性成长**：局部改进不触发全局回归，天然支持跨模态、跨具身的增量接入。
- **提出可检验的缩放律框架**：把"经验"量化为 $X$（强调可靠性、覆盖、可检索、可接地、可组合），并给出对照实验设计，为终身机器人学习提供可证伪的研究议程。
- **提出双速（慢教师/快学生）设计**：Agent 负责前沿获取与生成高质量结构化监督，成熟行为蒸馏为快速策略，兼顾探索与实时性。
