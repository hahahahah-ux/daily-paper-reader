## 摘要
我们提出了Riemann-1.0，一个用于具身智能的完全因果自回归世界动作模型。Riemann-1.0在统一的因果自回归序列中联合建模多视角视觉观测、机器人状态和具身特定动作，将机器人动作与世界演化表示为因果状态转移。与现有基于联合生成、视频优先预测或解耦建模范式的WAM不同，Riemann-1.0在单一模型中统一了在线机器人策略执行与以动作为条件的世界模拟，使其既可作为可执行的机器人策略，也可作为多具身视觉世界模拟器。为了跨异构数据源扩展具身经验，我们进一步开发了一种渐进式具身预训练框架，在共享的世界动作建模目标下，统一了从第一人称人类视频、手持夹爪演示以及异构机器人轨迹中的学习。基于超过20万小时的交互数据，Riemann-1.0将大规模具身经验逐步迁移为可执行的机器人操作能力。Riemann-1.0在仿真基准和真实世界操作任务上均达到最先进性能。它在RoboTwin2.0上达到94.3%的成功率，在LIBERO上达到99.0%，在长时程组合基准RoboCasa-365上达到62.6%，较此前最佳方法提升8.4%。在长时程真实世界操作任务中，Riemann-1.0达到85.0%的成功率（SR）和94.4%的进度成功率（PSR），在SR上超过最强开源基线15%。这些结果表明，统一的世界动作建模与渐进式具身预训练相结合，能有效地将大规模具身经验转化为可泛化的机器人操作能力。

## Abstract
We introduce Riemann-1.0, a fully causal autoregressive World Action Model for embodied intelligence. Riemann-1.0 jointly models multi-view visual observations, robot states, and embodiment-specific actions within a unified causal autoregressive sequence, representing robot actions and world evolution as causal state transitions. Unlike existing WAMs based on joint generation, video-first prediction, or decoupled modeling paradigms, Riemann-1.0 unifies online robot policy execution and action-conditioned world simulation within a single model, enabling it to function as both an executable robot policy and a multi-embodiment visual world simulator. To scale embodied experience across heterogeneous data sources, we further develop a progressive embodied pretraining framework that unifies learning from egocentric human videos, handheld-gripper demonstrations, and heterogeneous robot trajectories under a shared World Action Modeling objective. Built upon 200K+ hours of interaction data, Riemann-1.0 progressively transfers large-scale embodied experience into executable robot manipulation capabilities. Riemann-1.0 achieves state-of-the-art performance across both simulation benchmarks and real-world manipulation tasks. It achieves success rates of 94.3% on RoboTwin2.0, 99.0% on LIBERO, and 62.6% on the long-horizon compositional benchmark RoboCasa-365, outperforming the previous best method by 8.4% On long-horizon real-world manipulation tasks, Riemann-1.0 achieves a Success Rate (SR) of 85.0% and a Progress Success Rate (PSR) of 94.4%, exceeding the strongest open-source baseline by 15% in SR. These results demonstrate that unified World Action Modeling together with progressive embodied pretraining effectively transforms large-scale embodied experience into generalizable robot manipulation capabilities.

## 2. 方法论

### 2.1 核心思想：全因果自回归 World Action Model

- 将机器人交互表述为**多视角视觉观测、机器人状态、具身特定动作**的统一因果自回归序列，动作与世界演化均表示为因果状态转移。
- 联合分布按因果顺序因子化：

  $$p(a_{1:T}, z_{1:T} \mid z_0, s_0, c) = \prod_{t=1}^{T} p(a_t \mid z_{<t}, s_{<t}, a_{<t}, c)\, p(z_t \mid z_{<t}, s_{<t}, a_{\le t}, c)$$

  即：**先由历史观测、状态、动作历史预测当前动作，再把动作作为条件预测对应视觉隐变量**，符合真实机器人"先执行动作、后观测视觉后果"的因果过程。
- 机器人状态 $s_t$ **不由模型生成**，而是从环境观测或回放轨迹注入，作为下一步的条件信号。
- **双模式统一**：
  - 策略部署：预测动作后执行，用环境返回的真实观测替换预测隐变量，进入下一自回归步。
  - 世界模拟：把生成的视觉隐变量递归反馈，产生动作条件未来观测。
- 与 GIGA-World-Policy 等不同，Riemann-1.0 在预训练、后训练、部署全过程保持同一全因果动作-视频公式，动力学先验直接由具身动作监督塑造，而非从通用视频生成目标迁移。

### 2.2 架构与关键技术细节

- **输入与条件**：
  - 语言条件为结构化 prompt：`Video recorded from embodiment {embodiment_type}, showing the {num_views} camera views, while performing the task: {task}.`，由 T5 编码并经 cross-attention 注入。
  - 数值 **embodiment ID** 选择具身特定的动作/状态投影与预测头。
  - 多视角观测打包为具身特定画布，经 **Wan VAE** 编码为隐变量，再用 **3D patch embedding** 转成 token。
  - 位置编码使用 **CaPE（坐标感知位置编码）** 与 **TimePE + AdaLN 调制**。
- **具身特定接口**：共享 Transformer 主干，但对每个具身定义规范化动作/状态顺序，按 per-embodiment 统计量归一化，并 padding 到固定维度 $D_a, D_s$；embodiment ID 映射到类别槽位以索引类别特定线性投影与动作预测头。有效性掩码处理变维动作，**不强制异构具身共享物理动作空间**。
- **Token 序列**：`[context latent, clean latent, noisy latent, state, clean action, noisy action]`。clean token 作为 teacher-forced 历史，noisy token 为 flow-matching 去噪目标。动作流比视觉隐变量流时间更密。
- **时序对齐**：每个视觉隐变量对应一小段底层控制步（VAE 时间步长 × 帧采样率）；状态序列比隐变量序列多一个元素（初始状态 + 每次隐变量转移后的状态）。
- **Teacher Forcing 注意力掩码**（图 5）：
  - clean token 仅 attend 当前或更早时间步的 clean token；
  - noisy token attend 之前时间步的 clean token 与同帧内 noisy token，**不看未来 clean token**；
  - 局部生成块内可用双向注意力；padding token（含文本 padding）被掩蔽。
  - 掩码由 frame ID、time ID、clean/noisy flag 三个属性构建。
- **损失函数**：对两个预测头应用 flow matching：
  - 视觉隐变量速度损失：$\mathcal{L}_z = \mathbb{E}\|v^z_\theta(z_\sigma,\sigma,z_{<t},s_{<t},a_{\le t},c)-(\epsilon_z-z)\|_2^2$
  - 动作速度损失：$\mathcal{L}_a = \mathbb{E}\|v^a_\theta(a_\sigma,\sigma,z_{<t},s_{<t},a_{<t},c)-(\epsilon_a-a)\|_2^2$
  - 总目标：$\mathcal{L} = (1-\lambda)\mathcal{L}_z + \lambda \mathcal{L}_a$
- **Loss masking 与噪声注入**：latent mask 排除 padding 帧与 episode 边界无效隐变量；action mask 排除 padding 通道、padding 帧、无效底层动作步，损失仅在有效 channel-step 上归一化。同一有效性信息用于噪声注入，inactive padding 区域在 clean 样本、噪声、noisy 样本、速度目标中均保持为零，避免训练-部署不一致。
- **在线自回归推理**：维护增长式 KV cache。每步从 cache 读取历史，flow 去噪得到动作 chunk，执行 $a_{pf}$ 个底层控制步；环境返回新多视角观测与状态，编码为 $z_t$ 并连同 $s_t$ 追加为 clean context。长时程 rollout 时 cache 维持固定窗口，满后重置并以最近观测为新 context 帧。

### 2.3 统一具身数据基础设施

- **数据规模**：总计 230K+ 小时，其中第一人称人类视频 200K+ 小时、手持夹爪/可穿戴演示 12K+ 小时、异构机器人轨迹 20K+ 小时；覆盖家庭、办公、工业环境与数千种交互技能。
- **三类数据互补**：人类视频提供可扩展交互知识与长时程任务结构；手持夹爪演示桥接人类操作与机器人兼容控制；机器人轨迹提供具身特定可执行控制监督。
- **六阶段数据处理流水线**（图 2）：
  1. 视觉预处理（鱼眼与朝向校正、遮挡处理）；
  2. 分层 VLM 标注与动作分割（任务级/动作级片段、语义标注、任务与动作一致性校验）；
  3. 质量过滤（静态拒绝、多人、手出画、非第一人称、无意义/未完成动作等）；
  4. 3D 手部运动标注（检测、跟踪、MANO 重建、相机位姿估计、时序平滑）；
  5. 几何过滤（手部可见性、手部速度、相机运动与抖动）；
  6. 语义感知数据平衡（场景、任务、动作、相关物体四维分类，按语义维度采样）。
- **UMI/机器人扩展**：末端执行器状态、动作边界校准（利用夹爪状态转换）、机器人专用滤波（相机抖动、静止末端执行器、异常控制、尖锐运动、空闲片段过滤）。
- **统一表示**：所有数据转为 action-level 的 video–state–action 轨迹，含语言指令、具身身份、视觉观测、状态、动作、语义元数据。
- **渐进监督层级**：无标签人类视频 → 冻结 LAM 生成伪动作（弱监督）；3D 手部标注人类视频 + UMI + 异构机器人轨迹 → 真实动作监督；高质量机器人轨迹 → 具身特定动作预测与闭环策略执行。

### 2.4 渐进式具身预训练（三阶段课程）

- 各阶段共用同一动作-视频目标，**动作权重逐步提高** $\lambda: 0.1 \to 0.5 \to 0.9$。
- **Stage I：LAM-Action Bootstrap（λ=0.1）**
  - 仅用无标签人类操作视频。先训练 Latent Action Model（LAM）并冻结为伪动作标注器。
  - LAM 为相邻帧对上的 latent-action VAE：16×16 patch 化，每帧前置可学习 action-prompt token，时空 Transformer 处理两帧序列，未来帧 prompt token 隐状态投影为高斯矩 $(\mu,\log\sigma^2)$，定义 32 维隐动作空间；采样隐动作注入解码器，仅接收当前帧 patch 重建下一帧，迫使瓶颈编码转移信息。
  - 目标：$\mathcal{L}_{\text{LAM}} = \|\hat{x}_{t+1}-x_{t+1}\|_2^2 + \beta D_{KL}(q_\varphi(z_t|x_t,x_{t+1})\|\mathcal{N}(0,I))$，KL 项刻意较弱以避免隐码坍缩为通用先验；标注时使用后验均值 $\mu$ 而非采样值。
  - 冻结 LAM 在视频窗口上密集预测伪转移码，按 WAM 时序接口分组为动作 chunk；同时视频经 Wan VAE 编码为视觉隐变量。此阶段主要初始化视觉动力学主干，不追求可部署策略。
- **Stage II：Trajectory-Grounded Alignment（λ=0.5）**
  - 数据混合 UMI 演示、机器人轨迹、带 3D 手部姿态与关键点标注的人类视频。
  - 动作映射到具身特定规范顺序、per-embodiment 归一化并 padding；动作预测成为核心训练信号，视觉隐变量预测作为动力学正则。目标是把自回归动作-视频接口落地到真实轨迹监督，并跨相机布局、动作空间、机器人本体对齐共享主干。
- **Stage III：Robot-Policy Enhancement（λ=0.9）**
  - 仅用高质量真实动作-状态机器人演示，排除人类视频、LAM

（接上）

  - 伪动作监督与低质量片段，动作权重升至 λ=0.9，视觉隐变量预测退居辅助正则角色，模型重心转向具身特定闭环控制精度。
  - 目标是让共享主干在真实控制信号下收敛为可部署策略，同时借助前两阶段积累的跨具身视觉动力学先验，提升样本效率与泛化性。
  - 为防止灾难性遗忘，保留少量 Stage II 数据或采用低学习率微调，维持跨具身世界模拟能力。

## 3. 实验设计与评估

### 3.1 评估维度

论文从三个互补维度验证模型：

- **策略执行（Policy）**：在真实机器人上评估任务成功率、长时程任务完成度、跨具身/跨场景泛化。
- **世界模拟（World Simulation）**：评估动作条件未来视频生成的视觉保真度、时序一致性、因果一致性（动作变化是否引发对应视觉后果）。
- **具身经验规模化**：考察随预训练数据量、阶段推进，下游策略性能是否呈可预测的规模化趋势。

### 3.2 主要实验设置

- **基线与对照**：与现有 WAM 预训练范式（联合生成、视频优先预测、解耦动作-视频建模）以及纯模仿学习基线对比，控制数据与算力以隔离"全因果公式 + 渐进式预训练"的贡献。
- **消融研究**：
  - 因果因子化顺序（先动作后视觉 vs. 联合）对策略与世界模拟的影响；
  - 三阶段课程 vs. 单阶段混合训练；
  - λ 调度（固定 vs. 渐进）对收敛与最终性能的影响；
  - LAM 伪动作质量、UMI/机器人轨迹比例对 Stage II/III 的作用；
  - 具身特定投影/头 vs. 全共享接口的权衡。
- **数据规模化分析**：以人类视频小时数、机器人轨迹小时数为自变量，绘制下游任务成功率曲线，检验是否出现类似 LLM 的幂律/对数线性关系。

### 3.3 关键发现（论文主张）

- **统一公式有效性**：全因果动作-视频建模在策略学习与世界模拟上同时优于仅优化单一目标的公式，说明动作监督塑造的动力学先验可反哺视觉预测，反之亦然。
- **渐进式课程必要性**：直接从机器人轨迹训练难以利用大规模人类数据；三阶段课程使弱监督人类视频成为有效的动力学预训练信号，显著提升机器人阶段样本效率。
- **跨具身迁移**：共享主干 + 具身特定接口的组合在异构本体间实现知识迁移，未见具身/新场景下泛化优于具身专属模型。
- **世界模拟的因果一致性**：相比视频优先生成模型，Riemann-1.0 生成的动作条件未来观测与真实动作后果更一致，适合作为策略训练与规划的内部模拟器。
- **规模化趋势**：性能随具身经验数据量提升呈现可预测改善，支持"具身经验规模化驱动具身智能进化"的核心假设。

## 4. 贡献与创新点

- **公式层面**：提出全因果自回归 World Action Model，将观测、状态、动作、世界演化纳入统一因果序列，同时支持策略执行与动作条件世界模拟，避免现有 WAM 公式的片面性。
- **训练范式层面**：提出渐进式具身预训练三阶段课程，通过 λ 调度与数据混合，把无标签人类视频、弱监督伪动作、真实机器人轨迹组织成互补监督层级，实现异构具身经验的大规模统一学习。
- **数据基础设施层面**：构建 230K+ 小时、覆盖人类视频/手持夹爪/异构机器人的统一具身数据流水线，含六阶段处理、质量与几何过滤、语义感知平衡与统一 video–state–action 表示。
- **接口设计层面**：具身特定动作/状态投影与预测头 + 共享主干 + embodiment ID 索引，在不强制共享物理动作空间的前提下实现跨具身知识迁移。
- **工程实现层面**：teacher forcing 注意力掩码、loss masking 与噪声注入一致性、增长式 KV cache 在线自回归推理，支撑预训练—后训练—部署全程一致的全因果公式。

## 5. 局限性与潜在问题

- **数据依赖与偏差**：性能高度依赖大规模人类视频质量与 LAM 伪动作保真度；3D 手部标注、几何过滤可能引入选择偏差，长尾技能覆盖不足。
- **计算成本**：200K+ 小时视频的预训练与多阶段课程带来巨大算力需求，复现门槛高。
- **因果因子的近似**：状态由环境注入而非生成，世界模拟中的状态演化依赖外部回放，可能限制纯想象式长时程规划。
- **动作空间异构性**：虽不强制共享物理动作空间，但 padding 与归一化策略对极端异构具身（如高自由度灵巧手 vs. 移动底盘）的适配仍需验证。
- **评估范围**：论文未提供统一跨具身 benchmark，任务成功率与视觉指标可能难以直接与既有工作对比；真实机器人评估规模有限，规模化结论需更长周期验证。
- **安全与部署**：闭环部署中的失效模式、长时程误差累积、cache 窗口重置带来的上下文断裂尚未充分讨论。

## 6. 意义与展望

- **范式意义**：将"具身经验规模化"类比 LLM 的"文本知识规模化"，为 Physical AI 提供可扩展路径；全因果动作-视频公式为统一策略与模拟提供简洁而强表达力的框架。
- **方法意义**：渐进式预训练与具身特定接口的组合，为异构多具身数据学习提供可复用模板。
- **应用前景**：单一模型兼顾可执行策略与动作条件世界模拟器，可支撑机器人数据合成、离线策略评估、长时程规划与仿真到现实迁移。
- **未来方向**：扩大具身经验规模、引入更精细的状态生成与因果推理、发展跨具身统一评估基准、探索在线持续学习与安全约束下的自主进化。

## 7. 总结

Riemann-1.0 围绕"以具身经验规模化推动 Physical AI"这一核心命题，提出全因果自回归 World Action Model 与渐进式具身预训练范式，并通过 230K+ 小时异构交互数据的基础设施与三阶段课程加以验证。其关键主张是：只有在统一因果过程中联合建模观测、状态、动作与世界演化，并以渐进方式把弱监督人类数据与强监督机器人轨迹整合，才能让单一模型同时成为可执行策略与动作条件世界模拟器，并随具身经验增长持续进化。该工作为 World Action Models 提供了一条兼具统一性、可扩展性与工程可行性的路线，其局限与开放问题也为后续研究指明了方向。
