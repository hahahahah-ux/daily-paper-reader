## 摘要
我们提出了 Hydra-0，一个以动作流为条件的通用世界模型，将机器人动作表示为像素运动。这一共享视觉接口通过跨具身、任务、环境和视频生成骨干学习动作后果，从而实现通用世界建模与控制。我们最佳配置相比动作条件基线，将机器人运动误差降低 90.4%，物体运动误差降低 60.2%，同时支持零样本组合和数据高效适配。在 RoboLab 基准上，Hydra-0 在回放成功率与参考成功率之间达到 r=0.96 的皮尔逊相关系数。最后，我们揭示了该接口的一种涌现逆向模式：一个世界动作模型，可根据从人类演示迁移得到的期望物体流预测兼容的机器人运动。训练好的动作头将所得潜在特征映射为可执行动作，而无需任务特定的专家机器人演示。这些结果共同表明，动作流作为连接异构训练数据、开环策略评估和机器人控制的共享控制接口具有潜力。

## Abstract
We introduce Hydra-0, a generalist world model conditioned on action flow, which represents robot actions as pixel motion. This shared visual interface enables generalist world modeling and control by learning action consequences across embodiments, tasks, environments, and video-generation backbones. Our best configuration achieves 90.4% lower robot-motion error and 60.2% lower object-motion error than our action-conditioned baseline, while supporting zero-shot composition and data-efficient adaptation. On the RoboLab benchmark, Hydra-0 achieves a Pearson correlation of r=0.96 between replayed and reference success rates. Finally, we uncover an emergent inverse mode of this interface: a world action model that predicts compatible robot motion from desired object flow transferred from a human demonstration. A trained action head maps the resulting latent features to executable actions without requiring task-specific expert robot demonstrations. Together, these results demonstrate the potential of action flow as a shared control interface connecting heterogeneous training data, open-loop policy evaluation, and robot control.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：现有世界模型与动作条件视频模型大多与训练时的具身（embodiment）强绑定，难以做多具身训练，也难以迁移到新的部署场景。
- **根因分析**：这些模型依赖机器人原生指令——
  - 关节空间指令直接编码了机器人的结构；
  - 相同的末端执行器指令在不同运动学结构上会产生不同的关节轨迹与可见连杆运动；
  - 两类表示都**不指定图像平面上的最终运动**，因此视频模型必须额外学习"指令 → 视觉动力学"这一具身相关的映射。
- **已有线索**：运动/轨迹条件视频生成（ATI、Wan-Move）与流/轨迹接口（Track2Act、Flow as Cross-domain Interface、NovaFlow）表明图像平面运动可作为共享视觉条件，但**如何把共享视觉运动表示落地为跨具身的可执行机器人指令**仍未解决。
- **论文主张**：提出 **action flow（动作流）**——一种图像平面上的稀疏轨迹表示，既描述具身运动，也描述任务意图，从而同时支持**正向动力学预测**与**逆向运动预测**，成为连接异构训练数据、开环策略评估与机器人控制的共享接口。

## 2. 方法论

### 2.1 核心思想：动作流作为共享控制接口

- 设机器人在时刻 $t$ 接收观测 $o_t$ 并执行动作 $a_t$；编码器 $e_\varphi$ 把初始观测映射为空间隐状态 $s_0$；动力学模型预测 $\hat{s}_{1:H} = g_\theta(s_0, \mathcal{F})$；解码器输出 $\hat{o}_{1:H} = d_\psi(\hat{s}_{1:H})$。
- 动作流定义为 $N$ 个被跟踪点在预测视界 $H$ 内的相机平面轨迹：
  $$\mathcal{F} = \{\tau_n\}_{n=1}^N,\quad \tau_n = \{(x_{n,t}, m_{n,t})\}_{t=0}^H,\ x_{n,t}=(u_{n,t}, v_{n,t}),\ m_{n,t}\in\{0,1\}$$
- 因为 $\mathcal{F}$ 表达在观测平面内，同一接口可表示机械臂、夹爪甚至人手，而**无需向视频模型暴露原生动作空间**。

### 2.2 动作流的两条构建路径

- **几何感知构建（部署用）**：在机器人可见表面采样点，经连杆变换传播后投影到相机平面：
  $$x_{n,t} = \pi\!\left(K[I_3\ 0]\,T_{CW}\,T_{\ell(n)}(q_t)\,\bar{X}_n\right)$$
  其中 $q_t$ 由 Isaac Lab 中"控制器 + 物理仿真"执行候选指令得到；$T_{\ell(n)}$ 为连杆变换，$T_{CW}$、$K$ 为相机外参/内参，$\pi$ 为透视投影。
  - 可见性判据 $m_{n,t}=1$：正相机深度、落在图像边界内、且在 3×3 邻域内与渲染深度缓冲的偏差小于容差（附录给出 **1.2 cm**）。
- **仅视频构建（训练用）**：对缺少机器人描述文件或标定的大规模视频数据，先用 **AllTracker** 恢复稠密图像平面轨迹与可见性，再用 grounded masks（SAM 3）把轨迹划分为**具身**与**被操作物体**两类，得到相同的 $\mathcal{F}$ 表示。

### 2.3 训练时的流采样策略

- 四种条件模式，仅在"哪类轨迹填充共享运动张量"上不同，**不引入额外的可学习 token**：
  - **Embodiment**：本体（连杆、夹爪、人手）轨迹，是主要的动作条件策略；
  - **Object**：物体未来轨迹；推理时若显式给定物体轨迹，同一模式即变为"期望运动条件"，可诱发兼容的机器人运动；
  - **All**：具身 + 物体 + 未分配场景轨迹的并集，作为语义 grounding 不完整时的回退；
  - **None**：去掉轨迹条件，等价于条件 dropout。
- 规范 I2V 训练混合概率为 (None, Embodiment, Object, All) = **(0.05, 0.40, 0.40, 0.15)**；Embodiment/Object 采 1–128 条轨迹，All 采 256–1024 条；若某模式所需的轨迹池不可用，则移除该模式并重新归一化。

### 2.4 动作流条件的视频预测

- 把每条图像空间轨迹与时间压缩后的视频隐变量对齐，在归一化 latent 网格坐标下池化位置与可见性为 $\tilde{x}_{n,k}$、$\tilde{m}_{n,k}$。
- 对每条选中轨迹，从初始帧 latent 双线性采样源特征 $h_n = s_0(\tilde{x}_{n,0})$，并沿未来 latent 网格位置以高斯权重传播：
  $$M_k(\tilde{p}) = \sum_{n\in\mathcal{N}_K(\tilde{p},k)} \tilde{w}_{n,k}(\tilde{p})\,h_n,\qquad \tilde{w}_{n,k}(\tilde{p}) = \tilde{m}_{n,0}\tilde{m}_{n,k}\exp\!\left(-\beta\|\tilde{p}-\tilde{x}_{n,k}\|_2^2\right)$$
  其中 $\mathcal{N}_K$ 取原始高斯权重最大的 $K$ 条轨迹（实现中 $K=2$，$\beta=220$，不做 softmax/权重归一化）；同时要求 $\tilde{m}_{n,0}$ 与 $\tilde{m}_{n,k}$ 均有效。
- 存在门控（presence gate）：
  $$g_k(\tilde{p}) = \mathrm{clip}_{[0,1]}\!\left(\sum_{n\in\mathcal{N}_K(\tilde{p},k)} \tilde{w}_{n,k}(\tilde{p})\right)$$
  完整运动条件记为 $C_{\text{motion}} = (M, g)$，作为额外视觉条件与含噪视频 latent $Z_t$ 拼接后送入 DiT patch embedding。
- **学习目标**为标准 flow-matching：
  $$\mathcal{L}(\theta) = \mathbb{E}_{o_{0:H},\mathcal{F},t,\epsilon}\left[\|v_\theta(Z_t, t, c, C_{\text{motion}}) - v_t^\star\|_2^2\right]$$
- **训练策略**：冻结预训练视频骨干权重，仅训练 DiT patch embedding 与注意力 $q,k,v,o$ 投影及两个前馈投影上的 **rank-64 LoRA**。

### 2.5 高效因果 rollout

- **自回归转换**：采用 LongLive-2.0 的因果分块方案，把 latent 序列切成 $\mathcal{C}_1,\dots,\mathcal{C}_J$：
  $$p_\theta(s_{1:H}\mid s_0, C_{\text{motion}}) = \prod_{j=1}^J p_\theta\!\left(s_{\mathcal{C}_j}\mid s_{\mathcal{C}_{<j}}, s_0, C_{\text{motion},\mathcal{C}_j}\right)$$
  生成块替换干净历史并经 **KV cache** 复用；$C_{\text{motion}}$ 一次性在整窗口坐标下计算，按**绝对块偏移**切片，避免轨迹在块边界被重新锚定。
- **少步蒸馏**：以自回归 checkpoint 初始化学生，采用 DMD2，每块 4 步去噪，三个网络均保持因果性。

### 2.6 开环策略评估（正向）与世界动作模型（逆向）

- **正向模式**：输入由机器人指令或已达成轨迹计算出的夹爪流，预测视频结果。因为监督目标是"观测到的后果"而非规定行为，**成功与失败的 rollout 都可提供动力学监督**。开环评估时固定完整记录的夹爪运动条件。
- **逆向模式（世界动作模型）**：只给定期望物体流 $\mathcal{F}_{\text{obj}}$，不提供夹爪流；条件通路同样遵循上式。训练好的动作头读取干净 DiT token 特征，学习具身特定的逆向映射。
  - 动作/状态解码器各自拼接 mean-pooled 与单查询注意力池化的空间 token，经 LayerNorm 与两层 GELU MLP（隐藏宽度 1024），预测时间对齐的机器人动作与状态；状态预测仅作辅助监督，不回灌视频模型。
  - 从预训练因果模型出发，仅后训练 **rank-32 自注意力 LoRA**、运动输入投影与轻量动作/状态头：
    $$\mathcal{L}_{\text{WAM}} = \mathcal{L}_{\text{flow}} + \lambda_h(\mathcal{L}_{\text{act}} + \mathcal{L}_{\text{state}}

$$\mathcal{L}_{\text{WAM}} = \mathcal{L}_{\text{flow}} + \lambda_h(\mathcal{L}_{\text{act}} + \mathcal{L}_{\text{state}})$$
  其中 $\mathcal{L}_{\text{act}}$、$\mathcal{L}_{\text{state}}$ 分别为动作与状态预测损失，$\lambda_h$ 为平衡系数。动作流本身作为**共享视觉条件**贯穿两个方向，使同一模型既能"看动作预测未来视频"（正向），也能"看物体期望运动反推机器人动作"（逆向）。

## 3. 实验设置与评估

### 3.1 数据与具身覆盖

- 训练语料混合了**多种具身**：不同自由度与运动学结构的机械臂、平行夹爪，以及人类手部视频，均统一转写为图像平面动作流 $\mathcal{F}$。
- 对具备机器人描述文件与相机标定的数据，采用**几何感知构建**生成动作流（控制器+物理仿真）；对仅有视频的数据，采用**仅视频构建**（AllTracker + SAM 3 掩码）恢复轨迹。
- 这种双路径设计使模型能同时吸收**高质量机器人数据**与**大规模无标定视频**，缓解具身绑定问题。

### 3.2 评估协议

- **开环策略评估（正向）**：给定完整记录的夹爪运动条件，固定后预测视频 rollout，将预测结果与真实观测对比，作为对策略行为的"世界模型式"评分。
  - 关键点：监督目标是**观测到的后果**，而非规定行为，因此成功与失败 rollout 均提供动力学监督。
- **世界动作模型（逆向）**：仅给定期望物体流 $\mathcal{F}_{\text{obj}}$，由模型反推机器人动作，检验跨具身指令生成能力。
- **视频预测质量**：评估动作流条件视频生成在视觉保真度、运动一致性与长视界稳定性上的表现。

### 3.3 对比与基线

- 与**运动/轨迹条件视频生成**方法（如 ATI、Wan-Move）以及**流/轨迹接口**方法（如 Track2Act、Flow as Cross-domain Interface、NovaFlow）在共享视觉运动表示的可执行性上进行比较。
- 重点考察：共享视觉运动表示能否**落地为跨具身的可执行机器人指令**，而不仅是生成视觉上合理的运动。

---

## 4. 主要结果与发现

### 4.1 共享接口的有效性

- 动作流作为**图像平面上的稀疏轨迹表示**，同时刻画具身运动与任务意图，能够作为连接异构训练数据、开环评估与机器人控制的统一接口。
- 由于 $\mathcal{F}$ 表达在观测平面内，同一接口可表示机械臂、夹爪甚至人手，而**无需向视频模型暴露原生动作空间**，从而实现多具身训练与向新部署场景的迁移。

### 4.2 正向与逆向的双向能力

- **正向**：以具身/夹爪流为条件，模型可预测合理的视觉动力学，用于开环策略评估。
- **逆向**：以物体期望流为条件，动作头可学习具身特定的逆向映射，生成可执行机器人指令，体现世界动作模型特性。
- 两种模式共享同一 $C_{\text{motion}}=(M,g)$ 条件通路，验证了接口的**对称性**与**通用性**。

### 4.3 训练策略的贡献

- **条件采样**（Embodiment/Object/All/None）在不引入额外可学习 token 的前提下，实现了多模式条件与条件 dropout。
- **LoRA 微调**（rank-64 视频骨干、rank-32 逆向注意力）在冻结预训练权重下高效适配。
- **因果分块 + 少步蒸馏**（DMD2，每块 4 步）在保持长视界一致性的同时提升 rollout 效率，并通过**绝对块偏移**切片避免轨迹在块边界被重新锚定。

---

## 5. 贡献总结

1. **提出 action flow（动作流）**：一种图像平面稀疏轨迹表示，同时描述具身运动与任务意图，作为跨具身的共享控制接口。
2. **双路径构建方案**：几何感知构建（部署可用，依赖机器人描述与标定）与仅视频构建（训练可用，适配大规模无标定视频），使表示既能执行又能规模化。
3. **统一正逆双向建模**：同一动作流条件既支持正向动力学预测（开环策略评估），又支持逆向运动预测（世界动作模型），并可复用条件通路与注意力机制。
4. **高效训练与推理**：LoRA 适配、条件采样策略、因果分块 rollout 与少步蒸馏共同构成可扩展的实现路径。

---

## 6. 局限与讨论

- **几何感知构建的依赖**：需要机器人描述文件与相机标定，限制了在无标定真实场景中的直接部署。
- **仅视频构建的噪声**：依赖 AllTracker 与 grounded masks（SAM 3），轨迹与可见性估计的误差会传导至条件表示。
- **可见性判据的阈值敏感性**：如 1.2 cm 深度容差等参数可能影响轨迹质量与条件稳定性。
- **逆向映射的具身特定性**：动作头学习的仍是具身特定逆向映射，跨具身零样本迁移能力仍需进一步验证。
- **长视界一致性**：虽采用因果分块与 KV cache，长 rollout 的误差累积仍是开放问题。

---

## 7. 结论

Hydra-0 通过 **action flow** 将"图像平面运动"确立为连接异构数据、评估与控制的核心接口，绕开了原生动作空间对具身的绑定。其双路径构建、正逆双向条件建模与高效 rollout 策略，为多具身世界模型与可执行跨具身控制提供了一条统一路径。论文的核心洞察在于：**共享视觉运动表示本身即可承载具身运动与任务意图**，从而同时服务于动力学预测与逆向运动生成。
