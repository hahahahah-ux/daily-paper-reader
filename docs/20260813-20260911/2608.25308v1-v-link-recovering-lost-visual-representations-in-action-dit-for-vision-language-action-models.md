## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解和连续动作控制，为通用机器人操作提供了一条可扩展的路径。然而，我们揭示了 VLA 架构的一个关键局限：动作专家对 VLM 特征中可用的 3D 几何和 2D 语义信息的访问有限。这种可访问性差距削弱了感知基础，并限制了细粒度机器人操作的性能。为解决这一问题，我们提出了 V-Link，它在视觉-语言（VL）到动作（A）的特征迁移过程中显式恢复视觉表征。具体而言，V-Link 在 VLM 内学习互补的空间查询和语义查询表征，并通过非对称路径将其注入 Action DiT。语义查询补充原始 VLM 图像 token，而空间查询为具有空间基础的动作生成提供专门的几何条件。在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 上，我们的 V-Link 相比基础模型 GR00T N1.6 将平均成功率分别提升了 +1.9%、+31.2% 和 +18.8%。在 AGIBOT A3 Ultra 上，V-Link 进一步在两个真实世界人形机器人任务上取得了 +20% 和 +24% 的提升。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

- **背景**：VLA（视觉-语言-动作）模型是通向通用机器人操作的重要范式。其中"双系统架构"（dual-system）将负责场景理解与任务推理的 VLM 与负责高频控制的小型动作专家（action expert）解耦，代表工作为 NVIDIA GR00T N1.6，其核心是 **VL→A 特征迁移**。
- **关键问题**：GR00T N1.6 仅将 VLM **最后一层特征**传给动作专家（Action DiT）。论文追问：这种传递是否足以让动作专家获得精细操作所需的 2D 语义与 3D 几何线索？
- **诊断证据**：作者仿照 Spatial Forcing 设计诊断协议——冻结 VLM 与 Action DiT 特征，仅训练约 2.3M 参数的轻量深度估计头与语义分割头，用测试集性能衡量"表征可访问性"：
  - 深度 MAE：VLM 特征 0.015 → Action DiT 特征 **0.071**（恶化）；
  - 分割 mIoU：VLM 特征 0.665 → Action DiT 特征 **0.290**（大幅恶化）。
- **成因假设**：高度纠缠的末层 VLM 特征 + 仅动作监督，使 Action DiT 走"优化捷径"，优先利用能快速降低动作损失的语义线索，而**欠利用结构关键的 3D 空间线索**，导致感知接地不足、陷入局部最优。
- **与已有工作的差异**：Spatial Forcing、EVO-0、SpatialVLA 等主要增强 **VLM 内部**的 3D/空间推理；VLA-Adapter 关注 VLM 与 Action DiT 的**高效连接**；但都未解决"迁移之后动作专家能否真正访问这些感知信息"的问题。本文定位在 **VL-to-A 接口处的表征恢复**。

## 二、方法论

### 核心思想
在 VLM 内部学习两组互补的可学习查询——**Spatial Query（空间查询）** 与 **Semantic Query（语义查询）**，用训练期辅助任务头将其分别特化为几何与语义表征，再通过**非对称路径**注入 Action DiT，使两类感知信息在动作生成时可直接被访问。

### 关键技术细节

1. **VLM 表征解耦**
   - 在 VLM 输入中拼接两组查询 token：E = [E_t; E_o; E_d; E_s]（语言、多视图图像、空间查询、语义查询）。
   - 使用**定制因果注意力掩码 M_q**，让两组查询独立地从图文 token 中聚合信息，同时**不干扰原生多模态计算**（Qwen 末层 RMSNorm 输出 E′_t, E′_o, E′_d, E′_s）。
   - **深度头 Φ_Depth**：LN(2048)→Linear(2048,256)→GELU→Dropout，加每视图 Transformer 编码层与卷积稠密解码器；softplus 保证深度为正：D̂ = σ⁺(Φ_Depth(E′_d))，参数约 2.3M（刻意轻量，迫使信息被查询本身捕获）。
   - **语义头 Φ_Seg**：结构同深度头，输出软最大化分割 logits：Ŷ = Softmax(Φ_Seg(E′_s))。
   - **损失设计**：L_depth = L_sm + 0.1·L_rel + 0.5·L_patch（平滑 L1 全局尺度 + 绝对相对损失强调近场/机械臂区域 + top-k 难块挖掘避免背景梯度稀释）；L_seg = L_CE + 0.5·L_Dice（像素级分类 + 区域重叠，缓解类别不平衡）。
   - **训练稳定性**：先用与联合训练相同的超参预热 VLM LoRA 参数、两组查询与任务头，再做全部可训练组件的联合优化；**推理时辅助头被移除，不需要深度/分割标注**。

2. **Action DiT 中的视觉表征恢复（非对称注入）**
   - 基础模型为 32 层 AlternateVLDiT，注意力为 8 次 4 层循环：ℓ=4k 非图像交叉注意力、4k+1 状态/动作自注意力、**4k+2 图像交叉注意力**、4k+3 状态/动作自注意力；V-Link 仅在 **ℓ = 4k+2** 层注入，保持原交替调度。
   - 状态 s 与噪声动作 x_t 编码为 H⁰；在图像交叉注意力层：
     - 语义路径（并行交叉注意力，补充原图像 token）：N_l = CA_VLM(H_l, E′_o)，S_l = CA_Semantic(H_l, E′_s)；
     - 融合 + 残差 + 可学习门控 g_l：Z_l = H_l + Fuse(N_l, g_l·S_l)；
     - **空间路径（强制几何条件分支）**：H′_l = Z_l + CA_Spatial(Z_l, E′_d)；
     - 经 FFN 得下一层输入 H_{l+1}。
   - 设计意图：语义作为"补充"，几何作为"必需条件"，从结构上抑制语义捷径、强制动作特征显式编码深度感知表征。
   - **总目标**：L = L_act + 0.1·L_depth + 0.002·L_seg。

## 三、实验设计

- **仿真 Benchmark（3 个）**
  - **LIBERO**：Spatial / Object / Goal / Long 四个套件。
  - **LIBERO-Plus**：7 类分布偏移（Camera、Robot、Language、Light、Background、Noise、Layout）；所有模型**仅在标准 LIBERO 上训练，不做微调**直接在 LIBERO-Plus 评测（零样本鲁棒性）。

- **对比方法**
  - LIBERO：2D VLA（OpenVLA、Dita、CoT-VLA、π0-FAST、π0、π0.5、UniVLA、OpenVLA-OFT）与 3D VLA（SpatialVLA、GeoVLA、3D-CAVLA、Spatial Forcing），以及基座 GR00T N1.6。
  - LIBERO-Plus：OpenVLA-OFT、π0、π0-Fast、Evo-Depth、GR00T N1.6。
  - RoboTwin 2.0：π0、Xiaomi Robotics-0、EventVLA、π0.5、GR00T N1.6。
- **评测规模**：LIBERO / LIBERO-Plus 每任务 50 次试验；RoboTwin 2.0 每任务 100 次；真机每任务 50 次连续试验。
- **指标**：成功率（按套件/偏移类别/任务及平均）。
