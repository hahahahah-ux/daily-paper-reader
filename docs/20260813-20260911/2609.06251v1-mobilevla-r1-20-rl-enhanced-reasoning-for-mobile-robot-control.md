## 摘要
将自然语言指令落地为可靠且可执行的动作，仍是移动机器人上视觉-语言-动作（VLA）系统面临的根本性挑战，其原因在于高层语义推理与底层运动及操作控制之间持续存在鸿沟。现有方法往往依赖隐式推理或单体式动作预测，难以在生成精确且可适应的机器人动作的同时，保持连贯的长时程决策。为应对这一挑战，我们提出 MobileVLA-R1 2.0，一个由强化学习增强的 VLA 框架，显式地将结构化具身推理与可执行的移动机器人控制相结合。该框架通过监督式思维链（CoT）对齐和强化学习，在具身轨迹上学习多粒度推理，从而在纯行为监督之外提升推理到动作的一致性。为同时支持运动与操作，我们进一步引入一个推理条件动作解码器，将多模态推理表示映射为任务级动作目标，随后由机器人控制器将其转换为特定于本体的命令。该设计提供了统一的感知-推理-动作接口，同时将高层动作生成与机器人特定的驱动执行解耦。我们在语言引导导航、四足机器人控制和人形移动操作上进行了广泛评估，涵盖 VLN-CE、QUARD 以及在 Unitree Go2 和 G1 机器人上的真实世界部署。MobileVLA-R1 2.0 持续优于强 VLA 基线，在 VLN-CE 上的 SR 平均提升 1.6 个百分点，在真实世界 G1 移动操作任务上，全任务成功率较 MobileVLA-R1 提升 10.0 个百分点，同时在不同机器人平台上展现出鲁棒的长时程指令跟随和闭环执行能力。

## Abstract
Grounding natural-language instructions into reliable and executable actions remains a fundamental challenge for vision-language-action (VLA) systems on mobile robots, due to the persistent gap between high-level semantic reasoning and low-level locomotion and manipulation control. Existing approaches often rely on implicit reasoning or monolithic action prediction, making it difficult to maintain coherent long-horizon decision making while producing precise and adaptable robot actions. To address this challenge, we propose MobileVLA-R1 2.0, an RL-enhanced VLA framework that explicitly couples structured embodied reasoning with executable mobile robot control. The framework learns multi-granularity reasoning over embodied trajectories through supervised Chain-of-Thought (CoT) alignment and reinforcement learning, improving reasoning-to-action consistency beyond purely behavioral supervision. To support both locomotion and manipulation, we further introduce a reasoning-conditioned action decoder that maps multimodal reasoning representations to task-level action targets, which are subsequently translated into embodiment-specific commands by robot controllers. This design provides a unified perception-reasoning-action interface while decoupling high-level action generation from robot-specific actuation. We conduct extensive evaluations on language-guided navigation, quadruped control, and humanoid mobile manipulation, covering VLN-CE, QUARD, and real-world deployments on Unitree Go2 and G1 robots. MobileVLA-R1 2.0 consistently outperforms strong VLA baselines, achieving an average 1.6 point improvement in SR on VLN-CE and a 10.0 point improvement in full-task success on real-world G1 mobile manipulation tasks over MobileVLA-R1, while demonstrating robust long-horizon instruction following and closed-loop execution across different robotic platforms.

  - 显式推理类工作（ECoT、CoT-VLA、ACoT-VLA、密集具身推理）虽引入结构化推理，但**如何把推理表示转成可执行的紧凑动作抽象、并可靠地交给异构机器人控制器**，仍未被充分探索。
  - 移动操作/人形场景（MoManipVLA、GR00T N1）与 RL 增强 VLA（MoRE、ReinboT）分别关注动作生成、本体适配或策略优化，**未解决推理与异构控制的显式对齐**。
- **论文含义**：提出 **MobileVLA-R1 2.0**，采用 **System-2（推理）→ System-1（任务级动作）→ System-0（本体执行）** 的分层范式，在推理与物理执行之间建立**显式、可学习的接口**，使同一策略无需修改即可跨四足与人形平台迁移。

## 2. 方法论

### 2.1 核心思想
- 先做结构化具身推理（CoT），再由**推理条件动作解码器**把内部推理表示映射为**任务级动作**，最后由机器人专用低级控制器实现为具体驱动命令，从而**解耦语义动作生成与本体驱动**。

### 2.2 问题形式化
- 输入多模态观测 $s_t=\{x^{rgb}_t, x^{depth}_t, x^{pc}_t\}$ 与指令 $i$；策略输出结构化序列 $o_t=\texttt{<think>}r_t\texttt{</think><answer>}u_t\texttt{</answer>}$。
- 任务级物理动作：$\bar a_t=[v_t,\omega_t,\alpha_t]$，其中 $v_t=(V_x,V_y)$ 为平面平移速度，$\omega_t$ 为偏航角速度，$\alpha_t\in\mathcal A_{beh}$ 为离散行为原语（交互、姿态、技能切换等）。
- $\texttt{<answer>}$ 文本用于可解析的语言监督与格式感知强化优化；**物理执行由解码器预测驱动**，而非文本解析。

### 2.3 多模态推理骨干
- 基于 LLaVA 式架构，由 **NaVILA** 初始化，LLaMA3-8B 骨干。
- 各模态编码器（RGB / DepthAnything V2 / Point Transformer V3）输出 token $Z^m_t$，经投影层 $P_m$ 映射到统一隐空间后与文本 token 拼接，加入模态类型嵌入，由骨干 $F_\theta$ 上下文化得到 $H^{ctx}_t$。
- 区分观测上下文 $H^{obs}_t$ 与推理隐状态 $H^{rea}_t$。
- 训练时**冻结模态编码器**，只优化投影层、LoRA 参数与动作解码器。

### 2.4 推理条件动作解码器（关键创新）
- 构造联合上下文 $K_t=[H^{obs}_t;H^{rea}_t]$。
- 引入两个可学习动作查询 $q_{loc},q_{beh}$，通过**交叉注意力**分别聚合出 $h^{loc}_t$、$h^{beh}_t$。
- 运动分支经轻量回归头输出 $[\hat v_t,\hat\omega_t]$；行为分支经 Softmax 头输出行为原语分布，推理时取最大概率。
- 相比会议版的**确定性文本解析**，这是可学习的推理→动作映射。

### 2.5 两阶段训练
- **阶段一：监督式 CoT 对齐**
  - 先在 Episode 级与 Nav 级数据上微调，建立长时程推理对齐（自回归损失 $L_{CoT}$）。
  - 再在 Step 级数据上联合优化解码器：运动用 L1 损失 $L_{loc}=\|\hat v_t-v^*_t\|_1+\lambda_\omega|\hat\omega_t-\omega^*_t|$，行为用交叉熵 $L_{beh}$；总损失 $L_{SFT}=L_{CoT}+\lambda_{loc}m_{loc}L_{loc}+\lambda_{beh}m_{beh}L_{beh}$（$m$ 为有效性指示符）。
- **阶段二：GRPO 强化优化（离线）**
  - 对同一输入采样 $N=8$ 个候选输出，经**固定**解码器得到任务级动作，计算三类奖励：
    - 运动奖励：归一化命令空间下的余弦相似度 $R_{mov}$；
    - 行为奖励：精确匹配 $R_{beh}=\mathbb I[\hat\alpha_t=\alpha^*_t]$；
    - 格式奖励：$R_{fmt}=\mathbb I[o\in\mathcal F]$（符合 `<think>/<answer>` 结构）。
  - 复合奖励 $r_{t,j}=\lambda_{mov}R_{mov}+\lambda_{beh}R_{beh}+\lambda_{fmt}R_{fmt}$，组内归一化得到优势 $\hat A_{t,j}$。
  - 采用带裁剪与 KL 正则的 GRPO 目标 $J_{GRPO}$（$\pi_{ref}$ 为冻结参考策略，$\epsilon_c$ 为裁剪阈值，$\beta$ 控制 KL 强度）。
  - **关键设计**：GRPO 阶段解码器不接收梯度，作为固定的推理→动作接口用于奖励评估。

### 2.6 数据集构建
- 源数据：R2R（50K）、RxR（58K）、QUARD（262K），**全部来自官方训练划分**。
- 构建 **MobileVLA-CoT**：Episode 级 18K、Step 级 78K、Nav 级 38K，共 **134K** 条推理标注。
- 由 **Gemini-2.5-Flash** 驱动的模型无关 CoT 数据引擎生成，经四阶段半自动质检（格式校验→动作校验→安全与相关性过滤→人工核查），从 168K 原始生成筛至 134K。

## 6. 主要结论与发现

- **导航**：R2R-CE 上 SR 69.8 / SPL 66.9，较 MobileVLA-R1 提升 1.5/1.7 点，NE 由 4.05 降至 3.86；较最强先前方法 CorrectNav 高 4.7 点 SR。RxR-CE 上 SR 73.1、SPL 68.5、nDTW 77.6，较前代提升 1.6/1.7/1.5 点。VLN-CE 平均 SR 提升 **1.6 点**。
- **四足控制**：QUARD 平均成功率 0.70→0.76，全面领先所有 6 个任务；越难的任务（Go-avoid、Go-through、Crawl、Unload）增益越明显（+0.06~+0.12），说明显式推理条件化在复杂行为选择时更有效。
- **Go2 真机**：Simple 任务已接近饱和，Complex 任务增益明显（Workspace SR 0.91→0.94，Corridor 0.86→0.91，NE 分别降至 1.12/1.11）。
- **G1 人形移动操作**：全任务平均成功率 46.7%→**56.7%（+10.0 点）**；条件操作成功率 Tabletop 71.9%→79.4%，Shelf/Cabinet 65.5%→74.2%，Cluttered 53.8%→64.3%。**关键发现：训练完全未使用任何 G1 专用轨迹、演示、标注或微调**，说明任务级推理-动作接口可零微调迁移到人形平台。
- **消融结论**：
  - 可学习解码器 > 确定性解析；联合使用观测与推理表示最佳（SR 68.3→69.8）。
  - 解码器与 GRPO 互补，GRPO 单独增益更大。
  - 多粒度推理监督优于任何单一粒度（No-CoT 64.0 → 多粒度 68.3）。
  - 三奖励全开最佳；GRPO 优于 PPO（+4.2 SR）；模型生成 rationale 优于模板（Gemini-CoT 最佳）。
  - Dual-Query Dual-Head 解码器架构最优。
- **效率**：混合部署下端到端时延 205–245 ms（约 4.1–4.9 Hz 高层决策率），低级控制器独立以更高频率运行。
- **失败模式**：Go2 上 160 episode 中 10 次失败，主因目标定位、感知/避障、过度转向、窄通道与定位漂移；G1 上 120 episode 中失败 52 次，抓取（16）与操作执行（14）最多，其次导航定位（10）、目标定位（8）、低级控制（4），Cluttered 场景失败最多。

## 7. 优点

- **方法层面**：
  - 提出清晰的 **System-2→1→0** 分层范式，把"推理→动作"做成**显式可学习接口**，而非文本解析的隐式转换，理念清晰且工程可落地。
  - **本体解耦设计**：策略只预测任务级语义动作 $(V_x,V_y,\omega,\alpha)$，低级控制器负责"如何执行"，使同一策略无需改动即可部署到四足与人形，显著提升可迁移性。
  - **GRPO 与解码器的分工设计精巧**：解码器在 RL 阶段冻结并作为奖励评估的固定接口，避免奖励黑客同时保持表示稳定。
  - 奖励设计多元且互补（连续运动的余弦相似度 + 离散行为的精确匹配 + 格式约束），兼顾物理正确性与结构化输出约束。
- **数据层面**：
  - 构建 134K 多粒度（episode/nav/step）CoT 数据集，配四阶段半自动质检与明确的数据划分完整性论证，可复现性与规范性较好。
  - 数据引擎模型无关，可替换后端。
- **实验层面**：
  - 从仿真到两种真实机器人、从导航到移动操作，验证链路完整。
  - 消融体系完整、控制变量严格，且提供效率与失败诊断（时延、失败归因），超出多数同类工作。
  - G1 零微调迁移是较有说服力的泛化证据。
