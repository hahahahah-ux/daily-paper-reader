## 摘要
视觉-语言-动作模型（VLA）通过使机器人能够理解视觉观测和自然语言指令并生成可执行动作序列，推动了通用机器人抓取与操作的发展。然而，现有 VLA 往往隐含地假设夹爪不变性，尽管抓取策略本质上依赖于具身形态。不同夹爪类型（如平行夹爪和吸盘）通常需要不同的交互策略来实现相同的抓取目标。此外，当前用于 VLA 的数据集主要依赖平行夹爪，限制了夹爪感知学习。为弥补这一空白，我们提出 MiGA，一个多夹爪感知数据集，涵盖多种机器人上的五类不同夹爪，包含 103,000 次演示，明确捕捉共享任务目标下的策略差异。我们进一步提出 GVLA，它将新的多夹爪分词器与基于适配器的策略路由相结合。我们新的夹爪编码产生结构化的嵌入信息，在参数共享与策略差异化之间取得平衡，而逐层探测证实了 VLA 中具有意义的夹爪条件表示。在仿真和真实机器人中的大量实验表明，我们的 GVLA 在所评估设置中优于当前基线。我们的方法还提升了对新物体或未见任务的零样本泛化或少样本适应，并支持更高效的夹爪适应。

## Abstract
Vision language action models (VLAs) have advanced general purpose robotic grasping and manipulation by enabling robots to interpret visual observations and natural language instructions to generate executable action sequences. However, existing VLAs often implicitly assume gripper invariance, despite grasping strategies being inherently embodiment-dependent. Different gripper types, such as parallel-jaw and suction, usually require distinct interaction strategies to achieve the same grasping objective. Moreover, current datasets for VLAs predominantly rely on parallel-jaw grippers, limiting gripper-aware learning. To address this gap, we introduce MiGA, a multi-gripper-aware dataset spanning five distinct gripper types across multiple robots with 103,000 demonstrations, explicitly capturing strategy divergence under shared task objectives. We further propose GVLA, which combines a new multi-gripper tokenizer with adapter-based policy routing. Our new gripper encoding induces structured embedding information that balances parameter sharing and strategy differentiation, while layer-wise probing confirms meaningful gripper-conditioned representations for VLAs. Intensive experiments in both simulation and real-world robots show that our GVLA outperforms the current baselines across evaluated settings. Our method also improves zero-shot generalization or few-shot adaptation to new objects or unseen tasks, and enable more efficient gripper adaptation.

- **背景**：视觉-语言-动作模型（VLA）已推动通用机器人抓取与操作，能根据视觉观测与自然语言指令生成可执行动作序列。
- **核心矛盾**：现有 VLA 隐含假设「夹爪不变性」（gripper invariance），但抓取策略本质上是**具身依赖**的——不同夹爪（平行夹爪、吸盘、三指、灵巧手、软体）在接触力学、力传递、可控自由度上差异显著，实现同一任务目标往往需要完全不同的策略。
  - 典型案例：抓取薄平物体（DVD / 面朝下的盒子），平行夹爪需先推到桌沿再从侧面夹取；吸盘则可直接从上方吸附提起。
- **数据瓶颈**：现有大规模机器人数据集（Open X-Embodiment、Bridge V2、DROID、RT-1 等）几乎只用平行夹爪，且不显式编码「同一任务下的策略分歧」，导致 VLA 无法学到夹爪感知策略。
- **现有夹爪表示不足**：图/几何距离场、扩散合成、接触中心表示等多聚焦「形态相近夹爪间的抓取位姿迁移」，而非鲁棒夹爪分词；论文可视化显示 MLP 嵌入、VQ-VAE 分词、语言提示三种方案均无法形成按夹爪类型聚类的结构化表示（语言提示甚至近乎完全塌缩）。
- **中心问题**：「VLA 能否学习多夹爪的具身依赖性与策略级差异，以完成多样的真实世界任务？」

## 2. 方法论

### 2.1 总体框架
论文提出两部分贡献：**MiGA 数据集**（多夹爪感知）与 **GVLA 模型**（夹爪感知的 VLA 微调框架，可嵌入现有 VLA 骨干，实践中选 π0.5 / π0 作为骨干）。

### 2.2 多夹爪分词器（Multi-gripper Tokenizer）
- 用**软提示（soft prompt）**替代固定文本提示或 MLP 编码器，即随机初始化、端到端梯度优化的可学习嵌入，学习从夹爪硬件配置到连续提示空间的隐映射 Φ: H → R^{p×d}。
- **三级粒度分解**：
  - 平台级 token P^(r)：按机器人平台 r 索引，捕捉平台运动学结构与构型；
  - 夹爪类型级 token P^(g)：按末端执行器类别 g 索引，编码同类夹爪共享的机构先验；
  - 实例级 token P^(u)：按具体夹爪实例 u 索引，建模个体细粒度特性。
- **拼接与条件化**：按固定三级顺序拼接 P^(h) = [P^(r); P^(g); P^(u)] ∈ R^{(p_r+p_g+p_u)×d}，再前置拼接到观测嵌入 X 上，形成 X̃ = [P^(h); X]。
- 该分解在三个层级上分别共享知识，便于向新夹爪实例高效迁移。

### 2.3 双重 Mixture-of-Adapters（Dual MoA）
- 动机：仅靠高层提示不足以调控动作生成，需在执行层调制。
- **门控函数**：G(P) = Softmax(TopK(MLP(mean(P))))，对池化后的条件 token 计算归一化权重与专家索引。
- **双路由器**：
  - 平台感知门 G^(p)，由 mean(P^(r)) 驱动；
  - 夹爪感知门 G^(g)，由 mean([P^(g); P^(u)]) 驱动。
- **专家结构**（瓶颈变换）：A = W_up(GeLU(W_down(x)))，其中 W_down ∈ R^{d×d_b}、W_up ∈ R^{d_b×d}，d_b ≪ d。
- **输出融合**（加法残差）：x ← x + Σ_{i=1}^{k} G_i^(p)·A_i^(p) + Σ_{j=1}^{k} G_j^(g)·A_j^(g)。
- **插入位置**：通过逐层「类型敏感度」分析 S_type（同类夹爪实例隐藏表示的类均值两两 L2 距离）发现：早期层敏感度低、最后一层急剧升高，故将 MoA 插入**最后一层**以直接调制动作生成。

### 2.4 微调目标
总损失 L = L_action + λ_gripper·L_gripper + λ_LB·L_LB，包含三项：
- **动作损失**：条件流匹配损失 L_action = E‖v_θ(A_t^τ, O_t) − u(A_t^τ|A_t)‖²，学习将噪声动作 A_t^τ = τA_t + (1−τ)ε 输运回干净动作，ε ~ N(0, I)，τ ∈ [0,1]。
- **夹爪预测损失**：对池化视觉表示加线性分类器做夹爪类别分类（交叉熵），把夹爪相关信息注入共享嵌入，稳定下游路由。
- **负载均衡损失**：对各专家池的适配器使用分布方差取惩罚（平台池与夹爪池分别计算），防止路由器塌缩与适配器利用不均。

## 6. 主要结论与发现

- **主结果**：GVLA（π0.5 骨干）平均成功率 **66.00%**，较 π0.5 基线（58.38%）提升 **7.62%**，超过所有对比方法；π0 骨干上 GVLA 也从 38.13% 提升到 48.13%。
- **传统两阶段方法失效**：AnyGrasp、GraspMAS 在 Flat/Stacked 场景近乎完全失败（0%），暴露其泛化局限；GraspVLA 同样退化，说明单纯大规模预训练无法替代夹爪多样化的数据设计。
- **表示结构化有效**：本文多夹爪分词在嵌入空间中按夹爪类型良好聚类（同类型相似度约 0.7，跨类型约 0.1–0.4），而 MLP / VQ-VAE / 语言提示无法形成语义结构。
- **显式条件化优于隐式视觉推断**：Noise 与 Padding token 基线的线性探测准确率始终偏低，而 GVLA 从 L0 的 59% 升至 L12 的 80%，说明夹爪判别信号可在网络中持续传播。
- **预测精度与行为专门化可兼得**：GVLA 达到最低 PE（0.032）与最高 CAPD（1.34）及最高 GCS（0.249）。
- **消融结论**：夹爪类型 token P^(g) 对预测与适应均重要；平台 token P^(p) 对跨具身迁移至关重要（去掉后适应率骤降至 0.54）；实例 token P^(u) 主要提供细粒度特化；去掉双 MoA 后 PE 回到基线且适应率大幅下降（0.52），证明「表示层提示」离不开「计算层调制」；MoA^(g) 与 MoA^(p) 作用互补。
- **泛化与适应**：跨物体零样本保持较高成功率；同夹爪新任务适应更快（共享适配器与知识表示）；混合夹爪数据联合训练可进一步降低夹爪间歧义、提升性能。
- **真机结果**：在 UR5 + Robotiq 2F-85 上，仅 10 条演示 + 20K 步微调，GVLA 在四类任务上（0.70/0.85/0.75/0.90）全面优于 π0.5（0.40/0.50/0.70/0.70）。
- **失败模式**：类型内错位（策略对但接触对齐不精确）、夹爪物理限制、运动学失败（进入不可行构型无法恢复）。
