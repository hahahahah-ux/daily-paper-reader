## 摘要
我们研究人形机器人在杂乱室内环境中的导航问题。与传统将导航建模为二维路径规划问题的方法不同，人形机器人在杂乱环境中的穿行需要持续的、几何感知的全身适应，包括协调的手臂摆放、躯干调整和步态调节，以在复杂三维空间中实现无碰撞运动。我们提出 TANGO，这是首个用于杂乱环境中语言条件人形机器人穿行的全身视觉-语言导航框架。给定自然语言指令和第一人称视角 RGB 观测，TANGO 直接预测 29 自由度关节空间动作，用于下游全身控制。我们完全在仿真中训练 TANGO，通过全局路径规划、运动学全身运动生成、障碍物感知的运动编辑以及基于强化学习（RL）的跟踪来合成多样化的无碰撞穿行行为。该流程为学习语言条件的全身策略提供了动态可行的动作监督。在大量仿真实验中，TANGO 在视觉-语言导航中展现出最先进的性能，同时在需要应对障碍物的挑战性场景导航中优于强模块化基线。最后，我们将 TANGO 零样本部署到 Unitree G1 人形机器人上，并在未使用任何真实世界导航数据训练的情况下，观察到其在杂乱真实场景中稳健的语言引导穿行。

## Abstract
We study the problem of navigating cluttered indoor environments with a humanoid robot. Unlike conventional methods that model navigation as a 2D path planning problem, humanoid traversal in cluttered environments requires continuous geometry-aware whole-body adaptation, including coordinated arm placement, torso adjustment, and gait modulation for collision-free movement through complex 3D spaces. We introduce TANGO, the first whole-body vision-language navigation framework for language-conditioned humanoid traversal in cluttered environments. Given a natural-language instruction and egocentric RGB observations, TANGO directly predicts 29-DoF joint-space actions for downstream whole-body control. We train TANGO entirely in simulation by synthesizing diverse collision-free traversal behaviors via global path planning, kinematic whole-body motion generation, obstacle-aware motion editing, and RL-based tracking. This pipeline provides dynamically feasible action supervision for learning language-conditioned whole-body policies. In extensive simulation experiments, TANGO demonstrates state-of-the-art performance in vision-language navigation, while outperforming strong modular baselines in navigating challenging scenes requiring obstacle negotiation. Lastly, we deploy TANGO zero-shot on a Unitree G1 humanoid robot, and observe robust language-guided traversal in cluttered real-world scenes without training on any real-world navigation data.

## 2. 方法论：核心思想与关键技术

- **核心思想**：将导航从 2D 路径规划提升为 29 自由度全身动作生成。给定自然语言指令、第一视角 RGB 观测和本体感知，直接预测未来一段全身动作 chunk，并流式交给低层运动跟踪器执行。
- **问题形式化**：
  - 输入：语言指令 \(\ell\)，观测 \(o_t\) 包含前视/下视 RGB 序列和全身关节状态 \(q_t\)。
  - 输出：动作 chunk \(A_t=\{a_1,\dots,a_H\}\)，其中 \(a_i=\{q_{d,i}, r_{b,i}\}\)，\(q_{d,i}\in\mathbb{R}^{29}\) 为期望关节角，\(r_{b,i}\in\mathbb{R}^{6}\) 为基座 6D 旋转。
  - 训练时使用稳定化目标：在基座表示中加入相对 chunk 首帧的 yaw，以及辅助平面位移/朝向变化 \((\Delta x_i,\Delta y_i,\Delta\psi_i)\)。
- **三系统架构**：
  - **System-2 视觉-语言骨干**：Qwen2.5VL-7B，使用 InternVLA-N1 权重热启动；前后/下视图像垂直拼接；使用 BATS 预算感知 token 采样处理长历史，概率 \(P(t)=(1-\epsilon)e^{k(t-T)/T}+\epsilon\)；GridPool 对近期帧分配更细网格、历史帧更粗网格。
  - **System-1 动作专家**：基于 flow-matching 的 MM-DiT，生成未来动作 chunk；采用训练时 RTC，随机给定已提交动作前缀并补全剩余 horizon，以对齐离线训练与在线流式执行。
  - **System-0 低层跟踪器**：使用 SONIC 运动跟踪器，将预测动作 chunk 转为高频全身控制信号。
- **训练目标**：联合优化交叉熵损失与 flow-matching 损失，\(\mathcal{L}=\mathcal{L}_{CE}+w_{FM}\mathcal{L}_{FM}\)，其中 \(w_{FM}=20\)。
- **数据生成：Plan–Edit–Track（PET）流程**：
  - **Plan**：在增强场景中用 A* 规划碰撞感知路径，代价中加入障碍距离惩罚 \(c(x)=c_{step}+\lambda\exp(-\Phi_{2D}(x)/d_0)\)；检测窄通道并插入 90° 朝向调整，诱导侧身行走；再由 SONIC 生成自然行走参考。
  - **Edit**：通过 3D SDF、势场软力、SoftMimic 风格伪力编辑全身动作；对地面障碍进行步态适应和落脚点重定向，对头顶障碍进行下蹲/躯干降低，对侧向障碍进行侧身避让。
  - **Track**：用 SONIC 跟踪器验证动态可行性与无碰撞性，丢弃失败/碰撞轨迹；但训练监督采用编辑后的无碰撞参考运动，而非跟踪后的轨迹，以保留类人运动结构。
- **环境增强**：在 VLNVerse 和 SAGE-3D 中插入三类障碍：跨步低障碍、侧向窄通道障碍、头顶下蹲障碍；比例约为 44%、15%、41%。
