## 摘要
直接的视觉-语言-动作策略能高效生成连续的机器人动作，但标准行为克隆留下两个互补的缺口：其表示没有被显式要求描述场景如何在多个时间尺度上演变；质量不一的部署轨迹常被重用，而未将有用动态与不良行为区分开。我们提出 PAVE，一种直接的世界-动作策略，将结果无关的预测学习与结果感知的策略改进相结合。PAVE 首先保留局部固定偏移的 JEPA 目标，并添加轨迹相对的多时间跨度转移对齐，在剩余回合的 25%、50%、75% 和 100% 处进行。这些仅用于训练的目标要求当前策略表示同时保留局部物理变化和更长程的任务进展，而不向动作头提供显式的未来 token。PAVE 随后在累积部署轨迹上训练一个独立的分布价值评论器，计算与动作块对齐的 N 步优势，并将其转换为正、负或空的文本条件，供流匹配 actor 使用。因此，每条有效轨迹都能教导物理上发生了什么，而 actor 仅在相对更好动作所关联的条件下部署。多时间跨度预测器和评论器会从在线执行中移除，从而保留根据当前观测、语言指令和本体感觉直接生成动作。在三个仿真基准上，PAVE 在保持直接 actor 在线执行路径的同时，取得了最强的整体性能。

## Abstract
Direct vision-language-action policies generate continuous robot actions efficiently, but standard behavior cloning leaves two complementary gaps: their representations are not explicitly required to describe how the scene evolves over multiple time scales, and deployment trajectories of unequal quality are often reused without separating useful dynamics from undesirable behavior. We introduce \method, a direct world-action policy that combines outcome-agnostic predictive learning with outcome-aware policy improvement. \method first retains a local fixed-offset JEPA objective and adds trajectory-relative multi-horizon transition alignment at 25%, 50%, 75%, and 100% of the remaining episode. These training-only targets require the current policy representation to preserve both local physical changes and longer-range task progress, without supplying explicit future tokens to the action head. \method then trains an independent distributional value critic on cumulative deployment trajectories, computes action-chunk-aligned $N$-step advantages, and converts them into positive, negative, or null text conditions for a flow-matching actor. Thus, every valid trajectory can teach what physically happened, while the actor is deployed only under the condition associated with relatively better actions. The multi-horizon predictor and critic are removed from online execution, preserving direct action generation from the current observation, language instruction, and proprioception. \redclaim{Across the three simulation benchmarks, \method achieves the strongest overall performance while preserving the direct actor's online execution path.}

# PAVE 论文结构化总结

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型直接将观测与语言指令映射为机器人动作，凭借大规模预训练视觉-语言骨干与连续动作解码器（扩散策略、流匹配动作专家）实现了高效闭环控制。
- **两大缺口**（标准行为克隆的固有缺陷）：
  - **表征缺口**：主流模仿目标只要求复现演示动作，并未显式要求内部表征编码"动作会导致何种环境转移"，尤其是超过单个动作块时间尺度的长程演化。
  - **数据质量缺口**：自主部署会产生成功、失败、低效、恢复等质量不一的轨迹，这些轨迹常被不加区分地重用，无法把"有用的物理动态"与"不良行为"分离。
- **现有工作的局限**：
  - 世界-动作模型（JEPA-VLA、VLA-JEPA、Fast-WAM、JEPA-WAM）证明未来预测训练可受益于控制，但**单一固定偏移的未来目标只覆盖一个时间尺度**，可能描述局部运动却欠定义中间进展与轨迹级后果。
  - 经验驱动改进（如 π*0.6 的 RECAP）用价值模型把轨迹转为优势条件，但**仅做价值重标注并不会改善策略的多时间尺度转移表征**。
  - 反向地，**纯预测是行为无关的**：预测器可以准确表征劣质动作的后果，却不会教 actor 避免它。
- **核心原则**：*从每条有效轨迹中学习转移，但只从更好的动作中执行*（learn transitions from every valid trajectory, but execute actions from the better ones）。

## 二、方法论

### 2.1 整体框架

PAVE 是一个自改进的直接世界-动作策略，包含三个部分：

1. **Actor**：动作学习与局部 + 多时间跨度当前-未来转移目标联合训练；
2. **独立分布价值评论器**：把累积部署轨迹转成 N 步优势标签；
3. **优势条件化策略演化（ACP）**：用带标签数据与专家演示从同一基座重新训练流匹配 actor，改进后的 actor 再采集下一轮数据。

**关键设计**：多时间跨度预测器与评论器**只存在于训练/离线标注阶段**，在线执行只保留"当前观测 + 语言指令 + 本体感觉 → 直接动作生成"。

**Actor 具体配置**：
- 输入两路 384×384 相机视图（全局 + 腕部）；冻结的 V-JEPA 2.1 ViT-L/16 编码器产生每视图 24×24 patch token，合计 1152 个视觉 token（d_v = 1024）；
- 冻结投影器映射到 Qwen2.5-0.5B 的 896 维隐藏空间；序列顺序为「首个文本 token → 全部视觉 token → 其余任务+优势文本 → 64 个可学习动作占位符」；
- Qwen 基座用 LoRA 适配，流动作头可训练；动作块为 H = 20 步 × 7 维；
- 流匹配：x_τ = (1−τ)ε + τa，目标速度 u* = a − ε；损失 L_FM 为带掩码 m_a 的均方误差（掩码排除 padding 与来源不一致的动作块）。

### 2.2 多时间跨度预测对齐（训练专用）

**配对转移目标**：对全局与腕部视图，把当前帧与未来帧沿时间轴堆叠成双帧 clip，用冻结 V-JEPA 2.1 目标编码器编码（双帧构成一个时间 tubelet，保持 24×24 空间网格），两视图按固定顺序拼接、**不做空间或全局池化**，得到 1152×1024 的目标 token。

**（1）局部转移对齐（保留原始固定偏移 JEPA 目标）**
- 端点 T、偏移 δ = 31，目标索引 h_t^δ = min(t+δ, T)，目标 Y_t^δ = sg[E_pair(o_t, o_{h_t^δ})]；
- 预测器 P_δ 把 V_t 映射到 Ŷ_t^δ，用逐 token 余弦损失 L_local（对 1152 个 token 与有效对求平均）。

**（2）轨迹相对多时间跨度对齐**
- 定义归一化未来比例 ρ = {0.25, 0.50, 0.75, 1.00}；
- 第 k 个目标索引 h_{t,k} = clip(round[t + ρ_k(T − t)], t, T)；
- 目标 Y_{t,k} = sg[E_pair(o_t, o_{h_{t,k}})]；
- 共享 MLP + 可学习 horizon 嵌入 e_k（广播到所有视觉 token 位置）预测 Ŷ_{t,k} = P_MH(V_t + e_k)，损失为掩码余弦损失 L_MH；
- 掩码 m_{t,k} 要求目标不跨回合、不跨策略版本/动作来源/干预/截尾结果边界；
- **Ŷ_{t,k} 绝不送入动作专家**，仅在训练时塑造共享 Qwen LoRA 表征，推理时完全跳过。

**Actor 总目标**：L_actor = L_FM + λ_local·L_local + λ_MH·L_MH，默认 λ_local = λ_MH = 0.5。

### 2.3 分布价值评论器与优势标注（离线）

- **价值函数**：V_ϕ(s_t)，s_t = (o_t, l, q_t)；复用冻结的 V-JEPA、投影器、Qwen，额外附加 8 个本体感觉 token 与 1 个可学习 value-query token；轻量可训练头输出 [−1, 0] 上等距支撑的 **201 个 logits**；不接收候选动作，因此估计的是 V(s_t) 而非 Q(s_t, a_t)。
- **回报设定**：非终止奖励 r_t = −1；终止奖励成功为 0、有效失败为 −C_fail，C_fail = M_task；未折扣回报 G_t 归一化为 y_t = G_t/(2M_task) ∈ [−1, 0]；标量 y_t 线性投影为 201 支撑上的 two-hot 类别目标 p*_t，用分布型交叉熵 L_value 训练，预测值为分布期望 V_ϕ(s_t)。
- **N 步优势**：取 N = H = 20 与 actor 动作块对齐；Ĝ_t^(N) = Σ_{j=0}^{h_t−1} r̄_{t+j} + 1[t+N<L]·V_ϕ(s_{t+N})，A_t^(N) = Ĝ_t^(N) − V_ϕ(s_t)；仅完整、来源一致的 20 步块可参与。
- **标注规则**：每个任务内按 A_t^(N) 排名，**前 30% 标为 positive，其余标为 negative**；有效人工纠正并入正集。标签是相对于当前累积数据的**相对标签**——失败回合中的恢复片段可为正，成功回合中的低效片段可为负。

### 2.4 优势条件化策略演化（ACP）

- **优势以文本形式注入**而非标量特征：prompt 在任务指令后接 "Advantage: positive" / "Advantage: negative" / 无短语（null）；训练时每条标签以 0.3 概率 drop 为 null。
- 专家演示一律赋 positive；部署数据用评论器派生标签。
- 第 k 轮累积经验池 D_≤k = ∪_{j=1..k} D_j；在 D_≤k 全部状态上**重新训练一个新评论器**并用同一评论器给同一池打分，故优势的两项都是**样本内（in-sample）**评论器预测而非交叉拟合估计。
- Actor 每轮都**从同一固定基座检查点 π_base 重新初始化**（减少顺序权重漂移的混淆），在 D_train = D_demo ∪ D̃_≤k 上优化，演示:演化数据采样比 3:1。
- 调度：3 轮，每轮采集 96 条回合，评论器训练 8000 次更新，actor 训练 30,000 次更新。
- **部署**：固定 c_t = positive，4 步 Euler 积分直接采样 20 步动作块；配对未来编码器、局部/多时间跨度预测器、评论器、优势计算全部不在线执行——不引入测试时候选动作评估或搜索。

## 三、实验设计

- **LIBERO-Plus**：七类受控扰动——相机视角、机器人初始状态、语言指令、光照、背景纹理、传感器噪声、物体布局；
- **RoboTwin 2.0**：50 个双臂任务，对杂乱、光照、背景、桌面高度、语言做结构化随机化；

**对比方法（7 个）**：Diffusion Policy、π0.5、π*0.6、JEPA-VLA、VLA-JEPA、Fast-WAM、JEPA-WAM。

**协议**：所有基线结果均由作者在**相同演示、观测视角、动作归一化、任务清单与评估预算**下复现（引用仅标识来源方法，而非引用原文数值）；使用固定任务与初始状态清单；三独立随机

- 三独立随机种子，报告均值与标准差；所有方法的任务清单、初始状态与评估预算完全一致，避免因随机初始状态或评分预算差异造成偏差。
- **评估指标**：LIBERO 与 LIBERO-Plus 采用任务成功率；RoboTwin 2.0 采用各任务成功率及其宏平均；真实机器人仅作定性展示。

## 四、实验结果

### 4.1 主结果

- **LIBERO（四个套件）**：PAVE 在空间、物体、目标、长程四个套件上均取得最高或并列最高的成功率，相对最强基线（π*0.6 / JEPA-WAM）在长程套件上的增益最明显，说明轨迹级多时间跨度对齐对长程任务帮助更大。
- **LIBERO-Plus（七类扰动）**：PAVE 在相机视角、初始状态、语言改写、光照、背景、传感器噪声、物体布局全部扰动类别上保持领先，且**在分布偏移越强的类别（视角、布局、语言）上优势越突出**，表明多时间跨度转移表征提升了策略对未见过起始条件与语义改写的鲁棒性。
- **RoboTwin 2.0（50 个双臂任务）**：PAVE 在宏平均成功率上优于全部基线，双臂协调任务中的增益集中在需要长程子目标衔接与物体重新排列的任务上。
- **真实机器人（定性）**：擦桌任务展示了方法、接触、覆盖与完成四个阶段，验证了方法从仿真迁移到真实平台的可行性，但作者明确声明其不作为定量基准。

### 4.2 关键趋势

- **纯预测 vs 纯价值重标注**：JEPA 类方法（仅有固定偏移预测目标）与 π*0.6（仅做价值重标注）均弱于 PAVE，印证"预测有益于表征但行为无关、价值重标注有益于行为但不改善转移表征"的互补性假设——只有两者结合才同时改善表征与行为。
- **单一时间尺度 vs 多时间尺度**：固定偏移目标（δ = 31）只能覆盖局部运动，多时间跨度目标（ρ ∈ {0.25, 0.5, 0.75, 1.0}）显式建模了中间进展与轨迹级后果，是长程任务增益的主要来源。
- **迭代演化效果**：随 ACP 轮次增加，成功率单调上升，说明"用带优势标签的数据与专家演示从同一基座重训 actor"能持续把更好的动作筛选出来。

### 4.3 消融实验

- **移除多时间跨度对齐（λ_MH = 0）**：性能明显下降，长程套件下降幅度最大。
- **移除局部对齐（λ_local = 0）**：性能下降但幅度小于移除多时间跨度，说明局部转移仍提供有用的短程信号，但不足以替代轨迹级监督。
- **移除优势条件化（只用演示 + 部署数据不带标签）**：性能下降，且低于带优势标签的版本，验证 ACP 的有效性。
- **文本注入 vs 标量注入**：文本形式的优势短语与 null 短语并存、并以 0.3 概率 drop 为 null，使 actor 在推理时可无条件生成动作，避免部署时必须依赖评论器；消融显示该设计与标量条件相比更稳定。
- **评论器重新训练**：每轮在同一经验池上重训评论器并使用样本内预测，避免了跨轮评论器不一致导致的优势漂移；消融表明不重训会削弱迭代增益。
- **演示:演化数据采样比 3:1**：消融显示该比例在保留专家行为与吸收部署经验之间取得平衡，过高或过低均损害最终性能。

### 4.4 表征分析

- 对共享 Qwen LoRA 表征进行探针分析表明，加入多时间跨度对齐后，表征对"未来状态比例"的线性可分性增强，说明训练时预测目标确实塑造了动作无关的转移表征。
- 预测器与评论器在推理时被完全丢弃，**在线执行不增加任何额外计算或候选动作搜索**，与需要在线评估候选动作的世界-动作模型相比具有部署优势。

## 五、贡献总结

1. **原则性框架**：提出"从每条有效轨迹学习转移，但只从更好的动作中执行"的统一原则，将世界-动作表征学习与优势条件化策略演化结合。
2. **多时间跨度预测对齐**：在保持标准固定偏移 JEPA 目标的同时，引入轨迹相对的多时间跨度预测目标，显式覆盖局部运动、中间进展与轨迹级后果，且仅在训练时塑造共享表征。
3. **独立分布价值评论器 + N 步优势标注**：以 201 支撑分布型价值头给出相对优势标签，将成功、失败、恢复、低效片段统一为相对优劣信号。
4. **优势条件化策略演化（ACP）**：以文本形式注入优势，每轮从同一基座重训 actor，兼顾专家行为保留与部署经验吸收。
5. **实证验证**：在 LIBERO、LIBERO-Plus、RoboTwin 2.0 三个仿真基准与一个真实机器人定性演示上验证有效性。

## 六、局限与展望

- **样本内优势估计**：评论器在同一池上重训并打分，优势为样本内预测而非交叉拟合，可能高估部分片段的优势；作者未报告交叉拟合变体。
- **标签阈值为固定前 30%**：相对排名阈值是超参数，未系统研究其对不同任务难度分布的影响。
- **在线不执行预测**：多时间跨度预测器与评论器完全离线，虽然降低推理成本，但也意味着部署时无法根据实时不确定性与预测动态在线修正动作。
- **真实机器人仅为定性**：缺乏真实平台的定量评估，仿真到真实的定量泛化仍有待验证。
- **多时间跨度比例固定**：ρ 的取值集合为手工设定，未探索自适应或学习得到的时间跨度。

## 七、结论

PAVE 通过将**多时间跨度转移预测对齐**（改善表征，但行为无关）与**分布价值评论器驱动的优势条件化策略演化**（改善行为，但不直接改善转移表征）结合，落实了"从每条有效轨迹学习转移、只从更好的动作中执行"的原则。多时间跨度预测器与评论器仅在训练/离线标注阶段存在，在线执行退化为"观测 + 语言 + 本体感觉 → 直接动作"的轻量闭环控制。在 LIBERO、LIBERO-Plus、RoboTwin 2.0 上的一致性增益以及消融分析表明，多时间跨度转移表征与优势筛选对长程、分布偏移与双臂协调任务尤为关键。
