## 摘要
视觉-语言-动作（VLA）模型通常通过自回归文本坐标或不透明的动作 token 来暴露空间定位，这会在多模态推理与机器人执行之间造成脆弱的接口。我们提出 Pointing-VLA，一种构建于 Embodied-R1 之上的类型化隐状态空间读出。几何专用头预测归一化点、物体功能定位（OFG）热力图和视觉轨迹，而无需将几何信息序列化为文本。对于所评估的 Bridge/WidowX 和实体抓放部署，一个显式的执行契约将 PICK 分配给以源为条件的 OFG，将 PLACE 分配给 Pointing，从而提供与阶段直接对齐的空间目标。在启用碰撞的 CuRobo 执行下，Pointing-VLA 在 Bridge/WidowX 上达到 SOTA 性能，在未进行 Bridge 专用微调的情况下，在所评估的四任务集上平均成功率为 72.9%。Pointing 和 OFG 在原生与跨数据集评估中展现出互补优势。OFG/接触读出可迁移至 NORA-1.5，在保持或提升成功率的同时，将记录的控制器时间减少超过 20 倍；在共享外部测试套件上，类型化头也比 Embodied-R1 文本解码快 6.68--6.90 倍。当作为 $π_{0.5}$ 动作策略的空间引导进行集成时，Pointing-VLA 在三种视觉情境下将自主真实机器人成功率从 52.7% 提升至 80.7%。这些结果确立了类型化空间读出作为一种高效、可检查的接口，连接具身推理与机器人执行。

## Abstract
Vision-language-action (VLA) models often expose spatial grounding through autoregressive text coordinates or opaque action tokens, creating brittle interfaces between multimodal reasoning and robot execution. We present Pointing-VLA, a typed hidden-state spatial readout built on Embodied-R1. Geometry-specific heads predict normalized points, object-functional grounding (OFG) heatmaps, and visual trajectories without serializing geometry as text. For the evaluated Bridge/WidowX and physical pick-place deployments, an explicit execution contract assigns PICK to source-conditioned OFG and PLACE to Pointing, providing direct stage-aligned spatial targets. Pointing-VLA achieves SOTA performance on Bridge/WidowX, averaging 72.9\% across the evaluated four-task set without Bridge-specific finetuning under collision-enabled CuRobo execution. Pointing and OFG show complementary strengths across native and cross-dataset evaluations. The OFG/contact readout transfers to NORA-1.5, preserving or improving success while reducing recorded controller time by more than 20$\times$; typed heads are also 6.68--6.90$\times$ faster than Embodied-R1 text decoding on a shared external suite. When integrated as spatial guidance for a $π_{0.5}$ action policy, Pointing-VLA raises autonomous real-robot success from 52.7\% to 80.7\% across three visual contexts. These results establish typed spatial readouts as an efficient, inspectable interface between embodied reasoning and robot execution.

## 1. 核心问题与研究动机

- **接口瓶颈**：VLA（视觉-语言-动作）模型虽然能连接观测、语言指令与机器人行为，但其"输出接口"是瓶颈。许多操作子任务首先需要一个**显式的空间承诺**：要触碰的点、要使用的功能部件、或执行器应遵循的短视觉轨迹。
- **两条现有路线的缺陷**：
  - *自回归文本坐标*：几何信息成为"事后附加物"——模型需耗费 token 逐位拼写数字，评估器需把字符串解析回像素，密集的部件级证据在进入执行前就被丢弃。
  - *不透明动作 token*：省去解析，但隐藏了机器人栈或人工审计所需的**空间推理依据**。
- **两类接口失败**（图 1 示意）：① 文本生成可能根本产生不了可解析坐标；② 语法上合法的坐标（如 [222, 172]）仍可能落在目标区域之外。因此"解析"只是额外的执行依赖，并不保证定位正确。
- **核心主张**：具身定位应被建模为**类型化接口预测（typed interface prediction）**，而非文本坐标生成。指称点（稀疏）、功能区域（密集部件级）、视觉轨迹（时序结构）是相关但不同的目标；把它们塞进同一输出分布会造成**负干扰**，全部序列化为文本则使下游执行更慢、更不稳定。
- **理论依据**：源自 vision-for-action 与 population-readout 的计算观（Goodale & Milner 1992；Andersen & Buneo 2002；Cisek 2007）——下游读出应直接从分布式内部活动中解码空间变量，而不必经由表征系统本身序列化输出。

## 2. 方法论

### 2.1 总体架构（隐藏状态空间读出）

- 以 **Embodied-R1** 为冻结底座，复用其共享多模态隐状态 `H_mm`；不要求底座"说出"坐标，而是**从隐状态中读出空间意图**。
- 轻量 **Grounding Adapter**（1024 维投影 + 学习查询 + query cross-attention FFN）产出固定数量的 grounded tokens `G`。
- 三类几何专用头，各自以机器人执行所需的原生几何形式输出：
  - **Pointing 头** → 归一化点 → PLACE
  - **OFG 头** → 功能接地热图 → PICK
  - **VTG 头** → 视觉航点轨迹（可选）
- 每个专家共享骨干架构、底座权重与 Adapter 主体，但各自保留独立 LoRA、学习查询与解码器状态。

### 2.2 关键公式与流程（文字化描述）

- **共享接地空间投影**：`X_e = W_e^h H_mm + P_e`（加位置编码）→ 注意力 `A_e = softmax((Q_e W_Q)(X_e W_K)^T/√d)` → `G_e = FFN_e(A_e X_e W_V)` → 池化得全局摘要 `g_e`。Pointing 与 OFG 专家各用 **8 个接地查询**；VTG 专家改让学习的时间查询**直接注意完整多模态序列**，避免固定接地 token 的瓶颈。
- **Pointing 解码**：学习指针查询 `q_pt` 对 `G_pt` 做注意力得 `z_pt`，经 `σ(W_p·LN(z_pt)+b_p)` 直接输出 `(x̂,ŷ)∈[0,1]²`，对应像素 `(û,v̂)=((W-1)x̂,(H-1)ŷ)`。**无需生成或解析坐标文本**。用 PIB（point-in-bbox）/PIM（point-in-mask）评价。
- **OFG 解码**：保留空间延展而非塌缩为单 token。用全局摘要 `g_ofg` 经 **FiLM** 调制视觉塔 2D 特征图 `F_vis`（`F'_ofg = γ(g_ofg)⊙F_vis + β(g_ofg)`），再经卷积热图解码器得 `Ĥ_ofg`；其**归一化峰值** `(j*/(W_o−1), i*/(H_o−1))` 即面向执行的功能接触点。
- **VTG 解码**：学习航点查询带时间编码按序注意多模态序列，输出 `T=8` 个归一化图像空间航点；用 RMSE / ADE / FDE 评价（描述视觉轨迹，而非底层动作）。
- **结构化 PICK/PLACE 契约**（确定性、无推理期选择器）：

  - `q_place = T_place(ℓ, c_goal)`，`ŷ_place = F_pt(H_mm, G, q_place)` —— Pointing 给出紧凑放置目标。
- **图像空间→机器人坐标的外部 wrapper**：借助标定深度 `D`、相机内参 `K` 与相机-机器人变换 `T_{r←c}`，把像素提升为齐次坐标并变换到机器人坐标系，交由现有执行器消费；学习头本身仍是图像空间预测器。
