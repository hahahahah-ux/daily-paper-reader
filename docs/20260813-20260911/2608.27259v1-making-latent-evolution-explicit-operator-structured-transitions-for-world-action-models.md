## 摘要
世界动作模型（WAMs）通过预测任务相关场景状态在交互下可能如何演化，来增强机器人策略。近期的 WAM 越来越多地在潜在表示空间中进行此类预测，避免完整的外观级生成，同时保留与控制相关的信息。然而，潜在转移通常由基于 Transformer 的预测器实现，其归纳结构以 token 交互而非时间演化为核心。我们将转移实现视为一种区别于预测表示和预测-策略耦合的架构选择。我们提出潜在演化算子网络（LEON），它通过学习到的可观测空间，经由上下文调制的基于算子的传播与加性强迫来建模潜在演化。基于受控 Koopman 生成元的演化视角，LEON 将依赖上下文的转移变化组织在一个共享的演化算子结构周围，同时保留一条用于加性变化的互补路径。受控动力系统验证了由此产生的演化特定归纳偏置，以及算子传播与强迫的互补作用。在两种以不同方式将潜在预测集成到策略中的 WAM 方案中，LEON 提升了闭环性能与鲁棒性，同时在完全替换转移时仍然有效。这些结果确立了转移实现是潜在 WAM 中一项具有重要影响的架构选择。

## Abstract
World Action Models (WAMs) augment robot policies by predicting how task-relevant scene states may evolve under interaction. Recent WAMs increasingly perform such prediction in latent representation spaces, avoiding full appearance-level generation while preserving control-relevant information. Yet latent transitions are commonly realized with Transformer-based predictors whose inductive structure is centered on token interaction rather than temporal evolution. We study transition realization as an architectural choice distinct from predictive representation and prediction-policy coupling. We introduce the Latent Evolution Operator Network (LEON), which models latent evolution in a learned observable space through context-modulated operator-based propagation and additive forcing. Grounded in the controlled Koopman generator view of evolution, LEON organizes context-dependent transition variation around a shared evolution-operator structure while retaining a complementary path for additive change. Controlled dynamical systems verify the resulting evolution-specific inductive bias and the complementary roles of operator propagation and forcing. Across two WAM formulations that integrate latent prediction into the policy differently, LEON improves closed-loop performance and robustness while remaining effective under full transition replacement. These results establish transition realization as a consequential architectural choice in latent WAMs.

  - *预测表征*（predictive representation）：预测什么未来信息（像素/潜表征）。

- **整体含义**：论文主张"转移实现"应被视为潜 WAM 设计中的一等架构维度，并将受控生成元视角从物理控制推广到**学习到的语义与动作相关上下文**。

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 统一问题形式
- 潜转移写作 $\hat{X}^+ = T_\theta(X, Z)$：$X$ 为当前视觉潜状态，$Z$ 为语义/动作相关上下文，$X^+$ 为该 WAM 定义的未来目标。
- 干预只改变 $T_\theta$ 的实现形式，**保持预测表征、未来目标、条件通路与下游策略接口不变**，从而隔离"转移实现"这一变量。

### 2.2 理论基础：受控 Koopman 生成元
- 考虑控制仿射系统 $\dot{s} = f_0(s) + \sum_{j=1}^{m} u_j f_j(s)$。
- 生成元可精确分解：$\mathcal{L}_u = \mathcal{L}_0 + \sum_j u_j \mathcal{L}_j$。
- 在不变量子空间上得到有限维表示：$\dot{h} = G(u)h,\; G(u) = G_0 + \sum_j u_j G_j$。
- **关键启示**：控制通过"共享算子分量上的系数"改变演化生成元的组成。
- **推广**：WAM 中的 $Z$ 是学习到的语义/动作上下文而非显式物理控制，因此把"控制的仿射依赖"替换为"由 WAM 表征构造的学习式上下文调制"。

### 2.3 LEON 的三段式流程
1. **学习可观测量坐标**：状态 token $y_i \in \mathbb{R}^d$ 经可观测映射 $\phi$ 得 $h_i = \phi(y_i) \in \mathbb{R}^c$，构成 $H \in \mathbb{R}^{N\times c}$。
2. **构造转移上下文**：$\xi_i = C(h_i, Z) \in \mathbb{R}^{d_\xi}$，整合语义与动作相关信息（具体实现随 WAM 的条件接口而定）。
3. **上下文调制的可观测量演化**：
   - $\Delta h_i = A(\xi_i) h_i + b(\xi_i)$，$\tilde{h}_i = h_i + \eta \Delta h_i$，其中 $\eta$ 为残差更新尺度。
   - **结构化演化算子**：$A(\xi) = D + \sum_{k=1}^{r}\alpha_k(\xi)B_k = D + U\,\mathrm{Diag}(\alpha(\xi))\,V^\top$。
     - $D=\mathrm{Diag}(\delta)$：与上下文无关的基线算子；
     - $B_k = p_k q_k^\top$：共享秩一基算子，$U=[p_1,\dots,p_r]$、$V=[q_1,\dots,q_r]$；
     - $\alpha(\xi)$：上下文相关系数，决定算子在固定子空间内的"组成"。
   - **结构假设显式化**：$A(\xi)-D \in S=\mathrm{span}\{B_1,\dots,B_r\}$，$\dim(S)\le r$。即上下文依赖的变化被限制在一个**至多 $r$ 维的算子子空间**中，$r$ 上界为独立算子方向数。
   - **加性强迫 $b(\xi)$**：提供不局限于乘性作用于 $h_i$ 的上下文相关变化，与算子传播形成互补路径。
4. **读出与复合**：学习式读出 $\psi$ 把更新后的可观测量映射回 WAM 所需表征空间；跨网络深度复合，构成完整的 $T_\theta$。

### 2.4 两种预测-策略耦合下的实例化
- **表征中介式（VLA-JEPA）**：8 层 LEON 替换 Transformer 转移栈；状态 1024 维 → 观测量 768 维；条件 $Z$ 为 VLM 产生的**逐时间步 latent-action token**；上下文 $C$ 用**视觉-动作交叉注意力**（每个视觉 token 只查询同时间步的 $K$ 个 latent-action token），再与时间步级摘要向量 $\bar{z}_t$ 融合。**不引入视觉-视觉自注意力，也不跨时间步传播**。
- **策略面向式（LaWAM）**：12 层 LEON 替换全部 12 个 Transformer 解码块；冻结 DINOv3 输出 256 个 768 维 patch 特征，经保留的输入投影映射到 1024 维；条件 $Z$ 为策略预测的**全局 latent action**，经逐 patch MLP 构造上下文；**无 patch-patch 注意力**；读出映射回 1024 维供下一层使用。
- **训练**：沿用各 WAM 原有预测与策略目标（VLA-JEPA：未来状态预测 + 流匹配动作生成；LaWAM：latent action 蒸馏 + horizon 特征监督 + 条件动作学习），**不新增预测目标，也不需要单独预训练**。

## 6. 主要结论与发现

- **转移实现是有实质影响的架构选择**：在预测表征与预测-策略耦合保持不变的前提下，仅替换转移实现即可改变闭环策略表现。
- **表征中介式（VLA-JEPA + LEON）**：
  - LIBERO 平均成功率 **97.2% → 99.05%（+1.85）**；Spatial 96.2→99.0、Goal 97.2→99.4、LIBERO-10 95.8→98.0、Object 99.6→99.8；

## 7. 局限、开放问题与启示

### 7.1 作者已声明的局限
- 受控动力系统与 WAM 潜表征之间存在尺度与语义鸿沟，**不能据此推断 WAM 的潜空间服从相应的物理动力学，或存在精确的 Koopman 描述**；受控实验仅用于隔离归纳偏置的作用，而非为 WAM 提供机理解释。
- LEON 引入的结构超参（可观测量维度 $c$、算子子空间秩 $r$、残差尺度 $\eta$）需要针对不同 WAM 条件接口调整，文中未给出系统的敏感性分析。
- 加性强迫 $b(\xi)$ 与算子子空间 $S$ 的关系未被理论刻画：为何需要强迫项、其与算子路径的分工是否可由生成元理论推出，仍是开放问题。

### 7.2 方法层面的隐含局限
- **秩 $r$ 的语义未经验证**：论文以 $\dim(S)\le r$ 作为结构假设，但未分析学到的 $B_k$ 是否对应可解释的演化模式（如不同任务阶段、不同物体动力学），因此"结构化"目前更多是参数化层面的约束，而非可读的动力学分解。
- **算子作用域是逐 token 的**：$A(\xi_i)h_i$ 只在单个可观测量上做线性演化，token 间信息交换仅通过上下文 $Z$ 间接发生（VLA-JEPA 变体明确去掉了视觉-视觉自注意力，LaWAM 变体去掉了 patch-patch 注意力）。这意味着 LEON 以"抑制 token 交互"换取"显式时间演化"，两类归纳偏置的取舍尚未被系统研究。
- **条件 $Z$ 的构造仍是启发式**：VLA-JEPA 用同时间步交叉注意力 + 时间步摘要，LaWAM 用逐 patch MLP，两者都与 Koopman 意义上的"控制输入"相去甚远，受控生成元的理论形式在此更多是**设计隐喻**而非可推导的等价物。

### 7.3 对后续研究的启示
- 可将"转移实现"作为与预测表征、预测-策略耦合并列的第三轴，系统比较其他结构化方案（局部线性、隐式微分、状态空间模型、Neural ODE 等）。
- 需要 WAM 层面的**多种子 + 显著性检验**，以及对秩 $r$、可观测量维度 $c$ 的敏感性扫描，才能判断结构化收益的稳健边界。
- 值得探索"部分保留 token 交互 + 算子演化"的混合设计，以检验两类归纳偏置是否互补。

## 8. 总体评价

- **贡献定位**：论文的贡献是**概念性 + 方法性**的。它把"转移实现"明确为一个此前被默认、未被讨论的架构维度，并用受控 Koopman 生成元提供了一个有原则的参数化模板（共享基算子 + 上下文系数 + 加性强迫）。这一视角本身具有组织价值，即使具体实现的增益幅度有限。
- **实验说服力**：干预设计干净（只换 $T_\theta$）、受控系统的机制消融扎实、LaWAM 采用匹配重训，这些都是加分项。但 WAM 端的效果量偏小（LIBERO +1.85 点、LIBERO-Plus +1.1 点且存在两个维度退化、LaWAM 基本持平），缺少方差与显著性报告，使得"结构化转移更优"的结论在真实机器人基准上仍属**方向性证据**而非强结论。
- **诚实度**：作者主动声明受控系统结论不可外推到 WAM 潜表征、明确区分 matched 重训与 50 任务参考结果，学术表达较为克制。
- **最值得追问的问题**：如果性能增益主要来自"去掉 token 交互 + 显式残差演化"这一结构性简化，而非 Koopman 式的算子分解本身，那么论文的核心论点（演化律应被显式参数化）就需要更强的消融来支撑——目前 Residual MLP 对照只覆盖了受控系统，未覆盖 WAM 端。
