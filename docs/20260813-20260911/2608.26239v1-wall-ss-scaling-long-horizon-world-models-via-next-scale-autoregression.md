## 摘要
生成式世界模型为机器人提供了世界在交互下如何演变的预测模型，在仿真、规划、策略评估和机器人学习方面展现出日益增长的潜力。超越片段级未来预测，统一的生成式表述应将动作与后果关联起来，支持灵活的时间范围和连续交互，并支持奖励驱动的优化。我们提出 WALL-SS，一种通过尺度级自回归扩展（Scale-wise autoregressive Scaling）生成视觉未来的世界模型，能够实现动作可控且长时程的机器人仿真。WALL-SS 将具身轨迹表示为时间上交错的观测和动作的因果序列，使依赖动作的状态转移变得显式，同时自然支持可变长度生成、通过可复用因果状态进行流式扩展，以及通过序列概率直接优化。为使该表述在长时程上有效，我们以由粗到细的方式生成每个未来观测，并在同一层级结构内开发了三个互补组件。动作条件化的下一尺度预测注入尺度对齐的动作表示，以改善动作与未来的耦合，并对成功和失败行为进行建模。尺度压缩的长时程记忆以细粒度保留近期交互，同时压缩久远的观测和动作，并通过逐尺度梦想强制（dream forcing）增强对自生成上下文的鲁棒性。最后，同策略对齐（on-policy alignment）使用动作跟随和长期一致性奖励来优化自回归视觉动态，同时保持预训练的视觉分布。实验表明，WALL-SS 提升了动作跟随和轨迹精度，在有界内存下支持连贯的分钟级流式推演，并且持续受益于同策略对齐，以减少动作漂移和长时程不一致。

## Abstract
Generative world models provide robots with predictive models of how the world evolves under interaction, with growing potential for simulation, planning, policy evaluation, and robot learning. Beyond clip-level future prediction, a unified generative formulation should relate actions to consequences, support flexible horizons and continuous interaction, and enable reward-driven optimization. We introduce WALL-SS, a world model that generates visual futures through Scale-wise autoregressive Scaling, enabling action-controllable and long-horizon robotic simulation. WALL-SS represents embodied trajectories as causal sequences of temporally interleaved observations and actions, making action-dependent state transitions explicit while naturally supporting variable-length generation, streaming extension through reusable causal states, and direct optimization through sequence probabilities. To make this formulation effective over long horizons, we generate each future observation in a coarse-to-fine manner and develop three complementary components within the same hierarchy. Action-conditioned next-scale prediction injects scale-aligned action representations to improve action-future coupling and model both successful and failed behaviors. Scale-compressed long-horizon memory retains recent interactions at fine resolution while compressing distant observations and actions, with scale-wise dream forcing enhancing robustness to self-generated context. Finally, on-policy alignment optimizes autoregressive visual dynamics with action-following and long-term consistency rewards while preserving the pretrained visual distribution. Experiments show that WALL-SS improves action following and trajectory accuracy, supports coherent minute-long streaming rollout under bounded memory, and consistently benefits from on-policy alignment in reducing action drift and long-horizon inconsistency.

## 2. 方法论

### 2.1 核心思想
- 将具身轨迹建模为 **任务条件 + 观测 + 动作时间交错** 的因果序列：每个未来观测由前序世界历史与介入其间的动作生成，动作依赖的状态转移在模型因子分解中显式化。
- 每个未来观测以 **coarse-to-fine（粗→中→细）的 next-scale 自回归** 方式生成，视觉生成器由 **InfinityStar** 初始化；同一层级同时用于"预测未来"和"压缩记忆"。

### 2.2 动作接地的下一尺度动态
- **动作–视频时间对齐**：对每个相机 *v*，确定性渲染器 R(v) 仅用规划侧轨迹（初始自 rollout 状态 p₀）、标定信息，把控制投影到视觉时间线；共享因果编码器连续处理并**按与 RGB 相同的 clip 区间 J_c 切片**，保留时间连续性与 clip 级对齐；不使用未来遥测或目标视频。
- **尺度对齐因果条件**：动作 token 作为条件前缀置于同一 Transformer 序列；位置 (c, ℓ, r, v) 的 query 只读文本与 (c, κ(ℓ), v) 的动作图，其中 κ(ℓ) 取不超过 ℓ 的最细保留动作尺度；其他视图、相邻 clip、未来控制一律 mask；identity anchor 仅表示初始观测 O₀；跨视图适配器只交换因果可用的同步状态，不改变动作掩码。
- **学习目标**：在推理相同的因果顺序下最小化平衡负对数似然 L_AR，Bal 对 clip、scale、残差重复均匀平均，bundle log-prob 对有效 token 决策求和；无可靠动作的样本动作条件置为 ∅。

### 2.3 长时程时间–尺度记忆
- **记忆记录**：在保留的预测前边界 s ∈ S_M 物化同步因果状态 H_pre，尺度越细前缀越完整；每条视觉记录与同一物理区间的动作 bank A_u 配对，保证"记住的状态"始终绑定产生它的动作。
- **反向时间顺序**：近期 clip 保留细尺度状态，远期 clip 退化为粗尺度摘要；老化只改变寻址的预计算边界，**不在线转换 KV 状态**，无需额外记忆编码器或 RGB 空间压缩。
- **身份锚点**：H_anc 仅由 O₀ 导出，稳定身份与全局布局，不含未来动作，也不替代当前动态状态。
- **有界内存**：内存 bank 含活跃记录与预计算待用记录，每条在最后一次计划读取后被驱逐，固定 age–scale 调度使常驻内存 ≤ B_KV，与已完成 clip 数无关。
- **流式状态转移**：生成前组装 M_c、编码当前动作块、按粗到细生成全部同步视图；整个 bundle commit 后状态才持久化，随后老化记录、切换 cutoff、驱逐过期项。
- **逐尺度梦想强制（scale-wise dream forcing）**：将年龄相关的损坏历史与"滞后流式模型"采样的 detached 自生成后缀混合，监督目标仍为干净未来 clip，总损失 L_long = L_AR + λ_cor·L_cor + λ_self·L_self。属于"监督式曝光差距训练"，而非奖励优化。

### 2.4 世界动作策略（辅助动作专家）
- 训练一个流匹配动作专家，读取仅暴露已提交视觉状态的上下文 H^A_c 与本体/规划状态，预测下一控制块 A_c；掩码排除当前视觉目标、当前动作条件与所有未来记录。
- 预测动作与外部动作**共享同一接地映射** Γ，视觉模型从不读取专家私有状态；递归想象在动作预测、视觉生成、记忆提交间交替。
- 配对 teacher-forced 转移上联合训练：L_cotrain = L_long + λ_A·L_act，未配对历史仅保留视觉损失。

### 2.5 视觉动态的同策略对齐
- **策略化**：把 next-scale 视觉 token 生成视为随机策略 π^V_θ = S_η[p_θ]，控制保持固定条件；"on-policy" 仅指视觉生成策略（同一组采样共享相同预设控制）。
- **奖励**：两个冻结打分器——R_act 度量每次转移与预设动作的一致性，R_long 度量滚动窗口内的状态、边界、跨视图一致性；**任务进度与最终成功被排除在奖励之外**，留作闭环评测。
- **优化**：按 clip 聚合折扣回报并在 K 条 rollout 内归一化得到组相对优势（无需 critic），采用 PPO 式 clip 目标 L_PG；奖励 detach，梯度经采样 token 的对数概率回传。
- **先验保持正则**：L_align = L_PG + β·E[KL(π_θ‖π_ref)] + λ_AR·L^real_AR；KL 限制局部漂移，真实轨迹自回归回放保外观并抑制奖励攻击。仅更新视觉生成器及其条件适配器，tokenizer、打分器、参考生成器与动作模块全部冻结。

### 2.6 训练与推理流程
- 训练三段：① 干净真值上下文上的动作接地自回归学习（tokenizer 冻结，生成器与动作/视图条件模块联合优化，动作专家在配对转移上联合训练）；② 开启有界时间–尺度记忆的多 clip 窗口 rollout 鲁棒适配（干净历史 + 年龄损坏历史 + detached 自生成后缀混合）；③ 视觉动态的同策略对齐（先训练冻结两个保真度打分器，再做组相对策略优化，rollout 批次在有界更新次数后刷新）。
- 推理：构建一次 identity anchor，逐 clip 因果编码动作块、粗到细采样同步视图、commit bundle、推进有界记忆；可通过 fork 同一已提交状态并替换控制或采样种子获得反事实未来。闭环时冻结的外部策略消费最新生成的多视图观测并返回下一动作块，经轻量 action bridge 重采样到训练时的控制率与末端执行器表示，初始化后不再注入任何真值。
