## 摘要
视觉-语言-动作（VLA）模型已在机器人操作中展现出有效性，但诸如 pi0.5 等最先进模型在单帧范式下运行，限制了其保留过去观测并形成精确空间感知的能力。本文提出 StreamPI，一种流式多模态时序建模框架，在不引入任何额外参数的情况下，为单帧 VLA 赋予时序推理能力。一个核心设计是指令锚定的时序建模。它将每个（视觉观测，语言指令）对视为一个原子时序单元：对内的双向注意力实现跨模态融合，而对间的因果注意力保持自回归流式推理。这确保语言指令在整个任务执行过程中充当持久的语义锚点。为弥合同步训练与异步真实机器人部署之间的差距，我们引入随机间隔流式训练策略：适当的帧间间隔（例如每 3 帧）可实现更快、更平滑的动作执行。除此之外，随机化间隔还进一步提升了对帧时序扰动的鲁棒性，从而在实践中支持异步部署。此外，借助 LLM 主干的长度外推能力，StreamPI 无缝继承预训练的单帧权重，并支持灵活的单帧与多帧推理。在涵盖依赖记忆和精确感知场景的真实机器人任务以及仿真基准 LIBERO 上的实验表明，StreamPI 在多样化任务上优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

# StreamPI 论文结构化总结

## 1. 核心问题与整体含义

- **研究动机**：当前最先进的 VLA 模型（如 π0、π0.5）普遍采用**单帧范式**，每一步动作仅依赖当前单张图像观测，无法保留历史信息。
- **由此带来的两大能力缺失**：
  - 无法记忆并推理过去的观测（如“哪个杯子藏了物体”这类需要跨帧记忆的任务）；
  - 无法通过时序聚合形成精确的空间感知（如精细插入、动态物体抓取）。
- **已有多帧方案的问题**：
  - **基于窗口的方法**（如部分视频编码器方案）序列长度随时序线性增长，实时控制延迟过高；
  - **指令遗忘**：语言指令作为固定文本 token，随时序变长被视觉 token 稀释；
  - **训练-部署不匹配**：训练用固定间隔采样，真实机器人观测为异步、变间隔流；
  - **表征损坏**：引入新视频编码器参数会与预训练 VLA 特征分布错位。
- **整体含义**：提出 **StreamPI**，在不增加任何参数的前提下，把单帧 VLA 升级为**流式多模态时序模型**，同时兼顾时序记忆、空间感知与推理效率，并支持单帧/多帧灵活推理与异步部署。

## 2. 方法论

### 2.1 核心思想：指令锚定的原子时序单元

- 将每个时刻的输入定义为**原子时序单元** `u_t = (V_t, l_t)`，其中 `V_t = {v_t^f, v_t^l, v_t^r}` 为前视 + 左右腕部三路视觉观测，`l_t` 为语言指令。
- 将 T 个连续原子单元拼接为输入序列 `U = [u_{t-T+1}, ..., u_t]`，指令在每一步都与视觉观测**持续绑定**，避免长时程指令遗忘。

### 2.2 双层注意力结构

- **对间（Intra-pair）双向注意力**：在每个原子单元内部，视觉 token 与文本 token 双向互注意，完成充分跨模态融合，得到语义对齐表示 `h_τ = Attn_bi(V_τ, l_τ)`。
- **对间（Inter-pair）因果注意力**：融合表示 `h_τ` 仅关注此前所有单元，`o_t = Attn_causal(h_{t-T+1}, ..., h_t)`，保证自回归流式推理且未来帧不泄露。
- 最终由 `o_t` 条件生成动作 `a_t ~ π_θ(·|o_t)`。

### 2.3 无参数时序扩展

- 双层注意力完全通过**重构注意力掩码**实现，不新增任何网络参数。
- 借助 LLM 主干的**长度外推能力**，直接继承 π0.5 的全部预训练权重，仅扩展输入 token 序列并分配扩展位置嵌入。

### 2.4 随机间隔流式训练

- **随机间隔采样**：基础帧间间隔 `δ̄` 加随机扰动 `ε ~ U(-Δ, +Δ)`，得到 `δ = δ̄ + ε`，并裁剪到 `[δ_min, δ_max]`（实验中为 [3, 7]）。
- **时序掩码**：随机采样掩码数 `k ∈ {0, 1, ..., T-1}`，将最早 k 帧遮蔽，模拟流式推理中的增量观测模式。
- 目的：弥合固定间隔训练与异步真实部署之间的分布差异。

### 2.5 流式推理（KV-Cache）

- 初始时刻编码 `u_{t0}`，预测动作并将融合表示 `h_{t0}` 存入 KV-Cache。
- 后续每个时间戳仅需编码新到达帧，其表示与缓存中的历史表示做交叉注意力，避免对历史帧的重复计算；缓存满 T 后清空重置。
- 推理成本随时序长度基本恒定，适配长时程操作任务。

## 7. 优点

- **无需额外参数**：完全通过注意力掩码实现时序扩展，继承 π0.5 全部预训练权重，避免表征损坏与新增参数开销。

- **训练-部署对齐**：随机间隔采样 + 时序掩码直接针对真实机器人异步观测流，工程实用性强。

- **实验覆盖面广**：仿真 + 真实机器人、记忆 + 感知、效率 + 鲁棒性、消融 + 可视化，验证维度较全面。
