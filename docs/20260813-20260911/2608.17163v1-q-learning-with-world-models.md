## 摘要
离策略强化学习（RL）已变得越来越具有样本效率，使得诸如通过RL微调视觉-语言-动作模型，将其转化为可靠且高性能的策略等应用成为可能。世界模型为提升样本效率提供了另一条途径，因为它们预测的是状态变化而不仅仅是动作，但其成功在很大程度上仍局限于监督式策略学习。此前的基于模型的RL方法通常直接在想象推演上优化策略或价值函数，这容易导致偏差累积，并且难以扩展到真实世界机器人等大规模、高维问题，而随着任务时域和视觉复杂度的增加，该问题会进一步加剧。在这项工作中，我们转而探究是否可以直接在标准Q学习之上利用世界模型来提升性能，同时仍保持在真实、在线设定中进行训练并以其为基础。我们提出QWM，一个在Q学习之上利用世界模型对想象轨迹进行测试时搜索的框架，以在在线推演和评估期间选择高价值动作。由于策略和价值函数仅在真实转移上训练，QWM避免了模型偏差累积，同时仍能获得预测式搜索带来的样本效率优势。在具有挑战性的操作基准Robomimic和LIBERO上，QWM在样本效率和性能上均显著优于此前强大的最先进方法。

## Abstract
Off-policy reinforcement learning (RL) has become increasingly sample-efficient, enabling applications such as RL fine-tuning of Vision-Language-Action models into reliable, high-performing policies. World models offer a further lever for sample efficiency, as they predict state changes rather than actions alone, but their success has largely been confined to supervised policy learning. Prior model-based RL methods often optimize the policy or value function directly on imagined rollouts, which is prone to compounding bias and struggles to scale to large, high-dimensional problems such as real-world robotics, a problem that worsens with task horizon and visual complexity. In this work, we instead ask whether we can leverage world models directly on top of standard Q-learning to improve performance, while remaining trained and grounded in the real, online setting. We propose QWM, a framework that leverages world models to perform test-time search over imagined trajectories on top of Q-learning to select high-value actions during both online rollouts and evaluation. Since the policy and value function are trained only on real transitions, QWM avoids compounding model bias while still gaining the sample-efficiency benefits of predictive search. On challenging manipulation benchmarks Robomimic and LIBERO, QWM significantly outperforms strong prior state-of-the-art methods on both sample efficiency and performance.

# 论文总结：Q-Learning With World Models（QWM）

## 1. 核心问题与研究动机

- **背景**：离策略（off-policy）RL 的样本效率近年显著提升，已能支持如 VLA 模型的 RL 微调等高要求应用，但在真实机器人等复杂场景中，样本效率仍是瓶颈。
- **世界模型的潜力与困境**：世界模型能预测"状态变化"而非仅动作，理论上提供更强的样本效率杠杆；然而其成功目前基本局限于监督式策略学习。
- **既有基于模型 RL 的根本缺陷**：主流做法（如 Dreamer 系列、TD-MPC2、MuZero 类）直接在"想象推演"上优化策略或价值函数，或把模型生成的合成转移当作真实数据使用，导致模型偏差被继承并**复合放大**；该问题随任务时域变长、视觉复杂度提升而恶化，难以扩展到真实机器人。
- **核心研究问题**：能否**不**把世界模型当作环境交互的替代品，而是让 RL 智能体仍然"扎根"于真实在线训练，仅用世界模型在**决策时刻（test-time）**锐化动作选择？
- **核心洞察**：在标准 Q-learning 之上，用学到的世界模型对想象轨迹做测试时搜索来评估候选动作、选出最高价值动作，这种更优的动作选择本身就能直接转化为 Q-learning 的性能提升。

## 2. 方法论：QWM 框架

### 2.1 总体思想
- **训练/推理解耦**：策略 π 与 Q 函数**只在真实环境转移**上训练（标准 TD 学习）；世界模型 M_ψ 与搜索仅在**测试时**介入——既用于在线 rollout 时的动作选择（改善采集数据质量），也用于评估时的动作选择。
- 关键区别：不同于传统基于模型 RL 用状态价值函数 V 做搜索，QWM 用**动作条件**的 Q 函数进行搜索，得到更强、更细粒度的动作评估。

### 2.2 树搜索构建（Section 4.1）
- 三个控制量：每个状态节点采样动作数 **N**、每个动作经世界模型预测的下一状态数 **K**、搜索深度 **D**。
- 结构：根节点为当前状态 s₀；节点在"状态层—动作层"间交替（一个状态层 + 一个动作层 = 一层深度）。
  - 状态节点处：从策略采样 N 个候选动作 {aⁿ_d} ∼ π_θ(·|s_d)；
  - 动作节点处：查询世界模型 K 次得到 K 个预测下一状态 {s^{n,k}_{d+1}} ∼ M_ψ(s_d, aⁿ_d)；
  - 递归至深度 D；最终层再采样 N_leaf 个动作。
- 设计意图：树只做**短时域**后果预测，避免世界模型预测误差沿长 rollout 累积。

### 2.3 价值聚合（Section 4.2）——双估计器互补
- **状态-动作价值估计器**（低方差、与深度无关，但完全依赖 Q_φ 准确性）：
  V_Q(d|s_d) = agg_{n∈[N]} Q_φ(s_d, aⁿ_d)。
- **状态价值估计器**（利用完整想象 rollout，但误差随深度复合）：
  V_r(d|s_d) = agg_{n∈[N]} [ agg_{k∈[K]} ( r_ψ(s_d,aⁿ_d) + λ·V(d+1|s^{n,k}_{d+1}) ) ]；
  叶节点无 rollout 可递归，退化为对 Q 值的聚合：V(D|s_D) = agg_{n∈[N_leaf]} Q_φ(s_D, aⁿ_D)。
- **组合节点价值**：V(d|s_d) = ½ ( V_Q(d|s_d) + V_r(d|s_d) )，可推广为加权平均 αV_Q + (1−α)V_r。
- **根节点价值**（用于选择初始动作）：
  Q_ts(s₀,aⁿ₀) = ½ [ Q_φ(s₀,aⁿ₀) + ( r_ψ(s₀,aⁿ₀) + agg_{k∈[K]} λ·V(1|s^k₁) ) ]，s^k₁ = M_ψ(s₀,aⁿ₀)。
- 最终动作：对根动作按 Q_ts 取 **max 或 softmax**；该搜索流程同时用于训练期采样与评估期执行。

### 2.4 用 Q 函数做搜索策略与剪枝（Section 4.3）
- 树规模随深度指数膨胀，因此用 Q 函数作为启发式搜索策略，仅保留少量高价值路径：
  - 每条存活路径 b 在深度 d 的累积折扣分数：Σ(b,d) = Σ_{d′=1}^{d} λ^{d′} Q_φ(s^b_{d′}, a^b_{d′})；
  - 扩展候选分数：Σ̃(b,n,d+1) = Σ(b,d) + λ^{d+1} Q_φ(s^{b,n}_{d+1}, a^{b,n}_{d+1})；
  - 每层保留 **top-J** 个候选（beam）构成 B_{d+1}；
  - 深度 D 处每条存活路径采样 N_leaf 动作并按 beam 聚合 L(b) = agg_n Q_φ(s^b_D, a^{b,n}_D)；根节点价值综合所有存活 beam。
- 当 J 等于最大节点数时不发生剪枝；J 小于时每层按上式丢弃候选。

### 2.5 实现细节（Section 4.4）
- **低维状态观测**：确定性残差动力学模型 M_ψ(s_t,a_t) = s_t + Δ_ψ(s_t,a_t)，3 层 MLP（隐层 256），输入 Robomimic 低维状态（末端位姿、夹爪状态、物体特征）+ 7-DoF 动作；用 MSE 在演示转移上离线预训练，训练后**保持冻结**。
- **像素观测**：将 Wan2.2-TI2V-5B 改造为动作条件视频世界模型——3 层 MLP 动作编码器把动作映射为 action tokens，与文本条件 token 拼接后送入扩散 Transformer；**联合微调**动作编码器与 DiT，冻结 VAE 与文本编码器，使用 Wan2.2 flow-matching 目标训练；LIBERO 上生成 5 帧 128×128 片段，用预测的下一帧作为后续观测以迭代 rollout 与树搜索；推理时仅用 1 步去噪。
- **奖励**：因实验为稀疏奖励（仅终态非零），实际**未训练额外奖励模型**（公式中的 r_ψ 在该设定下退化）。

### 2.6 所依托的基算法
- **EXPO**：base flow 策略（监督训练）+ 轻量 edit 策略（最大化 Q，编辑量裁剪到 [−β,β]，避免对 base 反向传播），推理/TD 备份使用 OTF 策略在 N 个 base 与 edited 候选中取 Q 最大者。
- **RLPD**：离线+在线对称采样、高 UTD、critic 集成、SAC 风格熵正则高斯 actor。

## 6. 主要实验结果

### 6.1 状态观测（Robomimic）
- QWM 在 4 个任务上均优于其基方法：QWM on EXPO 相对 EXPO、QWM on RLPD 相对 RLPD 均有稳定提升，且提升幅度随任务难度/时域增长而更明显（Tool Hang 这类长时域多阶段任务收益最大）。
- 与 model-free 基线相比，QWM 在多数任务上达到或超过最强基线；与 model-based 基线（TD-MPC2、EfficientZero V2）相比，后者即便获得稠密奖励变体，在稀疏奖励设定下整体落后，说明"在想象中训练"带来的模型偏差确实损害了长时域任务性能。
- 中间对照 RLPD+tree search 表明：仅把搜索加在 RLPD 上而不改变其训练机制，收益有限，凸显 QWM 的收益来自"真实在线训练 + test-time 搜索"这一组合，而非单纯增加计算量。

### 6.2 像素观测（LIBERO）
- QWM on EXPO 在选取的 5 个语言条件任务上同样取得提升，说明该框架不依赖低维状态，可迁移到视频世界模型驱动的视觉控制。
- 定性上，Wan2.2 改造的动作条件视频世界模型能生成与动作语义一致的下一帧预测（如机械臂朝向、物体位移方向），为短时域搜索提供可用信号；但预测误差随 rollout 步数增长，这也解释了为何树深度 D 不能取太大。

### 6.3 消融结果
- **搜索使用阶段**：仅用于评估的收益小于仅用于在线采样，两者同时使用收益最大——支持"更优动作选择改善数据分布，进而改善 Q 函数"这一核心机制。
- **树深度 D**：性能随 D 先升后降，存在最优点；过深时世界模型预测误差复合放大，抵消了更长时域规划带来的收益，与设计动机一致。
- **折扣 λ 与候选动作数 N**：N 增大通常带来单调或饱和式提升；λ 存在较宽的合理区间。
- **扩展节点数 J（beam 宽度）**：J 增大提升性能但边际递减，说明 Q 函数作为搜索启发式已能有效剪枝，少量高价值路径即可承载大部分收益。
- **V vs Q 搜索**：用状态价值 V 做搜索明显弱于用动作条件 Q 做搜索，验证了 4.2 节关于 Q 提供更细粒度动作评估的设计选择；该结论在 EXPO 编辑策略与 AWR 式独立方法上均成立。

## 7. 结论、局限与启示

### 7.1 核心结论
- 世界模型不必充当"环境替代品"，而可作为**测试时动作锐化器**：在保持标准 Q-learning 真实在线训练的前提下，用短时域想象搜索改进动作选择，即可稳定提升样本效率与最终性能。
- 用动作条件 Q 函数而非状态价值 V 驱动搜索，是该框架有效性的关键设计；Q 同时充当搜索启发式与剪枝准则，使指数级树搜索在实际中可控。
- 该思路与具体基算法解耦：在 EXPO（flow 策略编辑）与 RLPD（SAC 式离策略）上均有效，具备一定的通用性。

### 7.2 局限
- **依赖世界模型质量**：搜索的价值上限受限于 M_ψ 的短时域预测精度；像素世界模型（5B 扩散模型、每步去噪）推理开销大，实际部署成本高。
- **稀疏奖励下的奖励模型缺位**：实验未训练 r_ψ，奖励项退化为终态指示，框架在稠密/学习型奖励下的表现未经检验。
- **评测范围有限**：任务数、随机种子数、模态覆盖均有限，缺乏真实机器人验证与计算开销的定量分析。
- **超参敏感性**：D、λ、N、J 均需调优，D 过大会因误差复合而反噬。

### 7.3 启示与展望
- 为"model-based 与 model-free 的融合"提供了第三条路径：不做想象训练、不做模型替代，而做 test-time 决策增强。
- 后续可探索：更长时域但误差可控的搜索（如多步一致性约束的世界模型）、学习型奖励模型、搜索计算的自适应分配（简单状态少搜索、关键状态多搜索）、以及在真实机器人上的落地验证。
