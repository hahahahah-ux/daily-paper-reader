## 摘要
我们提出了利用预训练加速灵巧性（ADEPT），这是一个大规模强化学习（RL）框架，用于在具有高自由度（DoF）的机器人本体上学习可仿真到现实迁移的灵巧性，这些本体能够直接基于原始视觉-触觉感知解决长时程任务。ADEPT 在一个通用物体重摆放任务上预训练一个灵巧策略，然后以该预训练行为作为先验，对下游策略进行后训练。ADEPT 能够学习多指机器人从头开始难以发现的新行为，并避免为每个新的下游任务重复学习同一组技能。预训练策略可零样本执行下游任务的重摆放阶段，但朴素的 RL 微调会在迁移过程中迅速削弱这一能力。我们通过一种稳定的后训练方案来解决这一问题，该方案结合了行为克隆蒸馏、critic 预热和保守的同策略更新。为安全地充分利用完整的运动学灵巧性，我们引入了关节空间 Geometric Fabric，在 RL 策略与机器人之间进行协调。我们将后训练得到的教师策略蒸馏为具备感知能力的学生策略，这些学生策略能够在两种本体上零样本仿真到现实迁移：配备两个 RGB 相机的 23 自由度 Kuka-Allegro，以及配备两个 RGB 相机和五个基于视觉的触觉传感器的 29 自由度 Flexiv-Sharpa，并能够以人类水平速度的灵巧性从具有挑战性的初始状态解决长时程任务。

## Abstract
We introduce Accelerating Dexterity via Pre-Training (ADEPT), a large-scale reinforcement learning (RL) framework for learning sim-to-real transferable dexterity across high degree-of-freedom (DoF) robot embodiments that can solve long-horizon tasks directly from raw visuo-tactile perception. ADEPT pretrains a dexterous policy on a generic object reposing task, then post-trains downstream policies with this pretrained behavior as a prior. ADEPT enables learning new behaviors that are otherwise difficult to discover from scratch on multi-fingered robots and avoids learning the same set of skills over again for every new downstream task. The pretrained policy zero-shots the reposing phase of downstream tasks, but naïve RL fine-tuning rapidly degrades this capability during transfer. We address this with a stable post-training recipe combining behavior-cloning distillation, critic warm-up, and conservative on-policy updates. To safely exploit the full kinematic dexterity, we introduce a joint-space Geometric Fabric that mediates between the RL policy and the robot. We distill post-trained teachers into perceptive students that zero-shot sim-to-real transfer on two embodiments: a 23 DoF Kuka-Allegro with two RGB cameras, and a 29 DoF Flexiv-Sharpa with two RGB cameras and five vision-based tactile sensors, and can solve long-horizon tasks from challenging initial states with dexterity at human-level speed.

## 1. 核心问题与研究动机

- **背景**：配备多指灵巧手的高自由度（DoF）机械臂系统（如 Kuka-Allegro、Flexiv-Sharpa）是机器人学习的核心难题。这类系统同时具有高维状态/动作空间与丰富的接触交互，从稀疏的任务奖励中很难发现有用行为。
- **核心痛点**：
  - 即使借助大规模并行 GPU 仿真（如 Isaac Gym），为单一任务从零训练出的 RL 策略也几乎无法迁移到新任务。
  - 每个新任务都要从零开始，反复重新发现相同的底层技能（reach、grasp、lift、reorientation），造成巨大算力浪费。
  - 多指手系统的长期任务（如 pick-reorient-insert）在仿真到现实（sim-to-real）迁移中尤其困难，且此前工作多依赖人类演示、姿态追踪器或平行夹爪流水线。
- **整体含义**：论文主张摒弃“为每个任务训练专用 RL 专家”的范式，转而采用**先获取通用灵巧操作基础（预训练），再适配到具体下游任务（后训练）**的两阶段范式。作者指出，策略在参数空间中的初始化位置与其下游优化目标同等重要。

## 2. 方法论

### 2.1 总体框架（三阶段 + 部署）

1. **预训练（Pre-Training）**：在通用物体重摆放（reposing）任务上用 PPO 训练一个基础灵巧策略。
2. **后训练（Post-Training）**：以预训练行为为先验，为接触密集型下游任务训练专用教师策略。
3. **教师-学生蒸馏（Teacher-Student Distillation）**：将基于状态的后训练教师蒸馏为仅依赖原始感知（RGB / 触觉）的学生策略。
4. **真实世界部署**：学生策略零样本 sim-to-real 迁移到真实机器人。

### 2.2 问题形式化

- 将灵巧操作建模为离散时间 MDP $M=(S,A,p,r,\gamma)$，动作空间 $A=[-1,1]^{n_q}$（$n_q=23$ 或 $29$）。
- 采用带非对称 actor-critic 的 PPO 学习随机策略 $\pi_\theta(a_t|o_t)$，最大化折扣回报 $J(\theta)$。
- 两个 MDP：$M_{pre}$（预训练）与 $M_{post}$（后训练），共享动作空间，但观测空间、动力学和奖励不同；$o_{post}$ 在 $o_{pre}$ 基础上增加容器位姿 $p_{rec}$ 和物体-容器接触力 $f_{or}$。

### 2.3 预训练阶段

- **任务**：每回合从 16 种基元形状（圆柱、立方体、球、圆锥）中随机采样一个（随机尺度），策略需完成“reach → grasp → lift → in-hand reorient → transport → reposing”完整序列，将物体摆放到采样的目标位姿。
- **技术细节**：
  - 采用**自动域随机化（ADR）**作为在线课程，成功率高时提升目标难度和环境复杂度。
  - 使用**基于群体的训练（PBT）**（16 个并行策略，每 200M 帧检查一次）搜索 PPO 超参数。
  - 重力从 $0$ 退火到 $-9.81\ \text{m/s}^2$。
  - 物体用点云表示，以获得更好的零样本泛化能力。
- **奖励函数**（式 1）：手-物对齐项 + 物体-目标对齐项（基于 8 个包围盒关键点的位姿误差）+ 接触门控项。

### 2.4 后训练阶段（核心贡献）

- **朴素微调为何失败**：直接 PPO 微调会在少量更新内将预训练能力破坏殆尽（成功率降为 0%）。作者归因于：任务奖励变化、新增观测维度、价值/优势估计失准、以及由此导致的大幅策略更新，形成“更差策略→更差 critic→更差 rollout”的恶性循环。
- **结构化后训练三步法**：
  1. **BC Actor 蒸馏**：用监督模仿将 $\pi_{pre}$ 蒸馏到具有下游观测空间的新 actor $\pi_{post}$，训练 40k 次迭代；rollout 使用学生-教师混合策略，目标为 Mahalanobis 加权的动作分布距离（式 29）。
  2. **Critic 预热**：冻结 $\pi_{post}$，仅用下游奖励训练新的 critic $V_{post}$（约 20 次 PPO 迭代 / 每 GPU 约 1M 环境步，4096 个环境），使价值估计与新任务对齐。
  3. **保守 PPO**：解冻后联合更新，采用保守超参：actor 学习率 $1e-3 \to 1e-5$（线性衰减）、PPO clip $\epsilon: 0.2 \to 0.05$、critic 学习率固定 $5e-5$。

### 2.5 教师-学生蒸馏

- **学生输入**：本体感知 + fabric 状态 + 两路 RGB 图像（+ Flexiv-Sharpa 上 5 个指尖触觉图）。
- **训练方式**：DAgger，教师提供逐步动作目标（均值与方差），学生使用 ResNet 主干（DextrAH-RGB 式解冻计划）。
- **辅助损失**：在共享立体图像特征上加 8 关键点位姿预测头，总目标 $\mathcal{L}=\mathcal{L}_{BC}+\mathcal{L}_{aux}$（$w_{BC}=1, w_{aux}=20$），解决插入任务中最主要的失败模式——peg 朝向感知。
- **两阶段学生课程**：
  - **Stage 1**：将预训练重定向教师重用于感知密集的替代任务（提升并重定向 peg 到直立位），用 $\mathcal{L}_{aux}$ 塑造视觉编码器。
  - **Stage 2**：从下游教师继续蒸馏，用 $\mathcal{L}_{BC}$ 驱动接触密集策略精调。
- **触觉感知**：采用 TacMap 的几何一致穿透深度图 + 二值接触图，经逐指共享 CNN 编码，并用 SaTA 式 FiLM 以指尖位置进行空间锚定。
- **域随机化**：物理、物体扰动（随机力）、视觉条件（光照、背景、相机内参/位姿）、传感器噪声均做激进随机化。

### 2.6 关节空间 Geometric Fabric

- 在策略与机器人之间放置一个二阶几何 fabric：$M_f(q_f,\dot q_f)\ddot q_f + f_f(q_f,\dot q_f) + f_\pi(a)=0$。
- **关键创新**：在**完整关节配置空间（Cspace）**中驱动 fabric，策略输出 $a_t\in[-1,1]^{n_q}$ 作为逐关节相对增量（缩放 $\delta_{max}=0.1$ rad），映射为 Cspace 目标 $q_t^*=q_f^{(t-1)}+\delta_{max}a_t$（并 clamp 到 URDF 限位）。这与先前 DextrAH-G/RGB 将手部限制在 5D PCA 子空间的做法形成对比。
- Fabric 提供碰撞与关节限位避让、Cspace 阻尼、速度控制，且同一 fabric 实例在仿真与真实机器人上运行，最小化控制器差异。

### 3.2 对比方法
