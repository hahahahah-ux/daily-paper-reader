## Abstract
Dexterous manipulation involves contact-rich and fine-grained interactions with the physical world, posing significant challenges for existing vision-language-action (VLA) models due to severe visual occlusions and complex contact dynamics. While recent works have incorporated tactile sensing into robotic manipulation, most approaches still rely on homogeneous multimodal fusion, lacking adaptive tactile integration and explicit modeling of physical dynamics. In this work, we present DeCAL, a physically-grounded dexterous vision-language-action model that unifies understanding, imagination and action generation for contact-rich dexterous manipulation. Built upon a Mixture-of-Transformers (MoT) architecture, DeCAL leverages specialized experts for each capability while enabling efficient information flow among them. To effectively leverage tactile information, we introduce Adaptive Visuo-Tactile Fusion that dynamically regulates tactile interactions via a contact-aware gating strategy. Furthermore, we propose Visuo-Tactile Latent Co-Imagination to jointly model visual and tactile dynamics, equipping the policy with implicit physical world knowledge. Experimental results show that DeCAL consistently achieves state-of-the-art performance across all tasks, attaining a 71% average success rate and an 83.4% progress success rate, while also demonstrating strong generalization to unseen scenarios. ## 二、论文提出的方法论

### 2.1 核心思想
- 基于 **Mixture-of-Transformers（MoT）** 架构，由三个协作专家组成：**理解专家（Understanding Expert）**、**生成专家（Generation Expert，世界模型）**、**动作专家（Action Expert，流匹配模型）**；
- 三个专家通过**联合注意力（Joint Attention）**进行方向性知识共享，实现"感知—理解—想象—行动"一体化；
- 引入两大关键机制：**自适应视触觉融合（Adaptive Visuo-Tactile Fusion）**与**视触觉潜在协同想象（Visuo-Tactile Latent Co-Imagination）**。

### 2.2 关键技术与细节

- **理解专家（Understanding Expert）**：
  - 基于 **Qwen3-VL** 构建，编码语言指令与多视角视觉观测；
  - 通过**专用交叉注意力**扩展触觉模态：以触觉特征为 K/V，视觉-语言特征为 Q，残差融合到自注意力特征中，实现视觉、语言、触觉统一潜在空间联合推理。

- **生成专家（Generation Expert）**：
  - 显式建模视触觉动力学，从历史交互预测未来视觉与触觉观测；
  - 采用**并行解码（非自回归）**策略以满足高频机器人控制的实时性要求；
  - 视觉侧：使用 **Cosmos VAE tokenizer** 编码多视角图像，并采用 8×8 卷积核将 32×32 潜在特征下采样至 4×4 进行 token 压缩；
  - 触觉侧：以每指 6-DoF 力为紧凑物理表征，经力编码器映射为触觉潜在，可解码为原始触觉图像、形变图、6-DoF 力向量三种粒度。

- **动作专家（Action Expert）与因子化流匹配（Factorized Flow Matching）**：
  - 以理解专家与生成专家的潜在特征 + 机器人本体状态为条件，通过流匹配预测动作块；
  - 因手臂与手部运动动力学和控制粒度差异显著，**显式解耦手臂与手部动作生成**：两者从独立噪声初始化、经独立 MLP 投影为 token 序列，再由 Transformer 联合处理以协调运动，最后解码为干净动作轨迹；
  - 流匹配插值形式：\(\hat{a}^\tau_{t:t+k} = (1-\tau)\epsilon + \tau a_{t:t+k}\)，其中 \(\epsilon \sim \mathcal{N}(0,I)\)，\(\tau \sim \text{Beta}(1.5,1.0)\)。

- **跨模态联合注意力（Cross-Modal Joint Attention）**：
  - 采用**块状注意力掩码**控制信息流：理解专家 → 生成专家 → 动作专家单向传播；
  - 后续专家可关注前序专家 token，反向禁止；
  - 理解专家与生成专家内部为双向注意力；动作专家中状态 token 可关注自身与更早块，动作 token 可关注自身、状态 token 及更早块。

- **自适应视触觉融合（Adaptive Visuo-Tactile Fusion）**：
  - **触觉特征提取**：使用多指形变图作为输入，共享 ResNet 触觉编码器提取特征，经空间池化与跨指 Transformer 融合，输出**局部触觉 token**（细粒度接触细节）与**全局触觉 token**（整体接触状态）；
  - **自适应交叉注意力**：局部触觉 token 作为 K/V，视觉-语言嵌入作为 Q，输出经残差连接融合；
  - **接触感知门控机制**：由于接触是间歇性的，直接注入触觉会引入偏差，故用门控权重动态调节：
    \[
    \tilde{X} = X + \sigma \odot \mathrm{CrossAttn}(Q_{vl}, K_{local}, V_{local}),\quad \sigma = \mathrm{Gate}(z_{global})
    \]
    门控权重 \(\sigma\) 由全局触觉 token 经轻量投影得到，使模型根据整体接触状态选择性纳入触觉反馈。

- **视触觉潜在协同想象（Visuo-Tactile Latent Co-Imagination）**：
  - **触觉潜在预测**：以每指 6-DoF 力为输入，经力编码器生成触觉潜在，可解码为原始触觉图像、形变图、6-DoF 力向量；
  - **视觉潜在预测**：用 Cosmos VAE tokenizer 编码多视角图像，预测未来视觉潜在，直接回归至 Cosmos VAE 目标；
  - 训练时触觉潜在以重建未来触觉观测为间接监督；推理时生成专家联合预测未来视觉与触觉潜在，省略重建解码器以避免像素空间重建。

- **训练目标**：
  \[
  \mathcal{L}_{total} = \lambda_v \mathcal{L}_{visual} + \lambda_t \mathcal{L}_{tactile} + \mathcal{L}_{action}
  \]
  其中视觉损失为预测潜在与 Cosmos 潜在特征的 L2 损失，触觉损失为原始图像、形变图、6-DoF 力的加权重建损失，动作损失为流匹配损失。

- **推理流程**：多视角视觉、语言、触觉嵌入为 prefix 与 middle token，经理解专家与生成专家处理，KV cache 缓存上下文；最终通过因子化流匹配迭代生成动作。
