## 摘要
视觉-语言-动作（VLA）模型通过大规模预训练获得了广泛的操作能力，但要通过语言激发这些能力，需要指令与物理交互之间的细粒度对齐。现有机器人演示通常只提供粗粒度任务描述，忽略了动作如何执行，包括哪个夹爪执行动作、接触哪个物体，以及如何抓取和移动。我们提出 YUBI-STAG，一个时空标注与定位框架，能够自动为操作演示丰富交互丰富的语义，从而使预训练 VLA 与细粒度操作语言对齐。结合接触物体分割与视觉-语言模型，YUBI-STAG 标注物体身份、属性和状态、每个夹爪的动作、双手协调以及空间定位交互。为解决 YUBI-STAG 对局部化序列和多阶段 VLM 推理的依赖，我们将其蒸馏为 YUBI-VLM。YUBI-VLM 能在少量推理调用中直接从原始、未分割视频中恢复动作结构和标注，并且仅依赖腕部视角运行。我们在 YUBI-STAG-Bench 上跨时间、语义和空间定位任务评估这两个框架。YUBI-VLM 以更少的推理调用和更短的运行时间保留了 YUBI-STAG 的大部分标注精度，同时能泛化到未见过的操作任务。最后，在这些标注上后训练 VLA 策略，使其与细粒度语言和接触感知结构对齐。双手实验表明性能和指令遵循能力有所提升，包括对物体身份、执行夹爪、目标位置以及原始标签中缺失的空间关系的控制。

## Abstract
Vision-Language-Action (VLA) models acquire broad manipulation capabilities via large-scale pretraining, yet eliciting them through language requires fine-grained alignment between instructions and physical interactions. Existing robot demonstrations typically provide only coarse task descriptions, omitting how actions are executed, including which gripper acts, which object is contacted, and how it is grasped and moved. We introduce YUBI-STAG, a framework for Spatio-Temporal Annotation and Grounding that automatically enriches manipulation demonstrations with interaction-rich semantics to align pretrained VLAs with fine-grained manipulation language. Combining contact-object segmentation with vision-language models, YUBI-STAG annotates object identities, attributes and states, per-gripper actions, bimanual coordination, and spatially grounded interactions. To address YUBI-STAG's reliance on localized sequences and multi-stage VLM inference, we distill it into YUBI-VLM. YUBI-VLM directly recovers action structure and annotations from raw, unsegmented video in few inference calls and operates from wrist views alone. We evaluate both frameworks on YUBI-STAG-Bench across temporal, semantic, and spatial grounding tasks. YUBI-VLM retains much of YUBI-STAG's annotation accuracy with fewer inference calls and shorter runtime while generalizing to unseen manipulations. Finally, post-training VLA policies on these annotations aligns them with fine-grained language and contact-aware structure. Bimanual experiments demonstrate improved performance and instruction following, including control over object identity, acting gripper, target location, and spatial relations absent from original labels.

# YUBI-STAG 论文深度总结

## 1. 核心问题与研究动机

- **核心矛盾**：VLA（视觉-语言-动作）模型通过大规模预训练已获得广泛的操作能力，而语言是激发这些能力的唯一通道；但现有机器人演示数据仅提供**粗粒度的任务级标签**（如“拿起零件放进盒子”），丢失了动作如何执行的关键信息。
- **丢失的信息包括**：
  - 哪个夹爪（左/右）执行动作；
  - 接触的是哪个物体；
  - 如何抓取、如何在双手间传递、如何释放；
  - 物体在交互前后的状态与空间关系变化。
- **数据规模与瓶颈的错位**：UMI、YUBI 等手持式无机器人采集接口已能提供超大规模数据（YUBI 达 8434 小时双臂交互），采集吞吐量远超遥操作，但**语言标注的细粒度与多样性成为新的瓶颈**。
- **理论依据**：借鉴 LLM 中的**浅层对齐假说（Superficial Alignment Hypothesis）**——预训练模型已具备丰富的世界知识与几何/物理表征，后训练主要作用是“激发”而非“赋予”。作者据此主张：VLA 的局限不在先天能力，而在于后训练阶段**缺乏精确的对齐信号**。
- **现有工作的不足**：已有指令增强或中间表示工作，或只用语言描述执行过程，或在图像坐标中定位动作与空间规划，但**没有工作能联合恢复“哪个夹爪—接触哪个物体—在哪些像素—持续哪个时间段—双手如何协调”这一完整结构**，并将其用于对齐预训练 VLA。

## 2. 方法论

### 2.1 整体框架

YUBI-STAG 由两部分组成：**(i) 接触-物体分割模块**（提供时空锚点）与 **(ii) 基于 VLM 的分阶段标注器**；随后将其蒸馏为 **YUBI-VLM**。

### 2.2 接触-物体分割模块（时空锚点）

- **动机**：低成本系统（UMI、YUBI）无触觉传感器；常用“夹爪开合度变化”作为抓取代理信号不稳定，且会漏掉用于稳定/支撑物体的**非抓取接触**。
- **技术细节**：
  - 用**冻结的 DINOv2-L** 编码两路腕部相机视频流；
  - 用轻量**时序 Transformer** 联合建模帧特征；
  - 每个夹爪由一个 **MLP 头**预测接触状态，一个 **DPT 风格解码器**预测被接触物体的像素级掩码。
- **训练数据构造（伪标签 + 自训练）**：
  - 当夹爪开合度稳定时，以指尖间一点作为提示，驱动 **SAM2** 分割并双向跟踪候选物体；
  - 用**点跟踪共运动（co-motion）**与**单目深度一致性**过滤背景候选；
  - 人工过滤初始训练集 → 在更多样数据上自训练 → 在少量精确人工标注上微调。

### 2.3 基于 VLM 的分阶段标注流水线（四阶段）

1. **场景配置（Scene Configuration）**：构建场景级物体清单，为每个实例记录名称、数量、颜色、材质、形状、尺寸、角色（部件/容器/表面/固定物），并分配**全局持久 ID**，避免同一物体在不同交互中被赋予新身份。
2. **PA 阶段、单夹爪动作与协调（PA Stages & Coordination）**：
   - 将每条接触轨迹绑定到清单中的物体 ID；利用**时间连续性**（释放后立即再抓、或通过手递手连接）解决外观相似物体的歧义；
   - 将给定的 PA 区间细化为子阶段；
   - 记录每阶段的参与物体 ID、每个夹爪的动作，以及 **7 种协调类型之一**（仅左/仅右、任一夹爪主导另一支撑、两个方向的手递手、双手协同）。
3. **物体变化（Object Changes）**：对比物体接触前与释放后的状态，记录其源/目标位置（相对其他物体）、状态变化、装配关系、包含关系；结合 PA 描述与抓取区间选取状态观测时机。
4. **统一 grounded PA 描述**：将上述解析结果合并为一段带空间定位的描述，每个物体提及都链接到持久 ID。

### 2.4 YUBI-VLM 蒸馏

- **架构**：以 **Qwen3.6-27B** 初始化，覆盖 **10 种预测模式**（场景清单与属性、给定描述下的 PA 跨度定位、PA 描述与跨度联合生成、持物归属、PA 子阶段/协调/描述、PA 级物体状态、状态轴发现与逐 PA 语义状态、包含与附着、grounded PA 描述）。
- **关键设计**：
  - 接触物体掩码以**轮廓叠加**在腕部帧上，夹爪与时间信息以文本形式提供，从而无需额外掩码编码器或视觉 token 即可实现时空定位；
  - 腕部帧在**接触区间附近优先采样**；
  - 训练时对 **50% 样本丢弃俯视图**，以支持仅腕部视角推理；使用时间裁剪与可变帧率采样覆盖长短视频。
- **训练配置**：在 Qwen3.6-27B 上使用 **LoRA**，可训练参数 **489M（1.76%）**。

### 2.5 VLA 后训练（接触与语义丰富对齐）

- 基于 **π0.5** 的 VLA，保留视觉-语言骨干与**流匹配动作专家**；先在 8434 小时 YUBI 语料上预训练，再在同一小规模演示集（10–20 小时）上以不同监督做后训练，从而**仅隔离监督信号的差异**。
- 动作表示为 UMI 末端执行器状态（双臂各 6-DoF 增量运动 + 夹爪指令）；流匹配损失为
  **L_FM = E[‖v_θ(a_s, s, c_t) − (a − ϵ)‖²₂]**，其中 a_s = (1−s)ϵ + s·a，s ∈ [0,1] 为流时间。
- **三类监督增强**：
  1. **任务相关的 PA 增强**：注入物体身份与属性、目标位置、空间关系（如分拣任务中指定零件颜色与目标料格）。
  2. **Handedness 标签**：四种类型（左爪、右爪、左→右手递、右→左手递），随时间更新。
  3. **接触阶段标签**：approach / grasp / hold / release；grasp 为接触起始 ±0.2 s，release 为接触段最后 0.2 s，其余为 hold。
- **接触优先采样（Contact-prioritized sampling）**：借鉴优先经验回放思想，将采样重心偏向接触阶段（例如仅占 5% 的抓取起始阶段可被采样到 30%），不改变训练目标。
- **公平性设计**：观测、动作、架构、目标均保持不变，仅改变监督信号。

## 3. 实验设计

### 3.1 新基准 YUBI-STAG-Bench

- **规模**：100 个 episode，10 个任务（每任务 10 个），共 **510 个物体、970 个 PA、2201 个交互区间**；以 10 fps 标注每个夹爪的时间区间与被接触物体掩码。
- **任务分组**：
  - **接触-物体定位**：从腕部视频检测各夹爪接触区间并以 10 fps 分割被接触物体；
  - **语义标注**：物体 ID、属性（形状/材质）、TAS（时间动作分割）、PA GEN TAS（联合生成 PA 描述与区间）、协调、位置（容器/相对位置）、状态（含转换时刻）。

### 3.2 评测指标

- 接触检测：时间 mIoU、帧准确率；
- 接触掩码：DAVIS J 与 F（未覆盖帧记 0）；
- TAS：边界 F1@0.5 s、segment IoU；
- PA GEN TAS：边界 F1、segment IoU、PA 数量准确率，并用 **GPT-5.2 作为评判**评估描述的身份一致性、充分性、粒度；
- 状态：时间 mIoU、转换 F1@1.0 s。

### 3.3 对比方法

- 接触分割基线：**开合度启发式 + SAM2**；
- 语义标注基线：**未训练的 Qwen3.6-27B 骨干**、**RoboFine-VLM-397B-A17B**（FineVLA 发布的 397B MoE 标注器）、**YUBI-VLM**、**YUBI-STAG**；
- 输入配置消融：**+PA**（给定真值 PA 描述与区间）、**+PA list only**（仅给描述需预测区间）、**默认**（原始未分割视频）、**w/o Top**（仅腕部视角）。

### 3.4 机器人实验

- **平台**：Franka 机器人 + YUBI 双臂末端执行器，10 Hz，8 步动作块。
- **任务**：
  1. **YUBI 零件分拣**：抓取指定 YUBI 手指零件放入指定料格；
  2. **燃料支架料箱抓取**：从源箱取五种工业零件之一转移到目标箱，超时 2.5 分钟；
  3. **袜子分拣（语言可控性）**：6 只不同颜色袜子、3 个料箱，测试颜色/夹爪/目标箱控制、相对空间放置（左/右/之间）、序数选择（“从左数第二个”）；
  4. **字母积木动作组合**：BED（ID）与 BUS（OOD），对比任务级基线 vs. YUBI-VLM 生成的 PA 监督。
- **对比策略**：π0.5 基线、YUBI-VLA（粗标签）、+Handedness、+Handedness + Contact。

- **充分性评估**：
  - **优点**：覆盖了标注质量、推理效率、真实机器人操作、语言可控性、组合泛化等多个维度；消融设计清晰（PA 输入形式、相机视角、蒸馏与否、监督丰富度）；用**未见任务**评估标注泛化性，用**未见字母组合 BUS**评估组合泛化，设计较为严谨。
  - **客观性与公平性**：VLA 后训练严格固定观测、动作空间、网络架构与目标，仅改变监督信号，隔离变量做得较好；语义评测中物体匹配按接触轨迹重叠一对一匹配而**不使用预测名称**，减少命名偏差；PA 描述用 GPT-5.2 做独立评判。
  - **潜在不足**：机器人实验每个条件仅 20 次试验（部分任务 10 次 rollout），统计功效有限；单机器人平台、单任务场景，外部有效性待验证；PA 描述评判依赖 GPT-5.2，可能存在评判模型偏差。

## 6. 主要结论与发现

- **接触分割**：学习式模块显著优于开合度启发式基线——接触检测 mIoU 89.7 vs. 71.8，帧准确率 94.5 vs. 83.8；掩码 J(e2e) 74.0 vs. 40.3，F(e2e) 75.1 vs. 43.6。
- **语义标注**：YUBI-VLM 以匹配的 PA 输入保留了 YUBI-STAG 的大部分能力，并在若干类别上持平或超越；相比未训练骨干，在时间、协调、空间、状态理解上大幅提升；仅用腕部视角仍保留大部分性能，但相对位置与状态时序下降，说明俯视图对全局上下文有价值。RoboFine-VLM 虽经大规模机器人视频训练，仍显著低于 YUBI-VLM，且不擅长

- **（接上）语义标注结论（续）**：RoboFine-VLM 虽经大规模机器人视频训练，仍显著低于 YUBI-VLM，且**不擅长**细粒度的接触归属、协调类型判定与状态转换时刻预测——这提示“通用机器人视频预训练”并不自动带来**接触级 grounded 结构**，任务特化的标注监督才是关键。加入 **PA 描述与区间**作为输入（+PA）后各方法均受益，但 YUBI-STAG 在身份一致性、粒度、充分性三个 GPT-5.2 评判维度上仍领先，说明其增益来自结构化标注而非仅靠描述文本。
- **机器人操作**：在零件分拣与料箱抓取两个任务上，监督信号的丰富度呈现**单调递增**趋势——π0.5 基线 < YUBI-VLA（粗标签）< +Handedness < +Handedness + Contact。手别标签主要改善**双臂分工与传递**相关失败，接触阶段标签进一步改善**接近-抓取-释放**的时序精度，二者叠加效果最佳。
- **语言可控性**：在袜子分拣中，YUBI-VLM 生成的 PA 监督使模型能稳定响应颜色、指定夹爪、目标箱、相对空间关系（左/右/之间）与序数指代（“从左数第二个”），且对**未见过的料箱排列顺序**保持泛化，说明监督提供了**可组合的空间-语言接口**而非死记任务。
- **动作组合泛化**：字母积木任务中，ID 组合 BED 上两类监督均能学会；而 OOD 组合 BUS 上，仅任务级标签的基线明显退化，YUBI-VLM 的 PA 监督仍保持较高成功率，验证了**分阶段 grounded 监督提升组合泛化**的假设。
- **推理效率**：YUBI-STAG / YUBI-VLM 相比 397B MoE 的 RoboFine-VLM 在 8×H200 上具有显著更低的推理延迟与显存占用，且精度更高，具备**在线标注或闭环使用**的可行性。

## 7. 局限性

- **依赖腕部相机与视觉接触假设**：接触-物体分割以腕部视角为主，当物体被遮挡、透明/反光、或接触发生在视野外时，掩码与接触检测可能失效；未使用触觉信号，本质仍是**视觉代理**。
- **伪标签与自训练的误差传播**：初始训练集依赖 SAM2 + 共运动 + 深度一致性筛选，背景干扰或快速运动下可能引入噪声，虽经人工过滤与自训练缓解，但误差仍可能被蒸馏进 YUBI-VLM。
- **持久 ID 与物体清单的假设**：场景配置阶段假设场景中物体可被枚举且身份可持久绑定；在**开放式、物体频繁进出**的真实环境中，清单维护与 ID 关联的鲁棒性未充分验证。
- **评测依赖 GPT-5.2 评判**：PA 描述质量由大模型评判，可能存在**评判模型自身的偏好与偏差**，与人类判断的一致性未系统量化。
- **机器人实验统计功效有限**：单机器人平台、每条件 10–20 次试验、任务场景偏桌面工业/家用，外部有效性（其他本体、其他形态、长时程任务）待验证。
- **训练算力披露不足**：VLA 预训练与后训练的算力开销、训练时长、迭代步数未给出，**复现成本不透明**。
- **蒸馏架构耦合**：YUBI-VLM 以 Qwen3.6-27B 为底座，其能力边界受底座限制；10 种预测模式需分别设计提示与输出格式，工程复杂度较高。

## 8. 对领域的启示

- **“数据规模 ≠ 监督质量”**：在 VLA 时代，瓶颈已从采集吞吐转向**对齐信号的粒度**。YUBI-STAG 表明，把“哪个夹爪、接触什么、何时、如何协调”显式结构化，比单纯扩大演示数据更有效。
- **浅层对齐假说的机器人验证**：结果支持“预训练已具备能力，后训练负责激发”的观点——同一 π0.5、同一数据、仅换监督，性能即可显著分化。
- **接触是动作语义的锚点**：以**接触区间 + 被接触物体掩码**作为时空锚点，可自然派生手别、阶段、状态变化与协调类型，为机器人数据标注提供了可复用的中间表示。
- **标注器可蒸馏、可在线**：将重型标注流水线蒸馏为轻量 YUBI-VLM，使**在线生成 grounded 监督**成为可能，为持续学习与数据飞轮提供路径。
- **评测需要结构化基准**：YUBI-STAG-Bench 把标注拆成接触定位、TAS、协调、位置、状态等多维指标，提示社区应避免用单一任务成功率掩盖**中间表征的缺陷**。

## 9. 总体评价

YUBI-STAG 的核心贡献不在于新模型架构，而在于**重新定义了 VLA 后训练的监督粒度**：它提出了一套从无触觉手持数据中自动恢复“夹爪—物体—像素—时间—协调”完整结构的流水线，并证明该结构可蒸馏为实用标注器、可注入 VLA 后训练、可显著提升真实操作与语言可控性。方法上，接触-物体分割的伪标签自训练、四阶段 VLM 标注、以及接触优先采样三个设计环环相扣，逻辑自洽；实验上，通过固定架构与数据、仅变监督的严格对照，以及对未见任务与 OOD 组合的评测，论证较为扎实。

其主要短板在于**视觉接触代理的固有脆弱性**、**训练算力披露不足**、以及**机器人实验规模有限**。尽管如此，它清晰地指出了 VLA 下一阶段的竞争焦点——**结构化、可 grounding、可组合的监督信号**——对后续数据引擎与对齐研究具有明确的指导意义。
