## 摘要
视觉-语言-动作（VLA）模型近来引入了世界模型，以在稀疏动作标签之外提供更丰富的动态监督。然而，显式预测未来图像或视频可能会包含与控制无关的外观，而源自整体未来视觉表示和共享全局动作特征的引导，可能无法建立动作与局部视觉变化之间特定于时间步的对应关系。为解决这一问题，我们提出 MotionWeave，一种用于动作块预测的以运动为中心的未来动力学框架，包含两个模块：动作诱导运动定位器（Action-Induced Motion Grounder, AIMG）和时域残差合成器（Horizon Residual Composer, HRC）。具体而言，AIMG 以动作和本体感受表示为条件，构建特定于预测时域的查询，从当前视觉 token 中定位与每个未来动作时间步相关联的交互区域。HRC 提取相邻时域交互表示之间的差异，将其编码为时间运动线索，并通过门控残差将其注入动作 token。训练期间，使用从未来帧渲染得到的机械臂掩码来构建基于 KL 的运动定位监督，而推理时仅使用当前观测。在六个 MetaWorld 任务上，MotionWeave 取得了 75.3% 的平均成功率，相较 π0（66.7%）绝对提升 8.6%，尤其是在持续交互任务上。我们的代码见 https://github.com/autu-mn/MotionWeave。

## Abstract
Vision-Language-Action (VLA) models have recently incorporated world models to provide richer dynamic supervision beyond sparse action labels. However, explicitly predicting future images or videos may include control-irrelevant appearance, while guidance derived from holistic future visual representations and shared global action features may fail to establish timestep-specific correspondence between actions and local visual changes. To address this issue, we propose MotionWeave, a motion-centric future-dynamics framework for action-chunk prediction with two modules: the Action-Induced Motion Grounder (AIMG) and the Horizon Residual Composer (HRC). Specifically, AIMG conditions on action and proprioceptive representations to construct horizon-specific queries that localize interaction regions associated with each future action timestep from current visual tokens. HRC extracts differences between interaction representations at adjacent horizons, encodes them as temporal motion cues, and injects them into action tokens through a gated residual. During training, robot-arm masks rendered from future frames are used to construct KL-based motion-grounding supervision, while inference uses only the current observation. On six MetaWorld tasks, MotionWeave achieves a 75.3% average success rate, an absolute gain of 8.6% over π0 (66.7%), especially on sustained-interaction tasks. Our code is available at https://github.com/autu-mn/MotionWeave.

## 1. 核心问题与研究动机

- **背景**：VLA（视觉-语言-动作）模型统一视觉感知、语言理解与动作生成，已成为学习可泛化机器人策略的有效范式，通常基于预训练视觉-语言模型，从当前观测直接预测连续控制信号。
- **核心痛点一**：低维、稀疏的动作监督只约束最终控制输出，难以显式刻画"操作过程中哪些视觉区域发生变化、这些变化如何沿动作序列演化"，导致视觉表示缺乏精确操作所需的局部交互信息与时间线索。
- **核心痛点二**：近期将世界模型引入 VLA 的工作（WorldVLA、DreamVLA 等）显式重建或稠密想象完整未来场景，不可避免地纠缠了控制无关的静态外观与背景；WoG、Fast-WAM 虽将像素级重建放松为隐式/免测试时引导，但仍监督未来视觉观测的**整体演化**，而非 horizon 特定的局部变化。
- **核心痛点三**：动作分块（action chunking）通常从共享全局特征解码整段序列，不同时间步获得同质的视觉证据，缺乏"时间步—后果"的显式对应关系。
- **核心主张**：VLA 不应冗余地重建完整未来视觉观测，而应**显式定位与动作相关的动态区域，并利用其时间演化来引导动作块生成**——即从"区域定位 → 运动线索 → 逐步控制"的闭环。

## 2. 方法论

### 2.1 整体框架

- 在时刻 $t$ 以当前 RGB 观测 $I_t$、语言指令 $l$、本体感受状态 $S_t$ 为条件，预测长度 $H=4$ 的未来动作块；未来观测 $I_{t+1:t+H}$ **仅在训练时**用于构造 horizon 特定运动监督，推理时不可用。
- 三条分支：
  - InternVL3-2B（语言侧为 Qwen2.5 系解码器）编码图像与文本 token，与可学习的动作查询占位符 $A_0$ 拼接后由 LLM 联合处理，输出动作 token $A \in \mathbb{R}^{N_a \times D}$ 与空间视觉 token $V=\{v_n\}_{n=1}^{N_v}$（实现中 $N_v=256$，对应 $16\times16$ 网格）。
  - 独立的 Proprio 编码器将 $S_t$ 映射为本体感受嵌入 $P$，**不进入语言模型**，直接供给后续模块。
- 流程链：$(A,V,P) \xrightarrow{\text{AIMG}} (M,\alpha) \xrightarrow{\text{HRC}} A' \xrightarrow{\text{Action DiT}} \hat{a}_{t:t+H-1}$。

### 2.2 Action-Induced Motion Grounder（AIMG）

- **目标**：不重建未来 RGB 帧，而是识别当前 $N_v$ 个视觉 token 位置中哪些会在未来 $H$ 步内发生变化。
- 设 $e_h$ 为第 $h$ 个未来时间步的可学习 horizon 嵌入，将 $A$、$P$ 经 LayerNorm 与线性投影映射到共同运动空间 $d_m$，构造 horizon 特定查询：
  $$q_h = e_h + \mathrm{Mean}(\mathrm{Proj}_a(A)) + \mathrm{Proj}_p(P)$$
  其中 $\mathrm{Mean}(\cdot)$ 在投影后的动作查询上取均值，使每个 horizon 查询携带全局动作引导；随后用轻量残差变换精炼 $q_h$。
- 注意力与交互表示：
  $$\alpha_{h,n} = \mathrm{softmax}_n\left(\frac{q_h^\top \mathrm{Proj}_v(v_n)}{\sqrt{d_m}}\right),\quad m_h = \mathrm{LN}\left(q_h + \sum_{n=1}^{N_v}\alpha_{h,n}\mathrm{Proj}_v(v_n)\right)$$
- 空间注意力矩阵 $\mathrm{Attn}\in\mathbb{R}^{H\times N_v}$ 接受 KL 运动定位监督；聚合后的交互 token $M=[m_1,\dots,m_H]$ 送入 HRC。所有 $m_h$ 均来自当前观测，仅通过 $e_h$ 区分，从而与未来动作时间步对齐。
- **监督构造（无需人工标注）**：每个训练样本提供 $I_t, I_{t+1},\dots,I_{t+H}$；对每个 $h$，用 Robot Engine 渲染对应的机械臂掩码，取 $I_{t+h}$ 的掩码作为该 horizon 的运动目标——它标记执行第 $h$ 个未来动作的机械臂区域，同时抑制静态背景、纹理等任务无关外观。二值掩码下采样到 $16\times16$ 视觉 token 网格、加小常数平滑并归一化，得到目标分布 $\mu_h$。

### 2.3 Horizon Residual Composer（HRC）

- AIMG 产生的交互表示彼此独立，未显式编码场景演化。将 $M$ 投影到 HRC 空间后定义相邻 horizon 差分：
  $$\Delta m_h = m_h - m_{h-1},\quad m_0 := m_1$$
  因此 $\Delta m_1 = 0$，后续差分编码相对前一时间步的变化方向与幅度。
- 以运动差分作 query、动作查询作 key/value 做交叉注意力，让每个局部演化线索"探测"需要修正的动作查询：
  $$U = \mathrm{MHA}(\mathrm{Proj}_m(\Delta M),\ \mathrm{Proj}_a(A),\ \mathrm{Proj}_a(A))$$
  （HRC 侧动作投影与 AIMG 侧相互独立）
- 更新与本体感受条件门控：
  $$\Delta A = \mathrm{Proj}_o(U),\quad g = \sigma(\mathrm{Proj}_g(P)),\quad A' = A - g \odot \Delta A$$
  采用**减法式残差更新**而非直接覆写，使每个动作查询只吸收与其时间步对应的运动增量，门控自适应控制注入强度并保留 $A$ 中原始控制先验。

### 2.4 训练目标与推理

- 以 $A'$、$P$、加噪动作块 $a_\tau$ 与扩散时间步 $\tau$ 为条件，Action DiT 用流匹配损失 $\mathcal{L}_{act}$ 预测 $\hat{a}_{t:t+H-1}$。
- 运动定位损失：
  $$\mathcal{L}_{motion} = \frac{1}{H\log N_v}\sum_{h=1}^{H}\mathrm{KL}(\mu_h \parallel \alpha_h)$$
  KL 项惩罚第 $h$ 个 horizon 上落在机械臂区域之外的注意力质量，除以 $\log N_v$ 按均匀分布熵归一化。
- 总目标：$\mathcal{L}_{total} = \mathcal{L}_{act} + \lambda_{motion}\mathcal{L}_{motion}$，实现中 $\lambda_{motion}=0.05$。
- **推理时**仅输入 $I_t, l, S_t$，移除掩码渲染与 KL 分支，DiT 去噪直接输出 4 个动作，不重建未来视觉观测，**不引入额外推理开销**。
