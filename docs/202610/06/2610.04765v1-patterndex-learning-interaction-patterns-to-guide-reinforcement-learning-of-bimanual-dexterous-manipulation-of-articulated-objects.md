在本文中，我们开发了一种方法，使双臂灵巧手能够以高成功率操作铰接物体，而不会受到具身差异的影响。我们观察到，手部运动与物体运动之间的相关性由物体而非手部决定，并且可以从人-物演示中学习。基于这一观察，我们提出 PatternDex，一种学习这种相关性并将其表示为 token 序列的方法，我们将该序列称为交互模式。根据该模式，PatternDex 估计适合目标机器人的手腕运动和接触点，然后训练一个利用这些估计作为引导的强化学习策略。由于该引导适合目标具身，策略仅探索目标机器人能够执行的动作，因此实现了高成功率。PatternDex 还可以复用学习到的交互模式，因此只需简单微调即可训练新机器人。我们在 ARCTIC 数据集的人类演示上，用双臂灵巧手评估 PatternDex。PatternDex 在 Allegro 手上平均达到 92.8% 的成功率，而最先进的基线方法达到 52.2%。此外，仅通过微调，它在另外三种机器人手上也达到了 70% 以上的成功率。进一步，我们验证了学习到的策略能够很好地迁移到打开微波炉的真实世界任务中。视频和更多结果可在 https://patterndex.github.io/PatternDex/ 获取。

## Abstract
In this paper, we develop a method that enables bimanual dexterous hands to manipulate articulated objects with a high success rate without suffering from an embodiment gap. We observe that the correlation between hand motions and object motions is dictated by the object rather than the hands and can be learned from human-object demonstrations. Based on this observation, we propose PatternDex, a method that learns this correlation and represents it as a token sequence, which we call an interaction pattern. From this pattern, PatternDex estimates the wrist motions and contact points that fit the target robot, and then trains a reinforcement learning policy that exploits these estimates as guidance. Since the guidance fits the target embodiment, the policy explores only the actions that the target robot can execute and thus achieves high success rates. PatternDex also requires only simple fine-tuning to train a new robot, since it can reuse the learned interaction pattern. We evaluate PatternDex with bimanual dexterous hands on human demonstrations from the ARCTIC dataset. PatternDex achieves, on average, a 92.8% success rate with Allegro hands, while the state-of-the-art baseline achieves 52.2%. Also, it achieves success rates above 70% with three other robot hands after fine-tuning alone. Furthermore, we verify that the learned policy transfers well to a real-world task of opening a microwave. Videos and additional results are available at https://patterndex.github.io/PatternDex/

## 1. 核心问题与整体含义

- **研究背景**：双臂灵巧手操作铰接物体（如开微波炉、笔记本、盒子等）需要协调高自由度手指、手腕和双臂，动作空间大、接触丰富，传统强化学习仅靠奖励难以稳定训练。
- **现有方法痛点**：
  - 遥操作采集机器人数据昂贵、耗时。
  - 运动重定向将人手关节映射到机械手关节，但人手与机械手在尺寸、结构和自由度上差异大，重定向动作可能不可行。
  - ObjDex 等方法只模仿人类手腕运动，虽缓解手指具身差异，但仍把机器人手腕放在人类手腕位姿；较大机械手会超出工作空间，较小机械手够不到物体。
- **核心观察**：在铰接物体操作中，手部运动与物体运动之间的相关性主要由**物体及其期望轨迹**决定，而非由具体手部决定，因此可从人-物演示中学习，并迁移到不同机械手。
- **整体含义**：论文提出 **PatternDex**，学习一种具身无关的“交互模式”（interaction pattern），再据此估计目标机器人可行的腕部运动与接触点，引导强化学习策略训练，从而缓解具身差异、提高成功率并支持跨机械手迁移。

## 2. 方法论

### 2.1 核心思想

- 将人-物演示中“物体轨迹—手腕运动”的关联编码为潜在空间中的 **token 序列**，称为 **交互模式 \(P_I\)**。
- 由于该模式依赖物体而非手部，因此可跨具身复用。
- 给定目标机械手描述，解码器从交互模式中预测适配该机械手的腕部运动和接触点，并用它们引导 RL 策略探索。

### 2.2 预测阶段：交互模式编码器-解码器

- **输入**：
  - 物体状态 \(O_t\)：位置、6D 旋转、铰接角、表面点云。
  - 人类手腕位姿 \(W_t\)：相对物体坐标系的双手 3D 位置和 6D 姿态。
  - 机器人手描述 \(R\)：从 URDF 解析，包含手指/手掌的关节数、连杆长宽等几何属性。
- **编码器 \(E\)**：
  - 空间网络 \(f\) 为 MLP，将 \(O_t\) 与 \(W_t\) 编码为空间 token，并加入层归一化和正弦位置编码。
  - 时间网络 \(T\) 为 Transformer，堆叠 4 层、每层 4 个自注意力头，学习连续帧间物体状态与手腕位姿变化。
  - 最终输出 \(P_I \in \mathbb{R}^{(H+1)\times d}\)，即交互模式，表示每帧手腕相对物体的位姿及其时序演进。
- **解码器 \(D\)**：
  - 通过具身编码器 \(\phi\) 将机器人手描述 \(R\) 转为具身 token \(T_E\)。
  - 将交互模式 \(P_I\) 与 \(T_E\) 拼接为 memory \(M\)。
  - 采用类似 ACT 的 chunk-wise 预测，一次预测 \(H+1\) 帧，文中 \(H=63\)。
  - 解码器含 6 层，每层包含自注意力、对 memory 的交叉注意力和前馈网络。
  - 输出腕部运动 \(\hat{W}\) 和接触点 \(\hat{C}\)。
- **训练**：
  - 使用 ARCTIC 人类演示重定向到多个机器人手，取重定向后的机器人腕部运动 \(W^R\) 和接触点 \(C^R\) 作为监督。
  - 损失为腕部与接触点的均方误差：
    - \(L_{wrist} = \frac{1}{H+1}\sum \|\hat{W}_\tau - W^R_\tau\|_2^2\)
    - \(L_{cont} = \frac{1}{H+1}\sum \|\hat{C}_\tau - C^R_\tau\|_2^2\)
    - \(L_{total} = L_{wrist} + L_{cont}\)
  - 即使重定向结果不精确，后续 RL 策略仍可修正估计误差。

### 2.3 引导策略学习阶段

- 将双臂灵巧操作建模为 MDP：
  - 状态 \(s_t\)：双手本体感知关节角 + 被操作物体状态。
  - 动作 \(a_t = (a^f_t, \Delta a^w_t)\)：手指目标关节角 + 对估计腕部位姿 \(\hat{W}_t\) 的残差修正。
  - 策略输入包括当前状态、参考物体轨迹 \(O_{t:t+H}\) 和估计接触点 \(\hat{C}_{t:t+H}\)。
- 使用 **PPO** 训练策略，目标最大化折扣回报。
- **奖励设计**：
  - **物体奖励 \(r_{obj}\)**：衡量被操作物体与参考物体在位置、旋转、铰接角上的接近程度。
    - \(r_{obj} = \exp(-\lambda_p r_p - \lambda_r r_r - \lambda_j r_j)\)
    - 文中取 \(\lambda_p=20, \lambda_r=2, \lambda_j=2\)。
  - **接触奖励 \(r_{cont}\)**：鼓励机器人手关键点接触估计接触点，并惩罚指尖接触错误位置。
    - 覆盖项 \(r_{cov}\)：目标接触点与机器人手关键点距离越小奖励越高。
    - 惩罚项 \(r_{pen}\)：指尖接触远离目标点时扣分，幅度受限。
    - \(r_{cont} = w_{cov} r_{cov} + w_{pen} r_{pen}\)，文中 \(w_{cov}=0.25, w_{pen}=0.1\)。
  - 总奖励 \(r = r_{obj} + r_{cont}\)。
- **关键作用**：由于引导已适配目标机械手，策略只需探索目标机器人可执行的动作，避免模仿人类不可行动作。

### 2.4 跨具身迁移

- 交互模式 \(P_I\) 与具体手部无关。
- 训练新机器人手时，可冻结编码器 \(E\)，仅微调解码器 \(D\) 和具身编码器 \(\phi\)。
- 文中以 Allegro 训练完整模型，再迁移到 Shadow、Paxini、XHand。
