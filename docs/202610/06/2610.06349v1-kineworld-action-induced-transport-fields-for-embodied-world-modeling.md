## 摘要
具身世界模型在执行前预测候选动作的视觉后果。然而，现有的动作条件世界模型往往采用均匀加权的视觉生成目标，这可能与具身预测需求不一致。即使有显式的运动条件，这些目标也可能低估对交互至关重要的空间稀疏变化。我们提出 KineWorld，一个传输感知的世界建模框架，将机器人运动学从运动条件扩展至生成监督的空间分配。运动学传输提升（KTL）从指令机器人运动中构建由渲染器导出、与相机对齐的传输场。传输感知世界扩散（TAWD）在视频潜变量网格上校准其运动支撑集，并通过均匀分布与以传输为中心的分布的归一化混合来重新加权未来RGB流匹配。我们使用 RoboTwin 2.0 的 ALOHA-AgileX 双臂操作数据训练 KineWorld。KineWorld 在单视角评估中达到 68.95 的 EWMScore-P，在多视角评估中达到 54.82 的 TWB-Score。这些结果支持从外观拟合转向面向具身决策的动作后果建模。

## Abstract
Embodied world models predict the visual consequences of candidate actions before execution. However, existing action-conditioned world models often adopt uniformly weighted visual generation objectives that can be misaligned with embodied prediction needs. Even with explicit motion conditioning, these objectives can underemphasize spatially sparse changes that are critical to interaction. We propose KineWorld, a transport-aware world-modeling framework that extends robot kinematics from motion conditioning to the spatial allocation of generative supervision. Kinematic Transport Lifting (KTL) constructs renderer-derived, camera-aligned transport fields from commanded robot motion. Transport-Aware World Diffusion (TAWD) calibrates their motion support on the video-latent grid and reweights future-RGB flow matching through a normalized mixture of uniform and transport-focused distributions. We train KineWorld using ALOHA-AgileX bimanual manipulation data from RoboTwin 2.0. KineWorld achieves an EWMScore-P of 68.95 in single-view evaluation and a TWB-Score of 54.82 in multi-view evaluation. These results support a shift from appearance fitting toward action-consequence modeling for embodied decision-making.

- **背景**：World Action Models（WAMs）旨在让机器人在真实执行前预测候选动作的视觉后果，可作为策略学习、动作评估、规划与合成经验生成的预测模拟器。近期大规模视频生成模型提供了外观与动力学先验，使从有限具身数据构建逼真机器人 rollout 成为可能。
- **核心问题**：现有动作条件世界模型普遍采用**均匀加权（uniform weighting）的 RGB 生成目标**。当动作响应区域（如机械臂、夹爪与交互物体）只占画面中很小一部分 token 时，均匀 token 平均会把优化重心偏向静态外观，**低估对交互至关重要的空间稀疏变化**。
- **关键洞察**：论文区分了「动作条件（action conditioning）」与「监督分配（supervision allocation）」两个不同目的——前者决定**生成什么运动**，后者决定**哪些预测误差获得更大权重**。已有工作（数值动作 token、隐式编码、embodiment mask、动作图像、光流、投影运动学场等）改进了前者，但这些运动条件本身**并不改变主 RGB 目标的逐 token 空间权重**。

## 二、方法论

### 2.1 总体框架
- KineWorld 是一个基于潜空间视频世界模型（Wan2.2-TI2V-5B 初始化）的传输感知训练框架，输入为初始观测、语言指令、候选动作序列，输出未来 RGB 视频。
- 两个组件：
  - **KTL（Kinematic Transport Lifting）**：构建相机对齐的传输场，并把其潜表示作为**干净结构条件**注入生成器（训练与推理均使用）。
  - **TAWD（Transport-Aware World Diffusion）**：从传输场校准运动支撑，构造归一化 token 权重以重加权流匹配目标（**仅训练时使用**）。

### 2.2 问题建模与预备（条件流匹配）
- 一个 episode 包含 RGB 观测 {I_t}、机器人构型 {q_t}、语言指令 c、动作轨迹 A；双臂设定下 a_t ∈ R^14（每臂 6-DoF 绝对末端位姿 + 1 个夹爪命令）。
- 视频 VAE 将 K 帧片段编码为 z_x = [z_x,cond, z_x,fut]，仅对**未来 RGB 潜变量**加噪（首帧保持干净并排除出损失）。
- 标准流匹配对所有未来 token 误差 e_i 做均匀平均：L_FM = E[ (1/N) Σ_i e_i ]。

### 2.3 KTL：运动学传输提升
- **前向运动学 rollout**：从初始构型 q_s 出发，用 embodiment 控制器执行指令动作序列，得到 q̂_j，仅依赖初始构型、指令末端目标与控制器，**不使用未来 RGB**。文中 K=9 关键帧、时间步长 δ=4（覆盖 32 个控制转移）。
- **渲染器导出传输**：固定渲染器生成 robot-only RGB 帧 R_j 与可见机器人掩码 M_j（固定背景纹理以稳定对应估计）；相邻帧之间用 **RAFT** 估计前向位移，并用源帧机器人掩码限制支撑：
  - u_j = 0 (j=0)，u_j = M_{j−1} ⊙ RAFT(R_{j−1}, R_j)（j≥1）。
- **视频原生传输条件**：把位移方向编码为色相、裁剪后的幅值编码为饱和度（零位移映射为白色），生成 HSV→RGB 的传输视频 G_j，再单独用 VAE 编码为 z_u。
- **干净传输条件**：RGB 潜变量走流匹配加噪路径，传输潜变量全程保持干净；RGB 与传输 token 分别 patchify、加流标识、赋予对齐时空位置，通过**联合自注意力**在去噪全过程中交互。

### 2.4 TAWD：传输感知世界扩散
- **潜空间传输支撑校准**：定义有界活动图 r_j(p) = clip(‖u_j(p)‖₂ / M_px, 0, 1)（M_px=25）；用固定、非学习的平均池化算子 P_lat 按 VAE 压缩比下采样并对齐到 RGB 潜网格，得到 d ∈ [0,1]，且用 **stop-gradient** 阻断（d 从原始传输而非学习到的传输潜变量计算，避免传输编码器自适应监督权重）；r_0 = 0、d_0 = 0。
- **预算归一化流匹配**：
  - 传输分布：ρ_tr_i = d_i / S_d（S_d > ε_sup），否则退化为均匀 1/N（零运动回退）。
  - 权重：α_β = β/(1+β) ∈ [0,1)，w_i = N[(1−α_β)/N + α_β ρ_tr_i]，满足 (1/N)Σw_i = 1（**均值归一，保持总 token 权重不变**）。
  - β=0 时 w_i ≡ 1，**精确退化为均匀流匹配**；无有效传输时同样退化为均匀。
  - 目标：L_Kine = E[ (1/N) Σ_i sg(w_i) e_i ]，即只**重新分配**监督，不改变总量。
- **辅助动作目标**：保留继承的动作头，作用于 stop-gradient 的 world model 特征，参数集与生成器不相交，故 ∇_θwm L_act = 0；总损失 L = L_Kine(θ_wm) + λ_act L_act(θ_act; sg(H_θwm))。
- **训练/推理差异**：训练时 TAWD 从渲染传输推导支撑并重加权；推理时不需要支撑校准与损失加权分支，干净传输潜变量仍作为结构条件，**不增加推理参数与去噪步数**。
