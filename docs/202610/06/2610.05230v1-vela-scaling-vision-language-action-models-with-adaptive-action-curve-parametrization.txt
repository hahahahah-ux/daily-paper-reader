## ABSTRACT 

Most vision-language-action models represent future motion as fixed-rate action chunks, tying temporal resolution and prediction horizon to a fixed output bud-get. This pointwise representation wastes capacity on highly correlated neigh-boring actions, leaves temporal continuity and smoothness to be learned implic-itly, and forces a tradeoff between long-horizon coverage and the local preci-sion required for contact-rich manipulation. To address these limitations, we in-troduce Vela, a vision-language-action foundation model that represents future robot behavior as continuous trajectories. Vela combines a compact spline-based action representation with motion-dependent temporal support and a shared ac-tion interface for heterogeneous embodiments, allowing a fixed output budget to adapt its temporal resolution across motions. We pretrain Vela on large-scale multi-embodiment robot data and evaluate it on LIBERO-X, EBench, and two real-world long-horizon tasks, egg-cake cooking and potato shredding, obtain-ing promising results across simulation and physical manipulation. These re-sults highlight the potential of continuous action representations as a founda-tion for future embodied foundation models. Project page and more results:

## 1 INTRODUCTION 

Vision–Language–Action (VLA) models are rapidly scaling to larger datasets, broader task distribu-tions, and more diverse robot embodiments (Intelligence et al., 2026; Yuan et al., 2026a; Ma et al., 2026). Yet most VLAs still represent future motion as a fixed-length sequence of actions sampled on a predetermined temporal grid. This pointwise interface assigns separate prediction capacity to highly correlated neighboring actions and couples the output budget to both prediction horizon and temporal resolution: representing a longer future requires more action points, while a fixed budget forces coarser sampling. Conversely, spreading the same budget over a long horizon can remove the local precision needed for contact-rich manipulation. Because temporal continuity is learned implicitly, execution also relies on a predefined sampling grid. These limitations reflect a mismatch between current VLA representations and the objects they control: robot actions are not isolated points but samples from continuous motions. A trajectory-level representation provides a more natural action space. Instead of predicting every temporal sample, a policy can predict a compact set of parameters that defines a continuous trajec-tory and query that trajectory at the desired temporal locations. This representation compresses cor-related actions, exposes temporal continuity, and decouples trajectory geometry from the time span over which it is executed. The same fixed parameter budget can therefore describe a long, smooth motion or a short, finely resolved one, while supporting different control frequencies. Splines pro-vide a practical realization of this idea: a small set of control points specifies a continuous curve that can be evaluated on arbitrary temporal grids.

Recent learning-based policies have explored dynamical-system parameterizations (Bahl et al., 2020), differentiable trajectory op-timization (Wan et al., 2024), and geometric curve representations (Li et al., 2026). Spline-based policies have further studied compact action tokenization, asynchronous execution, and temporal rescaling (Zhou et al., 2025; Yang et al., 2026; Han et al., 2026). These studies show the value of structured motion representations, but they mainly focus on task-specific policies, individual robot platforms, or downstream action tokenization and execution. Whether trajectory-level action model-ing can serve as the output space for foundation-scale VLA pretraining across large, heterogeneous robot datasets remains largely unexplored. To address this gap, we build a VLA that learns future motion in trajectory space and make this rep-resentation trainable at foundation scale. A shared cross-embodiment action interface and scalable supervision procedure allow the same model to absorb heterogeneous robot corpora. We further make the temporal span of each prediction motion-dependent: with a fixed number of spline control points, each demonstrated motion is assigned a sample-specific horizon by selecting the longest span that adequately represents it under a noise-aware criterion. Smooth motions can therefore use longer spans, whereas motions with rapid local variation can use shorter spans without changing the output budget. We train this framework on large multi-embodiment robot data and evaluate its transfer to downstream manipulation tasks. Our main contributions are: • We show how trajectory-space action modeling can be scaled to VLA pretraining through a shared cross-embodiment action interface and a training procedure designed for large heterogeneous robot corpora. • We introduce motion-dependent horizon adaptation, selecting for each demonstrated mo-tion the longest temporal span that a fixed spline budget can represent under a noise-aware criterion. • We evaluate the framework with controlled comparisons, downstream manipulation bench-marks, and ablations, showing improvements from trajectory-space modeling, large-scale pretraining, and horizon adaptation, particularly under contact-rich, long-horizon, and distribution-shifted tasks. 

## 2 RELATED WORK 

Vision-Language-Action Foundation Models. Extensive research on vision-language models has advanced cross-modal alignment and downstream visual reasoning (Li et al., 2024; 2025). Build-ing on this progress, vision-language-action (VLA) foundation models scale robot learning across heterogeneous tasks, data, and embodiments by coupling pretrained vision-language representa-tions (Beyer et al., 2024; Bai et al., 2025) with generalist action policies (Team et al., 2024; Black et al., 2024; Bjorck et al., 2025). Recent systems further improve cross-task and cross-embodiment generalization through heterogeneous co-training, embodiment alignment, and predictive supervi-sion (Intelligence et al., 2025; 2026; Yuan et al., 2026a; Zheng et al., 2026; Cai et al., 2026a; Ma et al., 2026; Zhou et al., 2026; Wang et al., 2026c); related robot-control work also studies structured visual representations (Jiang et al., 2026; Wang et al., 2024). Yet the low-level motion interface of modern chunk-based VLAs remains largely organized around fixed-resolution sequences of sampled future actions. Recent work begins to relax this temporal rigidity: MoH (Jing et al., 2025) models multiple prediction horizons, while AutoHorizon (Wang et al., 2026b) and AAC (Liang et al., 2026) use attention patterns and action entropy to determine execution lengths. These methods still op-erate on sampled action sequences. In contrast, Vela makes temporal support part of the action representation itself, using a fixed set of control points to parameterize continuous trajectories with motion-adaptive future spans.

## 3 METHODOLOGY 

We develop Vela by treating demonstrated actions as samples of a continuous trajectory and learning to predict a compact representation of that trajectory. Building on this formulation, we describe the policy, construct motion-dependent horizons, and scale training to heterogeneous robot data. 3.1 PRELIMINARIES : W HAT SHOULD A VLA PREDICT ?

Action prediction. Conventional VLA policies represent future motion as an action chunk condi-tioned on the current observation and instruction. At timestep t, let zt = ( vt, st, ℓ ) denote the mul-timodal policy context, consisting of visual observations vt, proprioceptive state st, and a language instruction ℓ. A conventional Vision-Language-Action (VLA) policy parameterizes a conditional distribution over a future action chunk, 

At,H ∼ πθ (· | zt) At,H = [ at, at+1, . . . , at+H−1]⊤ ∈ RH×da , (1) where H is the prediction chunk horizon and da is the action dimension. Regardless of the generative objective, this representation describes motion through its values on a discrete temporal grid. 

From actions to trajectories. We instead view a demonstrated action chunk as a sampled realization of an underlying continuous motion. For a given future window, let γt : [0 , 1] → Rda denote its 

latent intended trajectory, and write the recorded actions as

This view separates the motion to be represented from a particular noisy recording of it. Trajectory prediction. Rather than representing future motion by samples on a fixed temporal grid, Vela parameterizes each future motion by two complementary quantities: its geometry and its temporal span. The geometry is parameterized by a set of N control points C, which specify the curve, while a scalar horizon H specifies its extent in action steps. We model them jointly as y = ( C, H ) and predict them from y1. In implementation, H occupies an additional scalar output channel alongside the control-point coordinates. Thus, the number of predicted control points remains fixed, while the span of future motion they describe can vary with the context.

With N fixed, different temporal spans induce different allocations of the same representational capacity. Extending the horizon H distributes the same curve parameters over more action steps. This suits smooth, directionally consistent behaviors such as reaching and transport. Conversely, contact, alignment, and rapid corrective motion may require concentrating the parameters over a shorter interval to preserve local temporal variation. Existing spline-based policies typically predict over a globally fixed temporal span (Zhou et al., 2025; Tian et al., 2026; Yang et al., 2026), imposing a single compromise between temporal coherence and local expressivity across all motions. We instead formulate this trade-off as a horizon-selection problem and seek the longest temporal span that remains sufficient for the demonstrated motion. Let H denote the candidate horizons, each satisfying H > N :

H⋆ = max {H ∈ H : ψ(H) ≤ κ}, (6) where ψ(H) measures whether the demonstrated motion is adequately represented at span H and 

κ is a shared tolerance. The central problem is therefore to construct ψ(H) such that insufficient temporal resolution can be distinguished from variation already inherent in the demonstrations.

At deploy-ment, no fitting or horizon search is performed: The policy predicts both quantities from the current context. 3.4 TRAJECTORY -S PACE PRETRAINING AND OBJECTIVES 

We extend the target construction above to large-scale trajectory-space pretraining through a shared action representation and flow-matching objective. The action interface accommodates different embodiments, while source-specific normalization accounts for differences in motion statistics. 

Shared action space. To scale training across heterogeneous robot datasets, we map all data sources to a shared da = 26 dimensional action-path space. Each arm contributes 10 dimensions describing end-effector motion, including 3-D translation, 6-D rotation, and a 1-D gripper command. The remaining 6 dimensions describe the head, waist, and base motion with two coordinates each. Per-dimension validity masks exclude unavailable coordinates from target selection and supervision. Each source uses its own per-coordinate affine quantile normalization and estimates its noise scales 

ˆσj in the same normalized coordinates. This allows the shared tolerance κ to act on a dimensionless, noise-normalized statistic rather than on source-dependent raw errors. Because spline fitting acts along time and independently across action coordinates, the same fixed bases and horizon adaptation procedure apply throughout the training mixture. 5Preprint

## 4 EXPERIMENTS 

4.1 EXPERIMENTAL SETUP 

Implementation Details. Vela follows the π0.5 (Intelligence et al., 2025) architecture, comprising a 3B PaliGemma (Beyer et al., 2024) vision-language backbone and a 300M flow-matching action expert, without introducing additional trainable parameters. Our study examines trajectory-space action modeling at scale without relying on a larger network or benchmark-specific input. Starting from pretrained PaliGemma weights, we pretrain Vela directly in trajectory space on approximately 20,000 hours of public robot data from 60 datasets spanning 11 embodiment classes, together with approximately 20,000 hours of private robot data. For comparison, we also introduce π0.5-Vela, which is initialized from the same π0.5 base checkpoint as the point-wise baseline. It applies our tra-jectory representation and supervision during benchmark-specific post-training, without undergoing our trajectory-space pretraining stage. We map each data source to the shared 26-D action-path interface described in Sec. 3.4, with source-specific normalization and per-dimension validity masks. We use cubic B-splines with a fixed budget of N = 12 control points and candidate horizons H = {16 , 17 , . . . , 40 }. At inference time, the conditional flow is integrated using 10 Euler steps. Additional training and implementation details are provided in Appendix. B.1. 

Benchmarks and Evaluation. We evaluate Vela on two complementary simulation benchmarks, LIBERO-X and EBench, and through real-world experiments on a wheeled dual-arm robot with 7-DoF arms and three cameras mounted on the head and wrists. The real-world study considers two long-horizon tasks that require bimanual coordination, tool use, and contact-rich manipulation. We report the egg-cake cooking task and potato-shredding task in Sec. 4.3 and Appendix D, respectively. 

LIBERO-X (Wang et al., 2026a) is a MuJoCo-based tabletop manipulation benchmark evaluating generalization across five levels of progressively stronger spatial, visual, and instruction perturba-tions. We report success rate (SR) at each level and overall. EBench (Gao et al., 2026) is an Isaac Sim benchmark for generalist dual-arm mobile manipulation, comprising 26 tasks across three com-plementary regimes. Its evaluation covers background, object, instruction, and mixed distribution shifts. We report SR and the official task-progress Score for each task family and overall. For each simulation benchmark, we follow its official π0.5 fine-tuning recipe and evaluation protocol. Simulation Evaluation on LIBERO-X. LIBERO-X evaluates robust manipulation under progres-sively stronger distribution shifts. As shown in Tab 1, Vela achieves the highest average performance among the compared methods. Its advantage over π0.5 is more pronounced at levels 3 to 5 than at levels 1 and 2, indicating that the gains extend to stronger distribution shifts. Introducing trajectory-space modeling during benchmark post-training also improves performance. Starting from the same base checkpoint and using the same fine-tuning recipe as π0.5, π0.5-Vela improves SR at every level and reaches 42 .0% on average, compared with 39 .3% for the point-wise baseline. The results support trajectory-space action modeling for both adapting an existing VLA and pretraining a robot policy over heterogeneous robot data. 

Simulation Evaluation on EBench. EBench evaluates generalist manipulation under diverse con-trol demands, spanning dexterous-and-precise tabletop interaction involving sub-centimeter inser-tion, alignment, and bimanual coordination, mobile pick-and-place (PnP), and long-horizon mobile 

tasks composed of extended multi-stage sequences. As shown in Tab. 2, Vela achieves the highest overall SR and task-progress Score among the compared methods, and leads both metrics on PnP and Long-Horizon tasks. Relative to π0.5, its largest improvement occurs on dexterous-and-precise tabletop manipulation, which demands fine-scale motion representation. Trajectory space fine-tuning variant π0.5-Vela also improves overall performance to 42 .0% SR and a Score of 58 , with family-wise improvements on both Table Top and PnP tasks. Additionally, Vela, pretrained directly in trajectory space, outperforms both π0.5 and π0.5-Vela on all metrics. These re-sults demonstrate the breadth of the pretrained trajectory-space policy across precision-intensive in-teraction and extended execution, rather than an advantage confined to a single manipulation regime. ① Can Post-hoc Trajectory Fitting Recover the Gains? Since trajectory fitting can provide a continuous path for action resampling, one may ask whether the benefit of Vela can simply come from a smoother trajectory. To test this, we compare two ways of introducing trajectory structure from the same π0.5 base checkpoint. The post-hoc baseline retains action chunk prediction during post-training, then fits and resamples a spline at inference. In contrast, π0.5-Vela learns to predict trajectory parameters during post-training. Alongside the official 10-step configuration, we retrain a π0.5 baseline to support execution of up to 25 actions per prediction, the largest per-observation execution steps supported by the official evaluator. As shown in Tab. 3, post-hoc fitting alone does not recover the gains of Vela’s modeling under all execution settings. This advantage is observed without our trajectory-space pretraining stage, supporting the value of learning trajectory parameters itself rather than imposing spline structure only after point-wise action prediction. 

② Does Motion-Dependent Horizon Adaptation Matter? We next isolate the contribution of motion-dependent horizon adaptation from Vela’s modeling. We compare a globally fixed horizon with motion-dependent adaptive horizon while retaining the same spline representation and control-point budget. As shown in Tab. 4, Vela’s modeling provides gains even under a fixed temporal support, and horizon adaptation further raises performance at every level. This result supports al-lowing the same trajectory capacity to cover different temporal spans, rather than imposing a uniform temporal allocation on every predicted motion. 

③ Control Point vs. Decoded Trajectory Supervision. CP-FM and DT-FM supervise the same control-point flow residual with different metrics: CP-FM uses Euclidean distance in parameter space, whereas DT-FM measures the residual after spline decoding. We compare CP-FM, an equal-weight combination of CP-FM and DT-FM, and DT-FM alone. All three objectives yield effective policies, with DT-FM achieving the highest average SR in Tab. 5. The modest differences suggest that effective trajectory-space learning is not contingent on a particular loss composition; decoder-aware weighting provides a useful refinement rather than a prerequisite. ## 5 CONCLUSION 

We introduced Vela, a trajectory-space vision-language-action foundation model designed to ad-dress the limitations of fixed-rate action chunks. It predicts cubic B-spline control points together with a motion-dependent temporal span, using a shared action interface and scalable target con-struction to represent heterogeneous robot motion as continuous trajectories. Our experiments show that native trajectory-space learning improves action modeling, while post-hoc spline fitting is in-sufficient. Motion-dependent temporal support lets a fixed representation adapt its resolution to different motions, and decoder-aware supervision and large-scale heterogeneous pretraining further improve transfer across precision, mobile, and long-horizon tasks. Experiments on two real-world manipulation tasks further show that trajectory-space action modeling transfers beyond simulation to multi-stage bimanual manipulation involving tool use and sustained physical contact. Overall, these results support continuous trajectories as a promising action representation for future embod-ied foundation models.

## B ADDITIONAL IMPLEMENTATION DETAILS 

B.1 TRAJECTORY -S PACE PRETRAINING DETAILS 

This section describes the large-scale trajectory-space pretraining of Vela from pretrained PaliGemma VLM weights. π0.5-Vela does not undergo this stage: it is adapted from the π0.5 base checkpoint using the benchmark-specific post-training procedures below. Vela is optimized with AdamW ( β1 = 0 .9, β2 = 0 .95 , ϵ = 10 −8, weight decay 10 −10 ) and global gradient clipping at 1.0. The learning rate is linearly warmed up to 5 × 10 −5 over the first 10k optimization steps and kept constant thereafter. We apply a 0.5× learning-rate multiplier to the PaliGemma backbone, corresponding to 2.5 × 10 −5, while the action expert and output projection use the full learning rate. Training proceeds for 300k optimization steps. Normalization statistics are computed independently for each data source and action dimension using a quantile transform that maps the 1st and 99th percentiles to [−1, 1] , while unavailable action dimensions are excluded from supervision through validity masks. For adaptive target construction, only the two gripper coordinates are treated as event channels; all remaining valid action coordinates use the noise-calibrated adequacy criterion. We set the global adequacy threshold to κ = 2 .5 and the event-channel reconstruction tolerance to η = 0 .05 .Training is distributed over 64 NVIDIA H200 GPUs using FSDP with gradient checkpointing, with 24 samples per GPU, yielding a global batch size of 1,536. Transformer computation runs under bfloat16 autocast, while B-spline target construction, flow interpolation, and loss computation run in fp32 for numerical stability. ## E LIMITATIONS 

Vela provides a starting point for exploring how trajectory-space action modeling scales with model capacity and training data. The present study uses a model at the scale of π0.5, leaving larger vision-language backbones and more extensive pretraining as natural extensions. Studying these settings would help characterize how the benefits of trajectory-space modeling evolve with model size and data coverage. Expanding the action expert offers a complementary direction within the same con-tinuous trajectory interface. Building on the base-model capacity used here, larger or specialized action experts could be explored for fine contact dynamics and long-horizon bimanual coordination. Evaluating these designs would clarify how additional action-expert capacity affects the generation of trajectories for demanding manipulation tasks. A further direction is to adapt representation ca-pacity to motion complexity. The current policy adapts the temporal horizon while keeping the number of control points fixed. Allowing both quantities to vary could allocate compact represen-tations to smooth motions and additional detail to more complex trajectories. This extension would require variable-length prediction and corresponding training objectives to balance representation efficiency with motion fidelity. 18
