## 摘要
视觉-语言-动作（VLA）模型能够编码来自视觉-语言预训练的语义信息，但操作任务还需要精确的空间推理。我们提出 GeoBridge-VLA，一种两阶段方法，用于从预训练 VLA 的冻结视觉编码器中学习几何特征，并将其用于动作预测。第一阶段在深度监督下训练特征桥接模块和几何解码器。第二阶段冻结这些模块，并训练门控残差接口以及动作侧投影和动作专家。该残差对现有视觉 token 进行增强，而无需增加第二个图像编码器，也不增加 token 数量。部署时仅需 RGB、机器人状态和语言，无需深度观测。在匹配的评估条件下，GeoBridge-VLA 在 LIBERO 上取得 70.9% 的成功率，而 SmolVLA 为 60.0%。在同一训练检查点中禁用该残差后，成功率从 70.90% 降至 69.85%，且在不同套件上效果不一。在实体 ROBOTIS OMY 机器人上，GeoBridge-VLA 在四项任务中共 200 次试验中成功 148 次（74.0%），而 SmolVLA 为 200 次中成功 108 次（54.0%）。

## Abstract
Vision-language-action (VLA) models encode semantic information from vision-language pretraining, but manipulation also requires precise spatial reasoning. We present GeoBridge-VLA, a two-stage method for learning geometric features from a pretrained VLA's frozen visual encoder and using them for action prediction. Stage I trains a feature bridge and geometry decoder with depth supervision. Stage II freezes these modules and trains a gated residual interface together with the action-side projections and action expert. The residual augments the existing visual tokens without adding a second image encoder or increasing the token count. Deployment requires RGB, robot state, and language, but no depth observations. Under matched evaluation conditions, GeoBridge-VLA achieves 70.9% success on LIBERO, compared with 60.0% for SmolVLA. Disabling the residual in the same trained checkpoint reduces success from 70.90% to 69.85%, with mixed effects across suites. On a physical ROBOTIS OMY robot, GeoBridge-VLA succeeds in 148 of 200 trials (74.0%) across four tasks, compared with 108 of 200 (54.0%) for SmolVLA.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型通过视觉-语言预训练获得强语义先验，能识别物体、理解指令并泛化到多样场景。但机器人精细操作还依赖深度、相对位置、物体范围、局部空间关系等几何信息。
- **核心问题**：主要面向语义对齐优化的表示，未必能精确保留物理交互所需的几何信息。现有几何增强 VLA 方法通常依赖显式深度/3D 观测、外部空间表示、标定相机几何、辅助几何监督，或引入第二个图像编码器、额外几何 token，甚至部署时需要深度输入。
- **论文主张**：提出“几何改造”（geometry retrofit）问题——能否在不增加第二个图像编码器、不增加 token 数量、部署不使用深度的前提下，从预训练 VLA 的冻结视觉层级中学习深度监督的几何特征，并迁移到动作预测。
- **整体含义**：GeoBridge-VLA 验证了冻结 VLA 视觉编码器可作为几何适配基底，通过两阶段“几何获取—几何到动作迁移”提升操作成功率，同时保持部署接口不变。

## 2. 方法论

- **核心思想**：两阶段训练。
  - **Stage I**：冻结原生 VLA 视觉编码器，用深度监督训练特征桥接模块和 K4 几何解码器。
  - **Stage II**：冻结桥接与解码器，训练门控残差接口、动作侧投影和动作专家，将几何特征以残差形式注入原生视觉 token。
- **关键技术细节**：
  - **特征桥接**：对选定中间视觉特征 \(F^\ell\) 做空间重采样 \(S\)，再经层特定线性投影 \(B^\ell\) 得到 \(H^\ell\)，送入 K4 几何解码器 \(D_{geo}\)，输出深度预测 \(\hat d\) 和几何特征图 \(g\)。
  - **K4 几何解码器**：基于 SPACE-CLIP，采用固定局部 token 聚合；每个聚合阶段从四个固定邻域位置双线性采样，使用内容依赖的 softmax 权重混合，再经门控残差连接更新解码器特征。
  - **Stage I 深度损失**：尺度不变对数深度损失（SILog）+ 结构相似性损失（SSIM）+ 多尺度辅助 SILog 监督。
  - **深度监督来源**：LIBERO 使用模拟器真值深度；OMY 真机使用冻结的 Depth Anything 3 教师生成伪深度。教师仅用于训练，部署时移除。
  - **Stage II 残差接口**：将几何特征图 \(g\) 池化到原生 patch 网格，经可学习 \(1\times1\) 卷积 \(R_\omega\) 投影，得到残差 \(\Delta z = \alpha R_\omega(\mathrm{Pool}(g))\)，并加到原生视觉 token 上：\(\tilde z = z + \Delta z\)，其中门控 \(\alpha=\sigma(\eta)\)。
  - **恒等初始化**：\(R_\omega\) 权重和偏置初始化为零，初始门控 \(\alpha_0\approx0.002\)，因此初始时 \(\Delta z=0\)、\(\tilde z=z\)，Stage II 从原生视觉表示精确起步。
  - **Stage II 损失**：流匹配损失 + 残差惩罚 \(L_{res}=\mathrm{pmean}(\Delta z^2)+\epsilon\)，抑制对原生视觉表示的过度改变。
  - **训练范围**：Stage II 仅训练残差接口、动作侧投影和原生动作专家；视觉编码器、视觉投影器、VLM、桥接、几何解码器均冻结，且不使用深度监督。
- **部署特点**：仅需 RGB、机器人状态和语言，不需要深度观测；不增加视觉 token 数量，保留原生条件路径。

## 3. 实验设计

- **数据集与场景**：
  - **LIBERO**：四个操作套件 Spatial、Object、Goal、Long。Stage I 使用 LIBERO 衍生的 RGB-D 集合与米制深度监督；Stage II 使用 HuggingFaceVLA LIBERO 集合，含 1,693 条演示、273,465 个动作帧。
  - **真机 ROBOTIS OMY**：四个任务：T1 红色方块转移、T2 关闭抽屉、T3 碗转移、T4 按大小堆叠方块。每任务采集 50 条演示，记录前视与腕部 RGB、机器人状态和动作。Stage I 使用 DA3 生成伪深度。
- **Benchmark 与评估协议**：
  - LIBERO：40 个任务，每套件 10 任务，每任务 50 回合，每套件 500 回合，总计 2,000 回合；报告各套件成功率与未加权平均。
  - OMY：每任务 50 次匹配自主试验，共 200 次；相同初始配置、指令、相机设置、执行限制和成功标准；完整任务无人工干预才算成功。
  - 深度预测：在 LIBERO 前视验证集上报告 AbsRel、RMSE（米）、\(\delta_1\)。
  - 残差干预：同一训练检查点下，推理时启用残差（normal）与禁用残差（zero，\(\Delta z=0\)）对比。
- **对比方法**：
  - 主要基线：SmolVLA，使用相同动作数据和策略训练条件。
  - 深度预测对比：DA3-Mono-Large。
  - 附录独立深度对比：SPACE-CLIP V1 与 SPACE-CLIP V2，在相同冻结 CLIP ViT-B/16 编码器、相同训练对和任务不相交测试集下比较。
