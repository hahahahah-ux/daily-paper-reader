## 摘要
长时程组合式操作对真实世界机器人部署日益重要，其中单个任务涉及多个协调的子任务。现有的世界-动作模型（WAMs）联合预测短时程视觉未来和动作，但通常缺乏显式的子任务级推理。我们提出视觉目标条件动作推理（ViGAR），这是一种分层框架，将操作分解为视觉子目标规划器和子目标执行器。给定当前观测和全局指令，子目标规划器预测下一子任务的视觉子目标。子目标执行器随后以预测的子目标为条件，联合生成未来视觉轨迹和动作。两个组件共享一个预训练的世界模型表征，使任务级规划和动作生成能够受益于共同的物理知识。此外，我们的框架天然支持上下文学习：使用全局目标图像作为上下文，无需参数更新即可诱导不同的子任务分解和行为。在 RoboTwin Clean2Random 基准上，ViGAR 在 Clean 和 Random 设置下分别达到 82.00% 和 67.02% 的成功率，平均成功率超过最强基线 12.86 个百分点。在五项组合式任务和两项上下文学习任务上的真实机器人实验进一步证实了 ViGAR 的有效性。

## Abstract
Long-horizon compositional manipulation has become increasingly important for real-world robot deployment, where a single task involves multiple coordinated subtasks. Existing world-action models (WAMs) jointly predict short-horizon visual futures and actions, but typically lack explicit subtask-level reasoning. We propose Visual Goal-conditioned Action Reasoning (ViGAR), a hierarchical framework that factorizes manipulation into a visual subgoal planner and a subgoal executor. Given the current observation and global instruction, the subgoal planner predicts a visual subgoal for the next subtask. The subgoal executor then jointly generates future visual trajectories and actions conditioned on the predicted subgoal. Both components share a pretrained world-model representation, enabling task-level planning and action generation to benefit from common physical knowledge. Moreover, our framework naturally supports in-context learning: using a global goal image as context can induce different subtask decompositions and behaviors without parameter updates. On the RoboTwin Clean2Random benchmark, ViGAR achieves 82.00% and 67.02% success rates under the Clean and Random settings, respectively, surpassing the strongest baseline by 12.86 percentage points in average success rate. Real-world robot experiments on five compositional and two in-context learning tasks further confirm the effectiveness of ViGAR.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：真实生产/服务场景中的机器人越来越多面对**长时程组合式操作**（long-horizon compositional manipulation）——单个任务由多个需顺序协调的子任务构成（如"堆叠纸杯"含抓取、叠放、换杯等多阶段）。这类任务要求策略既能在子任务间维持进度，又要泛化到未见过的场景、物体与空间布局，而非复现训练时的固定动作序列。
- **现有范式及其缺口**：世界-动作模型（WAM）通过联合预测短时程视觉未来与动作，从稠密视频监督中学到物理落地的动作动力学，在跨任务、跨环境、跨本体与视觉分布偏移上表现优异。但 WAM 只提供"下一步会发生什么"的**局部控制信号**，**缺少显式的子任务级推理**，也没有一个可指定任务推进意图的**任务级接口**。
- **对比路线的局限**：另一类工作把决策外包给语言规划器（VLM 把任务拆成语言子任务再交给策略执行），但**语言子任务描述往往无法无歧义地指定精确的空间结果**，而视觉子目标对目标场景构型施加了更强的约束。
- **核心洞察**：组合式操作可分解为**长期未来选择**（选定意图达成的目标状态）与**短期未来实现**（生成使之发生的动作）。因此 WAM 应先显式给出机器人意图实现的目标状态，再生成动作。
- **整体含义**：论文提出 ViGAR（Visual Goal-conditioned Action Reasoning），把**子目标图像作为连接任务级推理与物理动作生成的显式决策变量**，并进一步指出：显式目标条件化可自然涌现**上下文学习（ICL）**能力——固定场景与指令、只更换全局目标图像，即可在**不更新任何参数**的情况下诱导出训练中未出现的子任务分解与行为重组。

## 2. 方法论

### 2.1 核心思想
- 分层框架，将组合任务 T = (T₁, …, Tₙ) 分解为：
  - **子目标规划器 G_θ**：给定当前观测 oₜ 与全局指令 ℓ，预测下一子任务的**视觉子目标图像** ĝᵢ（任务级推理）。
  - **子目标执行器 π^WAM_φ**：以 (oₜ, sₜ, ℓ, ĝᵢ, μ) 为条件，**联合预测未来视觉轨迹与动作块**（物理实现）。
- 两个组件均从**同一个预训练世界模型**（Cosmos3-Nano，16B-A8B 全模态世界模型，双分支 Mixture-of-Transformers：reasoner 分支处理语言/语义视觉 token，generator 分支以 flow matching 生成图像/视频，二者通过共享多模态注意力交互）初始化，从而共享物理知识。

### 2.2 关键技术细节

**（a）子目标规划器：把规划当作图像编辑问题**
- 设计选择：**固定 ℓᵢ = ℓ**，不为每个阶段生成子任务文本。理由是子目标图像已提供精确的目标状态 grounding，保留全局指令可作一致的语义锚点，同时避免子任务文本生成的误差累积。
- 训练对 (oₜ, ℓ, gᵢ) 由子任务分段的机器人演示构造，每段以其目标帧结尾。
- **子目标前瞻规则（subgoal look-ahead）**：子任务 Tᵢ 末端的帧在视觉上可能与 Tᵢ₊₁ 早期帧相似，但二者目标不同（gᵢ vs gᵢ₊₁）。若无修正，推理时规划器会混淆，重新生成 gᵢ 并把计划拉回已完成的子任务。规则为：若 oₜ 位于 Tᵢ 的**最后 p%** 且 i < n，则目标改为 gᵢ₊₁，否则为 gᵢ。
- **末端执行器 ROI 加权**：由于操作相关变化集中在末端执行器附近，将专家末端执行器位置经标定相机投影，取固定窗口并集构成二值掩码 mᵢ，面积池化到潜空间分辨率得到 m̃ᵢ；权重 wᵢ(u) = (1 + λ·m̃ᵢ(u)) / [ (1/|Ω|) Σ(1 + λ·m̃ᵢ(u′)) ]，并归一化使 Σwᵢ(u)/|Ω| = 1。
- **规划损失（加权 flow matching）**：令 x⁰_g = E_v(gᵢ)、zₜ = E_v(oₜ)，构造 x^τ_g = (1−τ)x⁰_g + τϵ，流匹配目标 v_plan = ϵ − x⁰_g，则 L_Plan = E[ ‖√wᵢ ⊙ (G_θ(x^τ_g, τ | zₜ, ℓ) − v_plan)‖²₂ ]。
- 训练时**冻结 reasoner 分支**，只更新 generator 侧参数。

**（b）子目标引导的世界-动作模型**
- 联合 flow matching：x⁰_v = E_v(O_{t+1})、x⁰_a = A_{t+1}，加噪得 x^τ_v、x^τ_a，目标 v_vid = ϵ_v − x⁰_v、v_act = ϵ_a − x⁰_a；L_WAM = E[ ‖v̂^v_φ − v_vid‖²₂ + ‖v̂^a_φ − v_act‖²₂ ]。
- **目标注入路径**：可选**语义路径**（ĝᵢ 经视觉编码器送入 reasoner）或**几何路径**（ĝᵢ 经同一 VAE 编码为干净潜变量 z^g_i 直接送入 generator，与参考潜变量 zₜ 并列，并加零初始化的可学习 goal-role 嵌入以区分）。论文采用**几何路径**，理由是它在像素级 grounding 子目标，而非经过更粗粒度的语义嵌入（消融支持此选择）。
- 训练时用已训好的 G_θ 对演示推理得到 ĝᵢ，语义不一致或视觉失真的预测**替换为真值 gᵢ**，在混合数据上训练策略以缓解训练-测试失配。

**（c）通过全局目标实现上下文任务指定（ICL）**
- 上下文 C 实例化为**全局目标图像 G**（任务终态）。G **只进入子目标规划器**：L_Plan−ICL = E[ ‖√wᵢ ⊙ (G_θ(x^τ_g, τ | zₜ, ℓ, G) − v_plan)‖²₂ ]；训练时 G 取每条演示轨迹的终止帧。
- 下游策略 π^WAM_φ 保持不变（只条件于 ĝᵢ），G 的影响通过 ĝᵢ 中介。因此**θ 与 φ 均不更新**即可由未见过的全局目标诱导出未被演示过的任务分解。

**（d）部署流程**
- 滚动时域循环：每个控制查询由 G_θ 从当前观测（及可选 G）重算 ĝᵢ，再由 π^WAM_φ 预测一个动作块；**子任务推进由场景演化隐式完成，无外部子任务完成检测器**。

## 3. 实验设计

### 3.1 仿真：RoboTwin Clean2Random
- **平台与本体**：RoboTwin 2.0 基准，Aloha AgileX 双臂本体。
- **数据**：多任务训练，仅用 **2500 条 Clean 专家演示**；19 个任务被判为长时程并切分为多子任务，其余 31 个为单阶段任务（终止帧即子目标）；每个任务在 Clean 与 Random 设置下各评测 **100 次 rollout**。
- **对比方法**：
  - VLA 类：StarVLA、Abot-M0、X-VLA、π0.5；
  - WAM 类：Fast-WAM、LingBot-VA、4D-WAM；
  - **受控基线** Cosmos3-Nano-RoboTwin：同一 Cosmos3-Nano 骨干、同一策略后训练配方，但**无子目标引导**，用于把子目标引导的贡献与预训练骨干的贡献分离。
- **子目标质量评测**：对比 VISTA、RxBrain，指标为 LPIPS（↓）、DINO-cos（↑）、ΔIoU（↑，变化掩码 IoU，阈值 25）、RetAcc（↑，DINOv2 特征检索到正确子任务终点帧的比例）。

### 3.2 真实机器人：组合式操作
- **平台**：AgiBot A2，两条 7-DoF 臂、两个腕部相机 + 一个前置相机。
- **训练**：先在**约 900 小时**同本体遥操作数据上 mid-training，再在任务级真机演示上 post-training。
- **任务（5 个长时程组合任务，含 3–5 个子任务）**：Pile Paper Cups（3）、Stack Colored Bowls（3）、Stamp Over Letters（4）、Tidy-up Desktop（4）、Take-out Steam Buns（5）。
- **评测**：每任务 20 次 rollout，报告平均任务进度（Task Progress Score，TPS）与逐阶段成功率。
- **基线**：VLA 策略 π0.5，以及 Cosmos3-Nano-Policy（同数据、同配方但**无子目标引导**）。

### 3.3 真实机器人：ICL 任务
- **Fruit Arrangement**：按全局目标图像指定的种类与数量把水果放入两个托盘。
- **Desktop Item Storage**：按全局目标图像把桌面物品放入收纳盒。
- 训练演示只覆盖受限的摆放模式，测试时全局目标可给出**未见模式（OOD）**；保持初始场景与语言指令不变，只改变全局目标图像。每任务 20 次 rollout，分 in-domain 与 OOD。

### 3.4 消融
- **目标注入路径消融**（用**真值**目标图像，隔离注入路径影响）：None / Reasoner（语义）/ Generator（几何）/ Generator+Reasoner，均在同样 2500 条 RoboTwin Clean 轨迹上训练 30k 步。
- **实现设计消融**：ViGAR 完整版 / 去掉子目标前瞻 / 去掉 EEF ROI 加权 / 两者都去掉，在 50 个 RoboTwin 任务上比较。

## 4. 资源与算力

- **文中明确提到的**：
  - 骨干为 **Cosmos3-Nano（16B-A8B 参数）**；规划器训练 **100k 步**、全局批大小 32、AdamW、LR 2×10⁻⁵（50 步 warm-up 后恒定）；策略训练 **50k 步**、全局批大小 256、LR 1×10⁻⁵（动作投影/嵌入 10×，目标嵌入 5×）、线性调度、BF16。
  - 推理优化在**单张 NVIDIA B20Z GPU** 上测得：策略推理加速 **2.5×**、子目标生成加速 **11.2×**（CUDA graph 静态编译、融合 QKV/SwiGLU、批量 CFG、按内容哈希的精确条件缓存、TeaCache）。
  - 真机 mid-training 使用约 **900 小时**遥操作数据。
- **未明确说明的**：
  - **没有给出训练所用的 GPU 型号/数量、总训练时长或总算力开销**（规划器与策略的 100k/50k 步各需多少卡时、预训练阶段的算力均未报告）。
  - 真机 900 小时数据的采集成本、mid-training 与 post-training 的算力分配亦未量化。
  - 因此，方法的**复现成本与算力门槛无法从论文直接评估**，这是资源透明度上的一个缺口。

## 5. 实验数量与充分性
