## 摘要
机器人脑模型融合视觉、语言和机器人状态，为复杂操作任务生成动作。大多数方法预测固定长度的动作块，这些动作块可能跨越多个任务阶段。这可能模糊阶段转换，并偏向频繁出现的动作模式，从而损害动态环境中的动作时序。我们提出 PhasePlan，一种面向机器人脑模型的有序未来阶段规划方法。根据当前多模态观测，它预测每个未来动作位置处的任务阶段。由此得到的规划表征对相应动作进行条件化，保持任务进展与动作生成之间的时间对齐。训练首先学习规划器，然后在动作模型适配期间将其冻结，以维持稳定的阶段表征。我们在预训练的 $π_{0.5}$ 和 AcrossWAM1.0 机器人脑模型上实例化了 PhasePlan。详细的定量评估使用 $π_{0.5}$ 实现。在传送带操作任务上，PhasePlan 相对于原始 $π_{0.5}$ 模型将离线联合动作误差降低约 22.5\%。它还改进了阶段转换建模和跨阶段动作预测。这些结果证明了有序未来阶段规划对连续动作生成的价值。

## Abstract
Robot brain models integrate vision, language, and robot state to generate actions for complex manipulation tasks. Most predict fixed-length action chunks that may span multiple task phases. This can obscure phase transitions and favor frequent action patterns, compromising action timing in dynamic environments. We propose \method, an ordered future-phase planning method for robot brain models. From current multimodal observations, it predicts the task phase at each future action position. The resulting planning representations condition the corresponding actions, preserving temporal alignment between task progress and action generation. Training first learns the planner, then freezes it during action-model adaptation to maintain stable phase representations. We instantiate \method on pretrained $π_{0.5}$ and AcrossWAM1.0 robot brain models. Detailed quantitative evaluation uses the $π_{0.5}$ implementation. On conveyor-belt manipulation, \method reduces offline joint-action error by approximately 22.5\% relative to the original $π_{0.5}$ model. It also improves phase-transition modeling and cross-phase action prediction. These results demonstrate the value of ordered future-phase planning for continuous action generation.

## 一、核心问题与整体含义

- **研究背景**：机器人脑模型（Robot Brain Models）与视觉-语言-动作（VLA）策略将多模态感知、任务规划与运动预测结合，用于复杂操作任务。当前主流做法（如 π0.5、GR00T N1）预测**固定长度的动作块（action chunk）**，一次输出未来 H 步动作。
- **核心痛点**：
  - 单个动作块可能横跨多个任务阶段（如 Wait → Act 或 Act → Release），导致**阶段转换位置被模糊化**。
  - 动作优化天然偏向高频动作模式（如长时间 Wait、Transport），而短促但关键的阶段（如 Release）容易被忽视，损害**动态环境中的动作时序精度**。
  - 平均动作误差相近的策略，其阶段转换时机与闭环行为可能差异巨大。
- **关键观察**：相同阶段计数的序列（如 Wait,Wait,Act,Act 与 Act,Act,Wait,Wait）在每个未来位置需要完全不同的动作，因此需要**位置对齐（position-aligned）的任务进度表征**，同时保留阶段类别与转换位置。
- **整体含义**：PhasePlan 提出一种**有序未来阶段规划**框架，将任务进度显式建模为每个未来动作位置的阶段分布，并用其条件化对应动作生成，从而在连续动作生成中保持任务进度与动作的时间对齐。

## 二、方法论

### 2.1 核心思想

- 在标准观测 $o_t=(I_t^{head}, I_t^{wrist}, s_t, \ell)$ 下，预测未来 H 个动作位置各自的阶段分布 $\hat{Z}_t=(p_{t,1},\dots,p_{t,H})$，并用其上下文规划表征逐位置地条件化对应动作 token。
- 阶段标签 $z_{t+h}\in\mathcal{Z}_\tau$ 在训练时提供位置级监督；传送带任务中 $\mathcal{Z}_\tau=\{\text{Wait, Act, Release, Return-Home}\}$。

### 2.2 关键技术细节

- **有序未来阶段规划器（Ordered Future-Phase Planner）**：
  - 引入 H 个可学习阶段查询 $u_1,\dots,u_H$，每个查询对应一个未来动作偏移。
  - 每个查询读取同一观测上下文 $X_t=E(o_t)$，但保留自身位置身份：
    $$Q_{t,h}=P_{\theta_P}(u_h, X_t),\quad p_{t,h}=\mathrm{softmax}(W_z Q_{t,h}+b_z)$$
  - 使用**相互独立**的查询（独立查询略优于交互查询），通过 $u_h \leftrightarrow z_{t+h} \leftrightarrow a_{t+h}$ 的一一对应形成有序结构。

- **阶段分类损失**（仅在有效未来位置 $V_t$ 上计算）：
  $$\mathcal{L}_{phase}=-\frac{1}{\sum_t |V_t|}\sum_t\sum_{h\in V_t}\log p_{t,h}[z_{t+h}]$$
  该逐位置目标同时保留阶段类别与阶段转换的时间位置。

- **逐位置计划条件化（Plan-Conditioned Action Generation）**：
  - 用可学习矩阵 $E_z$ 将阶段分布映射为软阶段嵌入，并与规划表征融合：
    $$\bar{e}_{t,h}=E_z^\top p_{t,h},\quad e_{t,h}=W_Q Q_{t,h}+W_P \bar{e}_{t,h}$$
  - 轻量网络 $f_{\theta_M}$ 预测逐位置的缩放与偏移：
    $$(\gamma_{t,h},\beta_{t,h})=f_{\theta_M}(e_{t,h})$$
  - 对动作专家表征 $x_{t,h}$ 进行调制：
    $$\tilde{x}_{t,h}=(1+\gamma_{t,h})\odot \mathrm{RMSNorm}(x_{t,h})+\beta_{t,h}$$
  - $f_{\theta_M}$ 最后一层零初始化，使适配初期保持预训练动作路径行为；每个 $e_{t,h}$ 只影响对应的 $x_{t,h}$，维持位置对齐。

- **两阶段训练与推理流程**：
  1. 第一阶段：优化 $\mathcal{L}_{phase}$，训练阶段查询与规划器层，动作专家固定。
  2. 第二阶段：冻结规划器，优化原始 flow-matching 动作目标 $\mathcal{L}_{flow}$，更新动作专家与逐位置调制路径。
  - 推理链路：$o_t \rightarrow (Q_{t,1:H}, p_{t,1:H}) \rightarrow A_t$，规划器与条件化路径同处一个策略模型内，部署时输入仍为标准多模态输入。

## 三、实验设计

- **任务与场景**：真实机器人遥操作采集的**动态传送带分拣任务**。机器人需等待红色可操作包裹（白色为干扰项），抓取后运输至蓝色篮子，释放后回到初始位姿，对应四阶段 Wait → Act → Release → Return-Home。
- **观测与动作空间**：头部 RGB、右腕 RGB、本体感知状态、语言指令；动作块长度 H=16；每步含 7 个右臂关节目标 + 1 个二值手部开合命令。
- **数据集**：325 条轨迹 episode，40,129 帧；按 episode 划分数据；每个有效 16 步窗口均有位置对齐的阶段监督标签。阶段标签由 VLX-Seek 物体标注 + 夹爪状态 + 任务时序规则构建；预处理去除 Wait 阶段抖动并平滑重锚定 Wait→Act 转换。
- **Benchmark 与对比方法**（共享 π0.5 初始化、数据、episode 划分、优化预算与动作表示）：
  - **Original π0.5**：直接适配原始动作专家。
  - **Future-skill histogram**：仿 GuidedVLA 的时序摘要形式，使用未来技能聚合分布。
  - **Ours-P**：训练有序未来阶段规划器但保留原始动作路径（用于分离阶段预测本身与条件化效果）。
  - **PhasePlan**：完整方法，逐位置连接计划特征与对应动作 token。
- **评估指标**：未来阶段预测精度、阶段转换质量、关节动作 MAE（整体与跨阶段）、手部命令准确率、跨阶段动作块性能。
