## 摘要
学习通用机器人策略需要大规模真实世界交互数据，然而收集机器人示范仍然昂贵且难以扩展。第一视角视频提供了丰富的人类交互经验，并包含与机器人操作相关的任务语义，但直接迁移具有挑战性，原因有二：从帧重建中推断出的潜在动作可能被自我相机运动等无关变化所主导，并且人类与机器人的行为通常表现出不同的时间动态。我们提出 WING（World Action Learning via INteraction-Centric Spectral Latent Guidance，基于以交互为中心的谱潜在引导的世界动作学习），一个将交互知识从第一视角视频迁移到机器人策略的框架。WING 首先将观察者引起的运动与手-物交互分离，并将以交互为中心的部分蒸馏为潜在动作。然后，它利用跨具身任务语义集中于缓慢变化的时间结构这一观察，在谱域中识别第一视角潜在动作与机器人行为之间共享的低频分量，并用其引导动作生成。WING 在 LIBERO 上达到 99.20% 的平均成功率，在 RoboTwin 2.0 上达到 93.80%，在 RoboCasa-GR1 上达到 57.7%，并且在多样泛化设置下的四个真实世界操作任务中也表现强劲。这些结果表明，以交互为中心的谱引导提供了一种有效且可扩展的方式，将物理交互知识从人类第一视角视频迁移到机器人控制。项目页面：https://mikuz12.github.io/wing/

## Abstract
Learning general-purpose robot policies requires large-scale real-world interaction data, yet collecting robot demonstrations remains expensive and difficult to scale. Egocentric videos offer abundant human interaction experience with task-relevant semantics for robotic manipulation, but direct transfer is challenging for two reasons: latent actions inferred from frame reconstruction can be dominated by nuisance variation such as ego-camera motion, and human and robot behaviors often exhibit different temporal dynamics. We propose WING (World Action Learning via INteraction-Centric Spectral Latent Guidance), a framework for transferring interaction knowledge from egocentric videos to robot policies. WING first separates observer-induced motion from hand-object interaction and distills the interaction-centric component into latent actions. It then exploits the observation that cross-embodiment task semantics are concentrated in slowly varying temporal structures, identifying shared low-frequency components between egocentric latent actions and robot behaviors in the spectral domain and using them to guide action generation. WING achieves average success rates of 99.20% on LIBERO, 93.80% on RoboTwin 2.0, and 57.7% on RoboCasa-GR1, and also performs strongly across four real-world manipulation tasks under diverse generalization settings. These results show that interaction-centric spectral guidance provides an effective and scalable way to transfer physical interaction knowledge from human egocentric video to robot control. - 总教师损失：L_teacher = λ_trk L_trk + λ_cam L_cam + λ_int L_int + λ_cons L_cons + λ_var L_var + λ_cov L_cov（λ_trk=λ_cam=λ_int=λ_var=1，λ_cons=0.1，λ_cov=0.01）。

### 2.4 交互蒸馏（RGB-only 学生）

- 教师依赖特权信息，部署不可用；冻结教师，将交互潜在蒸馏到仅输入 RGB 帧对的学生 S_φ。
- 对第二帧施加类相机的全局 warp 得到扰动视图，构造自然/增强两路输入 z^nat、z^aug。
- 蒸馏损失：
  **L_distill = (1/2D_i) Σ_{v∈{nat,aug}} ‖z^v − z^T_int‖² + (λ_view/D_i)‖z^nat − z^aug‖²**（λ_view=1）
- 第一项迁移教师交互表示，第二项保证相机扰动下的表示一致性；蒸馏后丢弃教师与所有特权组件。

### 2.5 谱潜在引导

- 将 H 个连续潜在动作堆叠为 Z ∈ R^{H×D_i}，沿时间维做正交 DCT-II，保留最低 K 个分量作为引导目标 **g^low**（截断仅作用于引导，不改变机器人动作）。
- **引导预测器 P_ψ**：以当前观测、语言指令（可用时含本体状态）为输入，最小化 **L_pred = (1/(KD_i))‖ĝ^low − g^low‖²_F**；未来帧仅用于构造训练目标。
- **条件化注入**：将 ĝ^low 投影为 U_t ∈ R^{K×D_hid}，逐频率系数向量加 LayerNorm 与频率模式嵌入，通过门控残差交叉注意力注入动作模型：
  **H_a^(l) ← H_a^(l) + γ_l · Attn(Q=LN(H_a^(l)), K=U_t, V=U_t)**，γ_l 为可学习标量。
- **训练策略（两阶段）**：
  - 阶段一：在约 200 小时自我中心视频上预训练（Wan2.2 视频专家 + 引导预测器）。
  - 阶段二：机器人策略学习，迁移预训练视觉骨干与预测器，与动作专家联合训练，**WING-LAM 编码器冻结**。
  - 总目标：**L_total = λ_video L_video + λ_action L_action + λ_pred L_pred**（λ_video=λ_action=1，λ_pred=0.1）。

## 3. 实验设计

### 3.1 表示层分析

- **数据集**：EgoDex、EgoVerse、Ego4D（按源轨迹划分避免重叠）。
- **三类评估**：
  - 运动可解码性：Ridge / 两层 MLP / RFF 探针，报告留出集 R²（相机目标为 EgoDex 的 6D 头部姿态，其余用图像空间相机运动代理；交互目标为去除全局相机运动后的局部残差）。
  - 相机扰动敏感性：匹配的“动态 vs 静态”扰动（A/B 同幅反向），报告动态减静态偏差，5 个递增扰动等级。
  - 动作语义：遵循 LARYBench 协议，在 Ego4D、EPIC-KITCHENS、HoloAssist、EgoDex 上做动作类别分类。
- **跨具身谱相似度**：从 EgoDex/EgoDex-Eval 分层标注构造 **100 组匹配 + 100 组不匹配**人–机片段对（覆盖 25 个任务），标签在计算任何潜在轨迹前确定，另有两名标注者复核；统一 0.2s 采样（5 Hz）、H=8（1.6s）。

### 3.2 仿真 Benchmark

- **LIBERO**：Spatial / Object / Goal / Long 四套件，10 任务×500 示范/套件，单 checkpoint，每任务 50 rollouts，共 2000 rollouts。
- **RoboTwin 2.0**：50 个双臂任务，clean 与域随机化场景，2500 clean + 25000 randomized 示范，每任务每条件 100 rollouts。
- **RoboCasa–GR1**：24 个桌面任务，Fourier GR1 人形（双 7-DoF 臂 + 双 6-DoF 手 + 3-DoF 腰），Unified 1K（每任务 1000 遥操作示范），每任务 50 rollouts。

### 3.3 真实世界平台

- **硬件**：Agilex Cobot Magic 双臂平台，3 个 Orbbec DaBai DC1 相机（1 前视 + 2 腕部），14 维动作空间。
- **任务**：Pack Objects、Stack Cups、Battery Insertion、Battery Assembly（长时程）；分别采集 100/100/150/150 条示范，每任务 20 次试验。
- **指标**：二元成功率（成功条件需保持≥3 秒）+ 分阶段进度分数（每任务满分 10）。
- **泛化设置**：单因子变化——物体外观、无关背景、物体几何、初始空间布局（电池类任务不评几何）。

### 3.4 对比方法

- **VLA**：π0、π0.5、X-VLA、LingBot-VLA、GR00T-N1.6/N1.7、StarVLA-OFT、LDA-1B。
- **潜在动作类**：LAPA、UniVLA、LaWAM、Being-H0.7、VLA-JEPA。
- **世界动作模型**：Motus、LingBot-VA、FastWAM、GigaWorld-Policy、DiT4DiT。
- **LAM 表示基线**：DreamDojo、CD-LAM、VILLA-X。
- 真实世界对比：GR00T-N1.7、π0.5、FastWAM。

### 3.5 主要结果

| 基准 | WING | 最强基线 |
|---|---|---|
| LIBERO（四套件均值） | **99.20%** | LingBot-VA 98.50% |
| RoboTwin 2.0（clean/rand 均值） | **93.80%** | LingBot-VA 92.20% |
| RoboCasa–GR1 | **57.7%** | LDA-1B 55.4% |
| 真实世界标准（4 任务均值 SR） | **75.0%** | π0.5 / FastWAM 较低 |
| 真实世界泛化（均值 SR） | 49.5% | 与 π0.5 相当或略优（进度分数略高） |
