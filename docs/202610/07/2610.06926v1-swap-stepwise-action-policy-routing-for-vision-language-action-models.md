## 摘要
使用视觉-语言-动作（VLA）模型作为骨干的机器人操作任务系统通常仅使用一个 VLA 来执行任务。然而，单个 VLA 在不同任务状态和环境中的表现并不理想。我们提出了一种在执行过程中动态组合多个 VLA 策略的框架：逐步动作策略路由（StepWise Action Policy Routing，SWAP）。SWAP 将策略路由形式化为离线强化学习问题，学习一个路由评价器，其根据当前观测在每个决策步骤选择最合适的策略。SWAP 使机器人能够在线选择新的策略来执行，而不是在一个回合内固定使用单一策略。我们在真实世界 DROID 操作任务和 LIBERO 仿真实验中评估了 SWAP。SWAP 优于固定策略执行和路由基线，在真实世界任务成功率上取得最高 33% 的绝对提升，同时将成功轨迹的机器人动作步长减少了 28.3%。

## Abstract
Robot manipulation systems using Vision-Language-Action (VLA) model backbones typically use just one VLA for task execution. However, individual VLAs do not perform well across different task states and environments. We introduce a framework for dynamically composing multiple VLA policies during execution: StepWise Action Policy Routing (SWAP). SWAP formulates policy routing as an offline reinforcement learning problem, learning a routing critic that selects the most appropriate policy at each decision step given the current observation. SWAP enables robots to select new policies to execute online rather than committing to a single policy for the duration of an episode. We evaluate SWAP on both real-world DROID manipulation tasks and LIBERO simulation experiments. SWAP improves over fixed-policy execution and routing baselines, giving absolute improvements in real-world task success up to 33% while reducing successful trajectory robot action step length by 28.3%.

## 1. 核心问题与研究动机

- **背景**：机器人操作正越来越多地以大模型（尤其是 VLA，Vision-Language-Action）为骨干，直接将视觉观测与语言指令映射为动作，并在多样化操作任务上展现出较强泛化能力。
- **核心矛盾**：现有系统普遍假设"整段回合只由一个策略控制机器人"。但现实中没有任何单一策略能在所有回合、场景配置与任务状态下都表现一致——某策略在自由空间运动阶段表现好，可能在接触密集的精细操作中失败；反之亦然。
- **已有工作的局限**：近期 VLA 的进展（更大数据集、更好架构、更广预训练、更强后训练）本质上仍在追求"更强的单一通用策略"，隐含假设一个策略能覆盖部署时遇到的完整状态分布；而真实场景中的分布漂移、误差累积与恢复行为会持续改变执行状态。
- **关键问题**：即便手头有多个策略，在回合开始时选定一个就相当于把机器人锁定在固定行为上，无法随执行演化而调整。且路由决策必须考虑**长时程下游结果**——局部看似合理的选择可能最终导致失败，而另一选择可能带来恢复或成功。
- **论文主张**：稳健的机器人执行可能并非只来自"造更强的单策略"，而来自"学会如何在多个策略间路由"。SWAP 让机器人能够在**每个决策步**动态选择由哪个候选策略执行动作，从而在单条轨迹内组合互补行为。

## 2. 方法论

### 2.1 核心思想与形式化

- 将动作选择形式化为 MDP：`M = (S, A, P, r, γ)`，t 时刻观测 `s_t`，执行动作 `a_t`。
- 不学习单一策略，而是假设有一个有限的候选策略库 `P = {π_1, ..., π_K}`，每个 `π_k(a_t | s_t)` 是预训练好的机器人控制器（可为不同架构、数据或算法训练的 VLA）。
- 学习一个**路由策略** `φ(z_t | s_t)`，其中 `z_t ∈ {1,...,K}` 是所选策略索引；实际动作由被选策略采样：`a_t ~ π_{z_t}(· | s_t)`。
- 优化目标：`argmax_φ E_{φ,P}[ Σ_{t=1}^{T} γ^{t-1} r(s_t, a_t) ]`。
- 与标准策略学习的区别：路由器的"动作空间"不是低层电机控制，而是**策略选择本身**，处于更高抽象层级。
- 与混合专家（MoE）的区别：SWAP 把候选策略视为**固定黑盒**，只学路由器，因此新增策略无需重训任何专家。

### 2.2 离线数据集构建

- 用每个候选策略在目标任务上收集轨迹（包含成功与失败），构成离线路由数据集。
- **关键设计：按 chunk 路由而非每个低层控制步路由**。VLA 通常一次预测并执行 c 个低层动作（chunk）：
  - 与 VLA 自身的推理节奏对齐，不引入额外策略查询；
  - 避免在 chunk 中途打断策略（中间动作单独看没有意义）。
- 路由转移样本：`(o_t, z_t, r_t, o_{t+c}, d_t)`，其中 `o_t` 为 chunk 起始观测，`z_t` 为所选策略，`r_t` 为稀疏奖励，`o_{t+c}` 为 chunk 执行后观测，`d_t` 表示回合是否终止。
- **奖励信号为稀疏二值**：成功完成任务时最后一步奖励为 10，失败为 0，其余中间转移奖励均为 0。作者刻意不做中间奖励塑形，认为稠密奖励难以获取。

### 2.3 离线评价器学习

- 采用 **IQL（Implicit Q-Learning）** 作为离线 RL 算法，因为其适合在"混合质量"的离线数据上稳定学习价值函数、对候选策略做准确排序。
- 学习两个路由评价器 `Q_1, Q_2` 和一个状态价值函数 `V`，最小化时序差分目标：
  - `L_Q = E[ Σ_{i=1}^{2} ( Q_i(o_t, z_t) − ( r_t + γ(1−d_t)V(o_{t+c}) ) )² ]`
- 价值函数 `V` 通过对学到的 Q 值做 **expectile 回归**单独优化。
- 训练与推理时均取两个评价器的**最小值**，以获得保守价值估计、抑制高估偏差。
- 直觉：离线 RL 使评价器给"成功下游结果"对应的策略选择更高价值，给"失败轨迹中出现过的"选择更低价值；持续重估价值使 SWAP 能选择最契合当前情境的策略，而不是锁定某个固定控制器。

### 2.4 路由评价器架构

- 使用**冻结的 Qwen2.5-VL-3B** 视觉语言模型作为编码器，把当前视觉观测与语言指令编码为 **2048 维**嵌入。
- 该嵌入与"候选策略身份"对应的**可学习嵌入**拼接，输入轻量级 **double-Q 评价器**（MLP），预测候选策略集合上的标量动作价值；另有独立的价值网络用于 IQL 训练。
- 用冻结 VLM 的好处：复用强预训练视觉/语言表征，从而只需较小规模离线机器人数据即可学出路由行为。

### 2.5 测试时策略路由（算法流程）

1. 用当前观测 `o_t` 计算嵌入 `h_t = f(o_t, instruction)`；
2. 在候选策略集合上评估评价器，选最高价值者：`z_t = argmax_z min( Q_1(o_t, z), Q_2(o_t, z) )`；
3. 查询被选策略，产生一个短时域 chunk 的低层动作并执行；
4. 每执行完一个 chunk 后重复上述过程，从而在执行过程中动态换策略。
- 真实 DROID 平台上额外做**多相机视角的 Q 值聚合**，以提升对视角歧义与遮挡的鲁棒性。

## 3. 实验设计

### 3.1 真实世界：DROID

- 平台：7-DoF Franka Panda 机械臂 + 多个外部与腕部 RGB 相机（DROID Franka 桌面操作设置）。
- 三个任务：把马克笔放入碗中（Marker→Bowl）、把方块放入杯中（Cube→Cup）、把布上的方块转移到碗中（Cube on Cloth→Bowl）。
- 候选策略集合：Physical Intelligence 的 **π0、π0.5、π0-FAST**。其中 π0.5 与 π0-FAST 使用公开的 DROID checkpoint **零样本**部署；π0 因在这些任务上无零样本能力，在小规模数据上做了微调。

### 3.2 仿真：LIBERO / LIBERO-Plus

- 使用 **LIBERO** 与 **LIBERO-Plus** 基准，聚焦 **LIBERO-Spatial** 子集；LIBERO-Plus 的 spatial 子集包含更具挑战性的分布外（OOD）任务变体，用于测泛化。
- 通过改变候选策略集合的组成来评估路由行为：
  - **五策略设定**：π0、OpenVLA、OpenVLA-OFT 及其变体（含 no-wrist、OFT+），异构且质量差异大；
  - **两策略设定**：π0.5（明显最优）与一个明显较弱的策略，考察路由是否会被弱策略拖累。

### 3.3 对比基线

- **单策略（固定执行）**：每个候选策略独立跑完整回合（标准设定）。
- **随机路由（Random）**：每个控制步均匀随机选策略，用来剥离"切换本身"带来的收益，隔离"学习型路由"的贡献。

### 3.4 训练数据规模

- DROID：每个策略在每个任务上收集 10 条成功 + 10 条失败 rollout，共 **180 条轨迹**（3 任务 × 3 策略）；每个任务用 **10 次留出试验**评估。作者指出这类数据在实践中可直接来自基础策略的评测过程。
- LIBERO：在 10 个 LIBERO-Spatial 任务中的 8 个上，每策略每任务收集 50 条 rollout，**留出任务 5 和 9** 用于评估。
- 训练轮数：真实世界 4k–8k epochs；仿真 200 epochs；DROID 与 LIBERO 分别训练各自的路由评价器。

### 3.5 额外实验

- **OOD 干扰物实验（真实机器人）**：在两个 DROID 任务中加入未见过的干扰物体，每任务 10 次试验，**不重新训练评价器**，直接迁移。
- **消融实验**：从五策略集合中移除 π0（SWAP w/o π0）、移除 OpenVLA-Spatial（SWAP w/o OpenVLA-Spatial）。
- **行为分析**：Q 值随时间的演化可视化、按轨迹归一化分段的策略选择频率统计、切换次数与切换带来的 Q 值提升统计、定性案例分析（自由空间移动 / 抓取 / 掉落恢复 / 搬运）。
