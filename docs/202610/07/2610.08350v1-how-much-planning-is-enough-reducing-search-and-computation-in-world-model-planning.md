## 摘要
视觉世界模型通过决策时动作搜索实现目标导向控制，但其部署效率往往受限于保守偏大的规划预算。我们表明，即使不与全预算动作一致，也能取得有竞争力的任务性能；充分预算因模型–任务对而异；并且迭代规划器会反复编码对求解不变的上下文。为解决这些低效问题，我们提出 SufficientPlan，一个简单的部署框架，无需修改预训练世界模型或规划器更新。其配对序列预算认证（Paired Sequential Budget Certification, PSBC）组件利用配对闭环证据，在预定义的全性能容差内搜索并认证一个缩减后的、模型–任务特定的预算。其静态上下文复用（Static-Context Reuse, SCR）组件在搜索迭代间缓存观测和目标表示，同时保留依赖于候选的规划和所选动作。在多个世界模型骨干和视觉控制任务上的实验表明，SufficientPlan 在保持有竞争力的控制性能的同时，显著减少了搜索预算和规划延迟。

## Abstract
Visual world models enable goal-directed control through decision-time action search, but their deployment efficiency is often limited by conservatively large planning budgets. We show that competitive task performance can be achieved without agreement with the Full-budget action, that sufficient budgets vary across model--task pairs, and that iterative planners repeatedly encode solve-invariant context. To address these inefficiencies, we propose {SufficientPlan}, a simple deployment framework that requires no modification to pretrained world models or planner updates. Its {Paired Sequential Budget Certification (PSBC)} component uses paired closed-loop evidence to search for and certify a reduced model--task-specific budget within a predefined Full-performance tolerance. Its {Static-Context Reuse (SCR)} component caches observation and goal representations across search iterations while preserving candidate-dependent planning and selected actions. Experiments across multiple world-model backbones and visual-control tasks show that SufficientPlan substantially reduces search budgets and planning latency while maintaining competitive control performance.

- **痛点一：固定大预算造成"过度搜索"**。现有规划器普遍对不同模型、不同任务统一使用一个全局固定且偏保守的大搜索预算（如 30 次 CEM 迭代 / 9,000 条候选动作序列），但该预算并不考察"增加搜索是否真的改善闭环任务成功率"。
- **痛点二：求解内重复编码**。迭代规划器把观测历史与目标图像的编码放在 CEM 循环内部，而这两者在一次规划求解中是不变的，导致 K 次迭代产生 2K 次静态编码调用（仅有 2 个不同输入）。
- **关键实证观察**（本文立论基础）：

- **整体含义**：部署效率的瓶颈可分为两个正交来源——"超出结果充分性的多余候选评估"与"求解内重复的静态计算"。论文主张用**部署期轻量插件**同时消除这两者，而不重训世界模型、不改变规划目标。

## 2. 方法论：SufficientPlan

### 2.1 总体框架

- 输入：冻结的世界模型 M、原生规划器 P、开发集 D_dev、Full 预算 B_Full、允许性能退化 δ。
- 两组件互补：**PSBC 削减搜索量（少搜）**，**SCR 消除剩余搜索中的冗余计算（搜得快）**；两者均完全在部署期生效，模型参数、规划目标、候选生成规则、代价函数、优化器更新全部保持不变。

### 2.2 Paired Sequential Budget Certification（PSBC）

- **成对结果定义**：对开发集 episode e，定义
  `D_e(B_i) = Y_e(B_Full) − Y_e(B_i) ∈ {−1, 0, 1}`
  分别表示"破损（Full 成功而 B_i 失败）"、"救援（Full 失败而 B_i 成功）"、"相同"。
- **总体退化量**：`Δ(B_i) = E[D_e(B_i)] = SR(B_Full) − SR(B_i)`，样本估计为 n 个成对 episode 的均值；保留 episode 级配对以保留协方差、支持成对不确定性量化。
- **贝叶斯后验**：将三类互斥结果（rescued / broken / unchanged）计数建模为类别分布，采用对称 Jeffreys 型先验 `Dirichlet(1/2, 1/2, 1/2)`，共轭更新得后验；用 `10^5` 次 Monte Carlo 采样估计非劣性后验概率
  `q_{i,n} = Pr(Δ(B_i) ≤ δ | D_{i,n})`。
- **序列决策规则**：
  - `q_{i,n} ≥ τ_acc` → **SUFFICIENT**（认证）；
  - `1 − q_{i,n} ≥ τ_rej` → **INSUFFICIENT**（换更大预算）；
  - 否则 → **UNCERTAIN**（在同预算下追加成对 episode）。
  - 实验设置：δ = 0.02（2 个百分点）、τ_acc = τ_rej = 0.95、检查点 N = {10, 20, 40, 60, 80, 100}。
- **认证与冻结**：返回首个被认证的预算 `B*`，冻结为 `B_deploy = B*`；开发集耗尽仍未认证则保守回退到 B_Full。**held-out 结果绝不用于修订预算**。
- **命题 1**：若 PSBC 认证 B*，则 `Pr(Δ(B*) ≤ δ | D) ≥ τ_acc`。作者明确指出这只是指定 Dirichlet 模型下的后验陈述，**不构成对所有预算与检查时点的频率派同时覆盖保证，也不保证有限 held-out 样本上成功率完全相同**。
- **预算定义**：`B_i = Σ_{k=1}^{K_i} N_k`，固定种群 CEM 下即 `B_i = N·K_i`（N=300，K∈{1,…,30}，预算网格 {300, 600, …, 9000}）。强调这是"预定义策略下的首个认证点"，而非全局最小预算，且**不假设性能随预算单调**。

### 2.3 Static-Context Reuse（SCR）

- **原始代价**：`J^(k)_orig = C(E_h(h), E_g(g), E_a(A^(k)))`，在每次迭代重算 E_h(h)、E_g(g)。
- **SCR 改写**：循环外一次性计算 `z_h = E_h(h)`、`z_g = E_g(g)`，循环内复用 `J^(k)_SCR = C(z_h, z_g, E_a(A^(k)))`；缓存仅在单次规划求解内有效，下一步环境交互前丢弃。
- **不缓存的内容**：候选采样、动作编码、潜在 rollout、终端代价评估、优化器更新——均仍逐候选执行，因此只改变"计算位置"而非"计算定义"。
- **计算缩减率**：静态编码调用从 2K 降至 2，`R_enc(K) = 1 − 1/K`（K=8 时 87.5%，K=30 时 96.7%）。作者强调这是**编码调用数的缩减，不等价于总 FLOPs 或延迟的缩减**。
- **定理 1（精确规划等价性）**：在确定性 eval 模式编码器、相同优化器与 RNG 初态、候选相关计算与排序/打破平局确定性等假设下，通过归纳法证明 SCR 与原规划器在每个迭代产生**完全相同的候选种群、候选代价、优化器状态与所选动作**（`a*_SCR = a*_orig`）。有限精度下还需匹配运算顺序、数值精度与确定性 kernel。
- **延迟模型**：`T_orig(K) = K(T_s + T_d) + T_o`，`T_SCR(K) = T_s + K·T_d + T_o`；加速比 `S(K)` 随 K 单调递增，且 `lim_{K→∞} S(K) = 1 + T_s/T_d`，即加速上限受不可复用的候选相关计算约束。

### 2.4 组合部署

- `a_t = P_SCR(M, h_t, g; B*)`：在认证预算 B* 下运行启用 SCR 的原生规划器。
