Abstract. We focus on language-conditioned flow-based manipulation, where robot flows (robot velocity fields) serve as embodiment-agnostic, motion-centric representations for leveraging data collected from multi-ple robot platforms. This task is crucial because language-conditioned manipulation is essential for practical robotic systems, yet scaling robot foundation models remains limited by the labor-intensive collection of embodiment-specific data. Existing methods either coarsely approximate robot flows with sparse keypoint displacements, or cannot handle language-conditioned manipulation. To address this limitation, we propose Narra-tiveFlow, which models robot flows as continuous velocity fields using a flow-matching formulation conditioned on language. Accordingly, Narra-tiveFlow generates robot flows that are physically consistent with real-world manipulation. To validate NarrativeFlow, we have conducted ex-periments on standard datasets for language-conditioned manipulation. The experimental results show that NarrativeFlow outperforms represen-tative baseline methods on standard evaluation metrics. Furthermore, through real-world experiments, we show that NarrativeFlow achieves higher success rates than baseline methods across multiple manipulation tasks. To meet this demand, such systems must perform diverse tasks across a wide range of real-world environments, while following natural language instructions. In this direction, recent work has explored robot foundation models, which are often pretrained on large-scale data collected from multiple robot platforms [3,4,24,33]. In this study, we focus on language-conditioned flow-based manipulation. In this task, a model generates a robot flow (robot velocity field) conditioned on an instruction, and then a robot performs object manipulation based on the robot flow. Robot flows serve as embodiment-agnostic intermediate representa-tions that bridge visual observations and robot actions. Because such flows can be extracted from arbitrary robot videos, flow-based approaches can leverage large-scale data collected from multiple robot platforms rather than relying on costly embodiment-specific data collection. However, this task remains challeng-ing: indeed, a representative method, Im2Flow2Act [49], still underperforms a method using oracle robot flows by 21 percentage points in average success rate (see Table 4). Many existing flow-based manipulation methods [2, 13, 49] do not formulate robot flows as dense velocity fields, but as displacements of sparse keypoints, even though robot manipulation is inherently a time-evolving physical process. Specifically, these methods predict sparse keypoint coordinates and then derive robot flows from their displacements, yielding only a coarse approximation of continuous robot motion. These formulations can be problematic because they assume that the displacements are deterministic, although such an assumption is rarely satisfied in practice. By contrast, Flow as Flow [38] can model robot flows as dense velocity fields; however, it cannot handle language-conditioned settings. Moreover, existing methods [2,13,38,49] typically rely only on primary flow-generation objectives during training, which provide no explicit supervision for capturing task-relevant semantics. As a result, such models can be misled by task-irrelevant visual details, such as background appearance and lighting. Moreover, we introduce an auxiliary loss that aligns the model’s intermediate representations with task-relevant scene changes, enabling the model to capture task-relevant semantics. Fig. 1 shows an overview of our approach. We first train our model on cross-embodiment datasets. We introduce the Narrative Delta loss as an auxiliary objective that aligns the model’s intermediate representations with task-relevant scene changes. We show that NarrativeFlow outperforms baseline methods across standard datasets. 4. Through real-world experiments, we show that NarrativeFlow achieves higher success rates than baseline methods across multiple manipulation tasks. 

# 2 Related Work 

Language-Conditioned Manipulation. Robotic foundation models aim to address diverse tasks across varied environments and have been actively investi-gated [22, 62]. Recent language-conditioned manipulation policies build on pre-trained foundation models such as multimodal large language models (MLLMs), adopting them as semantic backbones coupled with action heads that map lan-guage and observations to control [3, 4, 28]. This design inherits semantic and perceptual priors from large-scale pretraining, which transfer to unseen tasks and objects [3, 53]. A separate line of work introduces an explicit intermediate representation between language and action [8, 25, 49]. Such methods predict task- or scene-level targets, including 3D affordance maps (e.g., [18, 25]) and visual subgoals (e.g., [5, 61]), rather than conditioning the policies directly on latent features from the backbones. Among such targets, robot flows represent task progress as point or end-effector motion, bridging language specifications and the low-level trajectories that execute them [13, 19, 49, 52]. 

Flow-Based Manipulation. Flow-based manipulation methods use robot flows as embodiment-agnostic motion representations that bridge vision and action [2, 9, 11, 49, 58]. These representations can be extracted from heterogeneous robot 4 S. Kobayashi et al. 

videos (e.g., [43, 47]) and from web-scale human videos (e.g., [2, 38, 56]). More-over, a large body of work has demonstrated the effectiveness of robot flows across diverse real-world tasks including rigid, articulated, and deformable ob-ject manipulation (e.g., [49, 59]). Although earlier methods generate robot flows over the entire frame (e.g., [2, 47]), some studies use object-centric or hand-centric flows to further reduce the influence of embodiment-specific factors (e.g., [11, 19, 49, 56]). Other approaches adopt flow-conditioned video generation to predict the future scene (e.g., [13]), or extend 2D flows into 3D using depth estimation (e.g., [9, 54]). These methods derive robot flows from the displacements of sparse keypoints. As an alternative, Flow as Flow [38] directly predicts robot velocity fields via flow matching, a framework that predicts probability velocity fields in a generation space. However, this method is limited to goal-conditioned manipulation and hence it is unable to address language-conditioned settings. In contrast, Narra-tiveFlow generates robot flows using the flow-matching formulation conditioned on language. 

Learning Scene-Change Representations. To model temporal dynamics and task-relevant transformations, prior work has leveraged scene-change infor-mation in visual representation learning. For example, procedure-planning meth-ods predict sequences of high-level action labels from a current visual observation toward a visual goal in instructional video understanding [26,31,45]. Other work has focused on scene changes for object-centric localization (e.g., [51]), procedu-ral modeling (e.g., [32]), and fine-grained temporal modeling (e.g., [27, 50]). In parallel, recent work has explored efficient temporal representations using video codecs, further leveraging temporal and scene-change cues (e.g., [55]). In manipulation tasks, goal images are often used to specify desired final scene configurations [5,40]. These images provide fine-grained details of the scene change to be achieved, but are typically unavailable at inference time in language-conditioned settings. To leverage this information for language-conditioned ma-nipulation, GRIF [30] uses initial–goal image pairs during training to learn scene-change representations aligned with instructions. In addition, world models and dynamics models predict how objects and scenes change conditioned on actions. They model such changes through future observation prediction, learned physical dynamics, or dense geometric motion [5, 12, 17].

3.3 Vision-Language Fusion Encoder 

The vision-language fusion encoder integrates zimg and zlang into two purpose-specific joint representations, which are used in two downstream paths: one for conditioning the Flow-as-Flow module (Sec. 3.5) and the other for computing the Narrative Delta loss (Sec. 3.4). A standard approach to aggregating mul-timodal inputs into a single representation is to add a learnable special token (e.g., a [CLS] token) to the inputs and use its output as a global readout [10,41]. However, this single-token design can be insufficient for our model, in which the same token is used both to condition the Flow-as-Flow module and to compute the Narrative Delta loss. This can entangle the learning signals from both down-stream paths, hindering the token from capturing purpose-specific information. To address this issue, we introduce two subtask tokens, each dedicated to a distinct downstream path. This separation enables each token to act as a purpose-specific readout, helping to mitigate interference between the learning signals from the two downstream paths. Specifically, the subtask tokens are con-catenated with zimg and zlang , and the resulting token sequence is processed by a Transformer encoder consisting of Transformer layers. # 4 Experiments 

4.1 Experimental Setup 

Datasets. We used video clips from Fractal [6] and Bridge V2 [44], both of which are standard real-robot datasets in robot learning [24,33]. Table 1 provides an overview of the datasets used in our experiments. The two datasets were collected from different real-world robotic platforms, leading to variation in the recorded motion and visual appearance of the scenes (e.g., backgrounds and viewpoints). For Fractal, the training, validation, and test sets contain 84,212, 1,000, and 2,000 samples, respectively. For Bridge V2, the corresponding sets contain 57,064, 1,000, and 2,000 samples, respectively. We used the training sets to train the model, the validation sets to tune the hyperparameters, and the test sets to evaluate the model. Following prior work [38], we curated the datasets as described below. We set I0 as the first frame of the clip for each episode. In addition, we set G

according to the binary success label provided for each episode. Concretely, for a successful episode, G was set as the frame at which success was determined, whereas for an unsuccessful episode, it was set as the last frame of the clip. We used ℓ corresponding to I0 when ℓ was included in the original datasets; otherwise, ℓ was generated by Qwen2.5-VL [1] from the given I0 and G. To obtain Ξ0: T −1, we used CoTracker3 [20], an off-the-shelf point-tracking method. Here, T denotes the sequence length of the robot flow. Specifically, we initialized 

N points uniformly on I0 and tracked their trajectories throughout the clip. Following prior work [38], the datasets were preprocessed as described below. First, all images were resized to 256 × 256 pixels. Next, we obtained a segmen-tation mask of a robot end-effector from I0 for each video and incorporated it as an alpha channel of I0 in the model input. End-effector masks were gener-ated using Robot-SAM [57]. Because the pretrained Robot-SAM often generated masks covering the entire robot arm, we fine-tuned Robot-SAM to localize only the end-effector. Specifically, we used 300 samples from the RoboSeg [57] dataset with additional end-effector mask annotations. 

Baselines. We used representative language-conditioned robot flow generation baselines, FLIP [13] and Im2Flow2Act [49]. Both were trained on the same datasets as the proposed method. 

Metrics. Following prior work [38], we used average displacement error (ADE), final displacement error (FDE), and less than delta ratio (LTDR) as evaluation metrics, with ADE as the primary metric. Robot Platform. All of the experiments were conducted using the Human Support Robot (HSR), an 11-DoF mobile manipulator developed by Toyota Motor Corporation, as shown in Fig. 5. The visual inputs provided to the policy were captured with an external webcam. Specifically, these inputs consisted of 

I0 and the current observation at each timestep during execution.

The generated robot flow must provide the correct pushing direction and an appropriate pushing stroke; otherwise, the drawer cannot be closed completely. 2. Mobile bin picking : This task involves picking a specified object from a table, and placing it into a bin. Given ℓ, the model must identify the target object among multiple objects on the table. # 6 Conclusion 

In this study, we focused on language-conditioned flow-based manipulation. The contributions of this study are as follows: 1. We proposed NarrativeFlow, a language-conditioned robot flow generation method that formulates robot flows as probability velocity fields within a flow-matching framework, enabling high-quality robot flow generation. 2. We introduced the Narrative Delta loss as an auxiliary objective that aligns the model’s intermediate representations with task-relevant scene changes. We further introduced the subtask tokens to mitigate interference between this auxiliary objective and the primary flow-generation objective. 3. NarrativeFlow outperformed the baseline methods across standard datasets. 4. Through real-world experiments, NarrativeFlow achieved higher success rates than the baseline methods across multiple manipulation tasks. Future work will include lifting 2D image-plane robot flows into 3D space by incorporating depth information. This could enable depth-wise manipulation, such as pulling a book straight out of a bookshelf toward the camera viewpoint. In this case, the book appears nearly static in the image plane, resulting in a negligible 2D flow despite substantial motion in 3D.

# A Additional Related Work 

Standard Datasets in Robot Learning. Real-world robot manipulation data-sets have substantially expanded in both scale and embodiment diversity. Open X-Embodiment (OXE) [33] is a large-scale cross-embodiment dataset constructed by aggregating demonstration data from heterogeneous platforms, and it has been widely used for training vision-language-action (VLA) models (e.g., [3, 4, 24, 35]). Among the datasets within OXE, Fractal [6] and Bridge V2 [44] pro-vide language-annotated demonstrations for diverse manipulation tasks. Com-plementing these datasets, DROID [23] provides large-scale manipulation demon-strations across diverse in-the-wild settings, including households and offices. Recent efforts have further expanded the range of robot embodiments, with AgiBot World [7], RoboMIND [48], and ARIO [46] covering diverse platforms, including humanoid robots.
