## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大前景，但将其适配到新任务和新领域仍然效率低下：现有方法通常依赖参数调优，带来高昂成本，并有灾难性遗忘已学任务的风险。为解决这一问题，我们提出 Optimus-R，一种以记忆为中心的 VLA 框架，将机器人适配表述为显式的查询-技能记忆调优。Optimus-R 引入：(i) 用于技能提取的内联记忆接口。它将可学习记忆 token 插入 VLA 前缀流中，使主干网络能够在原生动作条件化路径中导出控制感知的查询和技能表示。(ii) 用于技能学习的查询-技能记忆库。它将技能外化为查询原型以决定检索什么，并外化为技能值以指定如何行动，支持在有限参数更新下进行技能复用与扩展。(iii) 一种轻量级的桥接-适配机制用于技能更新。它通过轻量适配器和残差记忆更新，将目标域的查询和技能与现有记忆空间对齐。在域内适配、跨域适配和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型已成为通用机器人操作的重要基础，依托大规模机器人数据预训练获得较强泛化能力。但在真实部署中，机器人需以少量演示适应新任务、新物体、新场景与新领域。
- **核心痛点**：现有适配范式是**参数中心（parameter-centric）**的——通过全量微调、LoRA、Adapter 等方式更新模型权重。这带来两个问题：
  - **适配成本高**：每个新技能都隐式写入模型权重，需反复训练。
  - **灾难性遗忘风险**：新任务学习会干扰甚至覆盖旧任务能力。
- **核心追问**：能否让 VLA 通过**显式记忆接口**获取、存储与复用技能，而非反复更新参数？
- **三个耦合难题**：
  - 技能应从 VLA 自身原生动作条件化路径中导出，而非作为“脱离的上下文”外挂（外部检索记忆与动作路径耦合弱）。
  - 技能应被显式组织，而非吸收进权重（否则难以检索、扩展、复用，且持续学习时相互干扰）。
  - 技能在域偏移下应保持可检索（视觉/动力学变化会使目标域观测偏离源域记忆空间，造成查询-技能错配）。
- **整体含义**：论文将机器人适配统一为**技能提取 → 技能学习 → 技能更新**三阶段，提出以记忆为中心的框架 Optimus-R，用查询-技能记忆调优替代参数微调，为 VLA 提供可复用、低成本的适应范式。

## 2. 方法论

### 2.1 核心思想

- 把机器人适配表述为**显式的查询-技能记忆调优**：技能被外化为记忆库中的键-值原型，新任务通过**复用、更新或追加**记忆条目来学习，而非反复调整模型权重。
- 三大组件：
  - **内联记忆接口（Inline Memory Interface）**：技能提取。
  - **查询-技能记忆库（Query-Skill Memory Bank）**：技能学习与存储。
  - **桥接-适配机制（Bridge-and-Adapt）**：技能更新与域对齐。

### 2.2 关键技术细节

- **内联记忆接口**：
  - 将可学习记忆 token $E_{mem}$ 插入 VLA 前缀流：$[H^{vl}_t; M_t] = F_\theta(O_t, L; E_{mem})$。
  - 用两个独立的注意力池化算子从共享记忆状态 $M_t$ 中分别读出检索上下文与动作相关技能内容：$\bar{m}^q_t = \text{AttnPool}_q(M_t)$，$\bar{m}^s_t = \text{AttnPool}_s(M_t)$。
  - 经 Query Encoder 与 Skill Encoder 得到查询 $q_t$（仅用于检索）与技能 $s_t$（作为记忆库的值表示）。
  - 训练时用轻量 **Skill Decoder** 监督 $s_t$ 重建未来动作块 $\hat{A}^s_t = D_s(s_t)$，使技能空间锚定在可执行行为上。
  - Token Projector $T_\psi$ 将技能映射为 VLA 兼容的 skill tokens，用于条件化 Flow Policy 生成动作块。
- **查询-技能记忆库**：
  - 存储解耦的键-值原型：$B = \{(p^q_j, p^s_j, n_j, E_j)\}_{j=1}^K$，其中 $p^q_j$ 为查询原型，$p^s_j$ 为技能原型，$n_j$ 为支持计数，$E_j$ 为用于回放的潜在查询-技能对。
  - 初始库构建：**运动感知降采样**（按动作变化分数 $\nu_i$ 保留高动态样本）+ **归一化进度分层采样**（防止轨迹局部主导）+ **技能聚类**（先在查询空间聚类，对技能方差高的簇再在技能空间拆分）。
  - 检索：查询先对齐 $q'_t = A_{mem} q_t$；取相似度 top-$K_r$ 原型，用温度 $\tau_{mem}$ 的 softmax 权重 $\alpha_{tj}$ 聚合：$\hat{s}_t = \sum_{j \in N_t} \alpha_{tj}(p^s_j + \Delta p^s_j)$。
  - 残差 $\Delta p^q_j, \Delta p^s_j$ 实现**不覆盖基原型的局部技能更新**。
- **桥接-适配机制**：
  - 查询侧线性对齐 $A_{mem}$（初始接近单位阵）。
  - 当技能空间错配较大时，启用零初始化的低秩残差 **Skill Adapter**：$\tilde{s}_t = A_s(\hat{s}_t) = \hat{s}_t + U_s V^\top_s \hat{s}_t$，$r \ll d_s$。
  - 激活条件基于 novelty rate $\eta_{batch}$ 与对齐误差 $e_{align}$ 连续多批次超阈值。

### 2.3 三阶段训练流程

- **Stage A：接口预训练**
  - 训练记忆 token、两个注意力池化器、Query/Skill Encoder、Skill Decoder、Token Projector 及 VLA 主干最后几层；无记忆库参与前向。
  - 损失：$L_{pre} = L_{fm} + \lambda_q L^{nce}_q + \lambda_s L_{skill}$，其中 $L_{skill}$ 为 Huber 重建损失；$L^{nce}_q$ 以同任务、近归一化进度的样本及同轨迹局部邻域为正样本。
  - 训练后冻结接口、Token Projector、Skill Decoder 与主干，构建初始记忆库 $B^{(0)}$（默认 $K_0 = 128$）。
- **Stage B：桥接适配（跨域）**
  - 解冻主干，与 $A_{mem}$、$\tau_{mem}$、活跃原型残差一同更新；接口模块、Token Projector、基原型保持固定。
  - 可选启用 Skill Adapter。
- **Stage C：记忆适配（域内持续学习）**
  - 冻结主干与内联记忆接口，仅更新 $A_{mem}$、$\tau_{mem}$、活跃原型残差与记忆库条目/统计。
  - 样本对齐查询与已有原型接近则更新残差与支持统计；否则进入候选缓冲，当簇满足 $|C_{new}| \geq N_{min}$、$Var_q \leq \epsilon_q$、$Var_s \leq \epsilon_s$ 时**追加新原型**。
  - 回放：每批混合 $\lfloor B/3 \rfloor$ 个存储的潜在查询-技能对（约 3:1 新-回放比），不存储原始图像/动作/轨迹。
- **统一适配目标**：$L_{life} = L_{fm} + \lambda_{align}\|\tilde{s}_t - \text{sg}(s_t)\|^2_2 + \lambda_{reg}\sum_{j \in A_t}(\|\Delta p^q_j\|^2_2 + \|\Delta p^s_j\|^2_2)$。
