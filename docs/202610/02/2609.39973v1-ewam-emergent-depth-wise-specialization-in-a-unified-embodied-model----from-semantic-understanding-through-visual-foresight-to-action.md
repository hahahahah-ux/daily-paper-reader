## 摘要
视觉-语言-动作（VLA）策略强调语义理解，而世界-动作模型（WAM）学习环境动力学的预测性表征。将策略同时接入这两类来源的系统，往往仍将动作计算集中在单一专家上。我们提出 EWAM，一种以动作为中心的统一具身模型；其非对称联合注意力使动作 token 在每一层都能读取语义、当前视觉、预测未来和动作信息，同时感知专家保持各自不同的角色。在没有逐层监督的情况下，EWAM 形成了涌现的深度分层专业化：动作查询在浅层主要关注视觉-语言特征，在中间层主要关注预测的未来帧，在深层主要关注动作 token 自身。这种交接在不同任务中可复现，并在去噪步骤间保持稳定。检查点跟踪与因果干预表明，这种专业化是学习得到的，且动作生成依赖于此。EWAM 在两种独立设置下预训练，一种基于跨具身机器人轨迹，另一种基于人类第一人称视频。在仿真和真实机器人实验中，它超越了现有 VLA、WAM 和混合基线。人类第一人称数据同时提升了跨具身迁移和真实机器人鲁棒性，而子任务阶段监督提升了长时程任务完成度。这些结果共同表明，统一具身学习能够诱导一种有序的内部演进：从语义理解，经由视觉前瞻，到动作形成。

## Abstract
Vision-language-action (VLA) policies emphasize semantic understanding, whereas world-action models (WAMs) learn predictive representations of environment dynamics. Systems that expose a policy to both sources often still concentrate action computation on a single expert. We present EWAM, an action-centric unified embodied model whose asymmetric joint attention lets action tokens read semantic, current-visual, predicted-future, and action information at every layer while the perceptual experts retain their distinct roles. Without layer-wise supervision, EWAM develops an emergent depth-wise specialization: action queries attend mainly to vision-language features in shallow layers, to predicted future frames in intermediate layers, and to action tokens themselves in deep layers. This handoff replicates across tasks and is stable across denoising steps. Checkpoint tracking and causal interventions show that it is learned and that action generation depends on it. EWAM is pretrained in two separate regimes, one on cross-embodiment robot trajectories and one on human egocentric video. In simulation and real-robot experiments, it surpasses existing VLA, WAM, and hybrid baselines. Human egocentric data improve both cross-embodiment transfer and real-robot robustness, and subtask-phase supervision improves long-horizon completion. Together, these results suggest that unified embodied learning can induce an ordered internal progression from semantic understanding, through visual foresight, to action formation.

## 1. 核心问题与整体含义（研究动机与背景）

- **范式分歧**：具身智能领域存在两大主流范式——VLA（视觉-语言-动作）模型继承了视觉语言模型的丰富语义表征，但静态预训练对物理动力学缺乏显式监督；WAM（世界-动作模型）从时序视觉数据中学习预测性表征，能获得运动先验，但预测合理未来并不等于具备语义推理与精细控制能力。
- **现有混合方案的局限**：已有的组合尝试通常有两种路径——(1) 仍以单一范式为中心，仅添加辅助输出，动作生成主要依赖视觉语言或视频特征之一；(2) 外挂一个独立运行的世界模型或理解模块。即使多专家模型（如 Motus），动作计算仍集中于单一专家。作者通过注意力可视化指出：π0.5 的动作注意力持续集中于 VLM token，Fast-WAM 集中于视频 token，Motus 仍被理解专家主导，均呈"单源主导"。
- **核心问题**：当语义理解、视觉预测与动作生成真正统一时，它们会在整个网络中持续竞争，还是会形成一种有序演进——先理解任务，再想象未来，最后形成动作？这一问题类比于 Kenneth Craik 提出的"内部模型"设想：智能体携带外部现实的小尺度模型，从而"在未来情境出现前做出反应"。

## 2. 方法论

### 2.1 核心思想
- **EWAM** 是一个以动作为中心的统一具身模型，包含三个**层对齐（layer-aligned）** 的 Transformer 专家：视觉语言（VL）专家、视频专家、动作专家。三个流在**同一次前向过程**中逐层交互，而非串行管线。
- 关键设计是**非对称联合注意力**：动作 token 是唯一的跨模态读取者，可在每一层读取语义、当前视觉、预测未来与动作信息；而 VL 与视频流各自保留模态内计算，互不读取。

### 2.2 关键技术细节
- **注意力掩码**：允许 A ← {V, A, L}，V ← V，L ← L。实现上通过一次拼接的掩码注意力完成三路查询计算，各流保留自己的归一化与投影参数。
- **模型初始化**：视频专家初始化自 Wan2.2-TI2V-5B，VL 专家初始化自 Qwen3-VL-2B。Qwen3-VL 输出 28 个隐藏状态，通过固定映射对齐到 30 个统一块（末尾重复第 26、27 层）；VL 侧采用递归融合：`x_L = q_L`（l=0），否则 `x_L = ½(q_L + z_{l-1})`，残差更新为 `z_L = x_L + W_O·Attn_L(x_L)`。
- **联合视频–动作流匹配**：对视频与动作目标独立采样噪声水平，构造插值 `x_τ = (1-τ)x + τϵ`，目标速度 `u* = ϵ - x`，回归速度场。基础损失 `L_base = λ_v‖û_v - u*_v‖² + λ_a‖û_a - u*_a‖²`。推理时联合积分两个速度场，未来视频特征在去噪过程中直接参与动作计算。
- **子任务感知后训练**：将长时程演示划分为 N 个语义阶段，提供当前子任务的文本描述 y_t 与归一化阶段索引 `p_t = k_t / max(N-1,1)`。轻量自回归解码器从动作表示与对齐 VL token 的拼接记忆 `Mem_t = [W_A h_A ; W_L h_L]` 预测子任务文本（损失 `L_sub`）；两层 MLP 头从动作表示的均值池化回归阶段索引（损失 `L_prog`）。总目标 `L_post = L_base + λ_p L_prog + λ_s L_sub`。VL 流只接收高层指令，不接收子任务文本。

## 3. 实验设计

### 3.1 数据集与场景
- **仿真**：RoboTwin 2.0（50 个双臂操作任务，含 Clean、Randomized、Clean-to-Random 三种协议）、LIBERO（Spatial/Object/Goal/Long 四个套件）。
- **真实机器人**：Franka 单臂（叠碗、物体入盒）、Dobot 双臂（倒水、整理桌面、毛巾操作）、Unitree G1-D 双臂人形（倒水壶、倒豆子），共 7 个任务，每任务 10 次试验。
- **预训练数据**：两种独立预训练机制——(1) 跨具身机器人轨迹约 30 万条、约 1,800 小时（来自 GM-100、RoboCOIN、RoboMIND1.0、RoboChallenge1.0/2.0、RDT、仿真数据等）；(2) 人类第一人称视频约 2,084 小时（VITRA-1M 283h、EgoDex 829h、Xperience 972h）。
- **人类数据接口**：以自我中心相机为锚定帧，将手腕位移表示为相机相对末端执行器动作（16 维，每手 6 维+2 个保留槽用于夹爪）；另通过 Lumos Ego 头显 + Vive Tracker 采集并重定向到 G1-D 动作接口。

### 3.2 对比基线
- **VLA**：starVLA、GalaxeaVLA、Xiaomi Robotics-0、X-VLA、ABot-M0、π0.5、ACE-Ego-0、LingBot-VLA、JoyAI-RA、HyVLA-0.5 等。
- **WAM**：Fast-WAM、ImageWAM、X-WAM、4D-WAM、GigaWorld-Policy、LaWAM、LingBot-VA 等。
- **VLA+WAM 混合**：GigaBrain-0.7、Motus、InternVLA-A1、WLA-0 等。
- **指标**：任务成功率（仿真为主指标）、真实世界成功率、动作 L2 误差、注意力分配质量与 token 归一化富集度 E。

### 3.3 核心实验组
- **仿真主结果**：RoboTwin C2R（EWAM 82.2% C2C / 72.1% C2R，平均 77.2%）、RoboTwin In-domain（平均 92.9%）、LIBERO（平均 98.8%）。
- **真实世界**：7 个任务全部取得最高成功率（如 Franka 叠碗 80%、物体入盒 90%）。
- **人类数据三组对比**：(1) 人类预训练用于跨具身迁移（Aloha-Agilex-2 上 40.1%→66.9%）；(2) 人类预训练用于真机协同训练（G1-D 倒水 40%→60%）；(3) 固定 60 条机器人演示下增加自我中心数据（10%→60%）。
- **子任务阶段监督**：三个指令条件积木任务（Ranking 83.5%→91.0%、Stacking 44.5%→58.5%、Ranking&Stacking 1.5%→16.0%）及 G1-D 双篮分拣（1.0/4→2.2/4）。
- **机制验证实验**：跨 50 任务注意力复制分析、12 个检查点训练动态追踪、层定向训练消融与推理干预、跨 5 任务反事实未来特征注入。

## 4. 资源与算力

- **训练算力**：文中明确提到 32 GPU 训练运行（用于收敛的 40,000 步训练）以及 4 GPU 的检查点轨迹训练（50–5,000 步），但**未给出 GPU 型号**（仅推理时提到单张 RTX 5090）。
- **训练时长/规模**：检查点跨越 50 到 40,000 优化步；未明确报告总训练小时数或总 GPU 小时。
- **推理配置**：单张 RTX 5090，batch size 1，bfloat16，5 步去噪下生成 16 动作块耗时 258 ms（含 chunk-overlap 校正）；相比基线 1,668 ms（10 步）实现约 3.6× 加速。
- **数据量**：机器人预训练约 30 万条轨迹 / 1,800 小时；人类预训练约 2,084 小时。
- **结论**：论文对算力细节披露有限，未给出精确的 GPU 型号组合与总训练时长。

## 5. 实验数量与充分性

- **实验规模**：覆盖 2 个仿真 benchmark（RoboTwin 50 任务、LIBERO 4 套件）、7 个真机任务、3 类机器人平台；机制分析覆盖 50 个任务的宏平均、12 个训练检查点、跨 5 任务的反事实注入、多种层定向干预配置。
- **充分性**：
  - **优点**：机制验证采用"观察证据 + 训练动态 + 因果干预 + 策略性能"四维框架，较为严谨；推理时干预使用固定检查点（不允许重训练补偿），比仅训练消融更能反映学习到的依赖；跨 50 任务统计复制给出 95% 置信区间与 Wilson 区间。
  - **公平性**：RoboTwin 与 LIBERO 报告了多范式强基线，且明确指出预训练数据不同，单次比较不能完全隔离注意力架构贡献；真机每任务仅 10 次试验，样本量偏小。
  - **潜在偏差**：部分基线结果引用自各自论文或第三方；C2R 与 In-domain 使用不同检查点来源；跨具身协议明确声明"与 Table 4/5 不可直接比较"。
- **总体判断**：实验覆盖面广、机制验证设计较为充分，但真机统计功效有限，部分对比存在数据/检查点不可比问题，作者对此有一定自我披露。

## 6. 主要结论与发现

- **涌现的深度分层专业化**：无需逐层监督，动作查询的注意力在浅层（0–9 层）主要指向 VL token（75.4%），中层（10–19 层）向预测未来帧转移（视频 24.3%、动作 39.1%、VL 36.6%），深层（20–29 层）动作自注意力升至 59.5%。视觉交接的原始交叉点稳定在中位第 13 层（IQR 12–13），归一化后第 14 层。
- **跨任务与去噪稳定性**：50/50 任务呈现浅层 VL 主导、中层原始视觉交接、深层动作主导；归一化后 49/50 任务仍呈现交接；跨去噪步骤平均相关系数 0.998。
- **该组织是学习得到的**：训练 50 步时无深度分工，150 步出现粗略组织，40,000 步收敛形成稳定三阶段。
- **因果必要性**：中层遮蔽未来特征使成功率从 92.80% 崩溃至 3.55%；浅层遮蔽 VL 损失 16.27 分；深层遮蔽视频损失 26.98 分。反事实未来特征注入使 5 任务成功率从 25/25 降至 4/25，且在 ADJUST BOTTLE 上改变手臂选择与空间定位。
- **性能优势**：仿真与真机均超越 VLA、WAM、混合基线；人类自我中心数据显著提升跨具身迁移与真机鲁棒性；子任务阶段监督提升长时程完成度。
- **架构对比发现**：在完全双向掩码变体下，粗粒度深度组织仍存在，但视觉交接不成立——图像富集度在深度上平坦（1.2 比值），VL 流自身转为视频消费者（深层 82% 注意力给视频）。说明非对称掩码是使"当前图像作为浅层依赖、深层释放"以及"VL 流保持纯语义源"的关键。

## 7. 优点

- **问题切入新颖**：不满足于"再加一个模块"，而是追问统一模型中语义、预测、动作如何内部协调，提出并量化了"涌现深度分层专业化"这一现象。
- **架构设计简洁且原则明确**：非对称注意力使动作流成为唯一跨模态读取者，既保护了感知专家的预训练角色，又使动作查询注意力成为定义良好的"信息检索来源"度量。
- **机制验证严谨**：结合观察性注意力分析、训练检查点动态、训练时结构消融、推理时层定向干预、跨任务反事实特征注入，形成多层次的因果证据链。
- **双向掩码对照实验有说服力**：通过完全双向掩码变体表明粗粒度组织不依赖掩码，但视觉交接依赖掩码，精确界定了贡献边界。
- **人类数据利用成本效益突出**：30 条自我中心数据即可匹配 90 条机器人数据的效果，1,000 条使鲁棒性从 10% 提升至 60% 且未见饱和。
- **工程优化务实**：省略未来帧 VAE 解码、图兼容 RoPE 重写实现全图编译，推理延迟降至 258 ms，具备实时部署可行性。
- **自我披露充分**：明确说明不可比协议、限制与未来方向。

## 8. 不足与局限

- **表征内容未完全解耦**：注意力路由只说明信息"从哪里检索"，不能完整刻画表征内容；残余连接可能将浅层语义传递至深层。作者建议未来用表征探针、激活修补、跨层因果中介进一步验证。
- **计算开销大**：维持三个大型专家仍代价高昂；虽提出按专家–深度网格分配容量、结构化剪枝的思路，但未在本工作中实现。
- **真机试验统计功效有限**：每任务 10 次试验，部分条件间差异仅 1 次试验（如 G1-D 泛化实验），顺序不应过度解读；倒水任务的溢出瓶颈（40 次中 12 次不完全成功，10 次与对齐不准相关）表明精度问题仍存在。
- **数据与基线可比性**：各方法预训练数据不同，仿真比较不能完全隔离架构贡献；部分基线分数引用自各自论文。
- **重定向质量有限**：离线重定向的 TCP P95 误差左工具最高达 77.01 mm、右工具 19.69 mm，虽通过一致性检查但存在残余目标失配。
- **人类数据表征假设**：假设整个 episode 使用单一手腕局部交互参考点，且不归一化具身尺度，可能限制跨具身泛化。
- **计算资源披露不足**：未给出 GPU 型号、总训练时长等关键信息，复现与算力评估受限。
- **任务覆盖偏桌面操作**：预训练与评估集中于桌面操作，向移动操作、非结构化环境的泛化性未验证。
- **未来规划仅为方向性讨论**：从视觉前瞻到反事实规划的扩展、任务与状态条件化动态路由等均为未来工作，未在本文实现。
