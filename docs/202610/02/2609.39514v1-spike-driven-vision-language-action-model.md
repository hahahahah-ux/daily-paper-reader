## 摘要
视觉-语言-动作（VLA）模型连接了多模态理解与机器人控制，推动了具身智能的主流范式发展。然而，大多数现有模型依赖大型 Transformer，其延迟与能耗成本阻碍了在资源受限平台上的部署。通过稀疏的事件驱动计算，脉冲神经网络为高性能与高能效计算提供了一种有前景的范式。在此，我们提出了首个脉冲驱动的 VLA 框架，可实现面向机器人操作的端到端直接训练，其主要包含三个核心组件。首先，我们开发了用于多模态感知的脉冲视觉与指令编码器，将视觉观测和语言指令编码为稀疏、可靠的脉冲表示，以供后续跨模态融合。然后，我们引入了多获胜者脉冲融合用于指令引导的场景理解，使用双向 top-k 胜者全取脉冲路由来抑制背景干扰并生成融合记忆。最后，我们提出了脉冲动作分块 Transformer，在融合记忆与当前机器人状态上引入脉冲交叉注意力，从而实现面向机器人控制的高效端到端连续动作块生成。在 LIBERO 和 Meta-World 上的大量实验表明，脉冲驱动的 VLA 以更少参数和更低的估计推理能耗，达到了与常规 VLA 模型有竞争力的性能。这项工作为神经形态 VLA 建模建立了基础框架，为资源高效具身智能的未来进展铺平了道路。

## Abstract
Vision-language-action (VLA) models bridge multimodal understanding and robotic control, advancing the dominant paradigm for embodied intelligence. However, most existing models rely on large Transformers, whose latency and energy costs hinder deployment on resource-constrained platforms. Through sparse event-driven computation, spiking neural networks offer a promising paradigm for high-performance and energy-efficient computing. Here, we propose the first Spike-driven VLA framework enabling end-to-end direct training for robotic manipulation, which mainly comprises three core components. First, we develop spiking visual and instruction encoders for multimodal perception, encoding visual observations and language instructions into sparse, reliable spike representations for subsequent cross-modal fusion. Then, we introduce Multi-Winner Spike Fusion for instruction-guided scene understanding, using bidirectional top-$k$ winner-take-all spike routing to suppress background interference and yield fused memory. Finally, we propose a Spike Action Chunking Transformer that incorporates spiking cross-attention over the fused memory and the current robot state, enabling efficient end-to-end generation of continuous action chunks for robotic control. Extensive experiments on LIBERO and Meta-World demonstrate that Spike-driven VLA achieves competitive performance with fewer parameters and lower estimated inference energy than conventional VLA models. This work establishes a foundational framework for neuromorphic VLA modeling, paving the way for future advances in resource-efficient embodied intelligence.

## 2. 方法论

### 2.1 整体架构（三阶段）

1. **多模态脉冲编码**：脉冲视觉编码器（SVE）+ 脉冲指令编码器（SIE）。
2. **跨模态融合**：多赢家脉冲融合（MWSF），生成任务条件记忆。
3. **状态条件动作解码**：脉冲动作分块 Transformer（SpikeACT），并行输出连续动作块。

流程（控制步 n）：
- $Z_{v,n}=E_v(O_n)$，$Z_\ell=E_\ell(\mathrm{Tok}(L))$，$M_n=F(Z_{v,n},Z_\ell)$
- $Z_{s,n}=E_s(S_n)$，$\hat A_n=\mathrm{SpikeACT}(P_a,[M_n;Z_{s,n}])\in\mathbb{R}^{K\times d_a}$

### 2.2 基础组件

- **LIF 脉冲神经元**：膜电位积分 $\tilde u^l[t]=\lambda u^l[t-1]+I^l[t]$；超过阈值 $V_{th}$ 发放脉冲 $s^l[t]=H(\tilde u^l[t]-V_{th})$；随后软/硬重置 $u^l[t]=\tilde u^l[t]-V_{th}s^l[t]$。突触输入 $I^l[t]=W^l s^{l-1}[t]$，只有活跃突触前神经元参与权重累加。反向传播用替代梯度（sigmoid/快 sigmoid/arctan 类）处理不可导的 Heaviside 函数。
- **脉冲自注意力（SSA）**：Q/K/V 经 BN+Linear 后由脉冲神经元二值化；**省略 Softmax**，仅保留缩放因子 s：$\mathrm{Score}=s\cdot Q\times K^\top$，$\mathrm{Attn}=\mathrm{SN}(\mathrm{Score}\times V)$，从而在脉冲域内实现高效全局依赖建模。

### 2.3 SVE 与 SIE（感知阶段）

- **SVE**：三阶段金字塔结构，前两阶段分别含 1、2 个 Conv Mixer 块（局部特征+下采样），第三阶段含 7 个 SSA 块（全局依赖）；特征图尺寸 $C\times H/4\times W/4$、$2C\times H/8\times W/8$、$4C\times H/16\times W/16$。主视角与腕视角**共享权重**双视图编码，各 14×14→196 个 token，拼接为 392 个视觉 token，线性投影到 d=256。骨干在 ImageNet-1K 上预训练后联合微调。
- **SIE**：基于脉冲 BERT（SmoothSpike-12-768，12 层/12 头，隐藏维 768，MLP 维 3072，T=4），经 MLM 预训练后**冻结**；通过适配器 $Z_\ell=\mathrm{BN}(\mathrm{Linear}_\ell(Z_{text}))$ 映射到共享维度 d=256，保留时间步维度（不做时间平均），$N_\ell\le 128$。

### 2.4 多赢家脉冲融合（MWSF）

- **动机**：视觉 token 数量远多于语言 token 且含大量背景杂波；直接用 SSA 做全局跨模态交互会让所有非零亲和度的视觉 token 都参与聚合，稀释显著证据。
- **做法**：
  - 生成脉冲域投影 $Q_v,V_v\in S^{T\times B\times N_v\times d}$，$K_\ell,V_\ell\in S^{T\times B\times N_\ell\times d}$；
  - 共享跨模态亲和矩阵 $R_n=Q_vK_\ell^\top\in\mathbb{Z}^{T\times B\times N_v\times N_\ell}$；
  - 在 $R_n$ 与 $R_n^\top$ 上分别做**双向 Top-k 胜者全取（WTAk）**路由，掩码定义为：$a_j^{(k)}=1$ 当且仅当 $j\in\mathrm{TopK}_k(r)$ 且 $r_j>0$，否则为 0；
  - 双向上下文：$C_v=Z_{v,n}+\mathrm{BN}(\mathrm{Linear}(\mathrm{SN}(\mathrm{WTA}_{k_v}(R_n)V_\ell)))$，$C_\ell=Z_\ell+\mathrm{BN}(\mathrm{Linear}(\mathrm{SN}(\mathrm{WTA}_{k_\ell}(R_n^\top)V_v)))$，两个方向使用不同的路由预算 $k_v,k_\ell$ 以适配视觉/语言序列长度不平衡；
  - 拼接并加带可学习通道尺度 $\gamma$ 的残差：$M_n=[C_v;C_\ell]+\gamma\odot\mathrm{BN}(\mathrm{Linear}(\mathrm{SN}([C_v;C_\ell])))$，$\gamma$ 可在推理时折入 BN 的仿射参数，不引入额外非脉冲运算。
- **效果**：抑制背景响应、稀疏化跨模态计算、保留梯度与信息直通路径；$M_n$ 保持连续膜电位残差，作为动作解码的任务条件记忆。

### 2.5 脉冲动作分块 Transformer（SpikeACT）

- 状态编码器 $E_s$ 将机器人状态映射为 $N_s$ 个状态 token $Z_{s,n}$，与记忆拼接得状态增强记忆 $\tilde M_n=[M_n;Z_{s,n}]$（$N_m=N_v+N_\ell+N_s$）。
- 使用 **K 个可学习动作 token** $P_a\in\mathbb{R}^{K\times d}$ 作为 query，从 $\tilde M_n$ 生成 K/V，得到亲和矩阵 $R_{a,n}=Q_aK^\top\in\mathbb{Z}^{T\times B\times K\times N_m}$。
- 经 $\mathrm{WTA}_k(R_{a,n})$ 稀疏二值路由，让每个动作 query 检索位置特定的视觉/语言/状态证据；再经脉冲读出与线性映射、时间平均与 tanh 限幅：
  $\hat A_n=\tanh(\mathrm{Avg}_T[\mathrm{Linear}_a(\mathrm{SN}(\mathrm{WTA}_k(R_{a,n})V))])\in\mathbb{R}^{B\times K\times d_a}$
- **一次前向并行预测 K 步未来动作**（动作分块），把计算代价分摊到连续控制步。
