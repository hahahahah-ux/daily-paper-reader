## 摘要
世界动作模型（WAMs）将机器人动作生成与未来状态预测相结合。现有的 WAM 通常预测视频或学习到的视觉潜变量，这些仅隐式地表示交互几何，并可能保留与控制无关的外观信息。我们提出 SkeleWAM，一种紧凑的 WAM，将操作场景表示为由机器人关节、物体中心和交互点组成的稀疏 3D 骨架。该骨架由当前 RGB-D 观测和机器人本体感知在线构建，为动作生成和未来骨架预测提供统一的几何状态。未来骨架预测为动作学习提供额外的几何监督，而无需视觉重建。在推理时，SkeleWAM 直接从当前骨架和语言指令生成动作，而 Medoid 动作共识（MAC）作为一种针对随机动作样本的辅助共识策略。在 LIBERO-Plus 上，SkeleWAM 以 57.1M 参数实现了 85.9% 的总体成功率，比 Cosmos-Policy 高出 3.7 个百分点。这些结果表明，稀疏 3D 机器人-物体结构为稳健且参数高效的世界动作学习提供了有效的状态空间。项目见 https://skelewam-project.github.io/。

## Abstract
World action models (WAMs) combine robot action generation with future state prediction. Existing WAMs typically predict videos or learned visual latents, which represent interaction geometry only implicitly and may retain appearance information unrelated to control. We introduce SkeleWAM, a compact WAM that represents a manipulation scene as a sparse 3D skeleton composed of robot joints, object centers, and interaction points. Constructed online from current RGB-D observations and robot proprioception, the skeleton provides a unified geometric state for action generation and future skeleton prediction. Future skeleton prediction provides additional geometric supervision for action learning without requiring visual reconstruction. At inference, SkeleWAM generates actions directly from the current skeleton and language instruction, while Medoid Action Consensus (MAC) serves as an auxiliary consensus strategy for stochastic action samples. On LIBERO-Plus, SkeleWAM achieves an overall success rate of 85.9% with 57.1M parameters, outperforming Cosmos-Policy by 3.7 percentage points. These results demonstrate that sparse 3D robot--object structure provides an effective state space for robust and parameter-efficient world action learning. The project is available at https://skelewam-project.github.io/.

## 2. 方法论
### 2.1 核心思想
- 用稀疏 3D 骨架 \(S_t \in \mathbb{R}^{N \times 3}\) 作为当前场景状态，由机器人关键点 \(J_t\) 和任务相关物体 landmark 组成。
- 对每个物体 \(m\)，定义 \(P_{t,m}=[c_{t,m}; u_{t,m,1}; \dots; u_{t,m,L_m}]\)，其中 \(c_{t,m}\) 为物体中心，\(u_{t,m,j}\) 为交互点。
- 完整骨架为 \(S_t=[J_t; P_{t,1}; \dots; P_{t,M}]\)，节点数 \(N=N_r+\sum_m(1+L_m)\)。
- 机器人节点由前向运动学计算，物体中心与交互点由冻结的预训练感知网络从 RGB-D 观测估计，所有坐标统一到机器人中心坐标系并归一化。
- 训练时同时学习动作生成 \(p_\theta^a(A_t|S_t,\ell)\) 和未来骨架预测 \(p_\theta^s(S_t^+|S_t,\ell)\)；推理时省略未来骨架预测分支，仅用当前骨架和语言指令生成动作。

### 2.2 关键技术细节
- **输入与输出**：给定语言指令 \(\ell\)、当前 RGB-D 观测 \(o_t\)、机器人本体状态 \(q_t\)，输出动作块 \(A_t=[a_t,\dots,a_{t+H_a-1}]\in\mathbb{R}^{H_a\times d_a}\)。
- **未来骨架序列**：\(S_t^+=[S_{t+\delta_1},\dots,S_{t+\delta_{H_s}}]\)，作为训练时的辅助监督目标。
- **模型结构**：采用双专家 Mixture-of-Transformers 设计，世界专家处理当前与未来骨架 token，动作专家处理动作 token，两者均以语言编码 \(C_\ell\) 为条件。
- **注意力掩码**：三组 token 顺序为（当前骨架、动作、未来骨架）。当前骨架组内自注意；动作和未来骨架各自关注当前骨架及自身；动作与未来骨架之间无跨分支注意力。输出头在一次前向中预测动作向量场和未来骨架向量场。
- **训练目标**：使用 flow matching。对动作和未来骨架分别采样高斯噪声，构造插值路径，目标向量场为噪声减数据。损失为 \(L=L_{\text{action}}+\lambda_s L_{\text{skeleton}}\)，两项均更新世界专家。
- **推理与 MAC**：从高斯噪声出发，沿学习到的动作向量场积分 10 步得到动作块。Medoid Action Consensus（MAC）从 \(K\) 个独立噪声初始化的候选动作块中，比较前 \(h\) 步、\(d_m\) 个连续运动维度的成对距离，选择平均距离最小的候选作为最终动作块。MAC 不需要奖励模型或价值模型，也不对轨迹做平均。
- **执行方式**：执行所选动作块的前 \(H_e\) 步，更新骨架后重新规划。
