## 摘要
我们关注语言条件化的基于流的操作，其中机器人流（机器人速度场）作为与具身无关的、以运动为中心的表征，用于利用从多个机器人平台收集的数据。这一任务至关重要，因为语言条件化操作对于实际机器人系统必不可少，但扩展机器人基础模型仍受限于劳动密集的、针对特定具身的数据采集。现有方法要么用稀疏关键点位移粗略近似机器人流，要么无法处理语言条件化操作。为解决这一局限，我们提出 NarrativeFlow，它使用以语言为条件的流匹配公式，将机器人流建模为连续速度场。相应地，NarrativeFlow 生成与真实世界操作在物理上一致的机器人流。为验证 NarrativeFlow，我们在语言条件化操作的标准数据集上进行了实验。实验结果表明，NarrativeFlow 在标准评价指标上优于代表性基线方法。此外，通过真实世界实验，我们表明 NarrativeFlow 在多个操作任务中取得了高于基线方法的成功率。项目页面见：https://shota0520.github.io/NarrativeFlow-project-page/

## Abstract
We focus on language-conditioned flow-based manipulation, where robot flows (robot velocity fields) serve as embodiment-agnostic, motion-centric representations for leveraging data collected from multiple robot platforms. This task is crucial because language-conditioned manipulation is essential for practical robotic systems, yet scaling robot foundation models remains limited by the labor-intensive collection of embodiment-specific data. Existing methods either coarsely approximate robot flows with sparse keypoint displacements, or cannot handle language-conditioned manipulation. To address this limitation, we propose NarrativeFlow, which models robot flows as continuous velocity fields using a flow-matching formulation conditioned on language. Accordingly, NarrativeFlow generates robot flows that are physically consistent with real-world manipulation. To validate NarrativeFlow, we have conducted experiments on standard datasets for language-conditioned manipulation. The experimental results show that NarrativeFlow outperforms representative baseline methods on standard evaluation metrics. Furthermore, through real-world experiments, we show that NarrativeFlow achieves higher success rates than baseline methods across multiple manipulation tasks. The project page is available at https://shota0520.github.io/NarrativeFlow-project-page/

- **机器人流的价值**：机器人流是与具身无关（embodiment-agnostic）、以运动为中心（motion-centric）的中间表征，可从未标注的机器人视频中提取，从而利用多平台大规模数据，绕过昂贵的具身专属数据采集。
- **现有方法的两个关键缺陷**：

  - Flow as Flow 虽能建模稠密速度场，但**仅支持目标图像条件（goal-conditioned）**，无法处理语言条件设定；而实践中推理时目标图像通常不可得，语言指令却随时可用。
  - 现有方法通常只用主流量生成目标训练，**缺乏对任务相关语义的显式监督**，易受背景外观、光照等任务无关视觉细节干扰。

## 二、方法论

### 2.1 核心思想
- 将机器人流建模为**概率速度场**，在**流匹配（flow matching）框架**下以语言为条件生成，使生成的流在物理上与真实操作更一致。
- 引入辅助损失 **Narrative Delta loss**，让模型中间表征对齐"任务相关场景变化"的叙事表征，从而抑制任务无关视觉细节的干扰。

### 2.2 整体架构
- 模型由**视觉-语言融合编码器**和 **Flow-as-Flow 模块**组成。
- 输入编码：指令 ℓ 用 Qwen3-Embedding-0.6B 编码为 z_lang，初始图像 I₀ 用 DINOv3-ViT-B/16 编码为 z_img。

### 2.3 视觉-语言融合编码器与子任务 token
- 标准做法是加入单个可学习特殊 token（如 [CLS]）做全局读出，但该 token 同时要用于两条下游路径（流量生成 + Narrative Delta loss），会导致学习信号纠缠。
- **解决方案**：引入**两个子任务 token**，分别专用于两条路径。子任务 token 与 z_img、z_lang 拼接后送入 Transformer 编码器（4 层），其输出投影为：
  - z_st⁽¹⁾：用于调节 Flow-as-Flow 模块；
  - z_st⁽²⁾：用于计算 Narrative Delta loss。

### 2.4 Narrative Delta Loss（辅助损失）
- **目标**：将 z_st⁽²⁾ 引导向任务相关场景变化的叙事表征，缓解任务无关细节的纠缠。
- **离线构造流程**：
  1. 用 MLLM（Qwen3.5-9B）输入 I₀、目标图像 G 及提示词，生成 **Nc=5** 条从不同视角描述同一操作的描述，要求聚焦物体运动、机器人/手部运动、状态变化、空间关系等，忽略任务无关细节；
  2. 用 Qwen3-Embedding-0.6B 将描述嵌入，得到目标叙事表征 {z_ND⁽ⁱ⁾}；
  3. 在叙事表征空间计算损失（式 1）：
     **L_ND = (1/Nc) Σᵢ [1 − cossim(z_st⁽²⁾, z_ND⁽ⁱ⁾)]**
- **特点**：仅在训练时使用，推理时**不需要 G**。

### 2.5 Flow-as-Flow 模块
- 在 I₀ 上均匀初始化 **N = 10×10** 个点，通过积分预测的速度场 v_θ 得到未来位置。
- 带稳定项的目标速度场（式 2）：
  **v(Ξ_t, X, t) = Ξ̇_t − k(X − Ξ_t)**，其中 **X ~ N(Ξ_t, σ₀²e^(−2kt)I)**，k 为稳定系数，σ₀ 为小常数。
- 实现基于 **Diffusion Transformer（DiT）**，每个 DiT 块用 **adaLN-Zero** 调制；条件向量由 z_st⁽¹⁾、I₀（ResNet-18 编码）与时间 t（正弦位置编码）相加构成。
- 输入序列 X_{0:t} 将当前点坐标追加到历史坐标序列，N 个点坐标展平为 R^{2N} 作为一个 token，经 DiT 处理后最后一个 token 表示速度场。
- 推理（式 3）：**X_t = X₀ + ∫₀ᵗ v_θ(X_τ, τ | I₀, z_st⁽¹⁾, X_{<τ}) dτ**
- 总损失（式 4）：**L = L_FaF + λ·L_ND**，其中 L_FaF 为条件流匹配损失（式 5），λ 为权重超参数（前 30k 步取 0.1，之后取 1.0×10⁻⁵）。

### 2.6 问题设定细节
- 假设固定相机下末端执行器在初始图像中可见；论文聚焦流量生成子任务，物体操作子任务沿用先前方法的流条件操作策略。

## 六、主要结论与发现

- **标准数据集**：NarrativeFlow 在两个数据集的全部指标上最优。
  - Fractal：ADE 21.68（基线最佳 37.14，提升 15.46）、FDE 31.59（基线最佳 47.74）、LTDR 76.29%。
  - Bridge V2：ADE 30.59（基线最佳 50.73，提升 20.14）、FDE 42.42（基线最佳 68.43）、LTDR 66.30%。
- **真实世界**：平均成功率 **55%**，优于 Im2Flow2Act（42%）13 个百分点、FLIP（28%）；与 Oracle（63%）的差距仅 **8 个百分点**，而 Im2Flow2Act 差距为 21 个百分点。
- **消融结论**：
  - 两个子任务 token 优于无 token 或共享单 token，说明其能让表征各司其职、减少干扰。
  - 去掉 Narrative Delta loss 后 ADE 分别变差 4.15（Fractal）和 3.20（Bridge V2），说明辅助监督有效。
  - 连续速度场建模（σ₀=0.05）优于稀疏关键点位移近似（σ₀=0）。
  - Nc=5、余弦相似度、I₀/G 作为描述来源的组合最优；更大的 MLLM（9B）优于 0.8B，但小 MLLM 仍优于基线。
- **失败模式**（100 例 Bridge V2 失败样本）：多模态语言理解错误 30 例、中间轨迹偏差 22 例、终点位置错误 14 例、语言指令模糊 9 例、目标物体遮挡 8 例、标注错误 17 例（其中 13 例为 Bridge V2 人工标注问题）。主要挑战是**多模态语言理解**。

## 七、优点

- **表征层面创新**：把机器人流从"稀疏关键点位移"提升为**连续概率速度场**，用流匹配统一生成，更贴合操作本质上的时变物理过程。
- **语言条件扩展**：将原本只能做目标图像条件的 Flow as Flow 扩展为**语言条件**，使其适用于推理时无目标图像的实用场景。
- **巧妙的辅助监督**：Narrative Delta loss 利用训练时可得的目标图像构造叙事监督，却**不在推理时引入额外输入**，兼具信息

量与推理时的轻量性——训练阶段借助 MLLM 生成的叙事描述把语义监督注入中间表征，推理阶段仅需指令与初始图像，不增加任何部署负担。
- **训练与推理成本可控**：单张消费级显卡（RTX 5090）约 6 小时即可完成训练，推理仅约 62 ms，对于需要闭环控制的机器人操作任务具备实用价值；同时模型规模（约 487M 可训练参数）相对克制，未依赖超大规模算力堆砌。
- **实证改进幅度显著**：在两个标准数据集上对 ADE/FDE/LTDR 三项指标均取得领先，且在真实机器人上把与"oracle 机器人流"上界的差距从 21 个百分点压缩到 8 个百分点，说明改进并非仅体现在离线指标上，而是能有效传导到真实操作成功率。
- **实验设计较为规范**：报告了统计显著性检验，保留了 oracle 上界作为参照，基线方法在同一数据集与相同训练流程下比较，避免"数据或训练配置不对等"带来的不公平对比；错误分析进一步提升了结论的可解释性。

## 八、局限与不足

- **真实实验统计功效有限**：主文真实实验每任务仅 20 次试验，三个任务合计 60 次；部分任务成功率绝对值偏低（如移动杯子堆叠约 20%），单次成功/失败的波动对均值影响较大，难以支撑任务级别差异的强结论。虽然补充材料扩展到 13 个任务、每方法 260 次试验，但主文结论仍主要建立在较小样本之上。
- **对上游模块存在较强依赖**：训练数据的构造链条较长——末端执行器掩码依赖微调后的 Robot-SAM，点轨迹依赖 CoTracker3，叙事描述依赖 Qwen3.5-9B，指令补全依赖 Qwen2.5-VL。任一环节的噪声（尤其跟踪漂移与伪标签误差）都会直接进入监督信号，论文对此类误差的传播与鲁棒性讨论较少。
- **叙事监督的可迁移性未经检验**：Narrative Delta loss 需要训练时具备目标图像 G。虽然推理时不需要 G，但在仅有单帧演示、缺少目标帧或成功标签的数据源上，该辅助损失的适用性会受限，论文未说明如何在此类数据上退化或替代。
- **失败模式集中在语言理解，但方法未直接应对**：错误分析显示最主要失败原因是多模态语言理解错误（30/100），而论文的核心机制主要作用于"运动表征"与"语义对齐"，并未针对语言解析本身设计专门模块或数据增强，说明瓶颈可能已从流生成转移到语言-视觉语义解析。
- **假设较为理想化**：固定相机、末端执行器在初始图像中可见、聚焦流生成子任务而沿用既有流条件操作策略，这些设定在杂乱、遮挡、相机移动的真实场景中并不总成立。
- **消融结论的泛化性存疑**：子任务 token 数量、λ 权重、Nc 取值、σ₀ 等超参的最优组合主要在两个具身数据集上验证，是否可迁移到其他平台（如双臂、灵巧手）尚不清楚；λ 在训练前 30k 步取 0.1、之后骤降至 1.0×10⁻⁵ 的调度策略也未给出敏感性分析。

## 九、结论与启示

- **核心贡献总结**：论文将语言条件机器人流生成从"稀疏关键点位移的确定性近似"推进到"语言条件化的稠密概率速度场"，并在流匹配框架下统一建模；同时以 Narrative Delta loss 在训练期引入任务相关语义监督，把"运动中心表征"与"叙事语义"耦合起来，兼顾了物理合理性与语义聚焦度。
- **方法论层面的启示**：
  - 具身无关的中间表征（机器人流）是降低多平台数据门槛的有效路径，但其价值上限取决于表征的表达能力——从"位移"升级到"速度场"带来的收益在实验中相当可观，提示后续工作应更重视中间表征的物理保真度。
  - 条件形式的选择具有工程意义：目标图像条件在训练时可获得、推理时往往不可得，而语言条件恰好相反。本文的"训练用图像、推理用语言"的非对称设计，是解决这一落差的可行范式。
  - 辅助监督不一定要引入推理期额外输入；通过离线用 MLLM 构造语义目标、在中间表征空间施加对齐损失，是一种低成本、易迁移的监督注入方式。
  - 多子任务 token 的解耦设计提示：当同一表征需服务多条下游路径时，显式分离读出通道可减少学习信号纠缠，这一技巧可能对更广泛的条件生成任务有借鉴价值。
- **后续可探索方向**：将叙事监督扩展到无目标图像的纯视频数据；针对语言理解失败引入更强的指令解析或语言-视觉 grounding 模块；在更多具身形态（双臂、移动底盘、灵巧手）与动态相机条件下验证表征的具身无关性；以及在大规模真实试验上给出更稳健的成功率估计。
- **总体评价**：这是一篇问题定位清晰、方法组合合理、实验较为扎实的工作。它没有追求模型规模的扩张，而是通过表征形式升级（速度场）、条件形式改造（语言条件）与监督形式创新（叙事对齐）三点改进，在离线指标与真实机器人成功率上同时取得了可见提升，且把与 oracle 上界的差距显著缩小。其局限主要在于真实实验样本量与对上游模块的依赖，但整体论证链条完整，对语言条件操作与具身表征学习方向具有明确的参考价值。
