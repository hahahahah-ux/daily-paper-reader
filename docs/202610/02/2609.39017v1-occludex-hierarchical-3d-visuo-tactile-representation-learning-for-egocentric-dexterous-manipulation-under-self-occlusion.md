## 摘要
可靠的灵巧操作需要在整个交互过程中持续估计物体几何形状与手-物体接触。然而，在使用第一视角感知时，执行操作的手经常遮挡与任务相关的物体表面和接触区域，减少了可用于状态估计的视觉证据，从而使稳健的闭环控制和对未见物体几何形状的泛化尤其具有挑战性。为解决这一问题，我们提出 OccluDex，一个分层3D视触觉表征学习框架，将全局几何结构与局部接触信息相结合，以在手-物体交互过程中动态自遮挡下实现稳健操作。OccluDex 采用多尺度掩码自编码以渐进编码部分3D几何，并通过跨模态注意力将触觉接触 token 与高层几何特征融合。编码器从同步的人类视触觉演示中预训练，并作为冻结的感知骨干迁移用于下游强化学习。我们在水龙头旋转任务（需要将手柄顺时针完整旋转一圈）和桌面物体重定向任务（需要在不倾倒的情况下将桌面物体旋转180度）上评估 OccluDex。在仿真实验中，对于未见过的物体，OccluDex 的准确率比最强的最先进基线模型高12.6%；对于先前见过的物体，准确率高8.3%。我们还使用 Shadow Hand 进行了物理实验，以证明对未见的物理物体成功的零样本仿真到现实泛化。这些结果可使类人机器人即使在操作手遮挡视觉时，也能对见过和未见的物体进行第一视角物体操作。

## Abstract
Reliable dexterous manipulation requires continuous estimation of object geometry and hand-object contact throughout interaction. With egocentric sensing, however, the manipulating hand frequently occludes task-relevant object surfaces and contact regions, reducing the visual evidence available for state estimation and thereby making robust closed-loop control and generalization to unseen object geometries particularly challenging. To address this, we present OccluDex, a hierarchical 3D visuo-tactile representation learning framework that integrates global geometric structure with local contact information for robust manipulation under dynamic self-occlusion during hand-object interaction. OccluDex adopts multi-scale masked autoencoding to progressively encode partial 3D geometry and fuses tactile contact tokens with high-level geometric features through cross-modal attention. The encoder is pretrained from synchronized human visuo-tactile demonstrations and transferred as a frozen perceptual backbone for downstream reinforcement learning. We evaluate OccluDex on a faucet rotation task, requiring one full clockwise handle revolution, and a tabletop object reorientation task, requiring a 180-degree tabletop object reorientation without toppling. In simulation experiments, OccluDex demonstrated 12.6% higher accuracy for unseen objects and 8.3% higher accuracy for previously seen objects than the strongest state-of-the-art baseline models. Physical experiments were further performed with a Shadow Hand to demonstrate successful zero-shot sim-to-real generalization on unseen physical objects. This results could enable humanoid egocentric object manipulation for seen and unseen objects even when the manipulating robotic hand occludes vision.

# OccluDex 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：在灵巧操作中，第一视角（egocentric）感知虽能减少对外部标定的依赖、保持与操作体一致的参考系，但操作手本身会持续遮挡任务相关物体表面与接触区域，且遮挡模式随手指关节运动与物体运动不断变化，导致视觉证据不完整、动态变化，使闭环控制与对未见物体几何的泛化尤为困难。
- **现有方法的局限**：
  - 3D 补全/生成式重建可恢复缺失几何，但在严重自遮挡下可用视觉证据有限且持续变化，几何推断歧义大、实时重建负担重；且几何补全并不能直接提供灵巧控制所需的瞬时接触信息。
  - 触觉可提供直接接触测量，但本质上是局部、稀疏、依赖接触的，缺乏全局几何信息。
  - 现有视触觉表征学习多基于 2D 图像表征，空间结构隐式编码；已有的 3D 视触觉方法主要针对平行夹爪，其接触模式与交互动力学远简单于多指灵巧手。
- **研究意义**：作者希望直接在第一视角观测下学习**控制相关的感知表征**，不依赖显式 3D 重建；受神经生理学中"身体中心多模态神经元以空间对齐感受野联合编码 3D 视觉与触觉信号"机制启发，提出分层 3D 视触觉表征学习框架，为自遮挡下的人形灵巧操作提供可泛化感知骨干。
- **定位**：据作者称，OccluDex 是首个面向遮挡丰富的近体空间灵巧操作的分层 3D 视触觉表征学习框架。

## 2. 方法论

### 2.1 核心思想

- 采用**分层多尺度几何编码 + 触觉 token 嵌入 + 最高语义层跨模态注意力融合 + 分层解码重建**的掩码自编码预训练范式，编码器从人类同步视触觉演示中预训练，随后**冻结**并作为下游 PPO 策略的感知骨干。
- 关键设计理念：几何分支逐步将局部表面结构聚合为高层空间表征；触觉编码为传感器特定的接触 token；只在最高语义阶段融合，以避免浅层几何 token（局部表面）与稀疏触觉 token（特定接触点）之间空间支撑严重不匹配。

### 2.2 关键技术细节

**（a）分层多尺度几何编码**

- 递归构建多尺度几何区域：在第 i 尺度，用最远点采样（FPS）从前一尺度采样中心，再用 k-NN 分组：
  - `Pi = FPS(Pi-1, Ni)`，`Ii = kNN(Pi, Pi-1, ki)`
  - 其中 `Pi ∈ R^{Ni×3}` 为采样中心，`Ii` 存储每个中心在 `Pi-1` 中的 ki 个近邻索引。
- **渐进多尺度掩码**：为避免各尺度独立掩码造成可见性不一致，在**最粗尺度采样可见性**，再通过层级邻域对应关系向细尺度传播：
  - `Vi = ∪_{j∈Vi+1} Ii+1[j, :]`，`i = S-1, ..., 1`
  - 掩码索引集 `Mi = {1,...,Ni} \ Vi`，可见/掩码位置分别为 `Pvi = Pi[Vi]`、`Pmi = Pi[Mi]`。
  - 论文强调：预训练掩码并非模拟物理自遮挡模式，而是提供自监督目标，促使编码器学习几何与触觉的联合表征及跨模态依赖。
- 第一编码阶段用轻量 PointNet 风格 tokenizer 将可见局部区域映射为点 token；后续阶段通过 token merging 逐步粗化（token 数减少、特征维度增加），各尺度加几何位置嵌入后由对应 Transformer 编码器处理。

**（b）触觉 token 嵌入**

- 19 通道触觉测量 `T ∈ R^19`，按固定阈值二值化（强调接触激活、降低对力大小的敏感性）。
- 每个触觉通道视为独立 token：`Ztac(j) = ϕtac(T̂j) + ptac(j) + etac`，`j = 1,...,19`，其中 `ϕtac` 为嵌入函数、`ptac(j)` 为第 j 个传感位置的位置嵌入、`etac` 为可学习模态嵌入，得到 `Ztac ∈ R^{19×C}`。
- 预训练时触觉 token 独立按 MAE 范式掩码，仅可见触觉 token 进入编码器。

**（c）跨模态视触觉融合**

- 仅在最高语义编码阶段融合：将最终阶段几何 token 与触觉 token 拼接，位置嵌入同样拼接，可学习模态嵌入区分两类 token，由最终 Transformer 通过跨模态注意力处理。
- 构造块状注意力掩码 `Mjoint = [[Mpc-pc, Mpc-tac], [Mtac-pc, Mtac-tac]]`，其中 `Mpc-pc` 保持几何注意力掩码，`Mpc-tac`/`Mtac-pc` 抑制涉及无效填充几何 token 的交互，`Mtac-tac` 允许可见触觉 token 间交互。

**（d）分层解码器与重建**

- 从最粗几何尺度开始，在掩码位置插入可学习 mask token，与编码可见 token 组合成解码器输入；解码器含 S-1 个轻量 Transformer 阶段。
- **触觉重建**在第一个解码器阶段后进行（触觉无显式多尺度空间层级，直接经轻量重建头映射到掩码触觉预测）。
- **几何解码**逐级向细分辨率推进，阶段间通过 token 传播将粗潜特征插值到细几何中心并与编码器特征经跳跃连接融合。
- 损失函数：
  - 几何重建用对称 Chamfer Distance：`Lpc = (1/|P̂m|)Σ_{p̂∈P̂m} min_{p∈Pm}‖p̂-p‖² + (1/|Pm|)Σ_{p∈Pm} min_{p̂∈P̂m}‖p-p̂‖²`
  - 触觉重建仅在掩码触觉 token 上计算：`Ltac = (1/|Mt|)Σ_{j∈Mt}‖t̃j - tj‖²`
  - 总目标：`L = λpc·Lpc + λtac·Ltac`

### 2.3 预训练超参数（表 I）

- 触觉阈值 40；点云掩码率 0.8；触觉掩码率 0.5；分组尺寸 [16, 8, 8]；分组数 [512, 256, 64]；编码器维度 [96, 192, 384]；编码器深度 [2, 2, 2]；解码器深度 [1, 1]；有效 batch size 128；点云损失权重 50。

- **消融结论**：
  - 触觉反馈贡献最大：去触觉在水龙头旋转 seen/unseen 上分别下降 45.7%/48.0%，桌面重定向下降 15.6%/17.3%。

- **总体**：分层 3D 视触觉表征学习可作为动态自遮挡下稳健、可迁移的第一视角灵巧控制感知基础。

## 7. 优点

- **问题切入精准**：直接针对第一视角灵巧操作中"动态自遮挡 + 接触信息缺失"这一真实且关键的痛点，而非回避遮挡（如引入外部视角或显式重建）。
- **方法设计有理有据**：
  - 采用**渐进多尺度掩码**保证层级间可见性一致，避免各尺度独立掩码造成结构不一致。
  - 只在**最高语义阶段融合**跨模态信息，明确论证了浅层融合会因空间支撑尺度不匹配而失效，并给出块状注意力掩码处理无效 token。
  - 触觉二值化降低对力幅值的敏感性，位置嵌入保留传感器空间语义。
- **训练范式高效实用**：人类演示预训练 + 冻结编码器 + 下游 PPO，既降低下游 RL 计算成本，又提升性能；掩码重建目标明确声明不模拟物理遮挡，而是学习跨模态依赖，定位清晰。
- **实验闭环完整**：从仿真 seen/unseen 到真实 Shadow Hand 零样本迁移，验证了表征的泛化性与可迁移性；消融量化了触觉、几何、预训练三者的贡献。
- **基线选择合理**：涵盖纯本体、2D 视触觉预训练、3D 适配的视触觉 Transformer，比较具有代表性。

## 8. 不足与局限

- **算力与训练细节披露不足**：仅给出 2× RTX 4080，未报告预训练时长、epoch、总 GPU 小时、推理频率预算等，复现难度较高。
- **消融的因果归因不干净**：完整架构从零训练因资源不可行，只能以"去层级的单阶段融合"作为从零参考；作者自己也承认该替代"并非隔离预训练效应"，因此预训练带来的增益不能完全排除架构差异的混淆。
- **任务与物体覆盖有限**：仅 2 个下游任务（水龙头旋转、桌面重定向）；未见泛化限于 YCB 留出物体与水龙头的 0.9/1.1 缩放，几何多样性不足；未测试更细粒度的操作（如工具使用、可变形物体）。
- **触觉感知受限**：仅使用 19 通道二值化接触信号，丢失力幅值信息，且缺少侧向指尖接触；作者在结论中也将其列为未来工作。
- **真实世界评估规模小**：每任务仅 2 个物体、20 次试验，无多物体类别或多次重复统计；未报告失败模式分析；未做真实世界微调对比，无法说明零样本与微调之间的差距。
- **鲁棒性验证不完整**：仿真训练未做动力学随机化，也未扰动点云观测，真实世界中的光照、标定误差、传感器漂移等风险未被评估。
- **无公开代码/数据说明**：论文未提及数据集或代码是否开源，限制了社区复现与基准对比。
- **理论层面**：跨模态融合为何必须放在最高语义层，主要依赖直觉与消融间接支持，缺乏更系统的层级融合位置分析。
