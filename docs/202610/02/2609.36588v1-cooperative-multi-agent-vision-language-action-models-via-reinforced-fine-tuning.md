## 摘要
我们研究用于协作多智能体视觉-语言-动作（VLA）模型的强化学习（RL）方法。该问题具有挑战性，因为 VLA 在大规模单智能体数据上预训练，因而缺乏机器人间协作所需的细粒度协调技能。在多机器人演示上进行监督微调（SFT）可以部分弥合这一差距，但其性能受限于演示数据，且无法从自身经验中改进。我们提出了一种用于多智能体 VLA 的三阶段强化微调（RFT）流程。第一，初始化感知的数据收集遍历初始配置，并仅在预训练 VLA 反复失败时调用人类演示，从而在降低人工成本的同时获得对初始化偏移的鲁棒性。第二，离线信用过滤微调为单个智能体分配信用，并在具有正优势的每个智能体轨迹上进行微调，而不是在整个联合 rollout 上微调。第三，我们发现现有针对 VLA 的在线 RL 在困难多智能体任务上效果较差，我们将其归因于嘈杂的协同探索和不稳定的更新。相反，我们使用在线潜在空间微调，即冻结 VLA 并在其潜在噪声空间中进行 RL。我们在 RoboTwin、RoboFactory 以及使用两个 Franka 机器人的真实世界操作中的 11 个任务上，使用 π_0 和 π_{0.5} 主干网络评估我们的多智能体 VLA。我们的多智能体 VLA 在 RoboTwin、RoboFactory 和真实世界任务上的平均成功率分别提高了 +23.1%、+16.4% 和 +44%。代码见：https://anonymous.4open.science/r/mavla_rft-2BC0/。

## Abstract
We study reinforcement learning (RL) methods for cooperative multi-agent Vision-Language-Action (VLA) models. This problem is challenging because VLAs are pretrained on large-scale single-agent data and therefore lack the fine-grained coordination skills required for inter-robot collaboration. Supervised fine-tuning (SFT) on multi-robot demonstrations partially bridges this gap, but its performance is bounded by the demonstration data and cannot improve from its own experience. We present a three-stage reinforced fine-tuning (RFT) pipeline for multi-agent VLAs. First, initialization-aware data collection sweeps over initial configurations and invokes human demonstrations only when the pretrained VLA repeatedly fails, yielding robustness to initialization shift with reduced human cost. Second, offline credit-filtered tuning assigns credit to individual agents and fine-tunes on per-agent trajectories with positive advantage rather than on entire joint rollouts. Third, we find existing online RL for VLAs are less effective for hard multi-agent tasks, which we attribute to noisy co-exploration and unstable updates. We instead use online latent-space fine tuning, which freeze the VLA and perform RL in its latent noise space. We evaluate our multi-agent VLA with both $π_0$ and $π_{0.5}$ backbones across 11 tasks in RoboTwin, RoboFactory and real-world manipulation with two Franka robots. Our multi-agent VLA improves the average success rate by $+23.1\%$, $+16.4\%$, and $+44\%$ on RoboTwin, RoboFactory, and real-world tasks, respectively. Code available at https://anonymous.4open.science/r/mavla_rft-2BC0/.

# 论文总结：Cooperative Multi-Agent VLA Models via Reinforced Fine Tuning

## 1. 核心问题与研究背景

- **研究动机**：视觉-语言-动作（VLA）模型已成为连接视觉感知、语言理解与底层机器人控制的通用接口，但它们在**大规模单智能体数据**上预训练，因此天然缺乏机器人之间协作所需的**细粒度底层协调技能**。
- **现实需求**：多臂装配、多机器人家庭操作等任务需要机器人协同，单智能体的强性能**无法自动迁移**到多智能体场景。
- **现有方法局限**：
  - VLM 领域的多智能体工作主要做**高层任务分解**（把共享任务拆成各智能体子目标），底层执行要么依赖规则策略，要么直接交给现成 VLA，忽视了 VLA 协作所需的细粒度动作细节。
  - 最接近的工作 CHORUS 通过**监督微调（SFT）**实现多 VLA 协作，但性能**受限于演示数据上界**，无法从自身经验中继续提升。
- **核心问题**：如何为多智能体 VLA 设计有效的强化学习（RL）微调范式，使其既能跨初始化泛化，又能从试错中自我改进。

## 2. 方法论：三阶段强化微调（RFT）流水线

整体思想是"数据收集 → 离线 RL → 在线 RL"三段式，弥合单智能体预训练与多智能体协作之间的差距（图 1、算法 1）。

### 2.1 阶段一：初始化感知的数据收集（Initialization-Aware Data Collection）
- **问题**：VLA 对初始条件（物体位姿、机器人位姿、任务布局）脆弱；某些初始化下成功率 SR(ξ)=0，所有 rollout 获得相同负奖励，RL 完全无法启动。
- **做法**：对每个初始化 ξ 执行预训练策略 K 次，估计经验成功率 SR(ξ)：
  - 若 **SR(ξ) > 0**：保留这 K 条 rollout（含成功与失败轨迹）用于后续 RL；
  - 若 **SR(ξ) = 0**：判定预训练策略缺少该配置所需的**基元技能**，仅对这些初始化调用人类专家演示，以最小代价扩展策略支撑集。
- **效果**：在可接受的成本下获得广泛的初始化覆盖，使后续 RL 可行。

### 2.2 阶段二：离线信用过滤微调（Offline Credit-Filtered Tuning）
- **核心难点**：多智能体**信用分配**——任务失败不意味着每个智能体都表现差（可能一个智能体完美完成子任务，另一个导致失败），因此整条联合 rollout 的微调会错误归因。
- **关键细节**：
  - 给定固定决策顺序 $i_1,...,i_N$，用共享 Transformer 拟合**智能体组合 Q 函数**，按序回归同一折扣回报 $G_t$：
    $$\min_Q \mathbb{E}_{\tau \in D_{offline}} \sum_{m=0}^{N} H(G_t, Q^{i_{1:m}}_\pi(s_t, a^{i_{1:m}}_t))$$
    其中 $Q^{i_{1:0}}_\pi = V_\pi$，$Q^{i_{1:N}}_\pi = Q_\pi$，中间项表示"前 m 个智能体已动作、其余未动作"时的价值。Q 输出 201 桶的回报分布，$H$ 为交叉熵（沿用 π*0.6 的分布式价值设计）。
  - **逐智能体优势**由相邻阶 Q 的望远镜式差分得到：
    $$A^{i_m}_\pi(s_t, a^{i_{1:m-1}}_t, a^{i_m}_t) = Q^{i_{1:m}}_\pi(s_t, a^{i_{1:m}}_t) - Q^{i_{1:m-1}}_\pi(s_t, a^{i_{1:m-1}}_t)$$
    依据**多智能体优势分解引理**（Lemma 3.1），各智能体优势之和恰等于联合优势。
  - 构建**正优势数据集** $D^+ = \{(s_t, a^{i_m}_t) \mid A^{i_m}_\pi > 0\}$，仅在其上用标准条件流匹配目标 $L_{offline} = \mathbb{E}_{D^+}[L_{FM}(\pi)]$ 微调。
- **理论保证**：Proposition 4.1 证明在"critic 优势估计准确、保留动作在前序智能体按新策略行动时仍有非负优势"等假设下，$J(\pi^+) - J(\pi) \ge 0$，即**单调策略改进**（证明用性能差引理 + 多智能体优势分解）。

### 2.3 阶段三：在线潜空间强化学习（Online Latent-Space RL）
- **诊断现有方法失效原因**：以 πRL 为代表的流匹配 VLA 在线 RL 在困难多智能体任务上不稳定，归因于：
  1. **嘈杂的协同探索**：在原始动作空间对各智能体独立注入高斯噪声，破坏精确协作，成功率可能跌回 RL 前水平；
  2. **不稳定的策略更新**：流匹配无解析似然，需高方差代理梯度，单智能体尚可容忍，多智能体并发更新带来的**非平稳性**会放大方差。
- **解决方案**：采用 **DSRL**，冻结 VLA 权重，改在**流匹配的潜噪声空间**做在线 RL。
  - π 系列 VLA 用 rectified flow：从噪声 $a^0 \sim N(0,I)$ 到动作 $a^1$ 的线性 ODE，插值 $a^\tau_t = \tau a^1_t + (1-\tau)a^0_t$。
  - 不调整 rectified flow，而是用小型策略 $\phi(a^0|s)$ 学习潜噪声分布，替代直接从 $N(0,I)$ 采样。
  - **优势**：探索被限制在分布内、时序连贯的行为，保留离线微调习得的协作能力；避免建模不可解的边缘似然，降低策略方差、抑制非平稳性。

## 6. 主要结论与发现

- **总体增益**：多智能体 VLA 在 RoboTwin、RoboFactory、真实世界任务上平均成功率分别提升 **+23.1%、+16.4%、+44%**。
- **阶段贡献**：离线 RL 平均 +8.1%，在线 RL 平均 +19.7%（相对离线 checkpoint 约 +11.6%）。
- **主干泛化**：π₀ 平均 +18.9%，π₀.₅ 平均 +20.6%。
- **数据覆盖的重要性**：初始化感知收集既提升离线阶段覆盖，又为在线阶段提供更广的成功覆盖，说明**数据覆盖是当前 VLA 在多智能体场景下的关键瓶颈**。
- **信用分配有效**：智能体级优势能正确把失败归因到具体机器人，避免"整条联合轨迹"微调的误归因。
- **在线 RL 方法选择**：单智能体 VLA 的 Flow 类在线 RL **不能直接迁移**到多智能体；

- **在线 RL 方法选择**：单智能体 VLA 的 Flow 类在线 RL **不能直接迁移**到多智能体；直接在动作空间注入噪声会破坏协作的时序一致性，导致成功率随噪声尺度增大而单调下降，且训练过程中出现偶发崩溃。将探索移到流匹配的**潜噪声空间**（DSRL）后，既保留了离线阶段习得的协作技能，又获得了稳定、单调上升的学习曲线，因此**探索发生的空间比探索本身更重要**。
- **数据收集的杠杆效应**：初始化感知收集不仅让离线阶段能覆盖成功率非零的初始化，还让在线阶段拥有更宽的"可改进起点"；这提示多智能体 VLA 的瓶颈可能不在 RL 算法本身，而在**策略支撑集是否覆盖任务所需的协作基元**。

## 7. 局限性

- **真实世界验证规模有限**：仅 3 个任务、单一主干（π₀.₅）、每个任务 50 次 rollout，且在线阶段退化为"离线 DSRL + 50 条真实 rollout"，因此真实环境结论更接近**概念验证**，不足以支撑"在线 RL 在真实多智能体系统上稳健有效"的强主张。
- **依赖人类专家演示兜底**：初始化感知收集在 SR(ξ)=0 时回退到人工演示，本质上仍是**人类数据补洞**；论文未讨论当所需基元技能数量增长、人工演示成本线性上升时的可扩展性，也未给出"零演示"条件下的替代方案。
- **信用分配依赖固定决策顺序**：离线阶段的价值分解假设智能体按固定顺序 $i_1,...,i_N$ 依次动作（顺序式价值分解），这种"自回归式"分解对**同步、并行决策**的多智能体场景是否仍成立、顺序如何选择、是否会引入顺序偏差，论文未做敏感性分析。
- **理论保证的条件较强**：Proposition 4.1 的单调改进结论建立在"critic 优势估计准确"与"前序智能体改用新策略后保留动作仍保持非负优势"等假设上；在分布式价值（201 桶）与有限数据下这些假设难以严格满足，理论更多提供**方向性指引**而非严格保证。
- **与经典 MARL 缺少直接对比**：实验主基线是 CHORUS（SFT）与 πRL 类 Flow 方法，未与 QMIX、COMA、MAPPO 等成熟 MARL 信用分配/协同算法在同等 VLA 设置下对比，因此难以判断本文离线信用过滤相对于既有 MARL 方法的**净增益**。
- **超参与阈值较敏感**：正优势过滤阈值 ϵ 被设定为"约保留 5% 原始数据"，但论文未系统扫描该比例；过滤过严可能丢失信号，过松则退化为普通行为克隆，这一关键超参的鲁棒性缺乏证据。
- **资源透明度不足**：如前所述，全文未报告 GPU 型号、数量与训练时长，使复现与算力规划缺少依据。

## 8. 未来工作方向（论文与评述综合）

- **减少对人工演示的依赖**：探索用基础模型生成、跨任务技能迁移或自监督重置等方式自动扩展策略支撑集，替代人工兜底。
- **更一般的信用分配**：将顺序式优势分解推广到同步决策、动态角色分配、智能体数量可变的场景，并研究顺序选择的自动学习。
- **真实世界规模化**：在更多真实任务、多主干、更多 rollout 下验证在线潜空间 RL，并评估长时程、部分可观测与通信受限条件下的表现。
- **探索与协作的联合设计**：在潜空间探索之上，进一步研究如何让多智能体的探索具有**协同结构**（如共享潜噪声、协同熵正则），而非各智能体独立探索。
- **与经典 MARL 的融合**：将价值分解、反事实基线等成熟技术与 VLA 的分布式价值、流匹配策略结合，形成统一的多智能体 VLA 后训练范式。

## 9. 总体评价

- **贡献定位**：本文把"多智能体 VLA 的后训练"形式化为一个**数据覆盖 → 离线信用过滤 → 在线潜空间探索**的三段式问题，并给出可操作的算法与理论动机，是对"VLA 能否从单智能体预训练走向多智能体协作"这一开放问题的系统性回答。
- **方法亮点**：
  1. 用"初始化感知"识别并补齐策略支撑集，直面 VLA 对初始条件脆弱、稀疏奖励下 RL 无法启动的现实困难；
  2. 用**望远镜式优势差分**实现智能体级信用分配，把"整条联合轨迹"的粗粒度反馈细化为"哪个机器人该改"的细粒度信号，并有可视化证据支持；
  3. 诊断出 Flow 类在线 RL 在多智能体下失败的两个根因（嘈杂探索、策略更新不稳），并用潜噪声空间 RL 给出对症方案，附噪声尺度与学习曲线的实证支撑。
- **证据强度**：仿真部分（11 个任务中的 8 个、2 个 benchmark、2 个主干、完整消融链）证据较为充分；真实世界部分为概念验证，统计强度有限。
- **影响与适用性**：工作对多臂装配、多机器人家庭操作等**需要细粒度底层协调**的场景有直接参考价值；其"数据覆盖优先于算法复杂度""探索空间选择优先于探索强度"的结论，对更广泛的具身多智能体学习也具有迁移意义。
- **一句话总结**：本文主张多智能体 VLA 的关键瓶颈是**协作基元的覆盖与信用分配**，并通过"补齐覆盖 + 智能体级信用过滤 + 潜空间在线 RL"三阶段流水线，在仿真与真实平台上取得了平均 +16%~+44% 的成功率提升，同时留下了真实规模验证、顺序假设松弛与算力透明化等开放问题。
