## 摘要
世界-动作模型联合学习机器人策略并预测未来观测，使表征空间成为控制与预测之间的接口。我们通过受控对比研究这一空间的设计，发现仅凭重建保真度或预训练感知特征都不足以确保有效的策略学习。这些发现促成了 ReWAM，一种以表征为中心、基于预训练 DINO 特征构建的世界-动作模型。特征校准（Feature Calibration）与时间表征瓶颈（Temporal Representation Bottleneck）将这些特征组织为适合动力学建模的紧凑世界状态。动作锚定表征塑形（Action-Grounded Representation Shaping）仅将动作损失梯度路由至瓶颈，从而使策略能够塑造表征所编码的内容，而世界模型则学习其如何演化。在没有生成式视频预训练的情况下，ReWAM 在 RoboTwin 2.0 上达到 93.6% 的成功率。在 RoboDojo 上，使用约 600 小时的具身预训练数据，它取得了 12.29 的平均得分和 8.28% 的成功率。

## Abstract
World-action models jointly learn robot policies and predict future observations, making the representation space an interface between control and prediction. We study the design of this space through controlled comparisons, finding that neither reconstruction fidelity nor pre-trained perceptual features alone ensure effective policy learning. These findings motivate ReWAM, a representation-centric world-action model built on pre-trained DINO features. Feature Calibration and a Temporal Representation Bottleneck organize these features into compact world states suited to dynamics modeling. Action-Grounded Representation Shaping routes only action-loss gradients to the bottleneck, thereby letting the policy shape what the representation encodes while the world model learns how it evolves. Without generative video pre-training, ReWAM achieves 93.6% success on RoboTwin 2.0. On RoboDojo, it achieves an average score of 12.29 and a success rate of 8.28% using approximately 600 hours of embodied pre-training data.

## 1. 核心问题与研究动机

- **背景**：世界-动作模型（World-Action Models, WAMs）联合学习机器人策略并预测世界如何演化，其**表征空间**因而成为"控制"与"预测"之间的共享接口。
- **主流路线及其隐患**：许多近期 WAM 建立在预训练视频生成器之上，在 Video-VAE 隐空间中预测未来观测。这类空间继承了大规模仿生视频预训练的动力学先验，但其优化目标是**视觉重建**，可能保留细粒度外观细节却不优先编码控制相关信息。
- **另一条路线**：表征空间 WAM 使用预训练感知特征或学到的视觉-动作 tokenizer 作为预测与控制的接口。
- **核心质疑**：既有比较研究已提示重建保真度不足以衡量控制效用。本文通过受控实验进一步验证——在**无生成式视频预训练**条件下，原始 DINO 特征在 RoboTwin 2.0 上反而优于 Video-VAE 隐空间（尽管像素重建 SSIM 更低：0.70 vs 0.91）。
- **第二重问题**：感知特征也并非天然适配动力学建模——逐帧特征不显式编码时序变化，其统计分布与扩散训练也不匹配。
- **由此提出的根本问题**：面向世界-动作建模的**表征空间应当如何定义**？论文的答案是：不仅在于选哪个编码器，还在于特征如何被准备、如何在时间上组织、如何被控制需求所适配。

## 2. 方法论：ReWAM

### 2.1 核心思想

- 提出**角色分工原则**：**策略塑造表征编码什么，世界模型学习该表征如何演化**。
- ReWAM 以冻结的 DINOv3-L 特征为基底，通过三个组件实现该原则：**特征校准（Feature Calibration）**、**时序表征瓶颈（Temporal Representation Bottleneck, TRB）**、**动作锚定表征塑形（Action-Grounded Representation Shaping, AGRS）**。
- 编码器 $E_\phi$ 将非重叠的观测对编码为状态：$z_j = E_\phi(o_{j-1}, o_j)$；当前状态 $z_0$ 同时条件化两个分支，$z_{1:H}$ 提供世界预测目标。

### 2.2 模型架构

- 沿用 Fast-WAM 的 **Mixture-of-Transformers（MoT）**结构，包含 world DiT（$W_\theta$）与 action DiT（$A_\theta$）两条分支。
- 两分支均接收语言指令 $\ell$ 与本体感受 $s_0$ 的条件嵌入；未来状态 token 与动作 token 都可注意当前状态世界特征，但**两组 token 之间禁止注意力**。
- world 分支使用**因果时序注意力**，且各未来状态独立采样噪声水平；action 分支**一次性预测整个动作块**。
- 条件模型分解为：$p_\theta(z_{1:H}, a_{1:H} \mid z_0, c) = p_\theta(z_{1:H} \mid z_0, c)\, p_\theta(a_{1:H} \mid z_0, c)$。
- 两分支均用 **flow matching** 训练；推理时 world 分支只处理一次 $z_0$ 用于条件化，**不生成未来状态**。

### 2.3 特征校准（Feature Calibration）

- **多层聚合**：从 DINOv3-L 的 blocks $\{12,14,16,18,20,22,24\}$ 提取 patch 特征，经非仿射 LayerNorm 并去除特殊 token；对选定层取平均，再叠加最后一层的空间均值广播到每个 patch（融合编码器深度信息与图像级上下文，同时保持 patch 网格与特征宽度 $d=1024$）。
- **归一化**：固定基线使用训练前估计的均值/方差标准化预测目标；ReWAM 因 TRB 会改变预测空间，改用**运行统计量**归一化其输出。
- **表征感知噪声调度**：以 flow time $\tau\in[0,1]$（0 为干净数据、1 为噪声），采样 $u\sim U(0,1)$ 后令 $\tau = \alpha u / (1+(\alpha-1)u)$，其中 $\alpha=\sqrt{D/D_{\text{base}}}$，$D_{\text{base}}=4096$。$D$ 为未来预测目标的标量元素总数（不含当前状态）。该偏移同时考虑 token 数与通道宽度，使更大目标偏向更噪的输入；每个未来状态独立采样 flow time，当前状态保持干净。

### 2.4 时序表征瓶颈（TRB）

- 对每个相机，将非重叠的 $2\times2\times2$ 时空块展平为 $8d$ 维 token；跨视图拼接后经**多头自注意力**与线性投影得到 **128 维 token**。
- 状态形式化：$z^{\text{raw}}_j = B_\phi(\text{Patchify}(F^{\text{MLA}}_{j-1}, F^{\text{MLA}}_j))$。
- **因果运行归一化**：用前序 batch 累积的逐通道均值 $\mu$ 与方差 $\sigma^2$ 归一化，并以指数移动平均更新；推理时统计量固定。
- 具体规模：头部相机 16×20 patch 网格、每个腕部相机 8×10，时空 patchify 后每状态 $80+20+20=120$ 个 token（初始 8192 维）；单层 8 头注意力混合跨视图 token，使用 2D RoPE（base 10000，坐标缩放 16）与相机特定的可学习 query/key 偏置。

### 2.5 动作锚定表征塑形（AGRS）

- 采用 Fast-WAM 的线性 flow matching：对干净目标 $y$ 与噪声 $\epsilon$，构造 $y_\tau=(1-\tau)y+\tau\epsilon$，目标速度为 $\epsilon-y$。
- **世界损失**：$L_{\text{world}} = \mathbb{E}\[\|W_\theta(\bar{z}_{\tau_z},\tau_z;\bar{z}_0,c)-(\epsilon_z-\bar{z})\|_2^2\]$，其中上划线表示 stop-gradient。
- **动作损失**：$L_{\text{action}} = \mathbb{E}\[\|A_\theta(a_{\tau_a},\tau_a;z_0,c)-(\epsilon_a-a)\|_2^2\]$。
- **非对称梯度路由**（关键机制）：
  - 参数更新：$\nabla_\theta L = \nabla_\theta L_{\text{world}} + \nabla_\theta L_{\text{action}}$；
  - 编码器更新：$\nabla_\phi L = (\partial z_0/\partial\phi)^\top \partial L_{\text{action}}/\partial z_0$。
- 即：世界损失梯度在**当前与未来表征处均截断**；动作损失梯度可经 world 分支的当前状态特征与 $z_0$ 进入 TRB。结果是 world 分支从两个目标学习，而**表征编码器只被动作目标塑造**。

### 3.2 对照与消融设置

- **表征空间对照**：在同一 MoT 训练协议下，比较 (i) Video-VAE 隐空间、(ii) 原始 DINO 特征、(iii) ReWAM 校准后的 DINO 特征，隔离"编码器选择"与"表征准备方式"两个变量。
- **组件消融**：分别移除特征校准、TRB、AGRS，以及把 AGRS 的非对称梯度路由替换为对称路由（即允许世界损失也回传至编码器），以验证"策略塑造表征、世界模型学习表征演化"这一分工原则的必要性。
- **噪声调度消融**：对比固定 flow time 采样与表征感知噪声调度，检验目标规模自适应偏移的收益。
- **冻结 vs 微调**：检验编码器是否应保持冻结，或允许动作目标对其做受控更新。

- 世界预测质量（以 SSIM、特征空间距离等衡量），用于说明重建保真度与控制效用之间的错位。

## 4. 主要实验结果

### 4.1 表征空间的重新排序

- 在**无生成式视频预训练**的受控条件下，原始 DINO 特征在 RoboTwin 2.0 上的控制成功率**高于 Video-VAE 隐空间**，尽管其像素重建 SSIM 明显更低（0.70 vs 0.91）。
- 该结果复现并强化了既有研究的判断：**重建保真度不是控制效用的可靠代理**；Video-VAE 隐空间优先保留外观细节，而控制所需的状态信息（几何、接触、任务相关语义）在其中未必占据主导。
- 进一步表明感知特征也非即插即用：逐帧特征缺少显式时序变化编码，其分布与扩散/flow matching 训练不匹配，因此需要校准与适配。

### 4.2 ReWAM 的整体增益

- 在 RoboTwin 2.0 多任务设定上，ReWAM 相对 Fast-WAM 基线在 clean 与 random 两种初始条件下均取得成功率提升，说明对表征的"准备与组织"比单纯更换编码器更关键。
- 在 RoboDojo 五类能力（Generalization、Precision、Long-Horizon、Memory、Open）上，ReWAM 在部分进度分数与二元成功率两个指标上整体占优，尤其在长时程与记忆类任务上体现时序表征瓶颈带来的收益。
- 具身预训练（约 600 小时真机数据、75k steps）后，ReWAM 在真机三任务上相较 Fast-WAM 取得更高成功率，说明该表征设计在真实、分布偏移的传感条件下同样成立。

### 4.3 消融结论

- **TRB**：移除后性能下降最明显，验证"把非重叠观测对压缩为时序 token"是让表征显式编码动力学变化的核心；因果运行归一化对稳定跨 batch 统计、避免推理期漂移有贡献。
- **AGRS**：非对称梯度路由（世界损失在当前与未来表征处截断，仅动作损失塑造编码器）显著优于对称路由，直接支持论文的核心命题——**策略应当决定表征编码什么**，而非让世界预测目标主导表征。
- **特征校准**：多层聚合与图像级上下文广播带来稳定的正向收益，说明编码器深度信息的融合有助于兼顾 patch 细节与全局语义。
- **表征感知噪声调度**：相对固定采样带来一致性提升，表明按预测目标规模自适应调整噪声水平有助于匹配不同 token/通道宽度下的训练难度。

### 4.4 表征分析

- 经 TRB 处理后，状态 token 在时序上更易区分、对动作更敏感，线性探测显示动作相关信息在表征中显著增强。
- 与原始逐帧 DINO 特征相比，校准 + TRB 后的表征分布更贴近 flow matching 的训练需求，缓解了"感知特征与生成式目标不匹配"的问题。

## 5. 贡献总结

1. **问题重述**：将世界-动作模型的表征问题从"选哪个编码器"推进到"特征如何被准备、如何在时间上组织、如何被控制需求塑造"。
2. **方法论**：提出 ReWAM 与"策略塑造表征、世界模型学习表征演化"的角色分工原则，并以特征校准、TRB、AGRS 三个组件具体实现。
3. **实证发现**：在无生成式预训练的受控条件下，重建保真度与控制效用出现系统性错位，DINO 特征优于 Video-VAE 隐空间。
4. **可迁移性**：在 RoboTwin 2.0、RoboDojo 与真机三任务上均取得增益，且与具身预训练兼容。

## 6. 局限与展望

- 核心实验主要在仿真中进行，真机任务数量有限（三个任务、每任务少量试验），统计效力受限。
- 编码器保持冻结，未探索动作目标对感知骨干的长期持续塑形是否带来进一步收益或灾难性遗忘。
- TRB 的时空块大小、目标维度与噪声调度超参（如 $D_{\text{base}}$、$\alpha$）的敏感性未做穷尽扫描。
- 未来方向包括：扩展到更多具身形态与更长时程任务、与更大规模视频预训练结合、以及研究表征瓶颈的可解释性与容量权衡。
