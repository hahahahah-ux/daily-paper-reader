## 摘要
基于模型的强化学习（MBRL）是一类学习环境模型并将其用于动作选择的强化学习方法，因其样本效率高而非常适合机器人领域。将学习到的模型与在线规划相结合可以进一步改善动作选择，因为规划器能够利用模型找到比仅靠学习策略更好的动作。近期将学习策略与在线规划相结合的方法通常学习策略的价值，而非更强的规划器引导行为。我们提出 CAST（Critic with Alternating State-value Target，即带交替状态值目标的评论家），它利用规划器引导行为来改进价值学习，同时用当前策略对价值估计进行正则化。CAST 将动作价值评论家替换为状态价值评论家，其训练目标结合了真实的规划器引导转移与当前策略下的想象转移。由此得到的价值函数对应于规划器引导行为与当前策略之间的交替过程，使其既能受益于更强的规划器行为，又受到正在学习的策略的正则化。我们在 DeepMind Control 和 HumanoidBench 套件上针对多种最先进方法评估 CAST，并展示了成功迁移到物理 Unitree Go2 四足机器人执行动态倒立动作。

## Abstract
Model-based reinforcement learning (MBRL) is a family of RL methods that learn a model of the environment and use it for action selection, making it well suited to robotics due to its sample efficiency. Combining learned models with online planning can further improve action selection, as the planner can exploit the model to find better actions than the learned policy alone. Recent methods combining learned policies with online planning typically learn the value of the policy rather than the stronger planner-guided behavior. We present CAST (Critic with Alternating State-value Target), which uses planner-guided behavior to improve value learning while regularizing the value estimate with the current policy. CAST replaces the action-value critic with a state-value critic, trained using a target that combines a real planner-guided transition and an imagined transition under the current policy. The resulting value function corresponds to an alternating process between planner-guided behavior and the current policy, allowing it to benefit from the stronger planner behavior while being regularised by the policy being learned. We evaluate CAST on the DeepMind Control and HumanoidBench Suites against several state-of-the-art methods, and demonstrate successful transfer to a physical Unitree Go2 quadruped performing a dynamic handstand.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于模型的强化学习（MBRL）通过显式学习环境模型来提升样本效率，特别适合机器人领域。将学习到的模型与在线规划（如 MPPI）结合，可进一步改善动作选择，因为规划器能找到比纯策略更好的动作。
- **核心问题**：近期将学习策略与在线规划结合的方法（如 MOPAC、LOOP、TD-MPC/TD-MPC2、BOOM、BMPC）通常让评论家学习**当前策略 πθ 的价值**，而非更强的**规划器引导行为 β 的价值**。然而，规划器 β 一般显著优于 πθ，尤其是在训练早期。
- **关键矛盾**：
  - 若直接以 β 的价值为自举目标，因 β 远优于 πθ，会导致策略更新幅度过大、训练不稳定（RL 中常见失效模式）。
  - 若学习动作价值 Qβ(z,a)，则每次 TD 目标都需重新查询规划器获取 β 的动作分布，计算代价极高。
- **整体含义**：作者主张评论家应学习 β 的价值（以获得更好的策略改进信号），但需要一种正则化机制来稳定训练。CAST 通过"真实 β 转移 + 想象 πθ 转移"交替构成混合 Bellman 目标，同时用状态价值评论家替代动作价值评论家，兼顾规划器优势与策略正则化。

## 2. 方法论

### 2.1 核心思想

- 将 TD-MPC2 中的动作价值评论家 Q(z,a) 替换为**状态价值评论家 V(z)**。
- 评论家训练目标由**一步真实 β 转移 + 一步想象 πθ 转移**组成，对应交替过程：**β → πθ → β → πθ → …**。
- 价值函数既非纯 Vβ 也非纯 Vπθ，而是两者交替组合诱导的价值函数，介于二者之间。

### 2.2 关键技术细节

- **基础架构（基于 TD-MPC2）**：
  - 编码器 z = hξ(s)、隐动力学 z′ = dξ(z,a)、奖励头 r = Rξ(z,a)；
  - 原 N=5 的动作价值集成 {Qiψ(z,a)} 替换为状态价值集成 {Viψ(z)}；
  - 保留 SimNorm、symlog 分布式目标、Polyak 平均目标网络等设计。
- **从动作价值到状态价值**：
  - 利用 Qπ(z,a) = R(z,a) + γVπ(d(z,a))，当需要动作价值估计时，用学习到的奖励/动力学模型与目标状态价值重构一步估计：**Q̂(z,a) = Rξ(z,a) + γV̄ψ(dξ(z,a))**。
  - 规划器终端评分由 Q̄ψ(z_{t+H}, a_{t+H}) 改为直接使用 **V̄ψ(z_{t+H})**，无需在规划时采样终端策略动作（式 8）。
- **混合价值目标（式 9）**：
  - yt = rt + γ[Rξ(z_{t+1}, ã_{t+1}) + γV̄ψ(z̃_{t+2})]，其中 ã_{t+1} ~ πθ(·|z_{t+1})，z̃_{t+2} = dξ(z_{t+1}, ã_{t+1})。
  - 第一项来自回放缓冲区的真实 β 转移，第二项由学习模型在当前策略下想象生成。
- **理论分析（命题 1）**：
  - 定义 Bellman 算子 Tβ 与 Tπθ，CAST 目标对应复合算子 **T_CAST = Tβ Tπθ**。
  - 在固定策略、确定性动力学、无表示误差假设下，T_CAST 是 **γ²-压缩**，存在唯一不动点 V_CAST。
  - 展开后 V_CAST(z) = E[r₀^β + γr₁^π + γ²r₂^β + γ³r₃^π + …]，即 β 与 πθ 交替折扣奖励，位于 Vβ 与 Vπθ 之间。

### 2.3 扩展策略梯度（Expanded Policy Gradient）

- 由于 V(z) 不含动作输入，无法像 Q(z,πθ(z)) 那样直接对策略动作求导，因此通过可微奖励/动力学头重构一步估计（式 19）：**Ĵ₁(z;θ) = Rξ(z, πθ(z)) + γV̄ψ(dξ(z, πθ(z)))**。
- 递归展开 Hπ 步，得到 k 步模型内策略改进目标（式 21）：Jk(z₀;θ) = Σ γ^i Rξ(z(i), a(i)) + γ^{Hπ} V̄ψ(z(Hπ))。
- 使用重参数化策略，梯度沿想象链 **πθ → Rξ → dξ → … → V̄ψ** 传播，世界模型被视为固定可微模拟器。主配置取 **Hπ = 1**。

### 2.4 算法流程（Algorithm 1）

1. 用 MPPI 规划（终端评分用 V̄ψ）选动作，执行第一步，存入回放缓冲区；
2. 采样轨迹，构造混合价值目标 yt（式 9）；
3. 联合更新编码器、动力学、奖励、价值头（策略 θ 不参与此步）；
4. 用扩展策略梯度更新策略 πθ；
5. Polyak 更新目标网络。

## 6. 主要结论与发现

- **样本效率**：CAST 在多数环境上匹配或超越基线，且更早达到高回报，尤其在人形机器人任务（H1hand-run、H1hand-pole、Dog-run）上明显优于 BMPC 和 BOOM。
- **AUC 性能剖面**：CAST 在 14 个任务上取得最佳的平均 AUC 性能剖面；DMControl 上其曲线与 BMPC 在 τ≈0.9 前均保持 1.0，BOOM 更早衰减；HumanoidBench 上 CAST 在 τ≈0.85 前保持 1.0，BMPC 衰减最早。
- **最终性能**：1M 步时 CAST 平均回报最高（764 ± 63），优于 BMPC（644 ± 43）与 BOOM（721 ± 41）；2M 步时各规划方法趋近收敛，差距缩小，CAST 仍具竞争力（839 ± 29，与 BOOM 849 ± 29 相当），优于 BMPC（691 ± 60）。
- **消融结论**：
  - 纯离策略（直接自举 Vβ）在所有任务上表现最差，验证了"直接从 β 自举导致训练不稳定"的假设；
  - 纯在策略（BMPC 式目标）有竞争力但仍落后于混合目标；
  - HV=1 在 Humanoid-run 上明显优于 HV=2/3，说明"一步真实 β + 一步想象 πθ"是良好平衡；
  - Hπ=1 略优于 Hπ=2/3 且置信区间更小，更长展开未带来收益。
- **真机迁移**：结合动力学域随机化与课程学习，仿真训练的策略无需在线规划即可直接部署到 Unitree Go2，稳定完成动态倒立。

## 7. 优点

- **动机清晰且反直觉合理**：指出"评论家应学 β 而非 πθ"这一被现有方法忽视的观察，并给出稳定化方案。
- **理论贡献**：给出了混合 Bellman 算子的 γ²-压缩性与唯一不动点证明，明确刻画了所学价值函数的语义（β 与 πθ 交替折扣回报）。
- **架构选择有据**：用状态价值替代动作价值不仅是为学习 Vβ，更因为 Qβ 需要反复查询规划器，计算上不可行；Vβ 仅需状态空间探索，可复用回放缓冲区。

- **真机验证**：在 Unitree Go2 上完成动态倒立，展示了 sim-to-real 的实用潜力。
