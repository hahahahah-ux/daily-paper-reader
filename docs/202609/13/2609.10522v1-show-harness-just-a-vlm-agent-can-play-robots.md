## 摘要
基础视觉语言模型（VLM）展现出关于世界的广泛智能，但将这种智能转化为机器人控制仍然颇具挑战。我们提出 Show-Harness，一种具身 Harness，它通过一个连接意图与动作的紧凑语义接口，使 VLM 能够“操控”机器人。Show-Harness 暴露出离散的语义动作单元，VLM 可以对其进行自然的推理，而针对特定具身形态的解释器则确定性地将这些动作单元落地为本地机器人动作，从而使 VLM 直接负责细粒度的物理决策。通过同一接口，Show-Harness 验证了两条路径的可行性：(1) 直接解锁闭源前沿 VLM 以实现零样本机器人控制；(2) 仅用数 GPU 小时的微调即可让中小规模开源 VLM 适配低成本部署。我们进一步开发了 GUMI（GUI 操作接口），它将同一语义动作空间扩展到基于 GUI 的示教数据采集，使人类与智能体无需专用遥操作硬件即可跨具身形态“操控”机器人。大量实验表明，配备 Show-Harness 的 VLM 智能体能够在任务、具身形态和环境之间稳健泛化，性能优于代表性的智能体型与 VLA 范式。这些结果表明，恰当的接口可以从基础 VLM 中释放出可观的具身能力，而无需额外的模型容量或昂贵的具身特定预训练。

## Abstract
Foundation vision-language models (VLMs) exhibit broad intelligence about the world, yet translating this intelligence into robot control remains challenging. We present Show-Harness, an Embodied Harness that enables VLMs to "play" robots through a compact semantic interface linking intent to action. Show-Harness exposes discrete semantic action units that VLMs can naturally reason over, while embodiment-specific interpreters deterministically ground them into local robot actions, keeping the VLM directly responsible for fine-grained physical decisions. Through the same interface, Show-Harness demonstrates the feasibility of (1) directly unlocking closed-source frontier VLMs for zero-shot robot control, and (2) adapting small-scale open-source VLMs for low-cost deployment with just a few GPU-hours of fine-tuning. We further develop GUMI (GUI Manipulation Interface), which extends the same semantic action space to GUI-based demonstration collection, allowing humans and agents to "play" robots across embodiments without specialized teleoperation hardware. Extensive experiments show that Show-Harness-equipped VLM agents generalize robustly across tasks, embodiments, and environments, outperforming representative agentic and VLA paradigms. These results suggest that the right interface can unlock substantial embodied capability from foundation VLMs, without requiring additional model capacity or costly embodiment-specific pretraining.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心矛盾**：基础视觉语言模型（VLM）已编码了机器人操作所需的大量知识（物体识别、空间关系、长程目标分解），但这类知识难以直接转化为机器人行为。
- **两条现有路线的困境**：
  - **VLA 路线（把 VLM 当低层策略）**：通过微调让 VLM 回归具身特定的连续动作，把广泛的语义知识坍缩为不透明的“像素→驱动”映射，跨任务、环境、具身往往需要反复适配，且依赖新的机器人轨迹数据。
  - **分层/程序化路线（把 VLM 当中层决策者）**：VLM 输出子任务调用、关键点、可供性目标或控制 API 程序，保留语义但“交出物理”——模型只表达意图，无法直接看到意图如何落地，每种表示都绑定到系统特定的工程化接地管线。
- **核心论点**：将基础模型智能带入物理世界，关键不在于增加模型容量或具身预训练，而在于**一个合适的接口**——既对 VLM 语义上可自然推理，又足够细粒度以直接进行物理控制。
- **整体含义**：Show-Harness 是一个模型无关的“具身 Harness”，通过紧凑语义动作接口让 VLM 直接“操控（play）”机器人；同一接口同时统一了人类 GUI 操作、智能体控制与策略学习。

## 2. 方法论

### 2.1 核心思想

- 将机器人控制重构为**离散语义动作单元**的序列决策：每个单元代表一个方向的单步移动或夹爪动作，VLM 直接输出这些符号；再由**具身特定解释器**确定性地把符号落地为有界的小幅机器人运动。
- 形成闭环：多视角观测 + 本体感知 → 推理 → 语义动作 → 执行反馈 → 下一步，使 VLM 成为“情境化智能体”，在它原生理解的语义空间中推理，同时直接负责细粒度物理决策。

### 2.2 语义动作空间 A

- 平移：`MV_FWD / MV_BACK`、`MV_LEFT / MV_RIGHT`、`MV_UP / MV_DOWN`（相对当前参考视图定义方向）。
- 旋转：`ROTATE_CW / ROTATE_CCW`，每个需指定轴（x/y/z），增量为 15°。
- 夹爪：`GRASP / RELEASE`。
- 终止：`DONE`。
- **三性质**：(i) **增量式**——每单元只造成局部小幅变化，VLM 可通过连续修正实现精确行为，且能灵活切换步长粒度而不需微调；(ii) **可解释且具身无关**——动作用语义符号而非数值目标表示；(iii) **视觉接地**——运动方向相对可观测视图定义，使空间推理可映射为动作。

### 2.3 具身接地（解释器）

- 解释器 g_E 更新 6-DoF 笛卡尔位姿设定点：

  `s_{t+1} = Π_E( x_t + σ_t · R_E · d_a , exp(θ_t [R_E r_a]_×) · Q_t )`

  - `d_a`、`r_a` 分别编码平移与旋转方向；`[·]_×` 为反对称矩阵算子；
  - `σ_t`、`θ_t` 为校准后的平移/旋转增量；`R_E` 把语义方向映射到具身运动坐标系；
  - `Π_E` 强制工作空间与单步平移/旋转限制（安全边界，违规动作执行前被阻止）。
- 夹爪单元绕过位姿更新，直接映射为开/合命令。
- **不同具身实现同一语义单元**：Franka 用阻抗控制跟踪笛卡尔设定点；AgileX 用逆运动学 + 流式关节目标；仿真执行相应操作空间命令。适配新具身只需新的解释器。

### 2.4 具身 Harness 架构（三阶段插件）

- **Perception**：
  - *Multi-View Guidance*：告知 VLM 各相机视图的角色与优先级（全局视角给场景上下文，腕部视角给细粒度对齐证据）。
  - *Proprioception*：将机器人状态、接触、夹爪状态转为文本反馈（夹爪高度、单步位移、阶段提示、接触状态等）。
- **Reasoning**：
  - *Subtask Planning*：VLM 作为规划器把指令分解为有序子任务及可视觉检查的完成标准。
  - *Situated Planning*：延迟不确定决策，待执行中信息可观测时再选择性重规划（支持条件任务）。
  - *Action Chunking*：在无需细粒度反馈时（如目标较远）自适应降低模型查询频率，开环执行短动作序列。
  - *Adaptive Step*：动态调整步长，远目标用大步（4 cm）、近目标用细步（2 cm）。
  - *Visual Prompt*：用专门模型调用把模糊语言目标转为视觉标记，突出相关可供性。
- **Action**：
  - *Action History*：携带最近 5 个动作，抑制振荡。
  - *Failure Recovery*：检测抓取失败，重置夹爪并回滚到抓取子任务。

### 2.5 两种控制模式

- **ZS 模式（零样本）**：闭源前沿 VLM 无需微调直接控制机器人，直接继承前沿模型能力的进步。
- **FT 模式（微调小模型）**：在共享动作空间采集的演示 D 上，最小化目标单元的词元级交叉熵：

  `L(θ) = −Σ_{(ℓ,o,h,a)∈D} log π_θ( a | Φ_Pmin(ℓ, o, h) )`

  - `Φ_Pmin` 仅保留任务指令、多视角观测与短动作历史；
  - 语义动作**通过 VLM 原生词表预测**，无专用动作头或特殊 token；使用 rank-64 LoRA（冻结视觉编码器与多模态投影器，仅更新约 3% 参数）。

### 2.6 GUMI（GUI 操作接口）

- 把离散语义动作空间暴露为轻量图形界面：每个单元映射到一个带标签的控件与按键。
- 人类可键盘“操控”机器人，computer-use 智能体可操作同一 GUI，通用 VLM 智能体可直接预测单元。
- 每步记录执行前观测与所选动作，生成策略可用的 `(o_t, a_t)` 对；因每单元被确定性接地，还可保留对应低层命令与轨迹，使一份演示同时训练语义动作策略与连续控制策略。
- 支持逐步控制、排队动作块、单/双臂操作、人–智能体混合采集（人类可介入纠正智能体 rollout）；无需专用遥操作硬件，支持远程采集。

## 4. 资源与算力

- **推理**：本地模型在**单张 RTX 5090 GPU** 上服务；前沿模型通过 API 访问。
- **微调**：Qwen3.5-2B 在**单张 H200 上不到 2 小时**完成；配置为 40 epochs、7.9K 单臂样本、学习率 1e-4、cosine schedule、warmup 0.1、bf16、256×256 视图、有效 batch size 32。
- **可及性**：论文明确称微调轻量，**可在 24 GB 级 GPU 上完成**。
- **未明确说明**：前沿 VLM（Gemini-3.1 Pro 等）的 API 调用成本、总推理 GPU 小时、实验总时长等未给出具体数字。

## 5. 实验数量与充分性

- **主实验规模**：Cross-task 10 任务 × 10 次 = 100 trials；Cross-environment 4 种偏移 × 20 次 + sim-to-real 20 次；Cross-embodiment 5 任务 × 10 次 × 2
