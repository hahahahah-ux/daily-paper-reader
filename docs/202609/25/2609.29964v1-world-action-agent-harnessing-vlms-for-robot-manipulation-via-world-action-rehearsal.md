## 摘要
通用视觉语言模型（VLM）为机器人操作带来了广泛的知识与空间推理能力，但现有系统要么间接使用它们来预测约束或编写程序，要么只给它们一个场景视图，而非一个可供行动的世界。我们提出 World Action Agent（WAA），一种多智能体驾驭框架，使 VLM 能够借助基本工具操控机器人，并在视觉动作工作空间中做出每一个决策。该工作空间具有三个特性。接触视图由场景几何自动选择，呈现当前交互周围的场景。动作预演将每个动作转化为可编辑的提案，智能体可独自或通过想象智能体（Imagination Agent）在执行前依据规划反馈预览并修改该提案。视图内校正闭合了观察、预演与底层执行之间的回路，使智能体能在其观察到残差偏移的视图中消除这些偏移。通过同一工作空间，WAA 以两种方式获得具身程序性知识：它在基于证据的评审下，从专家视频和人类教学中演化出多模态技能，并通过技能智能体（Skill Agent）调用这些技能；其交互轨迹则训练更小的 VLM 来操控同一框架。在 LIBERO-Pro 上，仅使用从 LIBERO-90 演化出的技能的 WAA 达到当前最优的 75.6% 平均成功率，优于端到端 VLA、代码即策略（code-as-policy）智能体，以及相同骨干网络的视觉框架基线；这些技能无需进一步学习即可在 robosuite 上保持有效。在框架轨迹上微调 Qwen3.5-9B，将其域外成功率从 1.7% 提升至 43.3%。

## Abstract
General-purpose vision-language models (VLMs) bring broad knowledge and spatial reasoning to robot manipulation, yet existing systems either use them indirectly, to predict constraints or write programs, or give them a view of the scene rather than a world in which to act. We present World Action Agent (WAA), a multi-agent harness through which VLMs pilot robots with basic tools, making every decision within a visual action workspace. The workspace has three properties. Contact views, selected automatically from the scene geometry, present the scene around the current interaction. Action rehearsal turns each action into an editable proposal that the agent, alone or through an Imagination Agent, previews and revises against planning feedback before execution. In-view correction closes the loop between observation, rehearsal, and low-level execution, letting the agent remove residual offsets in the view where it observes them. Through the same workspace, WAA acquires embodied procedural knowledge in two ways: it evolves multimodal skills from expert videos and human teaching under evidence-based review and consults them through a Skill Agent, and its interaction traces train smaller VLMs to pilot the same harness. On LIBERO-Pro, WAA with skills evolved only from LIBERO-90 reaches a state-of-the-art 75.6% average success, outperforming end-to-end VLAs, code-as-policy agents, and a visual-harness baseline with the same backbone; the same skills remain effective on robosuite without further learning. Fine-tuning Qwen3.5-9B on harness traces raises its out-of-domain success from 1.7% to 43.3%.

## 1. 核心问题与研究动机

- **背景**：视觉语言动作模型（VLA）从视觉、语言与动作中学习操作策略，但为动作预测而微调 VLM 可能削弱其通用理解与推理能力；世界动作模型（WAM）耦合环境动力学与动作学习，却仍需机器人数据做动作对齐，跨本体迁移对形态与动作空间差异敏感。
- **现有 VLM 用法的两条路线**：
  - 间接路线：HAMSTER/ReKep 让 VLM 预测中间路径或关系约束，交由下游策略/优化器转成运动；CaP/CaP-X 让语言模型把感知与控制 API 组合成程序并依据执行反馈修订。VLM 只是提供约束、空间指引或间接写程序，而非凭自身空间理解与基本原语直接控制机器人。
  - 视觉接口路线：Show-Harness、VIA 让 VLM 直接通过视觉机器人界面选择与修订动作，但界面只是"把场景显示给 VLM"，并未给它一个"可行动的世界"。
- **三个关键缺失**：
  1. 观察不以交互为中心，而成功往往取决于夹爪—物体—目标之间的局部关系；
  2. 动作一旦发出立即生效，VLM 无法在执行前看到其后果；
  3. 感知与动作处于不同空间，图像中观察到的偏移必须先被改写为坐标才能纠正。
- **核心问题**：通用 VLM 如何用基本动作原语，在执行全程持续做决策与修订，充当机器人"驾驶员"（pilot）？作者的回答是改变 VLM **看到什么**以及**决策如何生效**，而不是改变 VLM 本身。

## 2. 方法论

### 2.1 总体框架
- WAA 是一个多智能体具身驾驭框架（harness），智能体仅通过基本工具观察场景、构造动作、驱动机器人、构建与检索多模态技能，所有决策都在**同一个视觉动作工作区（Canvas）**内完成。
- **问题形式化**：给定任务指令 \(g\)，第 \(t\) 步 harness 提供多视图 Canvas \(C_t\) 与控制上下文 \(m_t\)（记录有效空间引用、待执行提案 \(\hat a_t\)、近期执行反馈），策略选择工具调用 \(u_t \sim \pi_\theta(\cdot \mid g, C_t, m_t)\)。
- **工具分三类**：query 工具（获取空间信息或技能指导）、proposal 工具（构造/修订 \(\hat a_t\) 并返回视觉预览与规划反馈）、execution 工具（移动机器人）。query 与 proposal 不改变物理世界，因此可反复检查与修订后再提交。回合在任务成功或交互预算耗尽时结束。

### 2.2 三个设计（构成视觉动作工作区）
1. **交互中心 Canvas（Contact views）**
   - 根据场景点云 \(P_t\)、机器人几何 \(R_t\)、高亮交互区域 \(H_t\) 主动求解接触视图相机参数：
     \(c_t = \arg\max_{c\in\Omega} S_{vis}(c;H_t,R_t|P_t) + \lambda_1 S_{frame}(c;H_t) - \lambda_2 E_{red}(c) - \lambda_3 E_{stab}(c,c_{t-1})\)
   - 其中 \(S_{vis}\) 衡量遮挡下交互区域与夹爪可见性，\(S_{frame}\) 鼓励紧凑取景，\(E_{red}\) 惩罚同方向冗余视角，\(E_{stab}\) 抑制视角跳变以保持跨步空间关系可比。可行集 \(\Omega\) 约束两个接触视图的水平投影正交，使对齐误差可沿两个独立方向读出。
   - Canvas = 全局视图（任务上下文）+ 接触视图（细粒度交互关系）；所有视图保留投影标定，图像空间标注可直接映射到 3D。
   - 只要求机器人基座系下的场景点云，故对来源无关：仿真渲染、标定 RGB-D 融合 + 正运动学手部几何、或 VGGT 等前馈模型从 RGB 重建均可。
2. **动作预演（Action rehearsal）**
   - 动作被表示为**可编辑提案**而非一次性输出。智能体在 Canvas 上定位目标并指定目标位姿，harness 解逆运动学、用 cuRobo 规划运动、在每个视图中叠加半透明机器人并报告可行性。
   - 智能体可先检查接近方向、预期接触与周边间隙，再修订位姿；更细调整可委托 **Imagination Agent**（独立上下文）在物理场景不变的前提下迭代编辑与重规划，只返回修订后的提案。
   - 只有具备可执行计划的提案才能变成物理运动，从而把 VLM 对任务几何的判断与规划器的可行性检查耦合，在执行前暴露错误。
3. **闭环执行与视内校正（In-view correction）**
   - 目标级规划适合大范围移动，但深度噪声、标定误差与接触扰动会留下残差偏移，往往决定放置是否成功。
   - 智能体直接在观察到误差的接触视图中从参考点拖拽到期望位置，harness 用该视图标定把图像空间意图转成**有界的末端位移**；参考点可为夹爪或所持物体的可见点，因此无需先把关系转换为绝对夹爪位姿。
   - 两个正交接触视图支持沿互补方向的校正；每次校正后由新观察决定继续调整、释放物体或进入下一个目标级动作。局部运动有界：水平/向下 0.03 m、向上 0.08 m、对角总位移 0.08 m。

### 2.3 通过同一工作区获得具身程序性知识
- **非参数路径——多模态技能库**：每个技能包含适用条件、程序、关键状态与参考图像、可观察的结果检查；程序规定夹爪/物体/目标应满足的关系、所需接触与间隙、失败恢复方式，而非固定坐标或位移，数值仅作待调整的暂定范围，因此可跨物体实例、布局与视角迁移。
  - 执行时主智能体按名称与描述选择技能，把解读委托给 **Skill Agent**（独立上下文）：它挑选相关程序状态与参考图、与当前 Canvas 对比、报告适用性、场景差异与尚无法确认的关系；参考图留在子智能体上下文中，避免历史图像被误认为当前场景。场景相关建议在观察或控制状态变化后失效。
  - **技能演化三
