## 摘要
当前的视觉-语言-动作（VLA）模型通常难以应对高精度机器人操作。我们将这一局限主要归因于其视觉注意力分散在任务无关区域。为解决该问题，我们提出 ActGaze，一种训练方法，引导 VLA 策略注视任务相关区域，就像人类在执行精细动作时会注视关键视觉线索一样。与依赖外部标签进行注视监督的先前方法不同，ActGaze 利用反事实视觉干预识别对动作预测至关重要的区域，从而直接从 VLA 自身的动作目标中导出空间监督。在四个高精度机器人操作任务上的大量真实机器人实验表明，ActGaze 能促使视觉注意力更集中于任务相关区域，并持续优于基础 VLA 策略和其他视觉接地方法。

## Abstract
Current Vision-Language-Action (VLA) models often struggle with high-precision robotic manipulation. We attribute this limitation primarily to their visual attention being dispersed across task-irrelevant regions. To address this issue, we propose ActGaze, a training approach that guides VLA policies to gaze on task-relevant regions, much like humans gaze on critical visual cues while executing precise movements. Unlike prior methods that rely on external labels for gaze supervision, ActGaze derives spatial supervision directly from the VLA's own action objective by using counterfactual visual interventions to identify regions that are critical for action prediction. Extensive real-robot experiments on four high-precision robotic manipulation tasks demonstrate that ActGaze induces more focused visual attention on task-relevant regions and consistently outperforms the base VLA policy and other visual-grounding approaches.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型在泛化性上表现良好，但在插入、装配等**高精度操作**任务上仍然脆弱，而这类任务在工业场景中极为基础且关键。
- **核心问题**：作者结合已有工作与自身实证分析，指出 VLA 的主要失败模式是**视觉注意力错配**——注意力分散在背景杂波、反光、干扰物等任务无关区域，而非聚焦于对当前动作真正关键的视觉线索。高精度任务中，关键信息往往只占极小的图像区域。
- **根因分析**：标准端到端 VLA 训练中，动作目标只监督预测动作，**不直接约束模型该看哪里**；任务相关的视觉证据未被显式优先化，从而影响鲁棒性与泛化。
- **现有方案的局限**：已有的空间监督来源包括人类注视记录、人工标注掩码/关键点、外部模型生成的伪标签。虽有效，但需要额外采集、标注或伪标签生成成本，且外部模型提供的多为**语义物体级**的粗略相关性，难以刻画随操作阶段变化的关键区域（如抓取区 → 目标开口/配合界面）。
- **整体含义**：论文提出从**策略自身的动作目标**中直接推导空间监督，无需任何外部标注或接地模型，为高精度操作提供一种可扩展的注意力监督范式。

## 2. 方法论

### 2.1 核心思想
用**反事实视觉干预**回答一个因果式问题：若抑制某个视觉区域的证据、其余观测不变，策略的动作预测会变差多少？损失增量越大，说明该区域对动作预测越关键。将这些干预响应转化为显式空间监督，训练注视头，再回流到 VLA 的注意力上。

### 2.2 问题形式化
- 策略 πθ 在时刻 t 输入多视角 RGB 观测 I_t={I_t^v}、机器人状态 s_t、语言指令 l，输出 H 步动作块 A_t。
- 引入注视头 G_φ 输出跨视角、跨 patch 的**联合归一化**相关性分布 ĝ_t，Σ_v Σ_p ĝ_{t,v,p}=1，从而可在不同相机视角间动态分配视觉相关性。

### 2.3 三阶段训练流程（Algorithm 1 / Fig. 2）

**Stage I：策略初始化（Policy Initialization）**
- 用标准动作预测损失 L_act 在示教数据 D 上训练 πθ 至收敛（验证动作损失低于经验阈值 ε_act=0.002），随后冻结为 π̄θ。
- 动机：收敛的动作目标只保证行为层面可用，**不保证视觉接地正确**（可能依赖相关但非本质的线索），因此后续不直接蒸馏其注意力，而是用干预重新定位关键区域。

**Stage II：动作到注视蒸馏（Action-to-Gaze Distillation）**
- **反事实视觉干预**：对区域 S 施加干预得到 I(I_t;S)，定义动作相关性
  r_t(S) = L_act(I(I_t;S)) − L_act(I_t)。
  干预时保持示教动作、状态、指令、流匹配采样时间/噪声/噪声动作/目标速度不变，使两次损失仅因视觉证据不同而不同，减少随机波动。
- **层级干预（两个尺度）**：
  - 相机级：掩蔽整个相机视角，估计各视角的相对重要性；
  - Patch 级：对视角内 K 个候选区域（每个为 16×16 patch 网格上的 2×2 共 4 个 patch 块）做模糊，估计局部相关性。
  - 相机级归一化相关性 w_{t,v} 用于加权 patch 级注视监督。
- **注视学习**：将每个视角内候选区域响应归一化为相对分布 q_{t,v}（相对归一化强调区域间的比较重要性、削弱绝对变化带来的分布偏移影响）；注视头从干净观测预测 patch logits，按候选区域聚合归一化得 q̂_{t,v}。优化加权交叉熵：
  L_gaze = −Σ_v w_{t,v} Σ_k q_{t,v,k} log q̂_{t,v,k}，其中 Σ_v w_{t,v}=1。
- **效率设计**：每步仅采样少量候选区域（每视角 K=2），避免逐 patch 穷举干预，支持“在线生成”干预监督。

**Stage III：注视到动作精炼（Gaze-to-Action Refinement）**
- 冻结注视头，将 πθ 从 π̄θ 重新初始化；将策略的动作-视觉注意力 α_{θ,t} 与注视预测 ĝ_t 在多视角全部有效 patch 上归一化后对齐：
  L_refine = L_act + λ_align ‖α_{θ,t} − ĝ_t‖²₂。
- 平方 L2 提供平滑的空间正则，L_act 保持动作预测能力；使用 **PCGrad** 缓解动作预测与注视对齐两个目标之间的梯度冲突。

### 2.4 理论支撑（附录 A）
- 定义区域 S 的**预测价值** V(S) = E‖Y−Ŷ_{−S}‖² − E‖Y−Ŷ‖²，并证明 **Proposition 1**：V(S) = E‖Ŷ−Ŷ_{−S}‖² ≥ 0；若移除 S 不改变最优预测则 V(S)=0，反之越大。
- 强调该价值是**上下文相关**的：其他区域/视角可能补偿被移除的信息，因此相关性是相对剩余视觉上下文而言。
- 实际量 r(S) 是对 V(S) 的**单策略近似**（用已初始化策略近似全信息预测器，用视觉抑制近似理想信息移除）；对实验中使用的流匹配动作头，其目标为速度回归 + 平方损失，与 Proposition 1 的设定直接匹配。
