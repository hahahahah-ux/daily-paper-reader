## 摘要
世界-动作模型通过预测未来观测来引导动作生成，但以视觉为中心的预测会遗漏决定富接触操作的局部接触线索。然而，在我们的实验中，将未来触觉观测作为额外视图进行朴素预测，仅能获得可实现增益的三分之一。这一差距反映了时序错配：预测先于执行，而触觉反馈在执行期间到达。我们提出 TacPAC，将触觉预测转化为实时动作校正。一旦基础模型规划出一个动作块，TacPAC 会将该规划所依据的预测接触连同规划自身的表示一起缓存，触觉专家则根据该缓存解读每个新观测到的触觉图像，以校正尚未执行的动作。因此，反馈是相对于规划所预期的情况来解释的，而非孤立解读；一次校正只需对该缓存进行一次前向传递，比重新生成动作块便宜 20.7 倍。在涵盖精密插入、易碎物体处理、物体重定向和长时程操作的五项真实机器人任务上，TacPAC 在每个任务上均领先，并将其仅视觉基础模型的平均成功率从 22% 提升至 64%。代码见 https://github.com/LogosRoboticsGroup/TacPAC。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

- **背景**：富接触操作（如插充电器插头、抓薯片）需要机器人依据物理交互调整动作，而不仅是可见的场景几何。图像能提供全局上下文，却难以分辨局部形变、初始滑移或微小插入偏差，而这些恰恰决定任务成败。
- **技术脉络**：近期视觉-语言-动作（VLA）策略直接将多模态上下文映射为动作块；世界-动作模型（WAM）则额外预测未来观测，让动作 token 关注预测结果，从而获得动作后果的预测先验。但该先验几乎完全由视觉观测主导。
- **直接问题**：当任务成败取决于图像中表达微弱或被遮挡的接触变化时，动作仍不可靠。将触觉图像作为额外视图与未来视频一起预测，确实能提升成功率，但实验显示**仅能获得触觉感知本可实现增益的约三分之一**。
- **根因诊断（时序错配）**：预测发生在执行之前，而触觉反馈在执行期间才到达。更根本地，执行前做出的预测无法修正"已规划但尚未执行"的动作。因此关键挑战是**把预测的触觉交互与执行中获取的触觉证据连接起来**。
- **整体含义**：论文主张触觉预测本身不足，必须让预测成为可被实时读取的"参照"，据此对尚未执行的动作进行在线校正。

## 2. 方法论

### 2.1 核心思想
- 将触觉预测转化为**实时动作校正**：基础模型规划出动作块后，缓存"该规划所依据的预测接触"以及"规划自身的内部表示"；触觉专家读取每个新到的触觉图像时，是对照缓存（即计划预期）而非孤立解读，输出未执行动作的逐步增量动作。
- 同一读数在不同执行阶段可能要求相反响应，因此"应该感知到什么"与"实际感知到什么"必须同时可见。

### 2.2 基础模型（Base Model）
- 采用三专家 Mixture-of-Transformers（MoT）结构：视频专家、动作专家（后续再加触觉专家）。
- 两个触觉视图被拼进同一视频流并编码为单一 latent `z`，因此**预测未来触觉就是预测未来视频的一部分**。
- 观测与动作生成均使用**条件流匹配**：构造 `x_τ = (1-τ)x + τϵ`，目标速度 `u = ϵ - x`；观测首帧保持干净，未来观测 latent 与动作块从噪声起步。流时间 `τ` 与物理时间 `t` 无关。
- 非对称注意力掩码：动作 query 可关注全部视频与动作 token；视频 query 只关注视频 token。因此**预测观测条件化动作生成，而含噪动作不干扰观测预测**。
- 触觉 token 兼具双重角色：既是被生成的内容，又是动作块的生成依据，即动作块被条件化于"模型预测自身动作将产生的接触"。

### 2.3 预测锚定的触觉校正（核心机制）
- **缓存构建**：去噪完成后，在流时间 `τ=0` 对干净视频 latent 与计划块 `â` 再跑一次额外前向，存储逐层注意力的 key/value 作为缓存 `C`。缓存保留两组：**触觉视图**（跨 horizon 的预测接触）与**动作 token**（模型在关注该预测时对计划块的表示）。不保留视觉键——理由是校正需分辨的是几个动作步内即可变化的接触，而场景在块内变化很小，且已被两组缓存（它们本就关注过视觉）承载。
- **触觉专家**：单次前向校正器。query 序列包含当前触觉图像 `I_m` 与更新后的计划块 `â`。更新方式：前 `m` 项替换为实际发送的命令，其余保留基础模型计划值，并为每项加入学习的状态嵌入（已执行/未执行）。每层注意力同时关注缓存 `C` 与专家自身 token。
- **输出**：逐步增量动作 `Δa = f(I_m, â, m, C)`，校正块为 `â + Δa`。
- 专家与基础专家共享深度与注意力几何，以便消费其逐层缓存；指令仅通过缓存键传入（缓存产生于文本条件下）。专家**以执行偏移 `m` 而非流时间条件化**：偏移决定了触觉帧落在计划的哪个阶段、应对照缓存预测的哪一部分、以及还剩多少动作可修正。
- **两项工程优势**：
  1. 每次校正仅需一次前向（触觉 token + H 个动作 token 关注固定缓存），不重跑视频流或去噪调度，可跟上触觉帧率。
  2. 每个校正**加在原始计划块上而非上次校正结果上**，避免虚假校正向后续传播。
