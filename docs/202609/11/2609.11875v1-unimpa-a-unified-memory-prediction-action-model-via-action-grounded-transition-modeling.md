## 摘要
视觉-语言-动作（VLA）模型的最新进展提升了机器人操作能力，但从观测到动作的学习仍受限于一个根本性的转移可实现性差距，表现为三个紧密耦合的问题：（i）转移歧义。视觉上相似的当前观测可能对应不同的操作阶段，并意味着不同的后续转移。（ii）预测-执行失配。视觉上合理的预测未来观测并不一定对应物理上可实现的转移。（iii）经验-实现失配。历史上可执行的动作模式在当前场景中未必能实现预期转移，因此需要上下文感知的适应。为此，我们提出 UniMPA，一种统一的记忆-预测-动作模型，通过共享的动作接地转移接口解决这些问题。（i）UniMPA 引入持续-选择性未来预测，通过建模预期的未来状态演化来解决转移歧义。持续潜在流持续跟踪任务级进展，而转移关键像素流通过基于记忆的预测选择性地解析细粒度交互变化。（ii）为了评估预期转移的物理可执行性，预测转移会查询一个时序视觉-动作记忆库。该记忆库检索历史上已实现的视觉-动作经验，将未来预测建立在可执行证据之上。（iii）为了将可执行经验适应当前场景，一个动作-视觉记忆库从历史动作演化中检索视觉接地的动作原型。随后，原型偏置流将流源推向历史上支持的动作流形，以进行上下文感知的细化。

## Abstract
Recent advances in Vision-Language-Action (VLA) models have improved robotic manipulation, yet observation-to-action learning remains limited by a fundamental transition realizability gap, manifested in three tightly coupled problems: (i) Transition ambiguity. Visually similar current observations may correspond to different manipulation phases and imply different subsequent transitions. (ii) Prediction--execution mismatch. A visually plausible predicted future observation does not necessarily correspond to a physically realizable transition. (iii) Experience--realization mismatch. A historically executable action pattern may not necessarily realize the intended transition in the current scene and therefore requires context-aware adaptation. Accordingly, we propose UniMPA, a Unified Memory-Prediction-Action model that addresses these problems through a shared action-grounded transition interface. (i) UniMPA introduces Persistent-Selective Future Prediction to resolve transition ambiguity by modeling the intended future state evolution. A persistent latent stream continuously tracks task-level progress, while a transition-critical pixel stream selectively resolves fine-grained interaction changes through memory-grounded prediction. (ii) To assess the physical executability of the anticipated transition, the predicted transition queries a temporal Visual-Action Memory Bank. The bank retrieves historically realized visual-action experience, grounding future prediction in executable evidence. (iii) To adapt executable experience to the current scene, an Action-Visual Memory Bank retrieves visually grounded action prototypes from historical action evolution. Prototype-Biased Flow then shifts the flow source toward a historically supported action manifold for context-aware refinement.

## 1. 核心问题与整体含义（研究动机与背景）

- **根本瓶颈：转移可实现性差距（Transition Realizability Gap）**
  - 现有 VLA 模型大多直接学习观测到动作的映射 `Vt → At`，将"预期转移"隐式化，导致无法回答：*如何把预期的未来变化翻译为当前场景中物理可执行的动作？*
  - 作者将这一高层科学问题拆解为三个紧密耦合的子问题：
    - **(i) 转移歧义（Transition Ambiguity）**：视觉上相似的观测可能属于不同操作阶段（如折衣时的起折、续折、抓取调整、释放），对应不同的后续转移，仅凭外观相似不足以判断任务意图。
    - **(ii) 预测–执行失配（Prediction–Execution Mismatch）**：视觉上合理的预测未来（像素级或隐空间）不一定对应物理上可实现的转移，像素预测易被静态背景主导，隐空间预测则可能丢失接触与几何约束。
    - **(iii) 经验–实现失配（Experience–Realization Mismatch）**：历史场景中可执行的动作模式，在当前位姿、接触、几何条件下未必可行，需要上下文感知的适应而非直接复用。
  - **现有方法局限**：预测类方法（Fast-WAM、DreamVLA 等）与记忆类方法（MemoryVLA 等）把未来预测与历史记忆当作独立辅助机制；记忆检索大多围绕观测、关键帧或隐式历史，而非"视觉转移与实现它的动作演化"之间的对应关系。
  - **核心主张**：预测、记忆与动作生成应统一在同一个**动作接地的转移（action-grounded transition）**接口上，形成"anticipate–ground–refine"（预期–接地–精炼）流程。

- **形式化定义**
  - 定义预期转移为条件状态演化算子 `T∆t`，而非图像差分 `Vt+∆ − Vt`：
    - `Vt --T∆t(·|Xt)--> Vt+∆`，其中 `Xt = {Vt, ℓ, qt, Ht}`（视觉、语言、本体状态、动作历史）。
  - 动作块 `At = [at, ..., at+K−1]` 是该条件演化的物理实现。

## 2. 方法论：核心思想与关键技术

### 2.1 整体架构：三系统 Transformer

- 在 π0.5 骨干（PaliGemma-2B VLM + 311M Gemma 动作专家）基础上新增 **World Expert**，构成三系统：
  - **VLM 骨干流** `Hc`、**World Expert 流** `Hw`、**Action Expert 流** `Ha`。
  - 三流在每层通过共享的块级可见性掩码 `Mr` 进行联合注意力（而非独立交叉注意力模块）。
  - World Expert 使用 `Nw=16` 个零初始化、内容无关的转移查询 `Q0 = 0`。
- **块级可见性（训练）**：骨干只见骨干；World 见骨干+World；Action 见全部三流，实现从视觉语言到世界转移再到动作的层级信息流。
- **推理缓存**：每控制步骨干与 World Expert 各前向一次并缓存 K/V；每个去噪步只重算 Action Expert，保留完整"预期–接地–精炼"路径但避免重复计算。

### 2.2 持续-选择性未来预测（Persistent-Selective Future Prediction）

- **目的**：解决转移歧义，让转移 token `Ztr_t` 编码"任务进度 + 交互关键变化"。
- **持续隐空间监督**：轻量预测头将 `Ztr_t` 投影到冻结的 V-JEPA 2 隐空间，用 L2 损失对齐未来帧表示：
  - `Llat = Σν ‖F̂ν_{t+∆} − sg(fJEPA(Iν_{t+∆}))‖² / (Nν·df)`。
  - 零初始化查询只能通过读取当前上下文、编码对演化有预测性的信息来最小化该损失，从而把 `Ztr_t` 塑造为未来监督的隐转移表示。
- **转移关键触发门（Trigger Gate）**：训练专用，融合语义与运动两类证据：
  - 语义分数 `rlat_t`：主视角预测隐位移相对变化率；
  - 动作指示器 `bp_t, br_t, bg_t`：平移、旋转、夹爪切换是否超过阈值；
  - 最终门 `mt = 1[rlat_t > ηlat ∨ bp_t ∨ br_t ∨ bg_t]`。
- **记忆接地的像素未来校准**：门激活时，用 `Ztr_t` 解码的隐端点构造转移感知查询 `qν_v,t`，从 Visual-Action Memory Bank 检索可执行视觉值 `ūν_v,t` 作为像素解码器的记忆：
  - `Lpix = mt · Σν ‖Îν_{t+∆} − Iν_{t+∆}‖₁ / |Ων|`。
  - **关键点**：解码的未来只用于监督，不喂给 Action Expert；Action Expert 直接消费预头部 token `Ztr_t`。

### 2.3 转移对齐的双向记忆预训练

- **Visual-Action Memory Bank**：从历史轨迹构建条目 `{视觉键/值, 动作键/值, episode 与时间索引}`。
  - 视觉键由冻结 V-JEPA 2 特征投影 + 均值池化 + ℓ2 归一化得到；动作键由动作历史投影得到。
  - **时序值编码**：视觉与动作流各用**有状态 Mamba** 建模 episode 级演化，并进行跨流转移接地：
    - 视觉状态以动作状态+语义视觉 token 为条件做注意力融合（把动作动态注入视觉记忆）；
    - 动作状态以多视角视觉状态+历史动作 token 为条件融合（把视觉转移语义注入动作记忆）。
  - **未来导向重建**：视觉值解码未来图像、动作值解码未来动作块，`Lrec` 同时约束两侧保留未来演化。
  - **检索模拟训练** `Lret`：软检索分布加权候选值后解码，评估"检索到的值能否预测正确未来"，而非直接在嵌入空间施加成对相似度。
  - **跨模态配对** `Lpair`：对同一物理转移的视觉值与动作值做双向对比学习（时间对齐对为正样本）。
  - 总损失：`Lbank = Lrec + λret·Lret + λpair·Lpair`。
- **粗到细时序索引**：先按查询选出最相关 episode `e*`，再仅在该 episode 内做软检索，避免跨演示混合视觉相似但时序不兼容的阶段。

### 2.4 动作流形原型精炼（Action-Manifold Prototype Refinement）

- **Action-Visual Memory Bank**：用近期动作历史构造动作查询 `qa,t`，检索视觉接地的动作原型 `ūa,t`（该值在预训练中被时序对齐的视觉动态所条件化）。
- **原型偏置流（Prototype-Biased Flow）**：不是直接执行检索到的动作，而是将其与历史投影融合为先验 token `Pa,t`，把流匹配的源分布从零均值高斯平移：
  - `p(ẽt | Pa,t) = N(λp·Pa,t, I)`，保留协方差与随机性。
- 噪声输入与目标速度：`xρ = ρ·ẽt + (1−ρ)At`，`uρ = ẽt − At`。
- 动作专家以 `(Ct, Ztr_t, Pa,t)` 为条件预测速度场，`Lact` 为流匹配损失。
- **总目标**：`LUniMPA = Lact + λlat·Llat + λpix·Lpix`。
- **推理时**：保留 World Expert 与 Action-Visual Memory Bank，禁用隐/像素预测头与视觉检索路径。

### 2.5 训练流程

- **Stage 1**：预训练记忆库（10 epoch，AdamW lr=1e-4，截断 BPTT 8 步，λrec=1.0, λret=1.0, λpair=0.5）。
- **Stage 2**：冻结记忆编码器与存储条目，微调策略（AdamW，峰值 lr=5e-5，VLABench 为 5e-6；30k/20k 步；5k–10k warm-up；bfloat16）。
