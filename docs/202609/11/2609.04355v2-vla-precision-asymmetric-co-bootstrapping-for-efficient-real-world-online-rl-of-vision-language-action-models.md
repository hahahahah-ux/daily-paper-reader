## 摘要
预训练的视觉-语言-动作（VLA）模型能够实现广泛的操控，但在要求精度与可重复性的任务中仍不可靠。将真实世界在线强化学习（RL）应用于 VLA 后训练，使其能够在仅有演示之外通过自主试错持续改进，但也暴露出两个瓶颈：1）不可靠的价值信号可能导致策略漂移；2）大型 VLA 的开销限制了吞吐量和样本效率。为应对这些挑战，我们提出 VLA-Precision，一个高效的真实世界在线 RL 框架，其核心是非对称协同自举（ACoB）算法与 ACoB-Stream 架构。具体而言，ACoB 在不同时间尺度上建立非对称协同自举：早期由干预引导的行为学习快速提升策略性能，同时提高在线经验质量。随着自主经验不断积累，全局回报传播与局部偏好排序逐步校准价值估计，为参考正则化的策略改进提供相对动作优势，同时抑制漂移。为在大型 VLA 上实现 ACoB，我们开发了 ACoB-Stream，一种闭环经验—策略架构，将不变状态解耦与按需流式传输确立为设计原则，在吞吐量和计算效率上带来最高 10.9 倍的提升。在涵盖四个类别、四种机器人本体的九项高精度化学任务上的广泛评估表明，VLA-Precision 在每项任务 45.8 分钟内达到 98.3% 的平均成功率，27.6 秒的回合运行速度分别为 VLA 和 RL 基线的 1.2 倍和 1.8 倍。相关资源见 https://vla-precision.github.io。

## Abstract
Pretrained vision-language-action (VLA) models enable broad manipulation but remain unreliable in tasks demanding precision and repeatability. Applying real-world online reinforcement learning (RL) to VLA post-training enables autonomous trial-and-error improvement beyond demonstrations alone, but exposes two bottlenecks: 1) unreliable value signals can induce policy drift; 2) large-VLA overhead constrains throughput and sample efficiency. To address these challenges, we present VLA-Precision, an efficient real-world online RL framework featuring the Asymmetric Co-Bootstrapping (ACoB) algorithm and the ACoB-Stream architecture. Specifically, ACoB establishes asymmetric co-bootstrapping across timescales: early intervention-guided behavioral learning rapidly improves policy performance while enhancing online experience quality. As autonomous experience accumulates, global return propagation and local preference ranking progressively calibrate value estimates, yielding relative action advantages for reference-regularized policy improvement while suppressing drift. To enable ACoB on large VLAs, we develop ACoB-Stream, a closed-loop experience--policy architecture that establishes invariant-state decoupling and on-demand streaming as design principles, delivering up to 10.9$\times$ improvements in throughput and computational efficiency. Extensive evaluations on nine high-precision chemistry tasks across four categories and four robot embodiments show that VLA-Precision achieves 98.3\% mean success rate in 45.8 min/task, with 27.6 s episodes running at 1.2$\times$ and 1.8$\times$ the speeds of VLA and RL baselines. Resources are available at https://vla-precision.github.io.

## 1. 核心问题与整体含义

- **研究背景**：预训练视觉-语言-动作（VLA）模型通过大规模多模态预训练获得了广泛的操控泛化能力，仅需少量演示即可完成多样任务。然而，**泛化性并不等于高精度与可重复性**——关键阶段的微小残差误差仍会导致间歇性失败。
- **核心动机**：行为克隆（BC）受限于演示分布，误差在分布外会累积；强化学习（RL）通过时序信用分配可突破演示性能上限。将真实世界在线 RL 用于 VLA 后训练，可实现自主试错改进。
- **两大瓶颈**：
  1. **算法稳定性**：不可靠的价值估计会诱发策略漂移（policy drift）。现有方法用 BC 约束稳定更新，但价值估计本身改进有限。
  2. **系统效率**：大型 VLA 的计算开销限制了训练吞吐与样本效率，真实世界在线交互进一步放大该负担。
- **整体含义**：论文提出 VLA-Precision 框架，旨在同时解决算法与系统两个层面的瓶颈，实现大规模 VLA 在真实世界中的高效、稳定在线 RL 后训练。

## 2. 方法论

### 2.1 整体框架：两阶段后训练

- **Stage I**：在任务演示上进行全参数模仿学习（flow-matching IL），得到任务特定策略先验 Θ_IL。
- **Stage II**：冻结基座参数（Θ_f, ψ）与 Stage-I 参考 θ_0，仅优化动作专家中的 LoRA 参数 θ，在异步 actor–learner 架构下进行真实世界在线 RL。
- 将 Stage II 建模为闭环经验–策略优化问题：Actor 用部署策略 ¯θ_n 采样轨迹，存入经验池 E_n（回放缓冲 R、纠正缓冲 C、上下文缓冲 K）；Learner 用 ACoB 在 B_n 上优化 θ_n，产出 θ_{n+1} 并部署。

### 2.2 ACoB 算法：非对称协同自举

核心思想是在**不同时间尺度**上耦合两种学习机制：快速的行为学习与渐进的价值校准，形成跨时间尺度的正反馈闭环。

**（1）渐进价值校准**

- **Critic 结构**：K 个任务特定 critic 集成，采用价值–优势分解 Q_φk(ω, b_a) = V_φk(ω) + A_φk(ω, b_a)，其中 ω 为视觉–本体状态分量。
- **全局回报传播（Global Return Propagation）**：通过集成 TD 目标 `L_TD` 沿执行轨迹递归自举长时域回报，TD 目标使用下一状态 bootstrap 动作与 K 个 critic 的最小值构造。
- **局部偏好排序（Local Preference Ranking）**：针对被人为纠正覆盖的原始提案动作，因其无后继观测被排除于 TD 学习，仅在状态匹配排序损失 `L_rank` 中使用，强制纠正动作优势高于原始提案（margin m_c）。这解决了长时域 TD 无法修正被覆盖提案价值的局部信用模糊问题。
- **Critic 总目标**：`L_critic = L_TD + λ_rank · L_rank`（λ_rank = 50）。

**（2）相对优势策略改进**

- **相对优势计算**：在每个 critic 内部先计算成对优势差，再做悲观集成聚合。基线 b_t,k 在无纠正时等于 A_ref，有有效纠正时取 max{A_ref, A_prop}；相对优势 ΔA_t = min_k [A_θ - sg(b_t,k)]，仅当所有 critic 都偏好当前动作时 ΔA_t > 0。
- **软边距目标**：`L_rel(θ)` 采用 softplus 形式的平滑边距目标（margin m_π，softness κ），critic 与比较分支保持固定，梯度仅通过 b_a^θ 回传。
- **流匹配行为克隆（L_BC）**：在任务演示、成功在线执行与有效人工纠正上优化 flow-matching 目标；行为掩码 χ_beh = max{y_suc, c_t} 选择成功轨迹的全部 chunk 及失败轨迹中的有效纠正。
- **参考正则化（L_ref）**：将本体动作坐标向冻结参考动作正则化，保持既有能力、抑制价值诱导漂移。
- **动作专家总目标**：`L_AE = w_BC·L_BC + w_rel·L_rel + w_ref·L_ref`，权重 (0.25, 0.50, 0.25)。

### 2.3 ACoB-Stream 系统架构

两大设计原则：**不变状态解耦**（避免重复计算/存储/传输）与**按需流式传输**（仅访问当前目标所需状态）。四阶段管理经验上下文状态与策略状态的生命周期：

1. **经验上下文形成**：保留 actor 推理时生成的 frozen-prefix KV cache，做观测 schema 感知压缩，R/C 仅存当前与后继上下文 ID，将 frozen-prefix 计算从每采样项一次降为新观测一次。
2. **经验上下文持久化**：磁盘支撑的上下文缓冲 K 做去重存储；回放采样用滑动窗口按 Linux page-cache 容量限定活跃集，提高页缓存复用；纠正采样独立进行。
3. **经验上下文访问**：面向目标对齐检索——价值优化仅取后继上下文，动作专家优化额外取当前上下文；后台 CPU worker 组装 batch，device worker 异步预取至 GPU。
4. **策略状态同步**：仅发布可训练动作专家状态（非完整 VLA 或参数增量），actor 原子替换激活状态，减少同步与部署开销。

### 2.4 训练与部署协议

- **遥操作**：设计 UR5e 同构主手（负载感知分级驱动 + 负载解耦关节结构），以及增量笛卡尔键盘接口用于毫米/亚毫米级精调。
- **状态–动作表示**：逐步增量任务空间动作，q_t ∈ R^19（相对 TCP 位姿、twist、力/力矩、夹爪状态），u_t ∈ R^7（增量末端指令 + 夹爪指令），15 Hz 采集。
- **机器人部署**：UR5e 力模式阻抗控制（forceMode 接口），Franka 力矩级阻抗控制（含零空间姿态调节与 Coriolis 补偿）。
