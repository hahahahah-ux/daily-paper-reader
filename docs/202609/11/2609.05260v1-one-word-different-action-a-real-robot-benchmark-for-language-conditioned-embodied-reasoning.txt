Abstract —Natural-language instruction changes can directly alter robot behavior. A reliable embodied system should preserve its action when the task is unchanged and update it correctly when the task itself changes. We introduce One Word, Different Action, a real-robot benchmark built on physical decision states and executable actions, using task-preserving and task-changing instruction pairs to jointly evaluate Decision Invariance and Decision Sensitivity, with further evaluation under multi-constraint reasoning and real-RGB grounding. Experiments show that modern models are near saturation on single-constraint instruction changes, yet several models degrade noticeably when multiple task constraints must be integrated into one executable decision.

I. Introduction One of the central goals of embodied intelligence is to enable robots to understand human intent and translate high-level task descriptions into executable behavior in physical environments. Foundation models are increasingly becoming high-level cognitive and decision-making components in robotic systems: language models can participate in action selection and task planning, multimodal models can combine visual observations, robot state, and language instructions, and vision-language-action models can map these inputs more directly to robot actions [1], [2], [3]. As the distance between language and physical execution becomes shorter, an error in instruction interpretation is no longer only a textual semantic error, but can directly change the behavior that the robot ultimately performs. arXiv:2609.05260v1 [cs.RO] 4 Sep 2026 Language-conditioned manipulation has also been studied through long-horizon policy learning and multimodal task prompts [4], [5], [6]. Unified multimodal task specifications further condition robot policies on multiple forms of human task description [7]. Large-scale robot datasets and generalist policies have continued to shorten the path from language-conditioned representations to executable robot actions [8], [9], [10]. This development raises a basic but important decision problem for robots operating from natural language: when a user’s instruction changes, should the robot preserve its action or update it? A user may express the same task in a different way, or may genuinely change the task requirements through a new linguistic condition. In the former case, a reliable robot should maintain its previous action decision; in the latter, it should identify the changed requirement and produce behavior consistent with it. Language-conditioned embodied reasoning therefore requires two complementary capabilities: decision stability under task-preserving instruction changes and an appropriate response to task-changing instruction changes. As illustrated in Fig. 1, the relevant property is not sensitivity to language change by itself, but sensitivity that corresponds to a change in the robot task. Recent embodied evaluations have begun to move beyond final task success toward more fine-grained capabilities in robot cognition and reasoning. Diagnostic evaluation of vision-driven embodied agents likewise considers capabilities beyond end-task success [11]. RoboBench diagnoses multimodal models as embodied decision-making systems, VLABench targets complex language-conditioned robot manipulation, and Manip-Bench examines lower-level reasoning about concrete robot operations [12], [13], [14]. These efforts show that a single task-success measure is insufficient to characterize weaknesses in instruction understanding, reasoning, and action decision, while leaving open the question of how a controlled instruction change affects an action decision within one fixed physical state. In parallel, a growing body of work directly studies how language updates affect robot behavior. BlockWorld-Repairs and Stoyanchev et al. consider user corrections, task revisions, and language updates during interaction, while SwitchVLA studies how a robot can switch from an ongoing task to a new behavior after a new instruction arrives [15], [16], [17]. These studies establish that an instruction change can directly influence the subsequent robot decision, motivating a more isolated analysis of when such a behavioral change is required. Intermediate language-conditioned action representations provide another route for language to intervene in robot execution [18]. This line of work further motivates examining whether a changed instruction should preserve or modify the action decision itself. Another closely related line of work examines robustness to variation in language form and the composition of multiple task conditions. CxMP uses controlled minimal pairs to test whether a model responds to meaning-bearing changes in linguistic form, LIBERO-Para evaluates paraphrase robustness for vision-language-action manipulation, and LIMP studies verifiable adherence to complex robot constraints [19], [20], [21]. Together, these directions motivate an evaluation that separates stable behavior under equivalent instructions from correct action updates under changed task requirements. Robot-learning benchmark families such as LIBERO provide a broader context for studying task and knowledge transfer in manipulation [22]. The present focus is the selective relation between instruction changes and executable action decisions. Despite these advances, a unified and controlled real-robot diagnostic framework is still needed. Such a framework should hold the physical decision state and executable action space fixed, test whether the robot preserves its action when the task remains unchanged, and test whether it updates the action when the task genuinely changes. It should also determine whether this selective decision stability persists when multiple task conditions jointly constrain one executable decision. We address this problem with One Word, Different Action, a real-robot benchmark for language-conditioned embodied reasoning. Its basic evaluation unit is not an isolated language instruction, but a controlled task family built on one physical decision state. Each family keeps the physical state and exe-cutable action space fixed while including task-preserving and task-changing instruction variations, so that the correct robot action either remains unchanged or changes deterministically. This structure supports Decision Invariance, which measures whether the robot maintains correct behavior when the task is preserved, and Decision Sensitivity, which measures whether it produces the correct update when the task changes. We further extend the evaluation to multi-constraint em-bodied reasoning, where a single action decision must satisfy several task conditions simultaneously. Correct decisions are defined jointly by real robot physical states, verified executable actions, and deterministic task constraints, and are evaluated through a machine-checkable action representation. In addition to the structured-state condition, the benchmark retains the same task relations under real robot RGB observations to test whether these embodied decision relations are preserved under visual grounding. The results show that current strong models are close to saturation on single-constraint instruction changes: they usually produce the correct robot action for both task-preserving and single task-changing conditions. Some models exhibit a clear degradation when multiple task constraints must be integrated into one executable decision, whereas the selected real-RGB condition does not cause a substantial overall degradation. The remaining challenge is therefore more concentrated in jointly integrating multiple task requirements into a robot action decision than in responding to an individual task change. This work makes three contributions. First, it constructs a controlled benchmark grounded in real robot physical decision states and verified executable actions, directly framing instruction change as a question of whether robot behavior should be preserved or updated. Second, it introduces paired evaluation of Decision Invariance and Decision Sensitivity and extends the same framework to multi-constraint embodied reasoning. Third, it provides a systematic evaluation across modern foundation models that identifies near-saturated single-constraint reasoning alongside a model-dependent robustness gap in multi-constraint reasoning. II. Related Work 

A. Embodied Reasoning and Robot Instruction-Following Benchmarks 

Existing embodied-intelligence benchmarks have begun to decompose robot capability beyond final task success into diagnosable reasoning and decision abilities. RoboBench treats multimodal foundation models as embodied brains and evalu-ates high-level robot cognition through instruction understand-ing, perception reasoning, planning, affordance judgment, and failure analysis. VLABench targets language-conditioned robot manipulation, emphasizing complex natural-language tasks, long-horizon reasoning, and multi-stage behavior. ManipBench further focuses on low-level manipulation reasoning by testing whether vision-language models can support concrete robot behavior through object interactions, action relations, and operational processes [12], [13], [14]. These benchmarks collectively promote a shift from asking whether a robot can complete a task to diagnosing which reasoning capability produces a failure. Their typical orga-nization nevertheless compares models across different tasks, environments, or capability dimensions, and therefore primarily asks whether a model can understand and complete a given task. We use a finer-grained controlled decision structure: the same physical decision state and executable action space remain fixed while task conditions change, allowing the robot action to be tested for preservation or update within one embodied state. 

B. Instruction Changes, Corrections, and Task Switching 

User modifications of task requirements during robot exe-cution turn instruction following from a static-input problem into a continuously changing interaction decision. BlockWorld-Repairs uses user-correction sequences to test whether multi-modal models can recover from an incorrect task interpretation and determine the appropriate manipulation from subsequent language. Stoyanchev et al. examine corrections, refinements, and interruptions during execution and study how language models use interaction context to regenerate robot behavior [15], [16]. SwitchVLA studies dynamic task switching at the robot policy level, conditioning behavior generation on the current execution state and a newly arriving task instruction. These studies establish that instruction change can directly affect real robot behavior, but their emphasis is on correction recovery, execution-context modeling, or task-switching policies. We compress this dynamic factor into a controlled diagnostic question: with the physical decision state held fixed, does a changed instruction require the action to remain the same or to be updated? [17] 

C. Controlled Instruction Variation and Constraint Composi-tion 

Controlled language variation provides a stricter diagnostic than accuracy on independent instructions. CxMP uses lin-guistic minimal pairs to control structural differences between inputs and tests whether language models respond selectively to a meaning-bearing change in form [19]. LIBERO-Para brings a related question to robot manipulation by constructing paraphrased instructions for the same task and evaluating whether vision-language-action models maintain stable execution. It is especially close to the present setting because both approaches hold the underlying robot task fixed to isolate language variation. Paraphrase robustness primarily ad-dresses task-preserving instruction changes, whereas we jointly evaluate task-preserving and task-changing pairs, covering both robustness to equivalent instructions and correct action updates under changed requirements [20]. Complex language tasks also require several conditions to be satisfied jointly rather than recognized independently. LIMP maps natural-language tasks to verifiable robot constraints and checks whether spatial and temporal requirements are satisfied, showing why multi-constraint following constitutes a distinct reasoning challenge. We therefore distinguish single-constraint and multi-constraint embodied reasoning within a fixed executable action space, comparing isolated task conditions with their joint effect on action-decision reliability [21]. III. Language-Conditioned Embodied Reasoning 

A. Embodied State and Executable Action Space

Depending on the task, these actions may represent target-object selections, candidate behavior choices, or action sequences composed of multiple behaviors in a specified order. Rather than treating natural-language understanding as an isolated classification or semantic-labeling problem, we study how language conditions act on an executable robot decision space. B. Task-Preserving and Task-Changing Decisions 

Instance-level action accuracy alone cannot distinguish two complementary reasoning capabilities. When the linguistic re-alization changes while the underlying task remains unchanged, the robot should preserve its decision. When the instruction changes the actual task requirements, the robot should instead update its action decision even though the physical state remains identical. For a base instruction 𝑥 , let 𝑥 + denote a task-preserving transformation. When the two instructions require the same robot behavior under the current physical state, 

𝑎 ∗ (𝑥, 𝑠 ) = 𝑎 ∗ (𝑥 +, 𝑠 ), (3) the model should preserve its action decision. We refer to this capability as Decision Invariance , which measures whether the robot maintains the same correct behavior under alternative expressions of an unchanged task. Let 𝑥 − denote a task-changing transformation. When the language change modifies a task constraint that affects robot execution, 

𝑎 ∗ (𝑥, 𝑠 ) ≠ 𝑎 ∗ (𝑥 − , 𝑠 ), (4) the model must correspondingly change its action decision. We refer to this capability as Decision Sensitivity , which measures whether the robot responds correctly when an instruction change genuinely alters the task. Together, these properties characterize selective decision stability under instruction changes. A reliable embodied rea-soning system should neither change its behavior after every linguistic variation nor mechanically preserve its previous decision. Instead, its action should change precisely when the task itself changes. We further define Over-Invariance as the failure mode in which the correct action should change but the model preserves its previous decision, and Over-Sensitivity as the case in which the task remains unchanged but the model incorrectly changes its decision. 

C. Deterministic Executable Decision Representation 

To enable strict verification of robot decisions, all outputs are mapped to a finite executable representation rather than evaluated through free-form text. Object-oriented tasks rep-resent decisions as a target object or an object set, whereas action-oriented tasks represent decisions as a single action, an action set, or an ordered action sequence. For set-valued decisions, correctness requires exact agree-ment between the predicted and target sets. For sequential decisions, both the selected actions and their ordering must match the target sequence. Multi-constraint tasks further require the output to satisfy all task constraints simultaneously, rather than receiving independent credit for partially satisfied conditions. The correct action decision for each task is computed deterministically from the physical state and the task constraints. Natural language serves only as the expression of these constraints and does not participate in determining the ground truth. This design allows model predictions to be evaluated directly and reproducibly against machine-checkable executable decisions. IV. Embodied Reasoning Tasks 

A. Single-Constraint Reasoning 

We organize single-constraint embodied reasoning into four task categories corresponding to action inhibition, set constraints, cardinality constraints, and temporal constraints. Across all four categories, the physical state and executable candidate space remain fixed, while the instruction changes a single task condition that directly determines the correct action decision. 

Action Inhibition Reasoning requires the model to de-termine whether an otherwise executable candidate action or target should be prevented from entering the final decision. The reasoning problem is not whether the candidate is physically feasible, but whether the current task instruction prohibits its selection. 

Set-Constrained Action Reasoning requires the model to apply exclusion or retention constraints over an explicitly defined candidate set. The resulting robot decision is therefore determined by a structured relation over multiple candidates rather than by an isolated local choice. 

Cardinality-Constrained Action Reasoning requires the model to reason jointly about candidate membership and the required size of the resulting action set. The final decision must satisfy the specified cardinality structure, so over-selection, under-selection, or an incorrect interpretation of the quantity constraint changes the executable decision. 

Sequential Action Reasoning concerns the execution order of multiple candidate actions. While the action candidates themselves remain unchanged, the instruction imposes temporal constraints that determine the correct ordered sequence. The model must therefore identify the appropriate actions and organize them according to the required order. These categories manipulate different structural properties of the robot decision space while preserving the same evaluation principle: the underlying physical state remains fixed, and only the task constraint changes the correct executable behavior. This structure directly connects instruction understanding to the robot action that should ultimately be executed. B. Controlled Task Families 

Rather than treating instructions as independent classification instances, we construct controlled task families around the same physical decision state. All instances within a family share the same robot state, candidate objects or actions, and executable decision space. Only the linguistic expression of the task constraints is varied. Each task family contains both task-preserving and task-changing transformations. Task-preserving transformations mod-ify the linguistic realization while keeping the correct robot decision unchanged, whereas task-changing transformations modify a task constraint that deterministically changes the correct action decision. A single family therefore supports the joint evaluation of Decision Invariance and Decision Sensitivity. This family-based organization shifts the evaluation unit from an isolated instruction to the relation between controlled tasks. A model succeeds on a complete family only when it remains stable under equivalent task formulations while responding correctly to task changes. The design therefore distinguishes insufficient response to genuine task changes from excessive sensitivity to task-preserving reformulations.

A. Physical Decision Anchors 

To ground every task instance in an actual robot decision state, we construct a collection of Physical Decision Anchors .Each anchor fixes a real physical state and defines the associated set of objects or executable actions from which language-conditioned reasoning tasks can be constructed. The benchmark contains 85 physical decision anchors, including 21 object-centric anchors and 64 action-sequence anchors. Object-centric anchors provide candidate objects, object identities, and physical information relevant to object selection, and they support action-inhibition, set-constrained, and cardinality-constrained reasoning. Action-sequence anchors provide verified candidate actions and their state relations, and they primarily support sequential action reasoning. Each candidate element within an anchor has a fixed identity, allowing the same anchor to support multiple language-conditioned tasks without changing the underlying physical state. Differences across tasks arise from different constraints applied to the same candidate space, enabling changes in model behavior to be evaluated against changes in the instruction rather than changes in the environment itself. 

B. Executable Action Candidates and Ground Truth 

For object-centric anchors, the candidate decision space consists of an explicitly identified set of objects in the physical scene, and the model must return the target object or object subset that satisfies the task constraints. For action-sequence anchors, the candidate space consists of verified robot actions, and the model must determine the correct action selection and ordering. For each physical anchor, a task is first represented as a deterministic set of action constraints. These constraints uniquely determine the correct robot decision, including the target action, action set, or ordered action sequence. Only after this decision has been determined are the task constraints realized as natural-language instructions. Benchmark construction proceeds from the physical decision state to the task constraints, then to the uniquely determined action decision, and finally to the natural-language instruction. This ordering ensures that ground truth is determined jointly by the physical state and the task rules rather than inferred retrospectively from the natural-language realization. Under the same physical anchor, task-preserving formulations necessarily correspond to the same action decision, whereas task-changing constraints produce a deterministic change in the correct decision. 

C. Paired Counterfactual Task Construction 

We construct corresponding task instances over the same physical decision anchor. Because the physical state and executable action space remain fixed, these instances form controlled counterfactual decision tests: when the robot’s world remains unchanged but the task instruction changes, the model must determine whether and how its behavior should be updated. Task-preserving pairs retain the same task constraints and correct action decision while varying the linguistic realization, thereby testing decision stability. Task-changing pairs retain the same physical state but modify a task constraint that changes the correct action decision, thereby testing whether the model updates its behavior appropriately. Because both members of each pair share the same physical anchor, differences in model output cannot be attributed to changes in the physical substrate. The paired design therefore directly evaluates whether action changes correspond to changes in the task requirements. 

D. Benchmark Scale and Physical-State Splitting 

The atomic benchmark contains 988 complete task families and 3,952 task instances. In addition, 84 multi-constraint instances are constructed to separately evaluate embodied action reasoning when multiple task conditions must be satisfied simultaneously. Data partitioning is performed at the level of physical decision anchors rather than individual language instances. All task families, linguistic realizations, and action decisions derived from the same anchor are assigned to the same split, preventing the same physical state from appearing across different partitions. This partitioning strategy ensures that held-out evaluation does not rely on repeated exposure to the same physical substrate. Decisions on held-out tasks must therefore be derived from the provided physical state and the current instruction rather than from linguistic variants of the same anchor observed elsewhere. 

E. Real-RGB Grounded Decision Subset 

In addition to the structured-state condition, we construct a real-RGB-grounded condition to evaluate whether embodied action reasoning remains stable when the physical state is presented through actual robot visual observations. The subset contains 748 task instances organized into 187 complete task families and covers all 85 physical decision anchors. Under this condition, the model receives the real RGB observation associated with the physical anchor together with the minimal structured information required to identify the candidate actions. Task constraints, family structure, and correct action decisions remain unchanged from the structured-state condition, so the two settings differ primarily in how the physical state is presented. This design enables a direct comparison of instruction-conditioned action reasoning under structured physical descrip-tions and real visual grounding. Because the executable action space and task definition remain fixed, the vision-grounded condition evaluates whether the model preserves the same decision relations when reasoning from real robot observations. B. Exact Action-Decision Evaluation 

The primary instance-level metric is Exact Action-Decision Accuracy . For each task instance, the model output is parsed into the standardized executable action representation and directly compared with the deterministic ground truth. For single-action tasks, the predicted action must exactly match the target action. For set-valued tasks, the predicted and target sets must contain exactly the same members. For sequential tasks, both action membership and ordering must match the target sequence. Any additional action, missing action, or ordering error is counted as an incorrect decision. We additionally report the Parse Success Rate to distinguish valid machine-readable outputs from interface or formatting failures. All requested calls remain in the overall denominator, so parsing failures are not removed from accuracy computation. System-interface failures and embodied decision errors are nevertheless analyzed separately. 

C. Paired Decision Metrics 

Because the benchmark is organized around task families, instance-level exact accuracy alone does not fully characterize how models respond to task changes. We therefore introduce a set of paired decision metrics. 

Pair Success requires all members of a paired relation to produce correct action decisions. It provides a stricter criterion than isolated instance accuracy and identifies cases in which only part of a controlled task relation is solved. 

Decision Invariance measures whether both members of a task-preserving pair produce correct and identical action decisions. A pair contributes successfully only when both predictions are correct and the decision remains unchanged. Decision Sensitivity measures whether both members of a task-changing pair produce correct decisions and whether the model changes its behavior according to the altered task constraint. The metric therefore jointly captures decision correctness and an appropriate response to task change. The complementary error measures Over-Invariance and 

Over-Sensitivity characterize incorrect decision relations. Over-Invariance occurs when the correct action should change but the predicted decision remains unchanged, whereas Over-Sensitivity occurs when the task remains unchanged but the model incorrectly changes its decision. 

D. Validity Controls 

We use several control conditions to verify that benchmark performance depends on task-critical information. A symbolic oracle directly executes the deterministic task constraints and verifies consistency between the ground-truth representation and the evaluator. A majority-type baseline measures output-distribution bias, while a random-valid baseline estimates performance under random selection from the executable candidate space. We further use a task-critical information masking control ,in which the physical state, executable candidate space, and remaining task content are preserved while the language information that determines the action decision is removed. This control directly tests whether paired decision performance depends on the task-critical constraints expressed by the instruction. If high benchmark performance were primarily driven by candidate-action priors, object frequencies, or fixed output preferences, removing the task-critical information should have little effect. In contrast, a substantial degradation after masking indicates that the model relies on the instruction information that determines whether and how the robot action should change. 

E. Statistical Evaluation 

To avoid treating highly correlated linguistic variants within the same task family as independent samples, we estimate confidence intervals using family-level bootstrap resampling. Each resampled unit contains the complete task family, preserv-ing the dependence between task-preserving and task-changing instances. We report 95% bootstrap confidence intervals for Exact Action-Decision Accuracy, Pair Success, Decision Invariance, and Decision Sensitivity. Paired bootstrap comparisons are additionally used to compare models over the same task families, ensuring that model differences are evaluated on matched physical decision states and task constraints. A. Single-Constraint Embodied Reasoning 

The main atomic results are summarized in Table II. Overall performance indicates that current models can map single task constraints to correct robot action decisions with high reliability. Pair-level performance remains consistently high alongside instance-level exact accuracy. This indicates that the strong results are not limited to isolated correct predictions, but extend to stable behavior across both task-preserving and task-changing relations. Under a controlled change of a single task constraint, the models usually determine correctly whether the robot action should remain unchanged or be updated. The results therefore suggest that single-constraint embodied reasoning within the scope of the benchmark is close to saturation for the evaluated models. The remaining errors are concentrated in a small subset of structurally more demanding constraints and a limited number of system-interface events rather than appearing as broad failures across task categories. 

B. Reasoning across Constraint Types 

Operator-wise performance is summarized in Table III. Action-inhibition and sequential constraints exhibit the most stable behavior, indicating that the evaluated models reliably suppress individual candidate behaviors and reorganize action order under a single task constraint. Set-exclusion and cardinality constraints retain more residual errors. Both categories require structured operations over a candidate set rather than a purely local action decision, producing a more complex decision space than single-action inhibition. Although the precise weakness pattern differs across models, the overall trend suggests that residual failures become more likely when task constraints operate on the structure of an action set rather than on a single local action property. This observation also motivates the multi-constraint evaluation. 

C. Multi-Constraint Embodied Reasoning 

The atomic and multi-constraint results are compared in Table IV. In contrast to the near-saturated single-constraint setting, Qwen3.5-27B and GLM-5-FP8 exhibit a measurable degradation when multiple task constraints must be satisfied jointly, whereas Gemma4-31B remains stable under the current compositional setting. This difference indicates that successfully handling multiple constraints in isolation does not necessarily imply that a model can reliably integrate them into one consistent robot action decision. Multi-constraint reasoning requires the model to interpret each local condition and then construct a final action set that satisfies all conditions simultaneously, so any integration error directly changes the resulting executable behavior. Changes in Pair Success and Decision Sensitivity are particularly informative in this setting. Compared with isolated instance accuracy, these metrics more directly capture whether a model produces the correct and complete action update when task requirements change, exposing compositional weaknesses that can remain less visible in aggregate accuracy alone. The results therefore suggest that single-constraint embodied reasoning is already highly reliable for current models, while the joint satisfaction of multiple task constraints remains a model-dependent source of reduced robustness. D. Reasoning from Real Visual Observations 

The structured-state and real-RGB-grounded conditions are compared in Table V. On the selected real-robot visual subset, replacing structured state descriptions with real RGB observations does not produce a substantial overall degradation, and both multimodal models retain performance close to their structured-state results. The models remain stable under task-preserving transforma-tions and continue to update their decisions appropriately under task-changing transformations. Within the evaluated physical decision anchors, instruction-conditioned action reasoning therefore remains largely preserved when the state is grounded in real robot visual observations. This result should be interpreted within the controlled visual conditions represented by the benchmark. It indicates that the evaluated decision relations remain reliable for these real observations, rather than implying that visual grounding is universally negligible for more complex robot tasks.

E. Validity of Task-Critical Reasoning 

The validity controls are summarized in Table VI. The symbolic oracle achieves the expected deterministic consistency, while the majority-type and random-valid baselines remain substantially below the evaluated models, indicating that high performance cannot be explained by simple output-frequency priors or random valid-action selection. Masking task-critical instruction information produces a substantially larger change. Paired decision performance de-creases markedly, with Decision Sensitivity being particularly affected. This behavior indicates that the models do not obtain their normal benchmark performance merely from fixed candidate-action patterns, but rely on instruction information that determines the correct robot behavior. The task-preserving and task-changing relations therefore provide meaningful tests of embodied decision behavior. Strong performance requires the model to distinguish changes that alter only the linguistic realization from changes that genuinely modify the robot task. 

F. Failure Modes in Embodied Decisions 

With atomic performance approaching saturation, the re-maining errors are concentrated in a limited number of action-decision structures. Cardinality errors correspond to predicted action sets that fail to satisfy the required set size, set-exclusion errors retain candidates that should be removed from the decision, and temporal errors preserve the correct action members but violate their required execution order. Pair-level failures reveal two complementary decision errors. A failure to update the action after a task-changing instruction indicates insufficient response to the altered task constraint, whereas an unstable decision under a task-preserving reformu-lation indicates unnecessary sensitivity to linguistic variation when the underlying robot task remains unchanged. These embodied decision errors are analyzed separately from system-interface failures. Parsing failures, connection errors, and other interface events indicate that a request did not produce a valid executable output, but they are not interpreted as direct evidence of an incorrect internal understanding of the task constraints. Taken together, the atomic and multi-constraint results indi-cate that the remaining model differences arise primarily from the integration of more complex constraints rather than from the recognition of individual task conditions. As tasks move from single-constraint to multi-constraint reasoning, the model must simultaneously preserve action-set structure, exclusion relations, and cardinality requirements, causing otherwise small residual weaknesses to become more visible. VIII. Conclusion This work studies whether a robot can correctly determine when its action should remain unchanged or be updated as the user instruction changes. By fixing the physical decision state and executable action space while evaluating task-preserving, task-changing, and multi-constraint conditions, we find that modern models are highly reliable on single-constraint changes but still exhibit model-dependent residual weaknesses under joint constraints. Overall, isolated instruction changes are approaching saturation, whereas reliably integrating multiple language-conditioned task constraints into correct robot be-havior remains a more demanding challenge for embodied reasoning.
