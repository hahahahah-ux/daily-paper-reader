## 摘要
视觉-语言-动作（VLA）策略利用预训练的视觉-语言模型（VLM）来引导机器人控制中的动作生成。VLM 提供分层的视觉-语义表示，这些表示会随网络层演变，从局部视觉几何到抽象的、与语言对齐的语义；因此，不同的操作任务可能需要不同层表示的混合。与此同时，动作模块维护在动作计算过程中不断演变的中间表示，这些表示可能为后续决策提供有用信息。然而，现有的 VLA 接口在表示访问方面灵活性有限：VLM 信息通过为每个动作层固定的层分配来暴露，而中间动作状态仅通过残差流隐式传播，无法显式复用。我们提出 LayerRoute，一种动作条件化的表示路由接口，能够自适应地访问 VLM 层和动作表示。Layer Mixture Router 动态形成缓存 VLM 表示的混合，而 Action-State Reread 则复用较早的动作表示。在多种仿真和真实世界基准上，LayerRoute 持续提升 StarVLA-$π$ 和 $π_{0.5}$，在 LIBERO Long 上以仅 0.31% / 3.87% 的额外参数实现了最高 7.2 的增益。消融研究验证了动作条件化层路由的优势，而路由分析揭示了跨动作层和任务设置的结构化分配模式。

## Abstract
Vision-Language-Action (VLA) policies leverage pretrained vision-language models (VLMs) to guide action generation for robot control. VLMs provide hierarchical visual-semantic representations that evolve across layers, from local visual geometry to abstract, language-aligned semantics; different manipulation tasks may therefore require different mixtures of layer representations. Meanwhile, the action module maintains intermediate representations that evolve throughout action computation and may provide useful information for subsequent decisions. However, existing VLA interfaces offer limited flexibility in representation access: VLM information is exposed through fixed layer assignments for each action layer, while intermediate action states are only propagated implicitly through residual streams without explicit reuse. We introduce LayerRoute, an action-conditioned representation routing interface that enables adaptive access to VLM layers and action representations. The Layer Mixture Router dynamically forms mixtures of cached VLM representations, while Action-State Reread reuses earlier action representations. Across diverse simulation and real-world benchmarks, LayerRoute consistently improves StarVLA-$π$ and $π_{0.5}$, achieving up to 7.2 gains on LIBERO Long with only 0.31% / 3.87% additional parameters. Ablation studies validate the benefit of action-conditioned layer routing, while routing analyses reveal structured allocation patterns across action layers and task settings.

## 1. 核心问题与整体含义（研究动机与背景）

- **VLA 策略的表征接口过于僵化**：现有视觉-语言-动作（VLA）策略（如 RT-2、OpenVLA、Octo、π0/π0.5、StarVLA）普遍把预训练 VLM 的表征通过**固定层分配**暴露给每个动作层，无法根据当前动作计算状态或任务需求动态调整访问哪些 VLM 层。
- **层级表征差异是问题根源**：ViT/CLIP/多模态语言模型的层级分析表明，浅层偏向局部纹理、几何与空间模式，深层偏向抽象、语言对齐的语义。抓取定位、夹爪-物体对齐、接触敏感放置更依赖细粒度视觉证据；指令落地、物体角色消歧、子目标选择更依赖抽象语义。因此**不同操作任务需要不同层表征的混合**，固定分配无法自适应。
- **动作模块内部同样受限**：标准残差传播下，早期动作状态被逐步变换并融入当前表示，后续模块只能通过残差流**间接**访问，无法显式"回看"早期中间状态，这在长时程操作中尤其不利。
- **总体论点**：策略被"双重约束"——外部受限于固定的 VLM 深度暴露，内部受限于仅残差可用的动作状态访问。作者据此提出 LayerRoute，一个**动作条件化的表示路由接口**，同时实现跨 VLM 深度的自适应选择与动作状态的显式复用。

## 2. 方法论

### 2.1 核心思想与形式化

- 将层级路由形式化为**读出（readout）问题**：静态接口 `Ṽ(s)_static = Φ_s({V_n}_{n∈C_s})` 不依赖当前动作状态；LayerRoute 的读出为 `Ṽ(s) = Φ_s({V_n}_{n∈C_s}, a(s))`，即根据当前动作状态自适应组合 VLM 层表征。
- 其中 `V_n` 为 VLM 在第 n 层边界的隐藏状态（n=0 为嵌入输入），`a(s)` 为动作层 s 的当前动作状态，`C_s` 为该层可用的 VLM 层索引集合。
- 两个互补组件：**Layer Mixture Router**（跨 VLM 深度路由）与 **Action-State Reread**（跨动作层复用）。

### 2.2 Layer Mixture Router（层混合路由器）

- **池化摘要**：对当前动作状态和每个候选 VLM 状态做掩码感知的 token 池化，得到 `p_a(s)` 与 `p_{V,n}`。
- **投影到共享路由空间**：分别 LayerNorm 后用层特定映射投影到 d_sel = 256 维，得到查询 `q(s)` 与键 `k(s)_n`。
- **路由权重**：缩放点积相似度得到 logits `ℓ(s)_n`，在可用层集合 `C_s` 上 softmax 得到深度权重 `α(s)_n`。
- **混合**：`Ṽ(s) = Σ_{n∈C_s} α(s)_n · V_n`，以加权和作为该动作层的 VLM 上下文。
- **粒度特性**：每个"样本 × 选定动作层"只预测**一个**深度分布，在**所有 VLM token 位置共享**。

### 2.3 Action-State Reread（动作状态重读）

- 在每个选定动作层 s，可访问源状态集合为 `I_s = {0, j1, …, jk, cur}`，即初始动作状态、若干保留的早期动作层状态、以及当前状态。
- 每个选定层维护一个**层内共享的可学习查询** `q_A(s)`，对每个 token 与各源状态的 RMSNorm 表示做内积，softmax 得到**token 特定**的权重 `ρ(s)_{t,i}`，再加权求和得到重读状态 `â(s)_t`。
- **与 VLM 路由的关键区别**：VLM 路由是"样本/层级共享分布"，重读是"逐 token 特定权重"，因此表达更细粒度。
- 重读结果送入 FFN 及后续动作块。

### 2.4 两种骨干的集成方式

- **StarVLA-π**：动作模块为 36 层 DiT（18 个交叉注意力层 + 18 个自注意力层）。缓存 Qwen3-VL 的 6 个深度状态 `[5, 11, 17, 23, 29, 35]`，在全部 18 个交叉注意力层用 256 维路由器替换原生编码器上下文 `Z(s) = Ṽ(s)`；Action-State Reread 应用于全部 36 个块，在 FFN 前重读。仅增 0.31% 参数。
- **π0.5**：PaliGemma + 流匹配动作专家。缓存层 `[2, 5, 8, 11, 14, 17]` 的在线 token 对齐状态，每个站点最多 6 个因果可用候选；在 18 个动作专家层各插入一个**不共享的 8 头动作到 VLM 交叉注意力适配器**（Q/K/V/O 无偏置，`A_pre = A_in + C`），在原生 prefix/suffix 联合注意力之前做残差更新；动作状态记忆位于层 `{2, 5, 8, 11, 14, 17}` 之后，重读在原生注意力之后、FFN 之前。增 3.87% 参数。
- 路由器动作侧深度查询投影**零初始化**，使初始深度分布均匀；两骨干均**联合微调**预训练 VLM、动作模块、路由器与重读模块，不使用辅助损失或额外专家。
