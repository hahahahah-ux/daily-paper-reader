## Abstract
Dexterous manipulation involves contact-rich and fine-grained interactions with the physical world, posing significant challenges for existing vision-language-action (VLA) models due to severe visual occlusions and complex contact dynamics. While recent works have incorporated tactile sensing into robotic manipulation, most approaches still rely on homogeneous multimodal fusion, lacking adaptive tactile integration and explicit modeling of physical dynamics. In this work, we present DeCAL, a physically-grounded dexterous vision-language-action model that unifies understanding, imagination and action generation for contact-rich dexterous manipulation. Built upon a Mixture-of-Transformers (MoT) architecture, DeCAL leverages specialized experts for each capability while enabling efficient information flow among them. To effectively leverage tactile information, we introduce Adaptive Visuo-Tactile Fusion that dynamically regulates tactile interactions via a contact-aware gating strategy. Furthermore, we propose Visuo-Tactile Latent Co-Imagination to jointly model visual and tactile dynamics, equipping the policy with implicit physical world knowledge. Experimental results show that DeCAL consistently achieves state-of-the-art performance across all tasks, attaining a 71% average success rate and an 83.4% progress success rate, while also demonstrating strong generalization to unseen scenarios. The website is available at https://aureleopku.github.io/DeCAL.

## 2. 方法论

### 2.1 核心思想
- 基于 **Mixture-of-Transformers（MoT）** 架构，由三个协作专家组成，通过**跨模态联合注意力（Cross-Modal Joint Attention）**实现方向性知识共享：
  - **理解专家（Understanding Expert）**：基于 Qwen3-VL，处理语言与多视角视觉 token；触觉特征通过专用 cross-attention 以 K/V 形式注入，与自注意力特征残差融合。
  - **生成专家（Generation Expert）**：以并行解码（非自回归）方式预测未来视觉与触觉观测，形成物理落地的多模态世界表示。
  - **动作专家（Action Expert）**：以 flow matching 目标预测动作块。
- **注意力掩码设计**：信息从理解专家 → 生成专家 → 动作专家**单向流动**，后序专家可 attend 前序专家，反向禁止；理解与生成专家内部为双向注意力；动作专家中 state token 可 attend 自身与更早 block，action token 可 attend 自身、state token 及所有前序 block。

### 2.2 关键技术细节

- **触觉特征提取**：
  - 输入为多指变形图（deform map），用共享 ResNet 编码器提取特征，经空间池化、跨指 Transformer 融合。
  - 输出**局部触觉 token**（保留细粒度接触细节）与**全局触觉 token**（概括整体接触状态）。

- **自适应视触融合（Adaptive Visuo-Tactile Fusion）**：
  - 在每个 transformer block 加入 cross-attention：局部触觉 token 作为 K/V，视觉-语言前缀投影作为 Query。
  - **接触感知门控机制**：由于接触是间歇性的，直接注入触觉会引入偏差。门控权重由全局触觉 token 经轻量投影得到：
    - 公式：$\tilde{X} = X + \sigma \odot \mathrm{CrossAttn}(Q_{vl}, K_{local}, V_{local})$，其中 $\sigma = \mathrm{Gate}(z_{global})$。
    - 含义：根据整体接触状态选择性放大或抑制触觉影响。

- **视触潜在协同想象（Visuo-Tactile Latent Co-Imagination）**：
  - **触觉潜在预测**：以每指 6-DoF 接触力为紧凑物理表示，经力编码器映射为嵌入，产生触觉潜在，可解码为原始触觉图像、变形图、6-DoF 力向量。
  - **视觉潜在预测**：用 Cosmos VAE tokenizer 编码多视角图像，采用 token 压缩（32×32 潜在网格经 8×8 卷积下采样到 4×4），并行解码未来视觉帧，复用理解专家的 KV cache。
  - 训练时视觉潜在直接回归 Cosmos VAE 目标；触觉潜在以当前 6-DoF 力为条件，通过重建未来原始触觉图像、变形图、力向量间接监督；推理时省略重建解码器。

- **因子化流匹配（Factorized Flow Matching）**：
  - 由于手臂与手部运动动力学和控制粒度差异大，共享去噪过程会模糊灵巧行为。
  - 手臂与手部动作从独立噪声分布初始化，经 MLP 投影为独立 token 序列，再由 transformer block 联合处理以协调动作生成。

- **训练目标**（三项加权求和）：
  - $\mathcal{L}_{total} = \lambda_v \mathcal{L}_{visual} + \lambda_t \mathcal{L}_{tactile} + \mathcal{L}_{action}$
  - 视觉：$\mathcal{L}_{visual} = \frac{1}{N_v}\sum \|\hat{z}_v^{(i)} - z_v^{(i)}\|_2^2$
  - 触觉：$\mathcal{L}_{tactile} = \lambda_R \mathcal{L}_{img} + \lambda_M \mathcal{L}_{def} + \lambda_F \mathcal{L}_{force}$
  - 动作：流匹配目标 $\mathcal{L}_{action} = \mathbb{E}\|v_\theta(q_t, \hat{a}^\tau_{t:t+k}, h_{und}, h_{gen})-(a_{t:t+k}-\epsilon)\|_2^2$，插值动作 $\hat{a}^\tau_{t:t+k}=(1-\tau)\epsilon+\tau a_{t:t+k}$，$\tau\sim\mathrm{Beta}(1.5,1.0)$。

## 6. 主要结论与发现

- **性能 SOTA**：DeCAL 在所有 6 个任务上取得最高成功率，**平均 SR 71%、PSR 83.4%**，比最强基线（DECO）平均成功率高出超过 15%。
- **视觉 vs 触觉**：纯视觉策略在简单任务（Wipe Vase、Pipetting）表现尚可，但在接触密集任务上大幅下降；触觉策略在接触阶段更强，但缺乏动力学建模导致长时程规划较弱。
- **朴素注入触觉有害**：InternVLA-A1t 在部分任务上反而下降，说明直接融合触觉会干扰视觉 grounding。
- **触觉潜在结构良好**：t-SNE 显示全局触觉 token 按接触模式（twist、insert、wipe 等）清晰聚类。
- **门控有效**：无接触时门控值低（视觉主导），接触发生时显著升高（触觉主导）。
- **力预测准确**：预测 6-D 力与真值高度吻合，验证协同想象能建模接触动力学。
- **泛化强**：未见物体场景下 Twist Cap 仍达 75% 成功率，超最佳基线 30 个百分点。
- **消融验证**：因子化流匹配贡献最大；视觉/触觉潜在生成对接触敏感任务重要；触觉门控帮助平衡视觉与触觉。
