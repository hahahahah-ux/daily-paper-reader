## 摘要
现代视觉-语言-动作（VLA）策略会一次性预测一整块动作：在一次前向传播中输出一到两秒的协调运动。然而，一个动作块本质上是一段短时多元轨迹，但在这些模型内部，它却是被一个线性头解码的、通用的逐时间步隐令牌序列。这未能充分服务于两种运动结构。第一，频率：一个动作块在多个时间尺度上叠加了平滑的全局趋势与精细的修正运动，而单个令牌将它们纠缠在一起。第二，跨相位几何：不同相位（接近、接触、抓取调整、稳定）的运动在表示空间中沿差异很大、近乎正交的方向展开，但它们对任务而言紧密相关，并且沿时间轴相继出现。点积注意力以内积来度量对齐程度，因此它偏好方向对齐的令牌，而在接近正交时最为不敏感，从而使这类关系只能由网络绕道恢复。我们提出时频几何交叉注意力（TFGCA），一个即插即用模块，可修复上述两个盲点。TFGCA 使用逐维可学习的平稳小波变换，将动作块分解为时频令牌，每个时间令牌通过一种交叉注意力从中检索信息，该注意力以一个可学习权重融合点积（相似性）与楔积幅值（对近乎正交敏感）。一个零初始化的残差在初始化时复现基础行为，因此它可以被直接加到预训练的 VLA 上并进行联合微调。相对于同源的基线，TFGCA 在分布内 LIBERO 上平均提升 +1.5，在分布外 LIBERO-Plus 上提升 +6.3，在 RoboTwin 域随机化下的随机平均提升 +28.5，在三个真实机器人 AgiBot A2 任务上的总体成功率提升 +11.67 个百分点，且在分布外增益更大。

## Abstract
Modern vision-language-action (VLA) policies predict a whole chunk of actions: one to two seconds of coordinated motion emitted in a single forward pass. Yet an action chunk is essentially a short multivariate trajectory, but inside these models it is a sequence of generic per-timestep hidden tokens decoded by a linear head. This under-serves two motion structures. First, frequency: a chunk superimposes a smooth global trend and fine corrective motion across time scales, and a single token entangles them. Second, cross-phase geometry: motions of different phases (reach, contact, grasp adjustment, settling) unfold along very different, near-orthogonal directions in representation space, yet are tightly related for the task and arise across the time axis. Dot-product attention scores alignment by an inner product, so it favors aligned tokens and is least sensitive near orthogonality, leaving such relationships for the network to recover through a detour.   We introduce Time-Frequency Geometric Cross-Attention (TFGCA), a drop-in module repairing both blind spots. TFGCA uses a per-dimension learnable stationary wavelet transform to decompose the action chunk into time-frequency tokens, and each time token retrieves information from them via a cross-attention that fuses the dot product (similarity) with the wedge-product magnitude (sensitive to near-orthogonality) through a learnable weight. A zero-initialized residual reproduces the base behavior at initialization, so it can be dropped onto a pretrained VLA and fine-tuned jointly. Relative to the same-source base, TFGCA improves in-distribution LIBERO by +1.5 on average, the OOD LIBERO-Plus by +6.3, the randomized average under RoboTwin domain randomization by +28.5, and the overall success rate on three real-robot AgiBot A2 tasks by +11.67 points, with larger gains out of distribution.

## 1. 核心问题与整体含义

- **背景**：现代 VLA（视觉–语言–动作）策略普遍采用"动作分块"（action chunking）输出接口——一次前向传播预测未来 T 步、D 维的整段轨迹（如 π0、π0.5、RDT-1B、ACT），再执行其中前缀后重新规划。这种接口提升了时间一致性与短时程协调能力。
- **核心问题**：动作块本质上是一段**结构化短时多元轨迹**，但现有 VLA 把它当作**非结构化序列**处理——Transformer 输出的只是逐时间步的通用隐 token，由单个线性头解码，导致两类运动结构被忽略：
  - **频率结构**：一个动作块在多个时间尺度上叠加了"平滑全局趋势 + 精细修正运动"（如搬运、接触修正、抓取调整、稳定），单个 token 将多尺度信息纠缠在一起。
  - **跨相位几何关系**：不同操作相位（接近、接触、抓取调整、稳定）在表示空间中沿差异极大、甚至**近乎正交**的方向展开，但它们沿**时间轴**相继出现、任务上紧密相关。作者将此现象命名为 **TO-DoL（Temporal Orthogonal Division-of-Labor，时间正交分工）**。
- **关键矛盾**：点积注意力只度量"对齐/相似性"，在**正交附近最不敏感**，因此必须耗费额外表示容量把正交关系"绕道"重新编码为相似性。
- **整体含义**：论文提出一个**即插即用模块 TFGCA**，为分块 VLA 补齐"多尺度频率内容"与"跨相位近正交几何关系"两块盲区，在不破坏预训练权重的前提下联合微调，且**分布外（OOD）增益显著大于分布内**。

## 2. 方法论

### 2.1 核心思想
在 VLA Transformer 输出 H 与动作头之间插入 TFGCA，将 H ∈ R^{T×d} 变换为 H̃：**用逐维可学习平稳小波变换把动作块变成时频 token（作 keys/values），让每个时间 token（作 query）通过"点积 + 楔积"融合的交叉注意力检索整块轨迹的时频证据**，并采用零初始化残差保证初始行为不变。

### 2.2 三个阶段

- **（C1）动作空间投影**
  - Z_act = ActionProj(H) ∈ R^{T×D}，把抽象隐空间投影到逐控制维度的物理动作空间（LIBERO 为 6 维笛卡尔末端增量 + 1 维夹爪；RoboTwin/AgiBot 为关节空间）。
  - 附加辅助对齐损失 L_align = ‖Z_act − sg(a)‖²（sg 为停止梯度），总损失 L = L_FM + λL_align。

- **（C2）逐维可学习平稳小波变换（SWT）分词**
  - 标准小波会下采样，SWT **不下采样**，每个频带长度仍为 T，因而能与原始时间步对齐并直接充当注意力 key。
  - 一级分解：低频/高频滤波器对 (h, g) 在膨胀 2^j 下作用于近似分支，递归得到 J 个细节带 + 1 个最终近似带，共 **J+1 个频带**（高频→低频排序）。
  - **三项面向机器人动作的设计**：
    1. **逐维可学习滤波器**：每个动作维度独立滤波器对，初始化为 Daubechies-2（db2，长度 4），两个消失矩使细节系数对局部线性运动不响应、只对曲率响应；
    2. **逐维去均值（DC removal）**：避免零频大能量淹没细节带；**刻意不做标准差归一化**，以保留"高运动段 vs 静止段"的幅度对比信号；
    3. **可选差分预处理**：对低频主导的序列先做有限差分（LIBERO 0 阶、RoboTwin 2 阶）把任务能量搬入高频带。
  - 每个 (时间, 频带) 位置的 D 维动作向量经逐带线性映射嵌入到模型宽度 d，并叠加频带类型嵌入与时间位置嵌入；按"频带索引最快"展平得到频率 token 序列 **F ∈ R^{T(J+1)×d}**（多动作维度结构作为 token 内容而非逐维配对）。

- **（C3）点积 + 楔积交叉注意力**
  - 查询为时间 token H，键/值为频率 token F：Q = W_Q H，K = W_K F，V = W_V F，缩放 s = 1/√d_h。
  - 两个打分矩阵：**点积** S_dot = s(qᵀk)；**楔积幅值** S_wed = s·√(‖q‖²‖k‖² − (qᵀk)²)（用 Cauchy–Schwarz 恒等式闭式计算，无需构造反对称张量）。
  - **两个 softmax 分别归一化后混合**（而非先求和再 softmax），保持每个通道是合法分布：
    **A = (1 − β)·softmax(S_dot) + β·softmax(S_wed)**，其中 β = σ(ℓ) 为可学习标量 logit，初始化为 0.5。
  - 输出：**H̃ = H + W_O(A·V)**。

### 2.3 零初始化与可训练性
- **W_O 零初始化** ⇒ 初始化时 H̃ = H，模块精确复现基础策略输出，可安全挂载到预训练 VLA 上联合微调（约 4.23M 参数，约占 π0.5 的 **0.10%**）。
- **只零初始化 W_O，保留 value 路径（频带嵌入、动作投影）非零**：初始梯度 ∇_{W_O}L = δ(AV)ᵀ 一般非零，模块能脱离恒等映射；若同时把 V 也置零则会永远卡在恒等。

### 2.4 理论性质（命题 1）
- 恒等式：**(qᵀk)² + ‖q∧k‖² = ‖q‖²‖k‖²**；归一化后 ŝ² + ŵ² = 1（ŝ = cos θ，ŵ = |sin θ|），即点积与楔积是"相关度单位圆"上的两个正交坐标，点积对 ŵ 轴完全盲视。
- **序分离**：固定 q，两个等范数 key 满足 qᵀk_a > qᵀk_b ≥ 0 时，点积通道必然给 k_a 更高权重、**永远无法偏好更正交的 k_b**；楔积通道则相反。
- 当 **β > β\* = Δ_dot/(Δ_dot + Δ_wed) ∈ (0,1)** 时，混合打分翻转排序——这是纯点积打分无法实现的排序。
- **表示复杂度视角**：‖q∧k‖² 是 (q,k) 的二次型，点积需二次特征提升 φ(x) = vec(xxᵀ)（维度达 O(d_h²)）才能复现，楔积以 O(d_h) 闭式得到。
- **范围说明**：该分离只在固定表示下成立；深层网络理论上可通过重学特征把正交关系编码为对齐，因此命题不是"点积模型不可能"的结论，而是"楔积提供了低成本、无需重学特征或二次提升的直接归纳偏置"。

## 3. 实验设计

### 3.1 基准与场景（四个设置）
- **LIBERO**（分布内、近饱和）：4 个任务套件 Spatial / Object / Goal / Long(L10)，单臂、末端增量控制，T = 10。
- **LIBERO-Plus**（OOD 泛化）：7 类扰动族 Camera、Robot、Language、Light、Background、Noise、Layout；**仅在干净 LIBERO 上训练**，直接零样本测试。
- **RoboTwin 2.0**（单任务、双臂）：6 个任务（open_microwave、stamp_seal、handover_block、turn_switch、stack_bowls_three、click_bell），**仅在干净演示上训练 30k 步**，分别在干净与域随机化环境测试；T = 50、SWT 两级、二阶差分。

### 3.2 对比方法与基线
- **同源基线**：同一数据、同一训练预算、同一评测流程下自行复现的 **π0.5（lerobot/pi05_base）**——这是主要对照。

### 3.3 主要配置
- 基础模型 lerobot/pi05_base；AdamW，初始学习率 2.5×10⁻⁵，cosine 衰减至 2.5×10⁻⁶，warmup 1000 步，30k 步；批大小 32/64，bf16，梯度检查点；FM 时间采样 Beta(1.5,1.0)，推理去噪 10 步；随机种子 1000。
