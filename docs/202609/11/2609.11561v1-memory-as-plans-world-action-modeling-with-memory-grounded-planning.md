## 摘要
主流机器人策略通常采用马尔可夫形式，但许多复杂的真实世界操作任务本质上是非马尔可夫的，需要超出当前观测的长时程记忆。现有记忆机制往往依赖语言摘要、不断增长的视觉窗口或二者组合，因此可能丢失细粒度视觉证据，或在历史覆盖范围与执行效率之间面临权衡。我们提出 MaP-WAM，一种“记忆即计划”（Memory-as-Plans）框架，它将依赖记忆的世界-动作建模分解为基于记忆的规划与以计划为条件的执行，并将长期多模态情景上下文用作规划阶段的证据，而非反复让执行器以完整历史为条件。MaP-WAM 将记忆表示为包含语言指令和稀疏视觉上下文的已完成片段记录，并将这种情景记忆转换为紧凑计划，该计划由下一片段级语言计划和相应的视觉引导组成。世界-动作-进展（WAP）模型在未知时长内执行每个计划，在推理时联合预测动作块与相应的执行进展，并通过计划-观测对齐来校准预测进展，以实现自适应片段转换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，而结构化注意力进一步在规划与执行中实现键值缓存。MaP-WAM 在 RMBench 上以 83.3% 的成功率取得当前最优性能，并在真实机器人任务上达到 78.0% 的成功率，同时随着任务历史增长，执行器推理延迟保持大致恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

## 1. 核心问题与研究动机

- **背景**：主流机器人策略（VLA、世界-动作模型 WAM）普遍采用马尔可夫假设，即仅以当前观测或固定短历史作为动作生成的依据。
- **核心痛点**：许多真实操作任务本质上是**非马尔可夫**的——决策所需信息可能已从当前视野中消失（如物体被遮挡、颜色/位置需回忆），因此策略必须具备超出当前观测的**长时程记忆**能力。
- **现有记忆机制的缺陷**：
  - **语言记忆**（如 MemER、Mem-0、MEM）：将历史压缩为语言摘要，语义紧凑但**丢失细粒度视觉与空间证据**。
  - **增长窗口记忆**（如因果 WAM、LingBot-VA）：保留逐帧历史，但推理延迟与 GPU 显存**随历史长度快速增长**（文中显示 1700 帧时显存超 80 GB 导致 OOM）。
  - **持续更新记忆**（记忆库/隐状态）：早期证据可能被压缩或覆盖，难以在长时程中保留任务相关信息。
- **核心矛盾**：历史覆盖范围与执行效率之间存在难以调和的权衡。
- **关键洞察**：长时程视觉历史**不必每一步都直接输入执行器**，它主要用于决定下一段级计划及期望的视觉演化，执行只需遵循一个记忆驱动的计划即可。

## 2. 方法论：Memory-as-Plans 框架

### 2.1 核心思想

- 将记忆依赖的世界-动作建模**解耦**为两个阶段：
  1. **记忆驱动规划（Memory-Grounded Planning）**：用长期多模态情景上下文生成紧凑计划。
  2. **计划条件执行（Plan-Conditioned Execution）**：执行器仅以固定长度的计划为条件，不再重复处理完整历史。
- 记忆表示为**已完成片段记录** `C_i = {l_i, G_i}`，其中 `l_i` 为语言指令，`G_i` 为从该段真实轨迹中均匀采样的 8 帧稀疏视觉上下文；初始观测记为 `G_0 = f_0`。

### 2.2 记忆驱动规划

- **语言规划器**：微调 VLM，输入全局指令 `l`、已完成片段指令 `l_<k` 和紧凑关键帧集 `f*`（初始帧 + 每段末帧），预测下一段级语言计划 `l_k`。
- **视觉规划器（CWM）**：以因果世界模型生成视觉计划 `G_k`，条件为长期视觉上下文 `G_<k`、语言计划 `l_k` 与全局指令 `l`，采用标准流匹配目标训练。
- **因果注意力设计**：将 token 按段组织为块，施加**块因果掩码**，防止未来信息泄漏，使已完成段证据成为可缓存的静态前缀。

### 2.3 World-Action-Progress（WAP）模型

- **动机**：计划执行时长未知，需在执行过程中判断何时完成当前段并触发重规划。
- **架构**：在预训练视频 DiT 基础上，用 **Mixture-of-Transformers（MoT）** 扩展出动作专家（1.02B 参数）与进度专家（207M 参数），联合建模未来视觉动态、动作块与执行进度。
- **进度定义**：对训练段 `f_{i:j}` 标注归一化进度 `p_t = (t-i)/(j-i)`，为执行状态提供连续时间坐标，可区分视觉相似但语义阶段不同的观测。
- **训练目标**：对未来视觉状态、动作块、进度序列分别施加条件流匹配损失，加权求和：`L_E = λ_v L_v + λ_a L_a + λ_p L_p`。
- **结构化注意力**：计划前缀为静态干净前缀，可预填充并缓存；动作/进度 token 与未来视觉 token 之间相互屏蔽，未来视觉预测仅作辅助训练目标，推理时可省略。

### 2.4 闭环规划与执行

- **计划-观测对齐（Progress Calibration）**：视觉计划每帧按归一化进度索引。给定当前进度估计，检索附近计划帧，用 RGB 像素平均绝对差选出与当前观测最相似的帧，将进度条件向该帧进度值校准，缓解递归进度预测的误差累积。
- **进度门控段切换**：对最近动作的预测进度取平均，超过阈值 `τ = 0.95` 即判定当前段完成，终止执行、更新情景上下文并触发下一段规划。
- **上下文更新**：真实执行观测被重采样为稀疏视觉证据 `G_k` 后追加到情景上下文，**保持上下文基于真实观测而非生成预测**。

## 3. 实验设计

### 3.1 仿真实验

- **Benchmark**：**RMBench**——专为长时程记忆依赖操作设计的仿真基准，包含 5 个 M(1) 任务（依赖单个过去观测）和 4 个 M(n) 任务（依赖多个过去观测）。
- **训练/评估协议**：每任务 50 条官方专家演示训练，每任务 100 次评估 rollout，全局种子 0；规划器多任务训练，WAP 按 Mem-0 方式单任务训练。
- **对比基线**：DP、π0.5、X-VLA、Mem-0、WLA-0、LingBot-VA。

### 3.2 真实机器人实验

- **平台**：7-DoF Franka Research 3 机械臂 + 第三人称与腕部 RealSense D435i 相机。
- **任务**：
  - **Find Button**：先观察按钮颜色，按钮被遮挡后人类在白板给出颜色指令，机器人需打开对应盖子。
  - **Press Buttons**：观察白板上两个数字，多次按下左/中按钮后按下右侧确认按钮。
- **规模**：每任务采集 50 条轨迹训练，每任务 50 次独立试验评估。

### 3.3 消融实验

- **记忆驱动视觉规划**：对比完整 MaP-WAM、w/o visual plan（去除 CWM，仅用语言计划）、w/o visual memory（用当前观测条件的普通世界模型替代 CWM）。

### 3.4 效率分析

## 6. 主要结论与发现

- **性能**：RMBench 总平均成功率 **83.3%**，超越所有基线（次优 LingBot-VA 为 77.1%，Mem-0 仅 42.0%）；真实机器人任务平均 **78.0%**（Find Button 88%，Press Buttons 68%）。
- **关键任务表现**：Swap T（需精确回忆初始位置）与 Press Button（需区分视觉相似但语义不同阶段）均达 **96%**；Observe and Pick Up 从最强基线的 9% 提升至 19%。
- **效率**：执行器每动作块延迟在历史增长下**近似恒定（约 827 ms）**；全上下文执行器在 1500 帧时约为零历史延迟的 4 倍，1700 帧时 OOM。
- **消融结论**：
  - 视觉记忆对需精确历史视觉证据的任务（如 Observe and Pick Up、Swap T）至关重要，用当前观测替代情景证据会导致物体身份/空间位置错误。
  - 进度条件对 Press Button 尤为重要（去除后 96%→18%）；进度校准对长时程任务（Blocks Ranking Try，平均 423.10 步）收益最大（38%→94%）。
  - 完整 MaP-WAM 在三项消融任务上平均成功率 96.7%，显著优于所有变体。

## 7. 优点与亮点

- **框架创新**：将"记忆"重新定义为"计划"，把长时程视觉处理与短时程动作生成解耦，从根本上避免了执行器上下文随历史增长的问题。
- **固定上下文 + KV 缓存**：执行器上下文长度固定，规划与执行阶段均支持键值缓存，推理延迟近似恒定，工程可扩展性强。
- **进度作为一等模态**：不同于将进度作为事后验证器或奖励信号，WAP 将进度与动作、视觉动态联合生成并反馈为条件信号，提供显式时间锚点。
- **计划-观测对齐**：轻量、免训练的对齐机制有效缓解递归进度预测的漂移，长时程任务收益显著。
- **闭环设计完整**：规划 → 执行 → 进度校准 → 段切换 → 上下文更新形成完整闭环，且上下文更新基于真实观测而非生成预测，避免误差污染记忆。
- **实验覆盖**：仿真 + 真实机器人、多基线、多消融、效率分析齐备，结论有说服力。

## 8. 不足与局限

- **依赖人工/基准分段结构**：MaP-WAM 当前依赖 RMBench 提供的片段边界标注来组织记忆与进度，扩展到无分段演示需引入自动分段发现机制。
- **对齐机制较为朴素**：计划-观测对齐采用 RGB 像素平均绝对差的免训练匹配度量，在视觉复杂场景下可能不够鲁棒，学习式相似度度量或可进一步提升。
- **真实机器人实验规模有限**：仅 2 个任务、每任务 50 次试验，任务多样性不足，难以完全证明泛化性。
- **基线对比不完整**：部分基线在部分任务上缺失（"-"），削弱了对比的全面性。
- **超参数敏感性未充分探讨**：如段切换阈值 τ=0.95、稀疏帧数 N=8、进度噪声偏移范围等超参数的敏感性分析未见报道。
- **应用限制**：方法假设任务可划分为语义连贯的片段，对连续、无明确子目标的灵巧操作任务可能不适用；真实部署还需考虑规划器 VLM 与 CWM 的推理开销（虽执行器延迟恒定，但规划阶段仍需调用大模型）。
