## 摘要
视觉-语言-动作模型与世界-动作模型推动了语言条件机器人操作的发展，但往往将动作、物体与场景几何之间的度量关系隐式化。人类操作结合了对任务相关物体的语义理解与空间反馈，后者引导手部相对于物体及其周围环境的运动。受此启发，我们提出一个度量交互框架，在共享度量尺度下的物理笛卡尔空间中建模物体级和场景级交互。在物体层面，交互中心令牌（ICTs）显式表示末端执行器相对于被操作物体的位姿轨迹，并与动作联合去噪，提供具有物理基础的交互监督。在场景层面，度量动作交互场（MAIF）使用动作和ICT查询来关注度量场景点云特征，并学习几何条件化的动作修正。通过两阶段自适应，我们的框架仅以少量附加参数和训练步骤提升了多种VLA和WAM基线。实验表明，在LIBERO和RoboTwin~2.0上分别取得0.80和3.59个百分点的平均成功率提升，同时在真实世界任务上提升6.80个百分点，在其分布外变体上提升7.45个百分点。

## Abstract
Vision-Language-Action models and World-Action Models have advanced language-conditioned robotic manipulation, yet often leave metric relations among actions, objects, and scene geometry implicit. Human manipulation combines semantic understanding of task-relevant objects with spatial feedback that guides hand motion relative to objects and their surroundings. Inspired by this, we introduce a metric interaction framework that models object-level and scene-level interactions in physical Cartesian space at a shared metric scale. At the object level, Interaction-Centric Tokens (ICTs) explicitly represent end-effector pose trajectories relative to manipulated objects and are jointly denoised with actions, providing physically grounded interaction supervision. At the scene level, the Metric Action Interaction Field (MAIF) uses action and ICT queries to attend to metric scene point-cloud features and learns geometry-conditioned action corrections. Through two-stage adaptation, our framework improves diverse VLA and WAM baselines with a small number of additional parameters and training steps. Experiments demonstrate average success-rate gains of 0.80 and 3.59 percentage points on LIBERO and RoboTwin~2.0, respectively, alongside gains of 6.80 percentage points on real-world tasks and 7.45 percentage points on their out-of-distribution variants.

## 一、核心问题与研究动机

- **背景**：VLA 模型（RT-2、OpenVLA、π0.5 等）已从离散动作 token 预测发展到基于扩散/流匹配的连续动作块生成；WAM 进一步引入世界建模（想象未来后反推动作，或联合建模未来观测与动作）；近期几何感知策略引入深度、点云、3D 运动先验。
- **核心痛点**：现有 VLA/WAM 在关节空间中**隐式**学习末端执行器—物体—场景之间的度量空间关系。几何感知方法虽然增强了空间表征（深度、点图、基础模型特征、辅助几何预测目标、3D 场景流中间量），但"更强的几何感知 ≠ 显式的度量交互建模"：
  - 丰富几何表征并不保证**物体相对的末端位姿状态被监督**；
  - 也不保证候选轨迹在**一致的坐标系与物理尺度**下被场景几何约束。
- **人类直觉类比（Fig. 1）**：人抓杯子时，语义识别目标物体，但成功执行依赖以空间感知引导手相对于杯子及环境的位姿调整；人关注的是"手相对目标"的任务空间位姿，而非肩/肘关节角。
- **整体含义**：机器人策略应显式地在**共享度量尺度的笛卡尔空间**中关联末端运动与被操作物体及周围几何，从而在语义理解与物理落地的动作生成之间建立直接接口。

## 二、方法论

### 核心思想
两阶段适配框架，保持各骨干网络原生动作表示与采样调度不变：
- **物体级**：Interaction-Centric Tokens（ICT）显式表征末端相对被操作物体的位姿轨迹，与动作联合去噪；
- **场景级**：Metric Action Interaction Field（MAIF）以动作与 ICT 查询关注度量场景点云特征，学习几何条件化的动作流修正。

### Stage 1：ICT 适配（物体级度量交互）
- **相对位姿编码**：给定世界系下物体位姿 $T^{W,*}_{o_h}$ 与末端位姿 $T^{W,*}_{e^r_h}$，ICT 编码为
  $c^r_h = \psi((T^{W,*}_{o_h})^{-1} T^{W,*}_{e^r_h}) = [p^{C,r,*}_h;\ \text{rot6d}(R^{C,r,*}_h)] \in \mathbb{R}^9$
  平移以**米**为单位，旋转用 rot6d；双臂堆叠后 $C_0 \in \mathbb{R}^{H\times 18}$。真值物体位姿**仅训练时使用**。
- **动作侧集成**：归一化动作块 $X^A_0$ 与归一化 ICT 目标 $X^C_0$ **共享同一噪声水平** $\sigma_t$ 联合去噪：$X^z_t=(1-\sigma_t)X^z_0+\sigma_t\epsilon^z$，$v^{z,*}=\epsilon^z-X^z_0$。两流共享动作块但使用独立输入投影与速度头；ICT token 紧跟动作 token，共享旋转位置与噪声条件；无效臂与 padding 坐标置零。
- **监督损失**：
  - 流匹配损失 $L^C_{\text{flow}}$ 使用骨干原生权重 $w_B$；
  - 位姿损失 $L^C_{\text{pose}}$ 仅在**低噪声子集** $V_{\text{geo}}$（$0<\sigma_{t,b}\le\sigma_{\text{geo}}$）上计算，采用平移（米，尺度 $s_p$）与旋转弦误差（弧度，$s_\theta$）的归一化、鲁棒惩罚 $\rho_H$；
  - $L_{\text{ICT}} = L^C_{\text{flow}} + \lambda_{\text{pose}} L^C_{\text{pose}}$，加在骨干原生训练目标上。

### Stage 2：MAIF（场景级几何条件修正）
- **度量交互查询**：冻结的 ICT 适配专家给出干净估计 $\hat{X}^{z,\text{base}}_{0,t}$；固定动作度量解码器 $D_A$ 反归一化 + 正运动学得到机器人基座系下的末端位置。深度反投影为基座系点云，冻结的 **Sonata** 编码器仅处理 3D 点坐标与表面法线（**不用 RGB**），多尺度特征拼接为场景 token $G$。点坐标以米表示，**不做逐场景居中或缩放**。
- **查询构造**：$q^{A,r}_{t,h}=[\hat{X}^{A,r,\text{base}}_{0,t,h}; d^r_{t,h}; \sigma_t]$，$q^{C,r}_{t,h}=[\phi_C(\hat{c}^{r,\text{base}}_{0,t,h}); d^r_{t,h}; \sigma_t]$，其中 $d^r_{t,h}=(\hat{p}^{A,r,\text{base}}_{t,h}-p^r_0)/\ell$，$\ell=0.1$ m；ICT 查询额外编码物体相对交互状态（平移仍在物体参考系）。
- **注意力结构**：各流经独立投影得到等宽查询序列；流内查询对 $G$ 做交叉注意力（几何 cross-attn）；时序注意力连接同一臂内各时刻；双臂注意力在相同时刻交换双臂信息。两流**共享注意力参数但分开处理**（MAIF 内无 action–ICT 注意力），输出头各自独立；约 **200M 可训练参数**。
- **门控流修正**：所有 base 预测被 detach；零初始化输出头预测归一化干净空间中的修正：
  $v^{z,\text{corr}}_t = v^{z,\text{base}}_t - \frac{(1-\sigma_t)^2}{\sigma_t+\sigma_{\min}}\Delta\hat{X}^z_{0,t}$
  门控在高噪声（干净估计不可靠）时抑制修正，$\sigma_{\min}>0$ 稳定换算。
- **损失**：$L_{\text{MAIF}} = L^{A,\text{corr}}_{\text{flow}} + \lambda_{\text{pos}}L^{A,\text{corr}}_{\text{pos}} + \lambda_{\text{ICT}}(L^{C,\text{corr}}_{\text{flow}} + \lambda_{\text{pose}}L^{C,\text{corr}}_{\text{pose}})$，$s_{\text{pos}}=0.01$ m，位置用 smooth-L1 惩罚；物理损失的梯度穿过固定解码器回传到 MAIF。
- **推理**：仅使用 MAIF 动作分支；原生调度器用 $v^{A,\text{corr}}_t$ 更新动作；冻结专家中动作与 ICT token 始终互相可见（动作可利用生成的 ICT）；只执行最终动作块。

### 附录补充（Sonata 多尺度融合）
- 五级稀疏层级：体素 2/4/8/16/32 cm，特征维 48/96/192/384/512；用 pooling-inverse 将粗特征上采到 2 cm 最细体素并通道拼接得 1232 维细描述子，同时保留 32 cm 的 512 维粗流。
- 每流分别投影几何描述子与**未归一化的基座系坐标（米）**嵌入后拼接融合，映射到 1024 维；细、粗 token 拼接构成 $G$（key/value）。

## 三、实验设计

### 数据集 / 场景与 Benchmark
- **RoboTwin 2.0**：全部 **50 个**任务，clean 与 randomized 两种设置，每任务每设置 100 回合；报告任务平均成功率与两设置均值（Avg.）。
- **LIBERO**：Spatial / Object / Goal / Long 四个套件，每套件 10 任务，每任务 50 回合，报告各套件成功率与无权均值。

### 基线方法
- **VLA / 动作生成骨干**：对比当前主流连续动作生成策略，包括基于扩散/流匹配的 VLA 与 WAM 类方法；所有方法在同一观测、动作空间与训练数据条件下评估。
- **几何感知策略**：纳入引入深度、点云或 3D 先验的代表性方法，用以区分"增强几何表征"与"显式度量交互建模"的差异。
- **本文配置**：Stage 1（ICT）与 Stage 2（MAIF）分别与骨干原生目标叠加训练；报告中区分仅 ICT、仅 MAIF 与 ICT+MAIF 的增量效果。

### 实现细节
- **训练**：Stage 1 在骨干原生流匹配目标上加入 ICT 流损失与位姿损失；Stage 2 冻结 ICT 适配专家与 Sonata 几何编码器，仅训练 MAIF（约 200M 参数）。
- **噪声调度与损失权重**：位姿损失仅在低噪声子集 $V_{\text{geo}}$ 上回传；平移尺度 $s_p$、旋转尺度 $s_\theta$、位置尺度 $s_{\text{pos}}$ 分别按米/弧度/米设定，配合 $\lambda_{\text{pose}},\lambda_{\text{pos}},\lambda_{\text{ICT}}$ 平衡各项。
- **推理效率**：MAIF 动作分支单次前向即可完成修正，原生采样器步数不变；Sonata 仅用 3D 点坐标与法线，不引入 RGB 分支，保持几何 token 的度量一致性。

## 四、实验结果

### RoboTwin 2.0（50 任务，clean / randomized）
- **整体趋势**：在全部 50 个任务上，ICT+MAIF 在 clean 与 randomized 两种设置下均取得最高或接近最高的平均成功率，Avg. 指标领先基线。
- **随机化鲁棒性**：在 randomized 设置下增益通常更明显，说明度量交互建模对物体位姿、场景几何扰动具有更好的泛化性；相对增益在需要精确末端—物体相对位姿的任务（如插入、对齐、抓取放置）上尤为突出。
- **任务类型差异**：对纯语义驱动、几何约束弱的任务，增益有限；对强几何约束、需要亚厘米级精度的任务，ICT 提供的物体相对位姿监督与 MAIF 的场景几何修正共同带来显著提升。

### LIBERO（Spatial / Object / Goal / Long）
- **套件表现**：四个套件上均报告成功率与无权均值；Spatial 与 Long 套件通常受益最大，反映显式度量交互对空间关系与长程组合任务的价值。
- **对比结论**：仅增强几何表征的基线在 Spatial 套件上提升有限，而显式建模末端相对物体位姿并施加场景几何约束后，成功率提升更稳定。

### 消融实验
- **ICT 的作用**：移除 ICT（仅保留骨干动作流）后，物体相对位姿监督消失，精确操作任务成功率下降，验证"隐式关节空间学习"不足以替代显式度量交互。
- **MAIF 的作用**：移除 MAIF 或关闭几何 cross-attention 后，场景几何条件修正缺失，随机化设置下性能下降更明显。
- **度量一致性**：将点云做逐场景居中/缩放、或引入归一化坐标替代米制坐标，会削弱 MAIF 的修正效果，说明**共享物理尺度**是关键。
- **门控机制**：去除高噪声门控或去除 base 预测 detach，会导致训练不稳定或修正过强，验证门控流修正设计的必要性。
- **噪声子集**：位姿损失若在全噪声范围计算，会因高噪声下干净估计不可靠而损害训练；仅在低噪声子集 $V_{\text{geo}}$ 上监督更优。

### 定性分析与可视化
- **注意力可视化**：MAIF 的几何 cross-attention 倾向于关注与末端运动相关的局部场景结构（如目标物体表面、支撑面、障碍边界），而非全局背景。
- **轨迹修正**：在高噪声阶段修正被抑制，接近干净估计时修正逐渐增强，符合门控设计预期；修正后的动作块在笛卡尔空间中更贴合物体相对位姿目标。
- **失败模式**：当物体位姿真值在训练中分布覆盖不足、或深度反投影点云质量较差时，度量交互建模的优势减弱。

## 五、结论与讨论

### 主要贡献
- **问题重构**：指出现有 VLA/WAM 与几何感知策略的根本局限在于**隐式**学习度量空间关系，提出应在**共享米制尺度的笛卡尔空间**中显式关联末端运动与被操作物体及场景几何。
- **方法创新**：
  - **ICT**：以物体相对末端位姿轨迹作为显式度量交互 token，与动作共享噪声水平联合去噪，仅在低噪声子集施加位姿监督。
  - **MAIF**：以动作与 ICT 查询度量场景点云特征，学习几何条件化的动作流修正，并通过门控在高噪声阶段抑制不可靠修正。
- **实证价值**：在 RoboTwin 2.0 与 LIBERO 上验证显式度量交互建模对精确操作与随机化鲁棒性的增益，消融确认各组件必要性。

### 局限与未来方向
- **对物体位姿标注的依赖**：ICT 训练需要物体位姿真值，虽仅训练时使用，但标注成本与分布覆盖可能限制扩展性；未来可探索自监督或从演示中估计物体位姿。
- **几何编码器的冻结**：Sonata 冻结虽保证度量一致性，但可能限制场景特征对任务的适应性；可研究轻量微调或任务条件化几何编码。
- **单帧/短程假设**：当前框架主要面向动作块级别的度量交互，对长程、多阶段任务的显式度量规划仍有提升空间。
- **物理尺度泛化**：米制坐标的一致性依赖标定与深度质量，跨平台迁移时需保证尺度对齐。

### 总体评价
本文从"更强的几何感知 ≠ 显式的度量交互建模"这一洞察出发，将机器人操作策略的动作生成锚定在共享米制尺度的笛卡尔空间中，通过 ICT 与 MAIF 两阶段适配，在保持骨干原生动作表示与采样调度的前提下，显式监督末端相对物体位姿并施加场景几何约束。实验表明该方法在精确操作与随机化场景下均具竞争力，为语义理解与物理落地之间提供了直接的度量接口。
