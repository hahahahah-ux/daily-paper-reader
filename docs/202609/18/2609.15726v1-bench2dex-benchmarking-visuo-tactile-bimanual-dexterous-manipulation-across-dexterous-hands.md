## 摘要
触觉感知提供了仅凭视觉难以推断的接触信息，但面向灵巧手的触觉硬件尚未收敛到统一设计。不同灵巧手在手指结构、接触表面和传感器布局上存在差异，而仿真触觉信号仍与物理传感器产生的测量不同。这些因素使得在一致的实验设置下研究跨多种灵巧手的视触觉操作变得困难。我们提出了 Bench2Dex，一个面向 12 种灵巧手的视触觉双臂操作仿真基准。我们改造现有机器人模型，为其配备共享的仿真触觉接口，将局部接触几何转换为类图像触觉观测。该接口在不同手部形态之间提供一致的观测格式，而不试图复现特定物理触觉传感器的输出。Bench2Dex 包含 26 项双臂操作任务，涉及工具使用、铰接物体交互和多阶段操作，并配有约 1.3K 条人类遥操作演示。该基准提供同步的视觉、触觉、本体感觉、动作和物体状态观测，以及可执行的任务指标。为了评估鲁棒性，我们将七种扰动类型归入不变性轴（正确动作不变）和等变性轴（正确动作随扰动变化）。我们在 Bench2Dex 上评估了 ACT、Diffusion Policy、pi0.5 和 GR00T N1.5，并报告了它们的性能和失败模式。Bench2Dex 旨在作为一个研究跨灵巧手视触觉学习的平台。它并不假设仿真触觉观测可以替代真实触觉感知；它是在触觉硬件和仿真模型仍在演进时为算法开发提供的共享设置。

## Abstract
Tactile sensing provides contact information that can be difficult to infer from vision alone, but tactile hardware for dexterous hands has not converged to a common design. Dexterous hands differ in finger structure, contact surfaces, and sensor layouts, while simulated tactile signals still differ from measurements produced by physical sensors. These factors make it difficult to study visuo-tactile manipulation across diverse dexterous hands within a consistent experimental setting. We present Bench2Dex, a simulation benchmark for visuo-tactile bimanual manipulation across 12 dexterous hands. We adapt existing robot models with a shared simulated tactile interface that converts local contact geometry into image-like tactile observations. The interface provides a consistent observation format across different hand morphologies without attempting to reproduce the output of a specific physical tactile sensor. Bench2Dex includes 26 bimanual manipulation tasks that involve tool use, articulated-object interaction, and multi-stage manipulation, together with about 1.3K human-teleoperated demonstrations. The benchmark provides synchronized visual, tactile, proprioceptive, action, and object-state observations, together with executable task metrics. For robustness, we group seven perturbation types into invariance axis, where the correct action does not change, and equivariance axis, where the correct action changes together with the perturbation. We evaluate ACT, Diffusion Policy, pi0.5, and GR00T N1.5 on Bench2Dex and report their performance and failure modes. Bench2Dex is meant as a platform for studying visuo-tactile learning across dexterous hands. It does not assume that simulated tactile observations can replace real tactile sensing; it offers a shared setting for algorithm development while tactile hardware and simulation models are still evolving.

## 1. 核心问题与整体含义（研究动机与背景）

- **触觉的价值与现实困境**：触觉能提供仅凭外部视觉难以推断的接触信息（如插入、抓握调整、接触富集操作中的受力状态），但面向灵巧手的触觉硬件**尚未收敛到统一设计**——不同灵巧手在手指结构、接触表面、传感器布局上差异显著，同一触觉信号无法直接跨手迁移；同时仿真触觉与真实物理传感器测量仍存在差距。
- **现有基准的空白**：主流操作基准（Meta-World、RLBench、robosuite、CALVIN、LIBERO、ManiSkill3、RoboCasa、RoboCasa365、RoboTwin 2.0、DROID、Open X-Embodiment 等）大多围绕**单一平台、平行夹爪或单一传感模态**构建；多具身数据集虽有覆盖，但评测协议并未面向跨臂–手设计与接触面的灵巧操作比较。
- **灵巧/双臂专项基准的缺口**：Bi-DexHands（无视觉）、BiCoord（无灵巧手）、DexMimicGen（3 具身/9 任务，无工具无触觉）、RealMirror（单具身/5 任务，无触觉）、DexJoCo（2 具身/11 任务，无触觉）、DexVerse（单具身/19 任务，无触觉）；RoboMIND 2.0 虽有视触觉支持，但使用平行夹爪，触觉信号并非面向异构灵巧手的共享表示。
- **论文主张**：据作者所知，**尚无基准同时**涵盖「多样双臂灵巧具身 + 遥操作仿真 + 跨具身视触觉数据采集 + 长程工具使用任务 + 可执行进度评测 + 泛化测试」。Bench2Dex 正是为填补这一空白而提出，定位为**共享仿真平台**，而非声称仿真触觉可替代真实触觉。

## 2. 方法论

### 2.1 总体框架
- 基于 **Isaac Lab** 构建完整流水线：任务构建 → 人类遥操作 → 多模态数据采集 → 可执行评测。
- 规模：**12 种双臂灵巧手机器人具身、26 个长程任务、约 1.3K 条人类遥操作示教轨迹**，支持 8 种数据模态。

### 2.2 在线遥操作采集
- 操作员通过 **Manus 数据手套 + ARKit 腕部追踪**控制机器人。
- Manus 运行时的 25 节点手骨架（共享内存）→ 转换为 21 个 MediaPipe 风格关键点 → 用 **DexPilot 重定向**求解目标关节角；同一重定向接口配置给全部 12 种手，实现统一遥操作协议。
- 手臂运动：ARKit 提供腕部平移/姿态线索，**基于 Pinocchio 的闭环逆运动学控制器**映射到手臂关节目标；手与臂目标合并为一条绝对关节位置指令。
- 记录动作、机器人状态、物体状态、相机观测、任务元数据与成功/指标信号；设计上**每步开销极小**，保证实时交互响应。每条轨迹前后将机器人复位到 home 配置，减少示教间不连续并重置滤波器与腕部锚点。

### 2.3 离线多模态回放（关键设计）
- **在线遥操作与昂贵渲染解耦**：在线仅记录运动流，其余模态由离线回放管线重建，可并行、可用新传感器配置重跑、可只对子集执行。
- 回放时加载保存的物体初始状态与关节轨迹，**使用相同随机种子确定性复现**。
- 生成内容：6 路标定相机视角（胸部、俯视、立体左/右、左腕、右腕）的多视角 RGB-D；语义/实例分割标签；体素化占据栅格；2D 图像坐标与 3D 世界坐标物体包围盒；同一回放过程中生成触觉观测。
- 统一写入 HDF5，附带相机标定、动作元数据、帧有效性、任务元数据，保证回放、评测与跨具身比较一致。

### 2.4 统一视触觉接口
