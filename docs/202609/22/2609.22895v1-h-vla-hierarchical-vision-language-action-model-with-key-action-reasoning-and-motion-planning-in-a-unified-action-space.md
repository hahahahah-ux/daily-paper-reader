## 摘要
视觉-语言-动作（VLA）模型在机器人操作中展现出强大潜力，但许多现有方法仍依赖从语言和视觉观测到稠密动作的直接映射。这种建模范式可能削弱从预训练视觉-语言模型（VLM）继承的语义推理能力，因为这些模型主要针对视觉-语言理解而非底层控制进行优化；同时，该范式在空间变化下变得脆弱，包括物体位置、场景布局、机器人本体和相机视角的变化。为解决这些局限，我们提出 H-VLA，一种分层 VLA 框架，将高层关键动作推理与底层运动生成解耦。H-VLA 结合了关键动作模型（Key-Action Model），用于预测作为下一个操作子目标的关键动作；运动规划模型（Motion Planning Model），用于以预测的关键动作为条件生成稠密的未来动作；以及统一的以相机为中心的动作空间（Unified Camera-Centric Action Space），用于在数据集、机器人和视角之间实现一致的表示。我们进一步采用两阶段训练策略，在预训练阶段强调关键动作推理，在微调阶段强调稠密运动生成。实验表明，H-VLA 在 SimplerEnv 上取得了强劲性能：在 Google Robot 视觉匹配上达到 91%，在 Google Robot 变体聚合上达到 84%，在 WidowX 视觉匹配上达到 81%。在 Agilex 真实机器人任务中，H-VLA 在分布内、分布外位置以及分布外场景/物体设置下，分别比最强基线提升了 10、47 和 16 个百分点。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for robotic manipulation, but many existing methods still rely on direct mappings from language and visual observations to dense actions. This formulation can weaken the semantic reasoning capability inherited from pre-trained Vision-Language Models (VLMs), which are mainly optimized for visual-linguistic understanding rather than low-level control, and becomes fragile under spatial variations, including changes in object positions, scene layouts, robot embodiments, and camera viewpoints. To address these limitations, we propose H-VLA, a hierarchical VLA framework that decouples high-level key-action reasoning from low-level motion generation. H-VLA combines a Key-Action Model for predicting a key-action as the next manipulation subgoal, a Motion Planning Model for generating dense future actions conditioned on the predicted key-action, and a Unified Camera-Centric Action Space for consistent representation across datasets, embodiments, and viewpoints. We further adopt a two-stage training strategy that emphasizes key-action reasoning during pre-training and dense motion generation during fine-tuning. Experiments show that H-VLA achieves strong performance on SimplerEnv, reaching 91% on Google Robot visual matching, 84% on Google Robot variant aggregation, and 81% on WidowX visual matching. On Agilex real-robot tasks, H-VLA improves over the strongest baseline by 10, 47, and 16 percentage points under in-distribution, out-of-distribution position, and out-of-distribution scene/object settings, respectively.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型将大规模预训练 VLM 从感知/推理扩展到具身控制，代表工作如 RT-2、OpenVLA、CogACT、π 系列等。

- **脆弱性表现**：在物体位置、场景布局、机器人本体（embodiment）、相机视角等空间变化下泛化差。
- **已有缓解手段的不足**：中间推理（RT-H、RT-Affordance、ECoT）、视觉子目标（CoT-VLA、HAMSTER、VISTA）、相机坐标动作（OC-VLA）等只解决了部分问题，尚未真正弥合"语义推理—运动生成—跨本体一致性"三者的鸿沟。
- **整体含义**：论文主张将"机器人**应该达成什么**"与"**如何执行**"显式解耦，并通过统一坐标系让异构数据共享监督。

## 2. 方法论

### 2.1 核心思想
分层 VLA 框架，把策略预测分解为两级条件生成：
- **关键动作模型（Key-Action Model, KAM）**：预测下一个操作子目标（绝对末端位姿 + 夹爪状态）。
- **运动规划模型（Motion Planning Model, MPM）**：以关键动作为条件生成稠密未来动作块。
- **统一相机中心动作空间**：所有状态、关键动作、动作统一表示在第三人称相机坐标系。

### 2.2 输入与特征提取
- 输入：第三人称 RGB、可选腕部视角、语言指令、当前末端状态。
- 骨干：Prismatic-7B（DINOv2 + SigLIP 视觉编码器 + LLaMA-2 语言骨干）。
- 在序列末尾附加**可学习 action token**，取末层隐状态作为 cognition feature；CLS token 提供全局视觉特征。
- 腕部视图由共享视觉编码器编码，用二值腕部相机掩码 `m_wrist ∈ {0,1}²` 处理缺失视角（零填充 + 掩码），保持固定模型接口。

### 2.3 动作表示
- 单臂状态/关键动作向量：`u_t = [x, y, z, φ, θ, ψ, g] ∈ R⁷`（位置 + 欧拉角 + 夹爪）。
- 双臂：左右拼接为 `R¹⁴`；单臂数据通过**复制（V2 策略）**填满 14 维共享接口（V1 掩码、V3 零填充均性能更差）。
- **关键动作与状态为绝对值；动作指令为帧间位置/朝向增量，夹爪为绝对值。**

### 2.4 关键动作模型
- 条件：`c_t^k = concat(f_t^cog, φ_s(s_t))`，其中 `φ_s` 为两层 MLP 编码当前末端状态。
- 目标：扩散去噪，`L_key = E[‖ε_θ(k_{t,i}, i, c_t^k) − ε‖²]`。
- **关键动作标签构建**：以夹爪状态发生切换（开/关）的下一帧、以及轨迹末帧为关键帧集合；每个时刻 `t` 的监督目标是**最近的未来关键动作**。双臂左右独立提取，可对应不同未来时刻，以刻画时序分离的双臂操作阶段。

### 2.5 运动规划模型
- 条件：`c_t^a = concat(f_t^cog, f_t^cls, φ_w(o_t^wrist), φ_m(m_t^wrist), φ_ak([s_t, k_t^cond]))`。
- 训练时 `k^cond` 为真值关键动作，推理时用 KAM 预测值。
- 输出动作块 `A_t = [Δa_{t+1}, …, Δa_{t+H}]`，实现中 `H = 16`（未来窗口 15）；更长动作通过闭环多次查询完成。
- 损失同样是扩散去噪损失 `L_act`。

### 2.6 统一相机中心动作空间
- 用标定的第三人称相机外参做变换：`T_ee^c = T_b^c · T_ee^b`。
- 位置与欧拉角从 `T_ee^c` 提取，动作的位置/朝向取相机系下相邻末端位姿的帧间增量。
- 好处：统一异构数据集与本体；使动作空间与预训练 VLM 的视觉坐标系对齐。

### 2.7 两阶段训练
- **Stage 1 关键动作中心预训练**：`L = λ_k L_key + λ_a L_act`，取 `λ_k = 10, λ_a = 1`，强调可迁移的关键动作推理。
- **Stage 2 运动规划导向微调**：`L = L_key + L_act`（等权），在下游适配中提升稠密动作学习的相对权重。
- 两阶段均**联合更新全部参数**（VLM、KAM、MPM、本体编码器、腕部投影器与掩码编码器）。

## 6. 主要结论与发现

- **仿真**：Google Robot VM 91%、VA 84%、WidowX VM 81%，三项平均均最优。在需要多步执行的 Drawer+Apple 上达 98%（DAM-VLA 为 78%），说明显式关键动作推理有助于连接语义与稠密动作。
- **真机**：ID 平均 93%（较最强基线 π0 的 83% 高 10 点）；OOD Position 平均 83%（较 MolmoAct2 36%、π0/π0.5 31% 高 47 点）；OOD Scene/Object 平均 66%（较 π0.5 50% 高 16 点、较 π0 44% 高 22 点）。优势在 PickBottles/HandOver 上尤其明显，LiftPot 上 π0/π0.5 更好。
- **数据效率**：仅用 183K 轨迹（远少于 π0/π0.5 的 >1000K、MolmoAct2 的 >300K），在参数规模相近下取得更强空间泛化。
- **消融结论**：
  - 仅 Stage 1 检查点已达 73%/49%/53%，说明关键动作与稠密动作联合训练有效。
  - 去掉混合预训练 + 两阶段训练：VM 91→85、VA 84→81、WidowX 81→74。
  - 再去掉相机中心动作空间：VM 85→68、VA 81→59，降幅最大。
  - 再去掉关键动作模型：VM 68→56、WidowX 68→54（VA 59→60 基本无变化），说明关键动作条件化在两个设置中有效。
- **定性**：预测的关键动作在拾取、开抽屉、放置、闭合等多样操作原语上与任务相关区域对齐。

## 7. 优点

- **架构解耦清晰**：将"目标（关键动作）"与"执行（动作块）"分离，避免让面向理解的 VLM 直接回归底层控制，保留语义推理能力。
- **统一相机中心动作空间**：一举解决跨数据集、跨本体、跨视角表示不一致问题，并使控制标签与 VLM 的视觉坐标系对齐；消融证明其贡献最大。
- **自动化标签构建**：基于夹爪切换 + 轨迹末帧生成关键动作监督，无需人工标注关键帧，可扩展性好。
- **两阶段训练权重设计合理**：先强化可迁移的关键动作推理，再转向下游稠密运动，兼顾泛化与适配。
- **工程细节扎实**：腕部视图掩码支持缺失视角；单/双臂共享 14 维接口并实验对比三种填充策略；提供相机自标定（PnP + FK）流程与真值反投影可视化验证。
- **数据效率与效率**：以较少机器人数据达到 SOTA，推理延迟与 π0/CogACT 同量级且远快于 MolmoAct2。
- **评测规范性**：区分自测与引用结果，明确 SimplerEnv 与 X-VLA 修改设置的差异（horizon、early stop、trial 数、外参），避免不公平比较。

- **关键动作标签启发式偏弱**：仅依赖夹爪状态切换与轨迹末帧，会漏掉与夹爪无关的重要中间事件，例如 RoboCOIN 的 Pour Water（持续臂运动）、DROID 的 Push Chair Forward（接触式推）、FractalData 的 Open Drawer（臂运动 + 接触）、BridgeDataV2 的 Move Can。作者在附录中用红框明确标出这些失败案例。
- **任务类型覆盖有限**：主要面向抓取

- **任务类型覆盖有限**：主要面向抓取—放置类操作，对长时程、多阶段、需要力控/接触丰富（如插拔、拧、擦拭、倒水）的任务验证不足；真机仅 3 个任务，且 LiftPot 上不如 π0/π0.5，说明方法并非在所有操作形态上占优。
- **对关键动作质量的敏感性**：MPM 在推理时以 KAM 预测的关键动作为条件，若关键动作预测出现空间偏移，误差会沿动作块传播（虽有闭环多次查询缓解，但缺少对关键动作误差传播的定量分析）。
- **相机中心动作空间的前提假设**：方法依赖标定良好的第三人称相机外参。在相机移动、标定漂移或存在遮挡/视角剧变时，绝对相机坐标系的稳定性可能下降；论文未系统评估标定误差或相机扰动的鲁棒性。
- **单臂→双臂接口的"复制"策略**：V2 复制填充虽然实验最优，但本质上是人为构造对称冗余，可能限制真正异构双臂（非对称工具、不同自由度）的扩展；缺乏对双臂协同任务中左右臂时序依赖的显式建模（仅靠"左右独立关键帧"隐含表达）。
- **腕部视图处理较简化**：用二值掩码 + 零填充处理缺失腕部视角，未探索更细粒度的缺失模式（如部分帧丢失、多腕部相机），也未分析腕部视图对性能的独立贡献。
- **统计严谨性**：真机每种方法仅训练/评估一个统一策略，未报告多随机种子或置信区间；OOD Scene/Object 仅对比部分方法，CogACT/MolmoAct2 的 trial 数偏少，削弱了跨方法比较的统计说服力。
- **算力与复现门槛**：预训练 + 多次下游微调总计需数十 GPU·天（8×H100 级别），完整复现成本较高；附录虽给出流程，但关键超参（如关键帧窗口、扩散步数、动作块 H 的选取依据）的敏感性分析不足。
- **消融的交互效应**：消融为顺序剥离，难以区分各组件间的耦合贡献（例如去掉相机中心动作空间后，关键动作模型的作用是否被掩盖），缺少正交/组合式的消融设计。

## 9. 总体评价与启示

- **定位**：H-VLA 属于"分层 + 统一表示"路线的代表工作，核心贡献不在于提出全新网络，而在于**用相机中心动作空间把异构数据、跨本体状态与语义推理对齐**，并以关键动作作为语义与运动之间的"锚点"。
- **最大亮点**：证明"让 VLM 只负责推理'做什么'、由独立运动模块负责'怎么做'"可以同时保留语义泛化能力与稠密控制精度，且**无需海量机器人数据**即可在空间 OOD 上大幅领先。
- **最强证据**：OOD Position 上 83% vs 31% 的差距，以及消融中相机中心动作空间带来的最大降幅（VM 85→68、VA 81→59），共同支撑"统一坐标系是空间泛化的关键"这一论点。
- **对领域的启示**：
  - 动作表示的统一（坐标系对齐）可能比模型规模或数据量更能决定跨场景泛化；
  - 关键动作/子目标监督可自动化构建，是连接语言语义与底层控制的高性价比接口；
  - 分层解耦为"理解型 VLM + 专用运动头"的混合架构提供了可复用范式。
- **适用边界**：在需要精确空间泛化、跨本体迁移、抓取—放置类操作时优势明显；在接触丰富、力控密集或相机标定不可靠的场景需谨慎。
- **未来可延伸方向**：引入与夹爪无关的通用关键事件检测（如接触、速度拐点）、显式建模双臂协同时序、对关键动作误差与标定噪声做鲁棒性分析、以及在更多长时程任务与随机种子下验证稳定性。

## 10. 一句话结论

H-VLA 通过**统一相机中心动作空间 + 关键动作/运动规划分层**，在保持 VLM 语义推理能力的同时实现了强空间泛化，以约 183K 轨迹在仿真与真机上取得领先，其核心价值在于验证了"表示对齐"是具身泛化的关键杠杆，但在关键事件覆盖、统计严谨性与标定鲁棒性上仍有提升空间。
