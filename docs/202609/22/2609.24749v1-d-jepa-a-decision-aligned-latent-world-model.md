## 摘要
潜在世界模型能够预测动作的后果，但准确的预测并不能保证潜在距离能反映哪个候选未来会被成功执行。我们识别出一种决策局部预测差距：在少数竞争执行的未来中，一个被预测为更接近目标的候选，其实际执行结果可能比可用的替代方案更差。我们提出 D-JEPA，一种决策对齐的潜在世界模型，它从已执行结果中学习候选未来之间与决策相关的关系。一个有界的、置换等变算子联合推理目标相对预测特征与序数证据，在动作选择最为关键之处精炼预训练的预测几何。受限的预测器适配与共享的序数接口将这种对齐扩展到互补的预测几何上。D-JEPA 进一步将学习到的决策结构实现在 JEPA 兼容的未来表示中，从而能够通过原生潜在距离规划进行部署。在潜在控制、操作、预训练动作生成模型、实体机器人和自动驾驶等任务上的评估表明，动作选择得到改进，包括在 PushT 上取得 87.89% 的成功率、在 RoboTwin 上平均提升 15.04 个百分点，以及在实体机器人任务上提升 17 个百分点。这些结果确立了决策相关的关系结构，作为预测世界建模与有效控制之间的直接桥梁。

## Abstract
Latent world models predict the consequences of actions, but accurate prediction does not guarantee that latent distance reflects which candidate will execute successfully. We identify a decision-local prediction gap: among the few futures competing for execution, a candidate predicted closer to the goal can produce a worse realized outcome than an available alternative. We introduce D-JEPA, a decision-aligned latent world model that learns decision-relevant relations among candidate futures from executed outcomes. A bounded, permutation-equivariant operator jointly reasons over goal-relative predictive features and ordinal evidence, refining pretrained predictive geometry where action choices are most consequential. Restricted predictor adaptation and a shared ordinal interface extend this alignment across complementary predictive geometries. D-JEPA further realizes the learned decision structure in JEPA-compatible future representations, enabling deployment through native latent-distance planning. Evaluations across latent control, manipulation, pretrained action-producing models, physical robots and autonomous driving demonstrate improved action selection, including 87.89% success on PushT, a 15.04-point average gain on RoboTwin, and a 17-point gain on physical robot tasks. These results establish decision-relevant relational structure as a direct bridge between predictive world modeling and effective control.

  - 96 个审计起始中，每个模型都有 8 个起始偏好失败候选，尽管存在成功替代方案。
- **整体含义**：预测几何在全局上仍具信息量，但在动作选择边界附近不可靠。论文将这一现象转化为监督学习问题：用已执行候选结果监督候选未来之间的相对关系，使潜在几何与真实决策后果对齐，从而连接预测式世界模型与有效控制。

## 2. 方法论

### 2.1 核心思想

- **决策对齐而非单纯预测优化**：D-JEPA 不重新训练完整世界模型，而是在预训练预测几何之上学习候选未来之间的决策相关关系。
- **候选集建模**：给定上下文 \(x\)、目标 \(g\) 和候选动作集合 \(\{a_i\}_{i=1}^K\)，模型对完整候选集进行置换等变推理，输出有界分数校正，使成功候选获得更高选择概率。
- **多几何互补**：不同预测模型（LeWM、TD-JEPA、JEPA-WM、DINO-WM）的密集描述子保留各自几何，序数排名提供尺度无关的共同接口。
- **表示写回**：学习到的决策结构不仅用于打分，还被写入 JEPA 兼容的未来表示，使原生潜在距离规划即可恢复对齐后的动作选择。

### 2.2 关键组件与流程

- **候选描述子与序数证据**
  - 目标相对描述子：\(d_i^m = \mathrm{LN}(\hat z_{i,H}^m - z_g^m)\)。
  - 序数坐标：\(r_i^m = (\mathrm{rank}_{\mathcal A}(c_i^m)-1)/(K-1)\)，由预训练原生成本确定。
  - 双模型 token：\(v_i = [d_i^L; d_i^T; r_i^L; r_i^T]\)。
  - 基础分数：\(b_i = \alpha r_i^L + (1-\alpha)r_i^T\)。
- **有界置换等变关系算子**
  - 共享编码器 + 两层、四头 Transformer，无候选位置编码，因此置换输入会置换输出。
  - 零初始化低秩校正头：\(\delta_i = \epsilon \tanh(W_{\text{up}}\tanh(W_{\text{down}}h_i))\)，\(\epsilon=0.2\)。
  - 最终分数：\(s_i = b_i + \delta_i\)。
- **训练目标**
  - 全局成功质量：\(L_{\text{success}} = -\log \sum_{i:y_i=1} p_i\)，其中 \(p_i = \exp(-s_i/T)/\sum_j \exp(-s_j/T)\)。
  - 局部边界排序：在低分候选子集内对成功/失败对施加 softplus 间隔。
  - 校正正则：\(\lambda_{\text{trust}}\sum_i \delta_i^2\)，抑制不必要的全局重排。
  - 总损失：\(L_R = L_{\text{success}} + \lambda_{\text{local}}L_{\text{local}} + \lambda_{\text{trust}}\sum_i \delta_i^2\)。
- **预测可塑性**
  - 仅适配 TD-JEPA 最后一个预测器块和预测投影。
  - 目标：\(L_P = L_{\text{success}} + \lambda_B L_{\text{boundary}} + \lambda_K L_{\text{rank}} + \lambda_Z L_{\text{latent}}\)，兼顾边界排序、秩保持和潜在一致性。
- **校准组合**
  - 关系对齐作为默认选择；当适配预测器的原生距离赢家具有足够可靠优势时，才接受可塑性提案。
- **多几何序数接口**
  - 四几何 PushT token 为 \([d_i^L; d_i^T; r_i^L; r_i^T; r_i^J; r_i^D]\in\mathbb R^{388}\)。
  - 密集方向留在各自预测空间，序数坐标跨几何比较。
- **表示提升**
  - 时间传输：\(\tilde z_{i,t}^T = \hat z_{i,t}^T + \beta_{i,t}\frac{\hat z_{i,t}^L-\hat z_{i,t}^T}{\max(\|\hat z_{i,t}^L-\hat z_{i,t}^T\|_2,\eta)}\)，系数有界。
  - 精确序数实现：\(\tilde z_{i,H}^T = z_g^T + \frac{\pi_i}{K+1}u_i\)，其中 \(\pi_i\) 为最终严格排名，\(u_i\) 为单位 RMS 方向。
  - 原生均方距离为 \((\pi_i/(K+1))^2\)，因此最小原生距离可恢复对齐动作。

### 2.3 理论性质

- 全局预测误差小、秩相关高，仍可能与固定执行后悔共存。
- 若成本误差有界为 \(\eta\)，执行后悔不超过 \(2\eta\)。
- 有界校正 \(\epsilon\) 只可能提升基础分数最低附近 \(2\epsilon\) 内的候选，基础分数差距大于 \(2\epsilon\) 的偏好保持不变。
- 序数证据对任意严格单调成本变换不变。
- 精确序数实现可在原生潜在距离下严格复现学习到的排名和选择。
