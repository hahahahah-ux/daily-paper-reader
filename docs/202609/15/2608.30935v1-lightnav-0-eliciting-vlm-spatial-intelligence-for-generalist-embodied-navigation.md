## 摘要
具身导航要求智能体将异构目标与视觉观测转化为动作，并跨任务、环境和机器人本体实现。现代视觉语言模型（VLM）已经编码了用于视觉定位、空间推理和指向的空间先验，但这些能力很少被直接激发用于机器人控制。现有导航系统转而依赖任务特定或本体特定的组件，割裂了感知、推理与动作，同时泛化能力有限。这里我们提出LightNav-0，一种紧凑的通用具身导航模型，它激发预训练VLM的空间智能并将其与导航对齐，且无需任务特定的预测头。LightNav-0通过统一的token接口表示多样化的导航任务：双通道指向表达任务、场景和本体无关的空间意图，而残差向量量化动作分词器将该意图映射为精确的、本体特定的轨迹。结合时间感知的视觉历史压缩、ER中期训练、监督微调和强化学习，该框架在单一模型中支持指令跟随、开放词汇目标导航和视觉跟踪。导航训练语料库涵盖2K+个场景和4K+小时的具身导航数据。LightNav-ER是用于初始化LightNav-0的具身推理检查点，在8个具身推理基准上取得最高完整集平均成绩，而LightNav-0在所有10个公开导航仿真设置中实现了最先进的单目成功率。真实世界评估进一步展示了跨机器人本体、多样场景以及静态和动态目标的零样本泛化能力。这些结果确立了紧凑型VLM作为通用具身导航的统一且可迁移的骨干网络。

## Abstract
Embodied navigation requires agents to translate heterogeneous goals and visual observations into actions across tasks, environments, and robot embodiments. Modern vision-language models (VLMs) already encode spatial priors for visual grounding, spatial reasoning, and pointing, but these capabilities are rarely elicited directly for robot control. Existing navigation systems instead rely on task- or embodiment-specific components, fragmenting perception, reasoning, and action while offering limited generalization. Here we present LightNav-0, a compact generalist embodied navigation model that elicits the spatial intelligence of a pretrained VLM and aligns it with navigation, without task-specific prediction heads. LightNav-0 represents diverse navigation tasks through a unified token interface: dual-channel pointing expresses task-, scene-, and embodiment-agnostic spatial intent, while a residual vector-quantized action tokenizer maps this intent to precise, embodiment-specific trajectories. Together with temporally aware visual history compression, ER mid-training, supervised fine-tuning, and reinforcement learning, this formulation supports instruction following, open-vocabulary object navigation, and visual tracking within a single model. The navigation training corpus spans 2K+ scenes and 4K+ hours of embodied navigation data. LightNav-ER, the embodied-reasoning checkpoint used to initialize LightNav-0, attains the highest complete-set average across 8 embodied-reasoning benchmarks, while LightNav-0 achieves state-of-the-art monocular success rates across all 10 public navigation simulation settings. Real-world evaluations further demonstrate zero-shot generalization across robot embodiments, diverse scenes, and static and dynamic targets. These results establish compact VLMs as a unified and transferable backbone for generalist embodied navigation.

- **现有痛点**：

## 二、方法论

### 2.1 核心思想

- 以 **Qwen3-VL-4B-Instruct** 为唯一骨干，保留原架构，仅扩展词表（`⟨aposi⟩`、`⟨oposi⟩`、RVQ 动作 token），所有中间空间预测与动作码均由**原始自回归 LM 头**解码。
- 用**双通道指向（dual-channel pointing）**作为任务/场景/本体无关的空间意图接口，充当"隐式空间思维链"，再由此条件化生成精确的本体特定轨迹。
- 单次决策输出固定为 5 个 token：
  `y_t = [⟨aposi_{i_a}⟩, ⟨oposi_{i_o}⟩, ⟨act_L0_{k0}⟩, ⟨act_L1_{k1}⟩, ⟨act_L2_{k2}⟩]`

### 2.2 关键技术

- **双通道指向（图像网格 token）**
  - 将当前视图划分为 `H_g × W_g` 网格，投影点 `p=(u,v)` 映射为扁平索引 `i(p)=r(p)·W_g+c(p)`，其中 `r(p)=min(H_g-1,⌊H_g v⌋)`、`c(p)=min(W_g-1,⌊W_g u⌋)`。
  - **affordance 点** `⟨aposi⟩`：表示可行局部方向或自由空间落点；**object 点** `⟨oposi⟩`：定位目标物体或目标位置。
  - 每通道使用**独立的 token 家族**，保留索引保留位表示原地转向、停止、目标不可见；不生成坐标 token 或通道标记 token。
  - 自动标注流水线（Fig.3）将 3D 目标/自由空间投影到当前视图生成监督标签。

- **时序感知视觉历史压缩**
  - 借鉴艾宾浩斯遗忘曲线：按"年龄" `ΔT_i = t - t_i` 衰减采样率 `f_s(i) = f_s^max·exp(-ΔT_i/τ_s)`，并按 `s_i = max(1, ⌊exp(ΔT_i/τ_p)⌋)` 做网格池化。
  - 近期帧采样更密、分辨率更细；远期帧更稀疏、池化更狠；时间戳 token 保留时序；支持 256K / 576K / 1M 像素预算，在固定视觉 token 预算内分配长/中/短时历史。

- **残差向量量化（RVQ）动作分词器**
  - 动作块 = 10 个未来 SE(2) 路点（`z_t ∈ R^{10×3}`）。
  - 3 级码本，每级 K=256：`k_ℓ = argmin_k d_J(r^(ℓ), e^(ℓ)_k)`，`r^(ℓ+1) = r^(ℓ) - e^(ℓ)_{k_ℓ}`，`r^(0)=z_t`；残差 k-means 使用雅可比加权轨迹距离。
  - 轨迹级分配距离 `d_traj(z, ẑ) = ADE(z,ẑ) + λ|Δθ(z) − Δθ(ẑ)|`，λ=0.3。
  - 解码：任取非空前缀 `ẑ^(L)_t = Σ_{ℓ<L} e^(ℓ)_{k_ℓ}`（L∈{1,2,3}）并在 SE(2) 上积分即得可执行轨迹；3 个 token 可表示 256³ 组合，平均位移误差 **0.72 cm**（对比单级 K=4096 的 VADv2 式方案 2.48 cm）。
  - 支持精度—时延权衡：资源紧张时可只生成 1~2 个 RVQ token 执行粗轨迹。

- **统一自回归目标**：导航、指向与空间 VQA 共用同一因果 LM 损失 `L_CE = −Σ_{j∈M} log p_θ(y_j | x, y_{<j})`，无需单独平衡导航损失，可共享打包训练循环。

- **效率设计**：动态序列打包（约 8.6 个样本/8192 token 序列）、融合视觉 RoPE、LM 头维度对齐 8 的倍数；推理时视觉编码器与 LM 单进程运行 + vLLM，**RTX 4090 上约 4 ms/token**。

### 2.3 三阶段训练

- **Stage I：具身推理（ER）中期训练** —— 13.0M 样本，任务均衡混合（空间推理、通用 VQA、图像指向、视频 QA、多图推理、情景 3D QA、可供性/失败理解、场景描述），不引入导航专用头；产出 **LightNav-ER**。
- **Stage II：监督微调（SFT）+ DAgger** —— 5.2M 样本，16 个导航源 + 33 个辅助 ER/VQA 源；优化混合中 **77.6% 为导航动作监督、22.4% 为 ER 复习**（specialize-then-retain 课程）；DAgger 缓解训练—部署状态分布偏移。
- **Stage III：在线 RL 后训练（GRPO）**
  - 组内标准化优势 `A^(g) = (R(τ^(g)) − μ_R)/(σ_R + ε_num)`，无需 critic；终端标量奖励赋给轨迹内每步 `r_t = R(τ)`；token 级代理目标 + 对参考策略的 KL 锚定（β=0.01，ε=0.2）。
  - 三类任务专用奖励：
    - **视觉跟踪**：逐步质量 `q_t = v_t·c(α_t)·b(δ_t)`（平坦顶部方位角项 + 双侧距离带项）+ 与特权 oracle 计划的匹配度 `m_t`，扣碰撞项，用 `T_norm`（早终止按 300 步计）把"平均质量"变为"持久性"。
    - **指令跟随**：`R_VLN = (1+nDTW)·1[success] + exp(−max(d_T,d_clip)²/σ_d²) − 0.25·1[timeout]`，3 m 成功半径，奖励到达且路径对齐。
    - **物体目标导航**：`R_OBJ = (1+0.25·PL)·1[success] + 0.25·exp(...)`，PL 为路径长度效率，1 m 成功半径。
  - **Rollout 基础设施**：仿真与优化解耦，每仿真进程常驻一个场景，scene hash 将同种子 rollout 路由到对应场景；用监督策略对候选任务跑 K 次分为 always-solved / mixed / never-solved，以 mixed 为主、少量保留两端；按事件分层保留样本（首末决策、停止/卡住/碰撞/大角度转向及其邻居）。G=8，B=32 种子（每轮 256 episodes），单节点 8×H100。

## 三、实验设计

### 3.1 数据与场景

- 导航语料：**2K+ 场景、4K+ 小时**具身轨迹；SFT 混合共 23.2M 样本，任务占比：指令跟随 43.4%、VQA 22.4%、ObjectNav 22.0%、Tracking 12.2%。
- 导航数据来源：R2R/RxR + 自蒸馏 + ScaleVLN、SRDF、VLN-CE、INSIGHT-Bench；PIRL-Nav、HM3D、MP3D、VLNVerse、Habitat-GS、InteriorGS、HM3D-OVON；EVT-Bench（人体跟随）。
- 相机随机化：FOV [90°,130°]、高度 [0.5,1.5] m、俯仰 [−15°,15°]。
- 质量控制：停止监督仅在末帧且目标可见时保留、停止样本 ≤2%、轨迹簇最大占比 5%。
