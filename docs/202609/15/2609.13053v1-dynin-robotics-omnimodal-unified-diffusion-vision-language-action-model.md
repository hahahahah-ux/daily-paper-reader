## 摘要
视觉目标与动力学预测能够为语言条件化的机器人策略同时提供目标结果以及动作依赖的场景变化表征。我们通过一个共享轨迹模型将这些预测引入动作生成与选择。Dynin-Robotics 在 Dynin-Omni 上实现了这一形式化，Dynin-Omni 是一个全模态掩码扩散骨干，将语言、视觉观测、目标和动作表示为离散 token。通过改变条件与目标跨度，同一模型可以学习动作预测、动作条件下的下一观测预测、终止目标状态预测以及轨迹到指令的重建。这些接口通过目标预测、动作候选评估以及动作与未来状态预测的联合精炼来支持测试时扩展。我们在来自 48 个 Open X-Embodiment 数据集的约 133 万条轨迹上持续预训练该模型，并将其分别适配到下游领域。在两个 VLABench 任务上，机器人预训练在固定的 Stage-2 步数预算内改进了适配，并且完整目标混合在相同的耦合解码器下相比仅策略后训练提高了偏移指令的成功率。将目标引导与联合动作-下一状态去噪相结合，相比仅动作解码进一步提高了偏移指令成功率；收益取决于预测如何组合。Dynin-Robotics 在 LIBERO 和零样本 LIBERO-Plus 上取得了有竞争力的性能，并在 Franka Research 3 机器人上在四种操作条件下达到 78.4% 的平均成功率。一个优化的块并行实现，在所述性能分析设置下，将模型侧动作解码相对于基础实现加速高达 29.2 倍。这些结果支持共享轨迹建模作为学习互补机器人目标并在控制过程中组合其预测的通用接口。

## Abstract
Visual goal and dynamics prediction can provide language-conditioned robot policies with both a target outcome and a representation of action-dependent scene changes. We bring these predictions into action generation and selection through a shared trajectory model. Dynin-Robotics implements this formulation on Dynin-Omni, an omnimodal masked-diffusion backbone, representing language, visual observations, goals, and actions as discrete tokens. By varying conditioning and target spans, the same model learns action prediction, action-conditioned next-observation prediction, terminal goal-state prediction, and trajectory-to-instruction reconstruction. These interfaces support test-time scaling through goal prediction, action-candidate evaluation, and joint refinement of action and future-state predictions. We continually pretrain the model on approximately 1.33 million trajectories from 48 Open X-Embodiment datasets and adapt it separately to downstream domains. On two VLABench tasks, robot pretraining improves adaptation within a fixed Stage-2 step budget, and the full objective mixture improves shifted-instruction success over Policy-only post-training under the same coupled decoder. Combining goal guidance with joint action-next-state denoising further improves shifted-instruction success over action-only decoding; the benefit depends on how the predictions are composed. Dynin-Robotics achieves competitive performance on LIBERO and zero-shot LIBERO-Plus, together with a 78.4% average success rate across four manipulation conditions on a Franka Research 3 robot. An optimized block-parallel implementation accelerates model-side action decoding by up to 29.2x relative to the base implementation under the reported profiling setup. These results support shared trajectory modeling as a common interface for learning complementary robot objectives and composing their predictions during control.

## 1. 核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型将自然语言指令和视觉观测映射为机器人动作，但语言条件化操作涉及目标识别、物体交互和连续控制等多个环节。视觉目标预测与动力学预测分别能提供"预期结果"和"动作依赖的场景变化"两类关键表征，如何将二者有效融入动作生成与选择，是当前 VLA 研究的核心问题。
- **诊断性发现**：作者在 VLABench 上用 SelectFruit 和 InsertFlower 两个任务对比 π0.5 与 Mimic-Video，发现二者呈现不同的任务性能轮廓和语言敏感性——π0.5 对指令替换更敏感（成功率下降 16–30 个百分点），Mimic-Video 反而保持甚至提升。这促使作者将语言条件化与视觉预测放在同一策略模型中研究。
- **整体含义**：论文提出将指令、观测、目标、动作统一表示为可作上下文或预测目标的变量，在共享轨迹模型下学习互补预测任务，并在推理时组合这些预测。这为统一多目标机器人学习与推理计算分配提供了通用接口。

## 2. 方法论

### 核心思想
- 基于 **Dynin-Omni**（全模态掩码扩散骨干），将语言、视觉观测、目标状态和机器人动作表示为离散 token，放入共享的轨迹序列中。
- 通过**目标条件化掩码**（objective-conditioned masking）指定哪些跨度可见（上下文）、哪些被重建（目标），同一 Transformer 和预测头即可支持四种学习目标。

### 统一训练目标
- 设 $O = \{o_{PO}, o_{WM}, o_{TU}, o_{GP}\}$ 分别表示策略、世界建模、任务理解、目标状态预测。对目标 $o$，模型学习条件分布 $p_\theta(x^{(o)}_{I_o} | x^{(o)}_{C_o}, o)$。
- **策略（Policy）**：从当前视觉状态和指令预测动作块，可选用目标状态与传感器上下文。
- **世界建模（World Modeling）**：给定当前状态、指令和动作块，预测下一视觉状态。
- **目标状态预测（Goal-State Prediction）**：从初始观测和指令预测终止视觉状态。
- **任务理解（Task Understanding）**：从轨迹帧重建任务指令。
- 损失函数为目标跨度上的掩码扩散损失，采用逆掩码概率加权，并对完整目标长度归一化；Stage-1 策略目标额外加入期望分箱 MAE 辅助损失（系数 β=0.2）。
- 微步损失为各目标损失的加权混合，训练调度由目标多重集 $A_n$ 和权重 $\lambda_o$ 共同决定。

### 动作与传感器 token 化
- 动作块按维度做固定均匀分箱，使用训练数据的分位数做鲁棒归一化，映射到保留的动作 token 块；Stage-1 使用 $B_A = 256$ 个 bin，Stage-2 按任务选择（VLABench 选 32）。
- 可选传感器接口对力/力矩等连续流做类似量化，映射到保留的传感器 token 块，但报告实验中未启用。

### 多阶段推理组合
- 提供六种推理组合：(a) 仅动作策略；(b) 动作/世界模型联合去噪；(c) 目标引导策略（默认路径）；(d) 世界模型候选重排；(e) 目标引导 + 联合去噪；(f) 目标引导 + 候选重排。
- 世界模型重排使用能量函数 $E_{WM}(c)$ 加策略先验惩罚，并设置双重接受条件（能量改善超过阈值 δ 且综合排序分数更优）。

### 加速实现
- 采用块并行掩码解码，在每个去噪步并行预测所有掩码动作位置，按置信度逐步提交 token。
- 结合 dInfer 推理栈（模态感知去噪、CUDA Graph 重放、循环展开、上下文复用），实现模型侧动作解码加速。

### 训练配方
- **Stage-1**：在 48 个 OXE 数据集、约 133 万条轨迹（6521 万 transition）上持续预训练，保留 Dynin-Omni 文本/视觉 tokenizer 冻结；分两段共 27.6k 优化器更新（220.8k 累积微步）。
- **Stage-2**：按下游领域分别微调，可使用仅策略监督或统一四目标混合；可选轨迹元数据条件（动作平滑度代理、轨迹长度、成功标志）。
- **在线 RL 微调**（可选）：冻结骨干和 tokenizer，仅训练轻量重掩码控制器（count head + position head），用 PPO 优化效率感知目标。

## 6. 主要结论与发现

- **机器人持续预训练收益显著**：在固定 70k Stage-2 步数下，从 OXE 预训练 checkpoint 初始化达到 49.61% ID / 47.28% OOD，而无预训练仅 3.26% / 0.70%。
- **完整目标混合提升偏移指令成功率**：相比仅策略后训练，完整四目标混合将 OOD 成功率从 33.88% 提升到 47.28%（+13.40 个百分点），ID 从 47.15% 提升到 49.61%，ID−OOD 差距从 13.27 缩小到 2.33 个百分点。
- **推理组合方式决定收益**：目标引导单独加入策略解码会降低 OOD（38.2% vs 41.4%），但与联合动作-下一状态去噪结合后提升到 47.3%；目标引导 + 世界模型过滤达到最高 OOD 47.7%，但吞吐下降约 44.6%。
- **策略性能**：LIBERO 平均 98.1%（与 X-VLA 持平，低于 ABot-M0 的 98.6%）；零样本 LIBERO-Plus 平均 73.0%（低于 ABot-M0 的 81.6%）；真实 Franka 平均 78.4%，在 Color-Ordered Stack 上最高（68.5%）。
- **视觉预测**：世界建模 PSNR 最高（20.79），但整体仍低于"复制最后一帧"基线（31.07 PSNR）；目标状态预测排名第二，BAGEL 在三项指标上领先。
- **加速效果**：BL7 达到 9.89× 加速，BL35 达到 29.15×；LIBERO-Goal 上 BL7 成功率 97.7%（base 97.8%），BL35 为 97.2%，查询延迟从 3795.7 ms 降至 130.2 ms。
- **动作分箱**：32 bin 最优（MAE 0.02，ID 49.61%），16 和 64 bin 均变差，非单调关系。
- **辅助损失权重**：α=1 最优，α=2 显著降低性能（ID 38.05%）。

## 7. 优点

- **统一形式化优雅**：将策略、世界模型、目标预测、任务理解统一为同一掩码扩散骨干上的条件去噪查询，通过改变可见上下文和目标跨度实现多任务，无需为每个任务设计独立头或专家。
- **推理组合灵活**：六种推理组合支持测试时扩展，可显式权衡成功率与计算成本，且组合方式对性能影响被系统研究。
- **训练配方控制严格**：消融实验在固定 Stage-2 步数预算和固定解码器下进行，能较好分离预训练、目标混合和推理策略的贡献。
- **加速实现实用**：块并行解码 + dInfer 在保持接近无损精度的前提下实现最高 29.2× 加速，对实际部署有意义。
- **评测覆盖广**：仿真（LIBERO、LIBERO-Plus、VLABench）+ 真实机器人 + 多模态输出（DROID），并包含指令随机化敏感性分析这一较独特的诊断维度。
- **诚实的负面结果报告**：明确指出帧复制基线在整图指标上优于世界建模、目标引导单独使用反而降低 OOD、Camera/Robot 扰动仍是短板等。

## 8. 不足与局限

- **算力信息不透明**：未披露 GPU 总数量、型号（除 B200 profiling）、总训练时长和总 GPU 小时，难以评估训练成本与可复现性。
- **视觉预测质量有限**：世界建模在 PSNR/SSIM/LPIPS 上均低于简单的"复制最后一帧"基线，说明动作依赖变化的建模能力仍有明显差距；论文也承认整图指标聚合了静态内容，不能充分反映动作相关变化。
- **任务理解仅定性评估**：轨迹到指令的重建只展示了定性示例，未与参考指令做定量对比（如 BLEU、ROUGE 或语义相似度）。
- **在线 RL 贡献未隔离**：重掩码控制器的效果未与其他后训练和解码选择分离，无法判断其独立收益。
- **物理实验覆盖窄**：仅一个 Franka Research 3 平台、一个工作空间、四种条件，泛化性结论有限。
- **LIBERO-Plus 迁移不均衡**：Camera（59.8%）和 Robot（48.2%）扰动下性能明显偏低，与 ABot-M0 的差距分别达 19.7 和 12.7 个百分点，说明对视觉和本体扰动的鲁棒性不足。
- **跨模型对比公平性存疑**：表格混合引用与复现结果，不同方法的训练数据、配方和推理预算不一致，作者虽声明"描述性"，但读者容易过度解读排名。
- **传感器接口未验证**：论文描述了传感器 token 接口和 RL 控制器设计，但报告实验中均未启用，其实际效果未知。
- **Stage-2 超参数敏感**：动作分箱和辅助损失权重均存在明显敏感性（32 bin 最优、α=1 最优），不同任务可能需要重新调参，增加了部署成本。
- **目标状态预测评价局限**：参考图像一致性只反映一个方面，不同但同样成功的终止配置可能被判为不匹配，缺乏任务条件满足度的直接评估。
