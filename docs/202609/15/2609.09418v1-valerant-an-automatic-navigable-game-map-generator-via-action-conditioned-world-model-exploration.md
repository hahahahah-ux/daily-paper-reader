## 摘要
世界动作模型（WAMs）将预测性世界建模与动作生成相结合，使预期的未来状态能够引导智能体行为。尽管 WAMs 在具身智能领域发展迅速，但其通用版本在游戏中仍基本未被探索。现有面向游戏的方法通常将动作条件世界模型与外部策略和奖励函数结合，以实现类 WAM 决策，但它们主要在 2D 视觉观测空间中运行，且不实例化持久的三维几何。将该范式扩展到 3D 游戏会带来一个独特挑战。在自动驾驶和机器人领域，物理环境独立于模型存在，提供了一个持久的三维世界，所选动作可在其中执行。游戏没有这样的外部基底；虚拟世界本身必须被实例化。大多数可玩游戏需要持久且可导航的空间，而 3D 游戏还额外需要支持移动和交互的显式几何。动作条件视频推演提供视觉观测，但不提供这种空间表示。我们提出 Valerant，一个免训练框架，将预训练的动作条件世界模型转化为 WAM，用于探索和构建 3D 游戏地图。通过将预测性视觉推演与基于 SLAM 的空间重建和探索驱动的动作选择相结合，Valerant 逐步将单张图像转化为持久的三维游戏地图。该框架将基于 WAM 的交互扩展到 2D 视觉仿真之外，并为减少 3D 游戏地图创建中的人工投入提供了一种新途径。

## Abstract
World Action Models (WAMs) couple predictive world modeling with action generation, allowing anticipated future states to guide agent behavior. Although WAMs are rapidly advancing embodied AI, general-purpose counterparts remain largely unexplored in games. Existing game-oriented approaches often combine action-conditioned world models with external policies and reward functions to realize WAM-like decision-making, yet they operate mainly in 2D visual observation space and do not instantiate persistent 3D geometry. Extending this paradigm to 3D games introduces a distinct challenge. In autonomous driving and robotics, the physical environment exists independently of the model, providing a persistent 3D world in which selected actions can be executed. Games have no such external substrate; the virtual world itself must be instantiated. Most playable games require a persistent and navigable space, while 3D games additionally require explicit geometry that supports movement and interaction. Action-conditioned video rollouts provide visual observations but not this spatial representation. We present \textsc{Valerant}, a training-free framework that transforms a pretrained action-conditioned world model into a WAM for exploring and constructing 3D game maps. By coupling predictive visual rollouts with SLAM-based spatial reconstruction and exploration-driven action selection, \textsc{Valerant} progressively transforms a single image into a persistent 3D game map. This framework extends WAM-based interaction beyond 2D visual simulation and offers a new approach to reducing manual effort in 3D game-map creation.

## 2. 方法论

### 核心思想
- 冻结预训练动作条件视频世界模型，不进行额外训练；通过**反事实探索（counterfactual exploration）**生成多个候选动作的 what-if 视频推演，再用**视觉 SLAM** 重建 3D 几何，并由**探索策略**评分选择最优动作，逐步累积成持久点云地图。

### 关键技术细节与流程
- **状态定义**：视觉上下文 \(O^c_t\)、当前相机位姿 \(T_t\)、全局地图 \(M_t\)。
- **候选动作空间**（5 个）：直行前进 \(u_w\)、左转后前进 \(j_w\)、右转后前进 \(l_w\)、原地左转 \(j_q\)、原地右转 \(l_q\)。
- **分支–重建–评估–提交循环**：
  1. 检查点当前 WM 与 SLAM 状态；
  2. 对同一行动前上下文 \(O^c_t\)，WM 为每个候选动作生成独立未来 rollout \(O^f_{t,m}\)；
  3. 每个 rollout 经视觉 SLAM 估计相机轨迹 \(\hat{T}_{t,m}\) 与候选几何 \(\hat{M}_{t,m}\)；
  4. 用映射效用评分：\(m^\star = \arg\max (\lambda_{cov} C_{t,m} + \lambda_{prog} P_{t,m})\)，其中 \(C\) 为探索覆盖度、\(P\) 为前向进展，碰撞违反者 \(B_{t,m}=1\) 被排除；
  5. 恢复行动前状态，仅执行最优动作，其余分支丢弃；
  6. 更新上下文与地图：\(O^c_{t+1} = \text{Update}(O^c_t, O^f_{t,m^\star})\)，\(M_{t+1} = \text{Fuse}(M_t, \hat{M}_{t,m^\star})\)；
  7. 重复直至探索预算耗尽，输出整合后的 3D 点云游戏地图。

### 鲁棒探索机制（应对几何漂移与视觉幻觉）
- **鲁棒地面估计（RF）**：不再使用一次性全局地面参考，而是在每个 SLAM 关键帧局部拟合主导平面，仅在几何支撑充分且法向与当前垂直方向一致时接受；无法可靠观测地面时沿用最近可靠的地面–相机关系。定义归一化地面相对高度 \(\bar{h}_i(p)\)，使局部地面为 0、相机中心为 1，从而抵消尺度/平移漂移对碰撞判定的影响。
- **互补碰撞检测**：
  - *点云碰撞*：将候选地图点投影到沿轨迹采样的归一化圆柱体体积内，满足水平距离、身体高度带 \([η_{low}, η_{high}]\) 且超过占据阈值 \(N_{occ}\) 即判定碰撞；
  - *深度碰撞*：直接使用所有 rollout 帧的原始深度图，若图像中心区域平均深度小于近场阈值且轨迹仍持续前向推进，则判定穿透，用于补充纹理缺失/反光墙面导致点云不可靠的情况。
  - 两者任一触发即 \(B_{t,m}=1\)。
- **死口袋回退（DP）**：当持续无进展时，沿已执行轨迹维护 WM–SLAM 同步检查点，回退到较早检查点 \(r<t\)，恢复视觉上下文、相机位姿与地图，并把被丢弃路段的栅格加入失败区域记忆 \(F_{t^+}\)，禁止后续候选再次进入，从而把贪心探索变成可恢复决策的空间搜索。

- **实验规模**：
  - 主结果：1 组定量对比（Valerant vs. HY-World 2.0）+ 4 个场景的定性展示；
  - 消融：3 组，每组针对一个鲁棒模块、在单一场景中进行定性比较；
  - 未报告多数据集/多游戏验证，也未报告统计显著性检验。
- **充分性评价**：
  - **偏少**。定量评估仅两个主观感知指标，样本量与评估者数量未披露；UP 为 83.33%、16.67% 的数值暗示比较次数有限，统计稳健性存疑。
  - **客观性/公平性**：使用相同初始帧、同一基线，具备基本可比性；但缺少几何精度（如地图完整度、轨迹误差、碰撞率）等客观定量指标，评估依赖 VLM 与人类主观偏好，存在偏差风险。
  - 消融仅覆盖 3 个场景、每个模块一个场景，能说明互补失效模式，但覆盖不足，无法量化各模块的普遍贡献。

## 6. 主要结论与发现

- Valerant 能够仅从单张图像出发，**无需人工指定轨迹或中间干预**，自动完成碰撞规避探索并增量构建持久 3D 点云游戏地图。
- 定量上：Valerant 在 AS 上为 80.00%（对比 HY-World 2.0 的 20.00%），在 UP 上为 83.33%（对比 16.67%），显著优于基线。
- 消融表明三个鲁棒模块解决互补失效模式：RF 解决地面参考漂移导致的错误碰撞与探索受限；COL 阻止轨迹穿透墙体；DP 使智能体摆脱局部死口袋并重新规划路线。
- 总体结论：将冻结的动作条件视频 WM 与视觉 SLAM、探索策略耦合，可把瞬态视觉推演转化为显式 3D 环境，扩展了 WAM 的应用边界。

## 7. 优点

- **免训练框架**：直接复用预训练动作条件世界模型，推理时耦合 SLAM 与策略，降低适配成本，易于替换不同 WM/SLAM 组件。
- **反事实分支设计**：从同一行动前状态并行生成多个 what-if 未来，显式重建每个候选的几何而非依赖额外学习预测器，使动作选择有空间依据。
- **分支–重建–评估–提交的闭环**：恢复到行动前状态再执行最优动作，保证持久世界状态不被未选分支污染。
- **鲁棒性设计针对性强**：归一化地面相对高度设计优雅地抵消单目 SLAM 尺度漂移；点云碰撞与深度碰撞互补覆盖不同失败场景；检查点回退加失败区域记忆把贪心探索升级为可恢复搜索。
- **问题定位清晰**：准确指出游戏与自动驾驶/机器人在“世界基底是否存在”上的本质差异，任务定义有价值。

## 8. 不足与局限

- **实验覆盖有限**：仅 VALORANT 单一游戏截图，未验证其他游戏类型或真实/合成混合场景；场景数量与评估样本量小。
- **评估主观且缺乏客观几何指标**：无 ground-truth 地图，AS 依赖 VLM 评判、UP 依赖人类偏好，未报告地图覆盖率、轨迹误差、碰撞率等定量指标，也未报告统计显著性。
- **基线单一**：仅与 HY-World 2.0 对比，未与更多 3D 生成/世界模型方法比较。
- **依赖上游组件质量**：性能受预训练视频 WM 的视觉幻觉与 MASt3R-SLAM 的单目尺度/位姿漂移影响；鲁棒模块是缓解而非根治。
- **输出形式受限**：最终产物为点云地图，而非可编辑的游戏资产（网格、材质、碰撞体、语义标注），距离实际游戏开发管线仍有差距。
- **动作空间简单**：仅 5 个离散候选动作，缺少跳跃、蹲伏、交互等复杂动作；探索预算、超参数敏感性未充分讨论。
- **算力与效率信息不完整**：虽说明使用单张 H100，但未给出推理耗时、探索步数、可扩展性分析；论文提及的附录超参数在给定文本中缺失。
- **潜在偏差风险**：输入图像全部来自单一 FPS 游戏，VLM 评估者与人类评估者可能对 VALORANT 风格画面存在先验偏好，结论外推需谨慎。
