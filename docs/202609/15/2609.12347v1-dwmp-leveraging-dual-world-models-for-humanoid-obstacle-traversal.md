## 摘要
人形机器人必须利用机载本体感觉和视觉观测穿越杂乱的障碍场，然而现有方法通常处理多模态观测时并未显式考虑其不同特性：本体感觉观测维度低，但受高度非线性的机器人动力学支配；而自我中心视觉观测则维度高、噪声大且冗余。我们提出 DWMP（Dual World Model Policy，双世界模型策略），该框架为人形机器人障碍穿越中的 actor 提供分离但互补的世界模型表征。一个基于 Koopman 的动力学世界模型将本体感觉观测提升到一个潜在空间，在该空间中其时间演化近似线性，从而使动力学特征更易于 actor 学习。一个基于 RSSM 的视觉世界模型将自我中心深度观测压缩为紧凑的随机状态，同时保留与障碍物相关的几何信息。学生策略接收融合后的潜在表征以生成动作，将线性化的本体感觉动力学与压缩后的视觉感知相结合。在仿真以及 Unitree G1 人形机器人上的实验表明，DWMP 相比基线方法提升了障碍穿越性能，并支持在随机障碍布局下的真实世界部署。

## Abstract
Humanoid robots must traverse cluttered obstacle fields using onboard proprioceptive and visual observations, yet existing methods usually process multimodal observations without explicitly considering their different characteristics: proprioceptive observations are low-dimensional but governed by highly nonlinear robot dynamics, while egocentric visual observations are high-dimensional, noisy, and redundant. We propose DWMP (Dual World Model Policy), a framework that provides the actor with separate but complementary world-model representations for humanoid obstacle traversal. A Koopman-based dynamics world model lifts proprioceptive observations into a latent space where their temporal evolution is approximately linear, making the dynamics features easier for the actor to learn from. An RSSM-based visual world model compresses egocentric depth observations into compact stochastic states while preserving obstacle-related geometry. The student policy receives the fused latent representation for action generation, combining linearized proprioceptive dynamics with compressed visual perception. Experiments in simulation and on a Unitree G1 humanoid robot show that DWMP improves obstacle traversal performance over baselines and supports real-world deployment under randomized obstacle layouts.

- **导致后果**：学生策略往往退化为"反应式动作模仿器"，而非学习到描述机器人状态与感知障碍布局如何演化的结构化特征。
- **整体含义**：论文提出 DWMP（Dual World Model Policy），为 actor 提供**分离但互补**的双世界模型表征——用 Koopman 线性化本体动力学，用 RSSM 压缩视觉感知，从而提升障碍穿越性能并支持真机部署。

## 2. 方法论

### 2.1 核心思想

- 将多模态观测按模态特性**分别建模**，而非简单拼接或只压缩视觉：
  - **Koopman 动力学世界模型**：把本体观测提升到近似线性演化的潜空间，使动力学特征更易被 actor 学习；
  - **RSSM 视觉世界模型（DepthDreamer）**：把深度图压缩为紧凑随机状态，保留障碍相关几何；
  - 二者融合后作为学生策略输入。

### 2.2 问题形式化

- 建模为 POMDP：$(O, A, T, R, \gamma)$。
- 观测：$o_t = \{o^{prop}_t, o^{vis}_t\}$，其中本体观测含关节位置/速度、机体坐标系重力向量、基座线/角速度、目标相对位置；视觉观测为头部相机深度图。
- 动作：$a_t = q^{target}_t$，即下肢关节目标位置，由 PD 控制器以更高频率跟踪：$\tau_t = K_p(q^{target}_t - q_t) - K_d \dot{q}_t$。

### 2.3 Koopman 动力学世界模型

- **理论基础**：Koopman 算子 $K$ 将非线性系统提升到无穷维可观测函数空间，使演化变为线性：$(Kg)(o^{prop}_t) = g(F(o^{prop}_t)) = g(o^{prop}_{t+1})$。
- **Auto-Koopman 网络**：编码器 $\phi: S \to \mathbb{R}^{d_k}$ + 线性转移矩阵 $K \in \mathbb{R}^{d_k \times d_k}$，满足 $\phi(o^{prop}_{t+1}) \approx K\phi(o^{prop}_t)$。
- **OFTL 层**：编码器首层为观测函数转移层，将每个输入维度映射为观测函数值，如 $[cos(x_i), sin(x_i), e^{x_i}]^T$。
- **训练目标**：重建损失 + 线性预测损失
  $$L_{koopman} = \mathbb{E}\left[\|o^{prop}_t - \psi(\phi(o^{prop}_t))\|^2 + \|\phi(o^{prop}_{t+1}) - K\phi(o^{prop}_t)\|^2\right]$$

### 2.4 RSSM 视觉世界模型（DepthDreamer）

- 维护确定性循环状态 $z^{vis}_t$（GRU 更新）与随机状态 $s_t$（对角高斯）：
  - 循环：$z^{vis}_t = f_{rec}(s_{t-1}, z^{vis}_{t-1}, a_{t-1})$
  - 先验：$p(s_t | z^{vis}_t)$；后验：$q(s_t | z^{vis}_t, o^{vis}_t)$
  - 解码器：$\hat{o}^{vis}_t = f_{dec}(z^{vis}_t, s_t)$；奖励预测：$\hat{r}_t = f_{rew}(z^{vis}_t, s_t)$
- VAE 编码器输出后验分布的均值与对数方差；训练时从后验采样，想象时从先验采样。
- 损失为变分下界：重建损失 + 奖励预测损失 + KL 正则（系数 $\beta$）。

### 2.5 策略输入与融合

- Koopman 潜状态 $z^{prop}_t = \phi(o^{prop}_t)$；RSSM 潜状态 $z^{vis}_t$。
- 融合输入：$x^{policy}_t = [z^{prop}_t; z^{vis}_t]$。
- 策略为 MLP，输出高斯分布参数：$a_t \sim \pi_\theta(a_t | x^{policy}_t) = \mathcal{N}(\mu_\theta, \sigma_\theta)$。

### 2.6 两阶段协同训练

- **Phase 1（教师训练 + WM 预训练）**：教师策略使用特权信息训练，收集探索数据 $D_{explore}$；联合预训练两个世界模型，总损失 $L_{world} = L_{koopman} + \alpha_{vis} L_{rssm}$，其中视觉模型以 Koopman 潜状态作为动作信号条件：$z^{vis}_t = f_{rec}(z^{vis}_{t-1}, VAE(o^{vis}_t), z^{prop}_{t-1})$。
- **Phase 2（学生训练 + WM 微调）**：学生仅用非特权观测，经世界模型编码后生成动作；世界模型在学生回放缓冲区 $D_{student}$ 上继续更新以适应学生分布；学生损失为奖励最大化 + 行为克隆：
  $$L_{student}(\theta) = -\mathbb{E}_{\pi_\theta}\left[\sum_{t=0}^{T} \gamma^t r_t\right] - \lambda_{bc} \mathbb{E}_{D_{teacher}}\left[\log \pi_\theta(a^{teacher}_t | x^{policy}_t)\right]$$
- 微调时仅编码器可训练以适配学生观测分布，前向传播层冻结。

- **性能提升**：DWMP 在仿真中相比强教师-学生基线将障碍穿越成功率提升约 **10%**，在更复杂地形上优势更明显，且训练流程更简单。

- **时序建模的必要性**：相比纯图像表征（VAE），基于 RSSM 的世界模型表现更好，说明学习视觉随机器人运动如何演化对处理未见视觉信息有益。

- **两阶段训练有效性**：教师探索数据为后续适配学生观测分布提供了更有效的初始化。

- **核心贡献成立且有价值**：论文最本质的洞见是"不同模态应按其统计与动力学特性分别建模"——本体感觉用 Koopman 追求可线性预测的动力学，视觉用 RSSM 追求紧凑的几何压缩。这一模态对齐思路比简单拼接或统一压缩更符合问题结构，且实验证据在仿真与真机上方向一致。
- **工程可迁移性较强**：利用教师-学生流水线中天然产生的探索数据预训练世界模型、并在学生阶段只微调编码器以适配分布漂移，是一种低额外成本、易嵌入现有蒸馏框架的训练范式，对其他人形/腿足机器人部署工作有直接借鉴意义。
- **结论强度受限于证据粒度**：成功率提升约 10%、推理更快等论断目前缺少重复实验与统计检验支撑，真机样本量偏小，因此更适合表述为"有前景的初步验证"而非"确定性结论"。
- **后续可推进方向**：补齐超参数与潜维度敏感性分析、引入分布外动力学与传感器退化测试、扩展到未见障碍类型与动态场景、并与更多通用表征基线做公平对比，将显著提升该方法的可信度与影响力。
