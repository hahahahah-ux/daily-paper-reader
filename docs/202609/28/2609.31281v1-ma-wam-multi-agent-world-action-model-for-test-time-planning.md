## 摘要
多智能体协作任务要求不同智能体同时执行联合动作，且每个智能体的动作都会影响其他智能体的观测和响应。因此，需要一个世界模型来预测所有智能体的联合动作所产生的团队回报。一种朴素的扩展方式是在逐步预测团队回报时，直接将单智能体世界模型应用于每个智能体的动作。然而，这种扩展无法捕捉多个智能体同时动作之间的依赖关系。我们提出多智能体世界-动作模型（MA-WAM），一种测试时规划框架，使冻结的多智能体流策略能够评估候选联合动作的未来。据我们所知，MA-WAM 是首个面向多智能体流策略的测试时世界模型规划器。MA-WAM 根据跨智能体依赖关系预测每个联合动作的后果，并实现高效的候选评分。在 MAMuJoCo、SMAC 和 MPE 上的 30 个离线多智能体强化学习（MARL）设置中，MA-WAM 相对于直接执行的平均相对增益为 22.0%，相对于均匀动作选择的平均相对增益为 25.6%。在 A100 GPU 上的标准评估协议下，MA-WAM 增加了 12.1 毫秒，占所测生成与评分时间的 2.5%。

## Abstract
Multi-agent cooperative tasks require different agents to execute a joint action simultaneously, and each agent's action affects both the observations and responses of the other agents. Hence, a world model is needed to predict the team return resulting from the joint actions of all agents. A naive extension directly applies a single-agent world model to each agent's action when predicting the team return step by step. However, such an extension fails to capture the dependencies among the simultaneous actions of multiple agents. We propose Multi-Agent World-Action Model (MA-WAM), a test-time planning framework that enables a frozen multi-agent flow policy to evaluate futures of candidate joint actions. To our knowledge, MA-WAM is the first test-time world-model planner for multi-agent flow policies. MA-WAM predicts the consequences of each joint action according to cross-agent dependencies and enables efficient candidate scoring. Across 30 offline multi-agent reinforcement learning (MARL) settings on MAMuJoCo, SMAC, and MPE, MA-WAM achieves mean relative gains of 22.0% over direct execution and 25.6% over uniform action selection. Under the standard evaluation protocol on an A100 GPU, MA-WAM adds 12.1 ms, accounting for 2.5% of the measured generation-and-scoring time.

- **现有问题**：
  - 近年离线 MARL 广泛采用生成式策略（如扩散、流匹配），同一联合观测可产生多个候选联合动作序列，但**现有方法仍采用"反应式"部署范式**——直接执行某一个采样输出，不评估其他候选，容易选中次优动作。
  - 世界模型是预测候选未来的自然选择，但**多数世界模型围绕单智能体转移建模**；若直接对每个智能体独立预测，则无法刻画"同时动作"之间的耦合，导致预测的联合未来偏离真实协作演化，候选排序不可靠。
  - 规划需在每个决策步评估多个候选，因此评估器必须**兼顾跨智能体依赖建模与低推理成本**。
- **整体含义**：论文将离线生成式 MARL 的部署问题形式化为"**测试时前瞻（test-time foresight）**"——在执行前比较候选联合未来的预测团队结果，并提出 MA-WAM，据称是**首个面向多智能体流策略的测试时世界模型规划器**。

## 2. 方法论：核心思想与关键技术细节

- **总体框架**：训练阶段用同一离线数据集学习两个监督模型——(a) 少步流策略（proposer）生成候选联合轨迹；(b) 路由世界模型（RWM）预测转移与奖励并打分。部署阶段两者均冻结，采用**滚动时域（receding-horizon）**执行。
- **协调少步流策略（Frozen Proposer，基于 CoFlow）**：
  - 将独立高斯噪声映射为短联合观测轨迹，单步形式为 `τ̂₀⁽ᵐ⁾ = ξ₁⁽ᵐ⁾ − û_θ(ξ₁⁽ᵐ⁾, 1 | cₜ, R_tgt)`，其中 `cₜ` 为联合观测历史，`R_tgt` 为归一化目标团队回报。
  - 采用 **classifier-free guidance** 组合条件/无条件速度（引导权重约 1.2），支持 K 步细化（K 在 1–5 之间）。
  - 共享**逆动力学头**将相邻预测观测转换为可执行动作（连续动作用 MSE，离散动作用 masked 交叉熵）。
  - 训练损失：`L_policy = L_vel + λ_act · L_act`，含 **stop-gradient 时序一致性代理**、25% 回报条件 dropout、门控跨智能体注意力（gate 初始化为 0，故初始退化为独立 proposer）。
- **路由世界模型（RWM）**：
  - **动力学分支（软路由 MoE）**：K_d = 8 个专家 × 每专家 S = 4 个 slot，共 L = 32 个 slot；每个 agent token 对所有 slot 做 softmax 软分发（dispatch），专家处理后按 combine 权重软聚合，残差预测观测增量 `ô_{t+1}^i = o_t^i + Δô_t^i`。
  - **奖励分支（稀疏 top-2 路由）**：K_r = 4 个专家，输入含当前观测、动作及**detach 的预测下一观测**（stop-gradient 隔离动力学与奖励优化），只保留 top-2 专家输出并重归一化，团队得分为各 agent 奖励之和 `R̂_ψ = Σ_i r̂_t^i`。
  - 训练损失：`L_WM = L_dyn + λ_r·L_rew + λ_b·L_bal`，其中 `L_bal` 为负载均衡项（λ_r = 1, λ_b = 0.01）。
- **测试时规划流程（Algorithm 1）**：
  1. 冻结策略采样 M 条长度 H 的候选联合动作序列；
  2. RWM 从真实当前观测 `sₜ` 出发逐步 rollout，累积预测回报得分 `J⁽ᵐ⁾ = Σ_{h=0}^{H−1} γ_plan^h · R̂_ψ(...)`（γ_plan = 1）；
  3. 选择 `m* = argmax_m J⁽ᵐ⁾`，**仅执行第一条联合动作** `aₜ^(m*)`；
  4. 收到真实 `s_{t+1}` 后重新规划，从而将模型误差累积限制在单次 H 步 rollout 内。
- **机制约束**：选择域严格限制在冻结策略采样的候选集合内，不更新策略或世界模型，无在线自适应。

## 6. 主要结论与发现

- **RQ1（规划 vs 反应式）**：在 30 个设置中 **26 个提升**、0 个持平、4 个下降，平均设置级相对增益 **22.0%**（p = 5.95×10⁻⁵）；最大增益达 MPE +31 归一化分、MA-MuJoCo +254 原始回报；SMAC 胜率 12 个设置中 8 个提升。
- **RQ2（何时有效）**：**反应式策略余量大（headroom 高）且 RWM 排序可靠（Top-2 高）**的设置增益最大；数据集质量越差，相对增益越大（9 个任务中 8 个单调，p = 0.04；最好/中/最差层分别 +2.6% / +14.9% / +50.8%）。
- **RQ3（可靠性与成本）**：
  - H=8 时平均 Spearman 0.81、8-way Top-2 0.78（随机基线 0.25）、pairwise 0.82、归一化 regret 0.13；H=16 时全部退化（Spearman 降至 0.65，regret 升至 0.22），因此请求 horizon 上限设为 8。
  - 同状态反事实：pairwise 准确率 5 个设置均超 0.5 随机水平（0.58–0.74），RWM 的归一化 regret（0.37）低于均匀随机（0.52）。
  - **成本**：M=8 时生成+评分在 A100 上共 473.7 ms，其中批量 RWM 评分仅 **12.1 ms（占 2.5%）**；RTX 3090 上为 13.4 ms（3.1%）；将候选折叠进 batch 后生成延迟降低 4.2–6.0×。
- **路由机制**：主导专家分配与"转移上下文"的关联强于与 agent 身份的关联（26/30 设置），平均使用 7.51/8 个有效专家，主导专家在 38.1% 的相邻转移中切换；路由图与动作扰动影响图高度相关（0.964 / 0.926），说明路由结构捕捉了跨智能体预测依赖。

## 7. 优点

- **问题定位清晰**：明确指出单智能体世界模型逐步预测无法刻画同时动作耦合，将部署问题形式化为测试时前瞻，视角新颖。
- **方法设计务实**：冻结策略 + 冻结世界模型，无需策略重训练；滚动时域 + 只执行第一个动作，有效抑制模型误差累积；选择域限制在策略候选集内，避免分布外动作风险。

- **统计严谨**：使用精确符号检验、bootstrap 置信区间，并主动报告 4 个负增益设置与失败案例。
