## 摘要
视觉-语言-动作（VLA）模型能够提供广泛的、由指令条件的操作行为，但在接触丰富的交互过程中，其物理执行仍可能不够精确。残差强化学习（RL）可以在保持 VLA 冻结的同时纠正此类误差，但真实机器人上的 RL 成本高昂且关乎安全。我们提出 VLA 潜在条件强化学习（VLaRL），它使针对冻结 VLA 的残差 RL 能够在仿真中训练，并部署到真实机器人上，而无需真实世界 RL 或在线自适应。关键挑战在于，尽管仿真与真实之间存在视觉差距，仍要迁移所学到的残差策略。VLaRL 不要求像素级视觉对应，而是利用 VLA 内部的视觉-语言潜在表示来条件化残差控制，并将其作为 sim-to-real 迁移接口，同时学习一个轻量级映射器，将仿真得到的潜在表示变换到真实潜在分布。在四个接触丰富的操作任务和两个 VLA 主干上，VLaRL 在所有任务-主干组合中都提升了真实世界成功率，而受控消融实验表明，潜在条件化和潜在对齐对于迁移仿真训练的残差控制都很重要。

## Abstract
Vision-language-action (VLA) models provide broad, instruction-conditioned manipulation behaviors, but their physical execution can remain imprecise during contact-rich interaction. Residual reinforcement learning (RL) can correct such errors while keeping the VLA frozen, but real-robot RL is costly and safety-critical. We propose VLA Latent-Conditioned RL (VLaRL), which enables residual RL for frozen VLAs to be trained in simulation and deployed on real robots without real-world RL or online adaptation. The key challenge is transferring the learned residual policy despite the visual gap between simulation and reality. Rather than requiring pixel-level visual correspondence, VLaRL uses the VLA's internal vision-language latent representation to condition residual control and as the sim-to-real transfer interface, and learns a lightweight mapper that transforms simulation-derived latents toward the real latent distribution. Across four contact-rich manipulation tasks and two VLA backbones, VLaRL improves real-world success in all task-backbone combinations, while controlled ablations demonstrate the importance of both latent conditioning and latent alignment for transferring simulation-trained residual control.

## 1. 核心问题与整体含义

- **背景**：视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、Flower、GR00T 等）已能提供广泛的、由语言指令条件的操作行为，但**接触密集（contact-rich）交互中的物理执行精度不足**——接触位置、对齐或持续接触的微小误差即可导致任务失败。
- **核心矛盾**：
  - 通过模仿学习纠正执行误差需要额外采集机器人示范并更新基座策略，成本高；
  - 残差强化学习（Residual RL）可冻结 VLA、仅学习修正动作，但**真实机器人上的 RL 交互代价高且安全风险大**。
- **研究目标**：将残差策略**完全在仿真中训练**，并**零真实世界 RL、零在线自适应**地迁移到真实机器人。
- **关键挑战**：仿真与真实之间的视觉差距会传播到 VLM 内部表示，导致仿真训练的残差策略无法直接迁移。
- **整体含义**：提出 VLaRL，以冻结 VLA 的**内部视觉-语言隐表示**作为残差控制的输入条件和 sim-to-real 迁移接口，并学习轻量映射器对齐仿真/真实隐分布，为冻结 VLA 的精确物理执行提供安全、高效的校正途径。

## 2. 方法论

### 2.1 核心思想
- 把冻结 VLA 拆为两部分：**视觉-语言模块**（编码观测与指令为隐表示）与**动作头**（产生标称动作）。
- 保留动作头作为名义控制器，复用其隐表示作为残差策略的输入与迁移接口。

### 2.2 关键技术细节与公式

- **隐表示提取**：`Zt = EVLM(ot, ℓ)`，`Zt ∈ R^{S×D}`（S 个 token，D 维）。
- **标称动作**：`aVLA_t ~ πact(·|Zt)`。
- **残差动作**：`aRL_t = πRL(zt, aVLA_t, st, ft)`，其中 `zt` 为池化后的 D 维隐向量，`st` 为本体状态，`ft` 为腕部笛卡尔力。
- **执行动作**：`at = aVLA_t + α·aRL_t`，`α = 0.10`（跨任务共享的固定残差缩放）。
- **潜在映射器**：`Ẑst = Mθ(Zst)`，在池化前作用于 token 矩阵；同时供冻结动作头与残差策略使用。
- **映射器训练目标**：基于**熵正则化最优传输（Sinkhorn）** 的分布对齐，代价函数为
  `Cij = ‖Mθ(Zsi) − Zrj‖²_F / SD + λτ(τsi − τrj)²`
  其中 `τ` 为归一化轨迹进度，`λτ = 0.5`，熵正则 `ε = 0.05`，Sinkhorn 迭代 50 次。
- **残差 RL**：TD3 算法，非对称 actor-critic（critic 额外获得仿真特权状态，actor 仅用部署可得观测）；演示派生残差目标
  `aRL,demo_t = (ademo_t − aVLA_t)/α`
  作为辅助正则项。
- **映射器结构**：4 层 Transformer 编码器，16 个注意力头，FFN 维度为 VLA token 维度的 2 倍；带可学习残差连接，缩放因子初始化为 0（初始近似恒等变换）。

### 2.3 四阶段流程
1. **微调 VLA 并冻结**，同时用同批示范重建数字孪生仿真环境。
2. **训练潜在映射器**，把仿真隐表示映射到真实隐分布。
3. **在仿真中训练残差策略**（VLA 与映射器均冻结），输入为映射后的隐表示。
4. **真实机器人部署**：直接使用真实 VLM 隐表示，**不使用映射器**，所有模型冻结，无在线自适应。

## 3. 实验设计

- **硬件平台**：Franka Research 3 机械臂，仿真环境为 MuJoCo。
- **数据采集**：每个任务通过 3D 鼠标遥操作采集 **32 条真实示范**；用 FoundationPose 重建物体位姿与环境，构建数字孪生。
- **四个接触密集任务**：
  - 按钮按压（精确目标接触）
  - 方块推动（持续接触）
  - 杯子堆叠（抓取 + 空间对齐）
  - 抽屉关闭（铰接接触）
- **两个 VLA 主干**：
  - Flower：Florence-2 视觉-语言模块，池化后 1024 维
  - GR00T N1.7：语言条件图像 token，2048 维
  - 动作空间均为 7 维归一化笛卡尔动作（3 平移 + 3 旋转 + 1 夹爪）
- **Benchmark / 对比方法**：
  - 基线：冻结 VLA
  - 对比：VLA + Mapper、VLA + Mapper + Residual RL（VLaRL）
  - 消融：w/o VLM latent（去掉隐表示，仅用标称动作 + 本体 + 力）、w/o Mapper（使用未对齐的仿真隐表示）
- **评估协议**：初始物体位置 ±3 cm、朝向 ±15°随机化（抽屉开度 ±3 cm）；仿真报告 3 个随机种子，真实世界每条件 **40 次试验**。
- **额外评估**：未见物体迁移（星形/三角形方块、天蓝/绿色杯子），以及基于**积分梯度**的输入归因分析。

## 4. 资源与算力

- 仅提供了训练超参数：残差策略训练 **60,000 环境步**，TD3，actor/critic 为 4 层 ReLU MLP（隐宽 1024），batch size 256，`γ = 0.99`，Polyak `τ = 0.005`，残差缩放 `α = 0.10`。

## 5. 实验数量与充分性

- **主要实验规模**：4 任务 × 2 主干 = **8 个任务-主干组合**，每个组合均报告仿真与真实世界成功率。
- **消融实验**：在 Flower 上做 2 组消融（w/o VLM latent、w/o Mapper），共覆盖 4 个任务。
- **未见物体迁移**：方块推动（星形/三角形）与杯子堆叠（天蓝/绿色），各含语言指定角色与左右放置的平衡条件。
- **归因分析**：对 4 任务 × 2 主干做积分梯度归因。
- **充分性评估**：
  - 优点：真实机器人 40 次/条件 + 3 个仿真种子，统计量较扎实；跨两个架构差异较大的主干验证了泛化性。
  - 局限：消融**仅在 Flower 上做**，未在 GR00T N1.7 上重复；未见物体评估范围有限；仿真与真实结果趋势不一致（如 Flower 杯子堆叠真实基线反而更高），提示存在未被完全控制的混杂因素。

## 6. 主要结论与发现

- **仿真结果**：加入 Mapper 可提升所有任务-主干组合的标称 VLA 成功率；再加入残差 RL 进一步提升（如 Flower 方块推动 32.5% → 42.5% → 67.5%）。
- **真实世界结果**：VLaRL 在**全部 8 个任务-主干组合**上均优于冻结 VLA。典型增益：Flower 按钮按压 67.5% → 100.0%，Flower 方块推动 22.5% → 50.0%，GR00T N1.7 杯子堆叠 17.5% → 45.0%。
- **消融结论**：
  - **去掉 Mapper**：方块推动与杯子堆叠在 40 次真实试验中 **0% 成功**（完整 VLaRL 分别为 50.0% 和 70.0%），说明隐对齐是 sim-to-real 迁移的关键。
  - **去掉 VLM latent**：四个任务真实性能全面下降（按钮按压 100% → 70%，方块推动 50% → 20%），说明隐表示提供了标称动作、本体与力之外的有用信息。
- **归因分析**：VLM 隐表示在残差动作范数上的归因占比最高（Flower 72.1%–89.7%，GR00T N1.7 84.0%–90.9%）；力的贡献在持续接触任务中上升，本体感知在空间对齐任务中更重要。
- **未见物体迁移**：VLaRL 使方块推动 40.0% → 57.5%，杯子堆叠 55.0% → 62.5%，且保留了冻结 VLA 的指令相关目标/角色选择能力。
- **总体发现**：仿真训练的隐条件残差 RL 可在无真实 RL、无在线自适应的条件下迁移到真实机器人，并适用于不同 VLA 架构。

## 7. 优点

- **接口设计巧妙**：用 VLA 内部 VLM 隐表示作为 sim-to-real 接口，避免像素级视觉对齐，也无需显式物体位姿估计与任务特定状态定义。
- **映射器轻量且训练稳定**：基于最优传输的分布对齐，带零初始化残差连接，初始近似恒等，训练扰动小。
- **零真实 RL 部署**：完全仿真训练 + 真实部署时直接消费真实隐表示、不用映射器，安全且成本低。
- **跨主干验证**：Flower 与 GR00T N1.7 两个差异显著的架构均获提升，增强结论可信度。
- **分析完备**：同时提供消融实验与积分梯度归因，既验证模块必要性，又揭示各输入的相对贡献。
- **保留泛化性**：未见物体上仍有提升，且不破坏冻结 VLA 的指令条件行为。

## 8. 不足与局限

- **依赖配对数据**：映射器训练需要近似对应的 sim-real 轨迹，依赖任务特定的数字孪生重建，扩展性受限。
- **未处理动力学差距**：映射器只对齐 VLM 表示分布，未显式建模接触动力学、摩擦、柔顺性等物理差异，这可能是仿真与真实表现趋势不一致的原因。
- **映射器与残差策略缺乏共享**：映射器对每个 VLA 主干单独训练，残差 RL 也按任务类别分别训练，尚未实现跨主干、跨技能的共享与迁移。
- **消融覆盖不均衡**：消融仅在 Flower 上进行，未在 GR00T N1.7 上复现。
- **泛化范围有限**：未见物体评估仅覆盖少量形状与颜色变化，未建立开放世界泛化。
- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，影响可复现性与成本评估。
- **语言指令多样性有限**：任务指令模板较固定，对更复杂、更开放语言条件的鲁棒性未知。
