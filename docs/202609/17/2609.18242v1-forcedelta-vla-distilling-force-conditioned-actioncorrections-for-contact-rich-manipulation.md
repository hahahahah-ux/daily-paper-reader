## 摘要
力感知的视觉-语言-动作（VLA）策略改善了接触丰富操作，但通常将任务级运动与依赖接触的调整结合在单个动作预测中。演示没有提供显式标签来将该预测分解为可复用的参考动作和修正。我们提出 ForceDelta-VLA，一种修正蒸馏框架，它利用冻结教师模型的力条件模式与学习到的力无关模式的成对预测，构建显式的力修正目标。一个单独的延迟修正目标用于解释参考动作不匹配以及参考状态的变化。训练使用异步调度回放，并利用执行期间可用的缓存任务上下文。由此得到的轻量级策略使用近期力历史和机器人状态调整参考动作，在参考动作更新之间对接触变化做出响应，而无需重新生成完整动作块。在九个单臂和双臂接触丰富任务上，ForceDelta-VLA 达到 82.2% 的平均成功率，而原始 ForceVLA 基线为 54.4%。直接执行我们的第一阶段时序教师（Stage-1 Temporal Teacher）达到 70.6%。相对于 ForceVLA，完整系统在两个平台上将成功试验中的平均峰值接触力降低约 26%。

## Abstract
Force-aware Vision-Language-Action (VLA) policies improve contact-rich manipulation, but typically combine task-level motion and contact-dependent adjustment in a single action prediction. Demonstrations provide no explicit labels for decomposing that prediction into a reusable reference action and a correction. We present ForceDelta-VLA, a correction-distillation framework that constructs an explicit force-correction target using paired predictions from a frozen teacher's force-conditioned and learned force-agnostic modes. A separate delay-correction target accounts for reference-action mismatch and the change in reference state. Training uses asynchronous schedule replay with the cached task context available during execution. The resulting lightweight policy adjusts the reference actions using recent force history and robot state, responding to contact changes between reference-action updates without regenerating complete action chunks. Across nine single-arm and bimanual contact-rich tasks, ForceDelta-VLA achieves an 82.2% mean success rate, compared with 54.4% for the original ForceVLA baseline. Direct execution of our Stage-1 Temporal Teacher achieves 70.6%. Relative to ForceVLA, the complete system reduces mean peak contact force over successful trials by approximately 26% on both platforms.

# ForceDelta-VLA 论文总结

## 1. 核心问题与研究动机

- **背景**：接触丰富操作（如 USB 插拔、按钮按压、抽屉/柜门开启、擦拭）要求动作随接触状态持续变化。力感知 VLA 策略（ForceVLA、TA-VLA 等）虽引入力/力矩反馈，但**通常把"任务级运动"与"依赖接触的局部调整"耦合在同一个动作预测里**，导致每次接触变化都必须等待一次完整动作块（action chunk）的重新生成。
- **核心矛盾**：理想方案是把"慢速生成的可复用参考动作"与"快速更新的接触修正"分离，让力反馈能在参考动作更新之间立即生效；但**演示数据只记录最终动作，不标注哪部分属于参考运动、哪部分属于接触修正**——同一示范动作可由不同的（参考 + 修正）组合加和得到，因此修正通路缺少明确的监督目标。
- **现有工作的不足**：
  - 异步/多速率策略（FAVLA、DAM-VLA、RTC、ImplicitRDP 等）只分离了计算或传感更新频率，**没有解决监督信号从何而来**的问题。
  - 残差强化学习与纠正式模仿学习需要**额外奖励或在线交互/人工纠正**，无法仅用原始演示数据。
- **整体含义**：论文提出仅用现有演示数据即可构造显式修正监督的框架，兼顾"轻量快速修正"与"异步执行"，在九个真机单臂/双臂任务上同时提升成功率、降低接触力、缩短完成时间。

## 2. 方法论

### 2.1 核心思想

将指令位姿分解为三部分（式 1）：

```
P(A_cmd) = P(A_ref) + ΔÂ_force + ΔÂ_delay
```

- `A_ref`：慢速生成通路输出的**可复用参考动作块**（不使用实测力输入）。
- `Δ_force`：**力修正**，学习"同一状态下力条件预测与力无关预测之差"。
- `Δ_delay`：**延迟修正**，补偿"存下来的旧参考动作"与"当前参考预测"之间的差异，包括参考状态的变化。
- 只修正位姿通道；夹爪命令沿用参考动作；位姿用 6D 连续旋转表示，修正后经 Gram–Schmidt 投影回合法旋转。双臂任务把两臂输入拼接后联合预测。

### 2.2 三阶段训练流程

1. **Stage-1：时序力条件教师**（基于 ForceVLA）
   - 用 FAVLA 风格的**因果时序卷积网络（TCN）**替换瞬时力嵌入，编码 100 ms 力/力矩历史：`z_F,t = E_FT(F_t)`。
   - 教师 `T_θ` 由 `(V_t, L, S_t, z_F,t; ε)` 预测 H=50 步动作块，训练后**冻结**。
2. **Stage-2：力无关参考动作模式**
   - 关键区分"力不可用"与"实测零力"：力无关模式把力历史替换为**可学习空 token `z∅_F`**，并用**秩 ρ 适配器** `(W_in, W_out)` 修改动作专家的位姿输出通道：`v_p ← v_p + W_out σ(W_in h)`。
   - 教师参数 θ 固定，仅训练 φ = {z∅_F, W_in, W_out}，沿用原流匹配目标，得到参考策略 `T_ref_{θ,φ}`。
3. **Stage-3：修正蒸馏**
   - **成对目标构造**：复用参考查询时刻缓存的多模态前缀 `E_k`（不重新编码当前图像），仅把机器人状态与力历史更新到当前时刻 t，并共享同一采样噪声 `ε_k`，得到当前时刻的力条件预测与力无关预测：
     - 力修正目标（式 8）：`ΔA_force = P(A_cond_{T,t|k,j}) − P(A_ref_{T,t|k,j})`。
     - 延迟修正目标（式 9）：`ΔA_delay = P(A_ref_{T,t|k,j}) − P(A_ref_k(t_j)) + Γ(S_t, S_k)`，其中 `A_ref_k(t_j)` 是旧参考在时间戳 t_j 的插值，`Γ(·)` 把参考状态差转换到归一化动作坐标。
   - **修正策略输入**（式 10）：缓存池化任务上下文 token `Z_ctx_k`、因果力编码 `u_F,t`、本体状态、插值后的参考动作段、时间特征（缓存年龄 + 插值相位），带类型嵌入。
   - **共享注意力 + 双头**：同一注意力模块 Φ 与同一可学习 query `q_corr` 前向两次——一次用全部条件输出力修正（式 11），一次**掩掉力 token** 输出延迟修正（式 12），避免延迟输出直接依赖力 token；两头分别输出 K=5 步位姿修正。
   - **异步调度回放**：训练前先采样查询周期与推理延迟，抽取目标并回放同一固定调度，使学生在"带延迟的参考动作"上训练。
   - **损失**（式 13）：`L_distill = Σ w_j [ℓ_pose(力修正) + λ_delay · ℓ_pose(延迟修正)]`，时间权重 `w_j ∝ β^{j-1}`（0 < β ≤ 1），均为归一化坐标 MSE。

### 2.3 异步部署

- 教师以约 5 Hz 周期性刷新参考动作；学生查询与教师计算并行进行。
- 每个控制步选择"最近启动且已完成、仍有效"的学生查询结果，按其活跃步 j 插值参考动作、**分别裁剪**两个修正、按式 1 合成归一化位姿，再用该参考的查询状态 `S_k` 转成绝对命令。
- 过期步跳过；有效修正步保持到下个时间戳或有更新结果。

## 6. 主要结论与发现

- **成功率**：ForceDelta-VLA 平均 **82.2%**，显著高于 ForceVLA 的 **54.4%**、TA-VLA 的 57.2%、π0.5 的 47.2%、ImplicitRDP 的 45.0%，也高于 Stage-1 时序教师的 **70.6%**（提升约 11.7 个百分点）。九个任务上全面优于 ForceVLA，增益最大的是 USB 插入（+40）、按钮按压（+35）、插头插入（+35）。
- **接触力与时间**：相对 ForceVLA，成功试验平均峰值接触力在单臂/双臂分别降低 4.2 N / 4.3 N（**约 26%**），完成时间分别缩短 5.2 s / 5.9 s；相对时序教师亦分别降低 3.3 N / 2.2 N。
- **延迟敏感性**：额外参考延迟从 0 增到 200 ms，ForceDelta-VLA 成功率下降 15 个百分点、峰值力上升 3.7 N；教师则下降 25 个百分点、上升 9.6 N——说明"在参考更新之间持续修正"确有价值。
- **消融结论**：
  - 监督定义上，"示范动作 − 力无关预测"目标显著变差（单臂 −12.5、双臂 −17.5 个百分点），支持用**上下文/状态/噪声匹配的教师成对预测**定义力监督；零力教师查询同样更差，支持学习力无关模式。
  - 输出分解上，去掉力修正下降 15 / 17.5 个百分点且峰值力上升，力历史置零比禁用力分支更差（说明分支确实依赖力反馈）；单一合并修正头下降 10 个百分点，支持**分离监督与分离预测**；快速全动作蒸馏亦不如"复用参考 + 预测修正"。
  - 异步方面，去掉学习到的延迟修正两个平台各降 7.5 个百分点；去掉调度回放单臂/双臂分别降 7.5 / 12.5 个百分点。
- **泛化**：未见物体上 ForceDelta-VLA 成功率 66.7%，高于时序教师 40.0% 与 ImplicitRDP 16.7%，峰值力低 8.2 N。
- **失败模式**：插接类失败多为到达目标区后撞到边缘或姿态小误差导致卡死，参考动作仍继续前进而修正幅度不足以回退重试；开柜/开抽屉常在与把手稳定接触前就开始拉；擦拭/翻转失败为接触面错位或接触几何丢失；参考更新延迟会加剧插入失败。

## 7. 优点

- **监督问题定位准确且有巧思**：用冻结教师的"力条件 vs 力无关"配对预测（共享多模态前缀、状态、采样噪声）构造显式力修正标签，**无需奖励、无需在线交互、无需人工纠正**，仅用原始演示数据。
- **区分"力不可用"与"零力"**：用可学习空 token + 秩 ρ 适配器学习力无关模式，比直接输入零力更合理（消融中"零力教师查询"明显更差，佐证了这一点）。
- **延迟修正目标设计完整**：不仅补偿参考动作不一致，还用 `Γ(S_t, S_k)` 显式做参考状态对齐，并在训练中通过异步调度回放模拟真实推理延迟，缩小训练–部署差距。
- **架构高效**：共享注意力模块 + 掩码力 token 的双头设计，让学生只用 2.43 ms 的前向就能更新修正，远低于 10 ms 控制间隔，避免每步重新生成完整动作块。
- **实验较为扎实**：9 个真机任务（含双臂）、与 4 个代表性基线对比、10 组消融、未见物体泛化、延迟敏感性、失败分析，指标同时覆盖成功率/接触力/完成时间。
