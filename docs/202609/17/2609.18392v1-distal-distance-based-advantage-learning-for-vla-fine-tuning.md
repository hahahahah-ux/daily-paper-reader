## 摘要
视觉-语言-动作模型（VLA）近年来通过将LLM的语义理解与流匹配策略的精确控制相结合，改变了机器人操作领域。优势条件化是一种近期技术，它通过在部署数据上训练价值函数，并利用该函数训练优势条件化策略，从而迭代地改进VLA。此前的工作仅采用简单、低信息量的成功/失败奖励，这使得价值函数除了任务进展的表观程度外，无法区分质量不同的状态。受对分布外（OOD）检测方法探索的启发，我们提出了基于距离的优势学习（DistAL），该方法通过将嵌入空间距离用作奖励，产生信息量更大的价值函数，并进而提高下游任务成功率。我们在一系列仿真基准以及真实硬件上的灵巧双臂操作任务中验证了我们的方法。

## Abstract
Vision-language-action models (VLAs) have trans- formed the field of robotic manipulation in recent years by combining the semantic understanding of LLMs with the precise control of flow-matching policies. Advantage conditioning is a recent technique that iteratively improves VLAs by training a value function on deployment data and using this to train an advantage-conditioned policy. Previous works have only applied simple, low-information success/failure rewards, which leave the value function unable to distinguish states of differing quality beyond how far along the task they appear. Motivated by an exploration of out-of-distribution (OOD) detection methods, we introduce Distance-based Advantage Learning (DistAL), which, by using an embedding space distance as a reward, produces a more informative value function and subsequently a higher downstream task success rate. We validate our method on a series of simulation benchmarks and dexterous bi-manual manipulation tasks on real hardware.

# DistAL: Distance-based Advantage Learning for VLA Fine-Tuning —— 论文总结

## 1. 核心问题与研究背景

- **背景**：VLA（视觉-语言-动作模型）已能借助 LLM 语义先验 + flow-matching 连续动作头实现灵巧操作，但接触密集的灵巧任务仍难以达到可部署的成功率，需要从自身部署数据中持续改进。
- **现有路线的问题**：
  - 人类干预数据（HIL-SERL、Sirius 等）需专家遥操作全程待命，硬件与操作复杂度高。
  - 在线 RL 微调（含蒸馏 RL 专家）样本效率低、不稳定、算力开销大。
  - **优势条件化（advantage conditioning）** 属于离线 RL 路线：在部署数据上训练价值函数，再以优势标签条件化微调 VLA，无需在线交互、稳定性好。但此前工作（π*0.6 / RECAP）**只用成功/失败二值奖励**——每步常数惩罚意味着唯一抬高状态价值的因素只是"剩余步数"，状态仅按任务进度排序。
- **核心痛点**：一个"勉强抓住"的不稳定抓取与一个"牢固抓住"的状态获得相同价值，尽管成功概率差异巨大；这种差异只能靠失败惩罚间接、噪声地回传。而手工设计任务奖励又牺牲可扩展性。
- **核心洞见**：失败轨迹相对成功参考数据集是 OOD 的；因此可用**嵌入空间距离**作为稠密奖励，替代稀疏成败信号。论文的定位是"**drop-in 奖励替换**"——策略、价值函数、训练流程完全不变，把奖励设计隔离为唯一变量。

## 2. 方法论

### 2.1 核心思想
- 用冻结视觉编码器在**基座 VLA 训练集**上的 kNN 距离衡量部署观测的"离群程度"，距离越远（越像失败）奖励越低，作为逐步稠密奖励驱动价值函数，再计算优势标签条件化微调策略。

### 2.2 关键技术细节

- **kNN 特征距离奖励**：
  - 冻结编码器 `f: O → R^df`（使用的是**基座 VLA 微调后的同一个 SigLIP 视觉编码器**，而非原始 SigLIP），在 `D_train` 上构建嵌入索引 `I`。
  - 逐观测得分：`s_k(o) = (1/k) · Σ_{j∈N_k(f(o);I)} ||f(o) − z_j||₂`，取 `k = 10`（实验发现对 k 不敏感）。
  - 奖励 `r_t = −s_k(o_t)`，归一化到 `[−1, 0]`。
  - **保留失败回合的大终端惩罚**，避免策略靠"停留在熟悉的早期状态"刷奖励；同时缓解"新颖但成功的恢复动作被惩罚"的问题。
  - 该假设并非普遍成立，作者明确承认其适用边界（见结论部分）。

- **价值函数**：
  - 结构：预训练 Gemma3 270M 语言模型 + SigLIP 400M 视觉编码器，最终输出 token 过 2 层 MLP 头。
  - 训练目标：蒙特卡洛回报 `G_t = Σ_{k=0}^{T−t} r_{t+k}` 上的回归（论文用全回合回报，而非原方法的 N 步自举优势）。
  - 按 [42] 的做法**预测离散化 return bin 上的类别分布**，用交叉熵训练（试过 HL-Gauss 损失，无提升）。

- **优势标签与策略微调**：
  - 优势 `Â_t = G_t − V_φ(o_t)`，标签 `y_t = 1[Â_t > κ]`，阈值 κ 设定使 **30% 标签为正**。
  - 策略：微调版 π0.5（PaliGemma 3B VLM + 300M flow-matching action expert），**只微调 action expert、冻结 backbone**。
  - 标签注入方式：在 tokenized 语言输入末尾追加文本 "Advantage: positive" / "Advantage: negative"；无条件时什么都不加。
  - 训练时以概率 `p` 丢弃标签为 null token `∅`；推理时用 classifier-free guidance 引导：`ṽ = v(a, ∅) + w·(v(a, y=1) − v(a, ∅))`，`w > 1`。

- **三步训练流程**：① 用式(4)对每条部署观测打分并赋 `r_t = −s_k(o_t)` → ② 拟合 `V_φ` 并生成优势标签 → ③ 带优势标签微调 VLA（训练时随机丢标签，推理时 CFG 引导）。

## 3. 实验设计

- **OOD 检测器作为失败预测器（动机实验）**：从基座 π0.5 在 LIBERO、LIBERO-plus 及两个硬件任务上收集带成败标签的 rollout，比较 5 种检测器，指标为 AUROC（轨迹级与逐步级，逐步级更贴合价值函数需求）：
  1. kNN – SigLIP（pre-LM，本文方法）
  2. kNN – LM image tokens（post-LM，检验 LM 上下文特征）
  3. Mahalanobis – SigLIP（消融距离度量）
  4. VAE likelihood（生成式替代）
  5. Action-chunk variance（16 次 flow-matching 采样的逐步标准差）
- **仿真 benchmark**：
  - **LIBERO-10**（LIBERO-Long，10 个长程任务）；省略 LIBERO-Spatial/-Object/-Goal，因 π0.5 已饱和无提升空间。
  - **LIBERO-plus**，按 8 种扰动类型分别报告：Layout、Camera、Light、Init.、Noise、Lang.、Texture 等。
  - 每任务采集 50 条带成败标签的部署 rollout；3 个随机种子 × 每任务 50 episode。
- **硬件平台**：双臂 Piper 机械臂（每臂一个腕部相机 + 一个外部场景相机），两个接触密集任务——**remove pen lid**（一臂固定笔身、另一臂拔笔帽）与 **remove ethernet cable**（一臂抵住端口、另一臂拔线）；每任务 50 条遥操作示范微调基座 π0.5，另采 50 条部署 rollout；50 次评估 rollout。
- **对比方法**（同一部署数据集训练，隔离奖励函数影响）：
  1. Base π0.5（无优势条件化）
  2. SFT（仅在成功轨迹上再微调）
  3. RECAP-style binary reward（同一 pipeline + 稀疏成败奖励与每步惩罚）
  4. DistAL（本文）

## 6. 主要结论与发现

- **kNN-SigLIP 距离是最强的失败预测器**：轨迹级均值 AUROC **0.82**、逐步级 **0.67**，优于 VAE likelihood（0.79 / 0.65）、Mahalanobis（0.71 / 0.58）、post-LM image tokens（0.57 / 0.51，在 LIBERO 上甚至倒置为 0.31）、action-chunk variance（0.58 / 0.51）。说明 SigLIP 空间本身携带失败信号，但 kNN 度量比类条件高斯拟合更有效；LM 上下文会**冲淡**而非锐化该信号。
- **逐步奖励曲线分离清晰**（Fig. 3）：成功与失败轨迹的 kNN 分数差距随回合推进逐渐张开，说明信号可用于**局部信用分配**，而非仅在终局出现。
- **仿真提升**：LIBERO-10 达 **96.2%**（base 94.8 / SFT 94.4 / binary 95.0）；LIBERO-10+plus 总均值 **78.4%**（base 75.1 / binary 77.2 / SFT 74.8）。SFT 与基座几乎无差别（−0.3），说明增益来自价值函数而非成功数据子集。
- **扰动维度上的分工**：两种优势条件化方法都在基座最弱的扰动上收益最大（Camera +25.2 / Noise +14.1 / Texture +10.7），DistAL 在 Camera（+4.8）和 Texture（+7.7）上优于二值奖励，并在 Camera、Texture 上达到 **100%**。
- **硬件提升显著**：均值 **69.5%**（base 44.0 / binary 60.0）；Ethernet 达 **87%**（base 46%、binary 72%），是全文最强单点结果；Pen lid 为 52%（base 42%、binary 48%），与 binary 奖励**统计上打平**。
- **失败可视觉分离性是适用条件**：Ethernet 失败（线未拔出、错过端口）视觉明显（轨迹级 AUROC 0.94），收益巨大；Pen lid 失败是"抓握正确但承重滑脱"的接触事件（逐步 AUROC 仅 0.56，接近随机），此时距离奖励退化为"二值奖励 + 噪声"。
- **两个源自奖励本身的失效模式**：① 分数纯图像驱动，忽略力、接触稳定性、机器人状态与语言；② 奖励偏好"接近训练分布"，原则上可通过停留在熟悉状态刷分，也可能惩罚新颖但成功的恢复（用终端惩罚与奖励有界化缓解，但未系统刻画）。
- **继承的假设**：依赖自身部署数据，策略需先达到能产生有意义信号的最低成功率，而该阈值仍为开放问题。
- **Layout / Language 回归**（约 −14 与 −11 点）在两种奖励下几乎一致，作者归因于**优势条件化本身**：这些扰动不改变视觉场景但改变正确行为，两种奖励都无法早期区分成败，条件化以牺牲分布内性能换取视觉偏移下的恢复能力。

## 7. 优点

- **方法极简且可插拔**：完全复用现有优势条件化 pipeline，只替换奖励项，是真正的 drop-in 模块，工程成本低、易迁移到其他 VLA。
- **动机—验证链条完整**：先用系统的 OOD 检测对比证明"kNN 距离能预测失败"，再证明"作为奖励能提升策略"，避免了直接跳结论。
- **严格的控制变量**：所有方法共享同一部署数据、同一策略与价值网络、同一训练流程，

同一策略与价值网络、同一训练流程，**使奖励函数成为唯一变量**，结论归因清晰，避免了"多因素混合改动"的常见混淆。
- **主动划定适用边界**：作者没有宣称普适，而是明确把"失败模式是否可视觉分离"作为适用前提，并用 Ethernet（轨迹级 AUROC 0.94、+41 点）与 Pen lid（逐步 AUROC 0.56、打平）的对比给出正反例证，这种"给出失效条件"的写法比单方面报喜更可信。
- **如实报告负面结果**：Layout / Language 上的约 −14 / −11 点回归、Pen lid 的统计打平、post-LM 特征在 LIBERO 上 AUROC 反转为 0.31、HL-Gauss 损失无提升等，均被写入正文而非隐去。
- **极低的额外数据与交互成本**：无需在线 rollout、无需人类干预待命、无需新采真机数据；奖励计算只是对已有嵌入索引做一次 kNN 检索，价值函数也仅 270M+400M 规模，工程与算力门槛远低于在线 RL 路线。
- **保留了可扩展性**：绕开手工任务奖励设计，使方法原则上可推广到任意有基座 VLA 训练集的场景。

## 8. 不足与局限

- **奖励模态单一（最根本的局限）**：奖励完全由图像嵌入距离定义，**忽略力/力矩、接触状态、本体状态与语言指令**。而论文自身最有价值的反面案例（Pen lid 的承重滑脱）恰恰是"视觉正确、接触失败"的任务——这正是该奖励原理上无法覆盖的失效类型，且这类任务在接触密集的灵巧操作中占比很高。
- **对参考分布 `D_train` 的强依赖**：奖励本质是"像不像训练集"，因此偏好分布内行为。原则上策略可通过停留在熟悉的早期状态、或回避必要的新颖恢复动作来刷分；论文用"失败回合大终端惩罚 + 奖励归一化到 [−1, 0]"来缓解，但这是**启发式补丁而非原理性解决**，且论文未对该失效模式做系统性刻画（例如对抗性刷分实验）。
- **适用性判据无法事前获得**：论文用"逐步级 AUROC"事后解释为何 Ethernet 有效而 Pen lid 无效，但要在新任务上决定是否值得用 DistAL，仍需先采集带成败标签的部署数据并训练检测器——判据本身有成本，未给出低成本的先验准则。
- **阈值与超参缺乏敏感性分析**：优势标签阈值 κ 固定为"30% 标签为正"，这一比例如何影响性能、是否需按任务调整，未做扫描；CFG 引导权重 w、训练时标签丢弃概率 p、终端惩罚强度、奖励归一化区间同样未见消融。
- **继承而非解决了优势条件化的固有缺陷**：Layout / Language 回归在两种奖励下几乎一致，说明问题出在"用视觉优势标签条件化"这一范式本身（这些扰动不改变视觉场景却改变正确行为，早期无法区分成败）。DistAL 未触及该层面。
- **统计功效不足**：单基座 VLA（π0.5）、2 个真机任务、3 个训练种子；真机仅 50 次评估。LIBERO-10 上 DistAL 相对 binary reward 的 +1.2 点、Pen lid 的 +4 点均落在种子/采样波动内，作者自己也承认不显著。硬件结论主要靠 Ethernet 单点支撑。
- **缺少与在线 / 干预式方法的同条件对比**：论文将自身定位为"离线奖励替换"，因此只与 SFT、binary reward、base 比较，未与 HIL-SERL、在线 RL 微调在同等数据预算下比较，读者无法判断其绝对水平与"省下的交互成本"是否划算。
- **未验证迭代可持续性**：只做了单轮"采数据 → 训价值 → 条件化微调"，未回答"用改进后的策略再采数据、再迭代"是否会持续提升，还是会因分布漂移导致 kNN 参考集失配。这直接关系到该路线能否作为长期自我改进的引擎。
- **算力与可复现信息缺失**：无 GPU 型号/数量/时长、无训练总步数与 wall-clock，第三方难以评估复现门槛（详见第 4 节）。

## 9. 启示与可迁移点

- **"隔离奖励变量"的实验范式值得借鉴**：把奖励设计从策略学习中剥离，让所有对比方法共享数据、价值网络与训练流程，是评估任何奖励塑形方法时最干净的协议。
- **OOD 距离是一种"近乎免费"的稠密奖励**：只要有基座模型的训练集与一个冻结编码器，就能在不采任何新数据、不设计任何任务奖励的前提下得到逐步信号，这对部署阶段的持续改进极具吸引力。
- **先用失败预测指标做"可行性体检"**：在下游策略实验之前先测逐步级 AUROC，可作为判断某任务是否适合该方法的低成本前置筛查（本文的 0.94 vs 0.56 对比即为示例）。
- **潜在改进方向**：把力/触觉/本体状态纳入嵌入空间或另建一路奖励以覆盖"视觉正确但接触失败"；将参考集从固定 `D_train` 改为随策略演化而更新的在线/滑动参考分布以支持迭代自我改进；对优势阈值做校准（如按分位数自适应）以替代固定 30% 正标签。
- **对实践的提醒**：当任务的失败在视觉上不可分离时，距离奖励会退化为"二值奖励 + 噪声"，此时不应期待增益；而视觉扰动主导的任务（Camera、Texture、Noise）才是该方法的甜点区。
