## Abstract
Dexterous grasp synthesis has advanced rapidly in generating stable and physically plausible hand poses, but real-world manipulation requires grasps that preserve the function implied by the task. We study open-vocabulary task-oriented dexterous grasp generation, where a robot must infer functional intent from free-form language, ground it in multi-view visual observations and object geometry, and generate an executable high-degree-of-freedom grasp. We present OpenDexGrasp, a unified data and generative modeling framework for this setting. OpenDexVerse provides dual-source supervision organized by the Coverage-to-Alignment (C2A) Recipe: OpenDex-Scale offers large-scale semantic and geometric coverage through automatic grasp synthesis and vision-language annotation, while OpenDex-Align supplies high-quality embodied alignment through human teleoperation and category-level transfer. OpenDexGrasp learns a shared perception-action latent representation that couples open-vocabulary vision-language context with dexterous action generation. Affordance grounding and grasp generation provide complementary supervision over this latent space, enabling direct generation of task-consistent dexterous grasps without a separate affordance-to-pose inference stage. Extensive simulation and real-robot experiments demonstrate improved functional alignment, physical feasibility, generalization to unseen categories, and real-world execution success. Additional details and videos are available at https://opendexgrasp.github.io/.

## 2. 方法论

### 2.1 核心思想
- 学习一个**共享感知-动作隐空间**，其中语言、功能区域、物体几何与手部姿态被联合优化：可供性监督使隐空间在物体表面可解释，动作监督使其具备生成性与物理落地性。
- 形式上，可供性与动作是共享隐状态 z 的两个观测：
  - pθ(m, a | u, I, P) = ∫ pθ(m|z,u,P) · pθ(a|z,u,P) · pθ(z|u,I,P) dz
  - **注意**：该分解只是设计原则的形式化，**不是测试时的可供性→动作级联**。
- 学习目标是直接建模条件分布 pθ(a | u, I, P)，采样所得抓取既物理可行又功能一致。

### 2.2 问题形式化
- 样本表示为 (u, I, P, a, m)：u 为自由形式功能指令，I = {Iv} 为多视角 RGB，P ∈ R^{N×C} 为点云，a 为抓取姿态，m ∈ [0,1]^N 为可选的点级可供性标签（**仅作辅助监督**）。
- 抓取姿态参数化：a = [p, r6D, q]，其中 p ∈ R³ 为全局平移，r6D ∈ R⁶ 为连续 6D 腕部旋转，q 为手部关节配置；总维度 31（3 平移 + 6 旋转 + 22 关节）。

### 2.3 开放词汇语义-几何隐表示
- **语义侧**：所有物体视图与指令格式化为多模态序列，经预训练视觉-语言编码器（Qwen3-VL-4B-Instruct）得到隐状态 Hℓ ∈ R^{B×S×d_vl}。**使用隐状态而非最终文本回复**，以保留任务词、物体外观与视角相关部件证据之间的关联。
- **几何侧**：点云 P = {(xi, ci)}，xi 为**原始米制尺度坐标**（保留物体尺寸可观测性），ci 为 RGB。采用 PointNet++ 层次编码器（2048 点，两级 set abstraction）输出全局几何 token zP，同时保留中间点特征供可供性解码。

### 2.4 流匹配灵巧动作生成
- 动作头为基于 Transformer 的流匹配扩散（DiT），18 个 block，隐维 1024，16 注意力头，8 个 future query token。
- 前向加噪：给定目标动作 a（记为 a1）、噪声 a0 ~ N(0,I)、时间 t，插值 at = (1−t)a0 + t·a1，目标速度 v* = a1 − a0。
- 动作侧序列 St = [zP, zF, zA]（几何 token、查询 token、含噪动作 token）；自注意力融合三者，**偶数 block 交叉注意力**到对应 Qwen 隐状态，**奇数 block** 做因果自注意力。
- 训练损失：L_act = E‖Fθ(at, t, zP, {Hℓ}) − (a1 − a0)‖²₂。
- 推理：从 a0 ~ N(0,I) 出发，用 **32 步确定性 Euler 积分** a_{k+1} = a_k + Δt·Fθ(...)，直接返回 a_K。

### 2.5 辅助可供性 grounding
- 几何 token 作为 query 交叉注意 Qwen 隐状态，得到文本条件化的几何 token，聚合为多模态特征后拼接回 PointNet++ 特征传播阶段，经点嵌入头 + sigmoid 解码逐点功能分数。
- 损失：L_aff = L_focal(m̂, m) + λ_dice·L_dice(m̂, m)，其中 focal α=0.5、γ=2.0，λ_dice=1.0。
- 总目标：L = L_act + λ_aff·L_aff，λ_aff = 0.3。

### 2.6 数据体系 OpenDexVerse 与 C2A Recipe
- **对象来源**：Omni6DPose（153 类、4302 实例，类别级对齐的真实扫描物体），筛选出 105 个可灵巧抓取类别；按最大对角线长度做尺寸分级，扩展为 185 个"类别-尺寸"对（1 类 56、2 类 18、3 类 31）。
- **OpenDex-Scale（覆盖）**：用 BoDex 采样+优化合成物理可行的抓取候选，每个候选渲染 3 个物体中心视角，由 VLM 判定是否保持功能并生成任务描述。**刻意"广而不精"**，提供难以靠人工演示获得的语义-几何多样性。
- **OpenDex-Align（对齐）**：每类选 3 个尺寸感知模板，用 Manus 手套遥操作采集高质量任务导向抓取（159 个类别-尺寸对 × 10 = 1590 个），再经 8 步稠密对应迁移（SDF 预处理 → DeepSDF 训练 → 形状重建 → 潜空间插值 → 接触信息提取 → 接触迁移 → 抓取姿态精化 → SAPIEN 仿真 300 步降穿透）扩展到约 2.7 万个抓取。
- **C2A 训练流程**：先在大规模 OpenDex-Scale 上预训练，获得开放词汇感知-动作先验；再在 OpenDex-Align 上继续训练，将分布从"自动合成的可行性"对齐到"具身功能偏好"。两阶段共享同一模型与目标，**不引入额外推理流程**。
- **文本标注**：GPT 作为标注器，输入 3 个抓取视角 + 3 个物体参考视角 + 预计算的手-物接触信息，输出 1 个 functional/非 functional 二分类、5 条抓取导向描述、5 条任务导向指令（JSON 格式，带解析校验与重试）。

## 5. 实验结果

### 5.1 主结果（开放词汇任务导向抓取）
- 在与 DexGraspNet 2.0⋆ 的受控对比中，OpenDexGrasp 在**物理合理性、成功率与感知分数**三类指标上均占优，尤其在**功能性-未见类别**上提升更明显，说明共享隐空间带来的开放词汇泛化能力。
- **可供性 + 优化基线**虽然能获得较高的可供性对齐，但因测试时逐样本 Adam 优化，**推理耗时显著更高**，且成功率与风格多样性不及直接生成的 OpenDexGrasp，印证了"直接建模 p(a | u, I, P)"相对"级联 + 优化"的效率与质量优势。
- 在**非功能性-未见类别**上，方法同样保持稳定的抓取成功率，说明共享隐空间并未因功能监督而牺牲通用抓取能力。

### 5.2 消融实验
- **去掉可供性辅助监督**：点级功能区域可解释性下降，功能性抓取的感知分数与成功率下降，但非功能性抓取基本不变，说明 L_aff 主要贡献于任务对齐而非通用抓取。
- **去掉语言隐状态（改用句级文本嵌入）**：在未见动词与部件名上退化明显，验证"使用 Qwen 隐状态而非最终文本回复"对开放词汇泛化的必要性。
- **去掉米制尺度坐标**：物体尺寸可观测性受损，抓取姿态在跨尺寸泛化上变差。
- **C2A 两阶段训练**：仅用 OpenDex-Scale 预训练时成功率尚可但功能偏好弱；仅用 OpenDex-Align 时功能对齐好但开放词汇覆盖不足；两阶段结合取得最佳平衡，说明"广覆盖 + 精对齐"的互补性。
- **流匹配步数**：32 步 Euler 是质量与效率的折中点，步数过少时物理合理性下降，步数过多收益递减。

### 5.3 真机实验
- 在 Sharpa Wave Hand + Franka + RealSense 平台上，对 5 个已见 + 5 个未见类别进行评估，OpenDexGrasp 的成功率高于 DexGraspNet 2.0⋆ 基线，尤其在需要保留功能区域的物体（如水壶、洗发水、刷子）上优势更明显。
- 真机流程中"多次采样 + 人工剔除"引入了人工筛选，成功率不能完全等同于端到端自主抓取成功率，作者对此作了说明。

### 5.4 定性结果
- 可视化显示，方法能够针对同一物体在不同指令下产生不同的抓取姿态（如"握住水壶把手" vs "握住瓶身"），体现了语言条件化的功能区分。
- 可供性热力图与最终接触区域高度一致，说明共享隐空间确实将语言、几何与动作耦合到同一表征中。

- **手部模型单一**：方法在 22 自由度手上验证，未讨论跨手型（如多指、不同自由度）的迁移能力。
- **任务复杂度**：当前聚焦"抓取姿态生成"，未涉及抓取后的连续操作（如倒水、递刀的动作执行），功能一致性仅在抓取层面验证。
- **未来方向**：扩展到闭环操作、跨手型泛化、减少对 VLM 标注的依赖、以及更高效的推理与训练方案。

## 8. 总体评价

OpenDexGrasp 的核心价值在于**把"功能可供性"与"灵巧抓取"从级联流水线重构为同一条件分布的两个监督视角**，并用共享隐空间 + 流匹配生成实现。这一视角转换既缓解了误差传播，又避免了测试时检索/优化带来的效率瓶颈，与当前"统一多模态表征 + 生成式动作建模"的趋势一致。数据侧的 OpenDexVerse 与 C2A Recipe 用"广而不精的合成 + 精而不广的遥操作"互补，为开放词汇功能抓取提供了可扩展的数据范式。主要不足在于算力信息缺失、真机评估规模有限、以及尚未覆盖抓取后的连续操作，这些也是该方向后续研究可以自然延伸的空间。
