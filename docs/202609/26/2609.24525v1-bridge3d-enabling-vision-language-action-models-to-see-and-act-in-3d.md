## 摘要
视觉-语言-动作（VLA）模型通过大规模多模态预训练在机器人操作中展现出显著的泛化能力。然而，VLA模型主要基于以2D为中心的观测进行训练，这本质上限制了其进行精确空间操作的能力。先前方法通过引入隐式空间先验来增强3D感知，但仍缺乏显式几何引导。本文提出Bridge3D，将隐式和显式3D几何引导同时集成到预训练的2D VLA模型中，使其能够在3D中“看见”和“行动”。Bridge3D引入两种策略：1）隐式融合，利用3D基础模型的特征丰富视觉token，以提升在3D中的“看见”能力；2）显式条件化，将动作去噪与显式3D语义场相结合，以实现在3D中的“行动”。此外，我们利用所提出的逐层线性探测来提高学习效率。实验表明，Bridge3D相较最先进方法取得了更优性能。在RoboTwin 2.0基准上，Bridge3D比π0高出14.0个百分点，而在真实世界实验中，它比Spatial Forcing高出11.7个百分点。这些结果证明了Bridge3D在高精度和空间敏感的操作任务中具有强大能力。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable generalization in robotic manipulation via large-scale multimodal pretraining. However, VLA models are mainly trained on 2D-centric observations, which inherently constrains their capacity for precise spatial manipulation. Previous methods enhance 3D awareness by introducing implicit spatial priors, but still lack explicit geometry guidance. In this paper, we propose Bridge3D that integrates both implicit and explicit 3D geometry guidance into pre-trained 2D VLA models, enabling them to ''see'' and ''act'' in 3D. Bridge3D introduces two strategies: 1) Implicit Fusion, which enriches visual tokens with features from 3D foundation models to improve ''seeing'' in 3D; 2) Explicit Conditioning, which integrates action denoising with an explicit 3D semantic field to achieve ''acting'' in 3D. Furthermore, we utilize the proposed layer-wise linear probing to improve learning efficiency. Experiments show that Bridge3D achieves superior performance against state-of-the-art methods. On the RoboTwin 2.0 benchmark, Bridge3D exceeds $π_0$ by 14.0 percentage points, while in real-world experiments, it outperforms Spatial Forcing by 11.7 percentage points. These results demonstrate Bridge3D's strong capabilities in high-precision and spatial-sensitive manipulation tasks.

## 1. 核心问题与整体含义

- **研究动机**：VLA（Vision-Language-Action）模型虽借助大规模多模态预训练在机器人操作中展现出强泛化能力，但主流模型（如 RDT、GR00T-N1.5、π0 等）主要依赖 **2D RGB 观测**，其视觉 token 来自 2D VLM，天然缺乏空间几何信息，难以支撑高精度、空间敏感的操作任务。
- **问题定义**：作者将这一现象形式化为 **“3D 感知—动作鸿沟”（3D perception-to-action gap）**，并指出它体现在两个耦合瓶颈上：
  - **感知瓶颈**：VLM 视觉 token 缺乏空间几何信息；
  - **动作瓶颈**：精确动作生成需要显式几何引导。
- **现有方法局限**：
  - 隐式对齐类（如 Spatial Forcing、Evo-0）只增强感知侧表示，未把动作生成显式锚定到度量 3D 空间；
  - 显式注入类（如 PointVLA）多用点云编码器压缩为紧凑表示，损失原始几何结构；
  - 原生 3D 策略（如 SpatialVLA）需专门架构设计，不易兼容已有预训练 VLA。
- **整体含义**：论文提出统一框架 Bridge3D，让预训练 2D VLA 同时具备 3D 的“看”（感知）与“动”（控制）能力，从而修复被破坏的空间通路。

## 2. 方法论

### 2.1 核心思想
- 在冻结的预训练 2D VLA 上叠加两条互补路径：**Implicit Fusion（隐式融合）** 提升 3D 感知，**Explicit Conditioning（显式条件化）** 为动作去噪提供显式几何引导；并用 **逐层线性探测** 决定显式模块插入位置，兼顾效果与学习效率。

### 2.2 Implicit Fusion（隐式融合）
- **双流 token 编码**：
  - 语义流：预训练 VLM 编码器 Φ_VLM 处理多视角 RGB，得到语义 token z^VLM_v ∈ R^{L×C}；
  - 几何流：冻结的 3D 基础模型 VGGT 作为 Φ_3D，从多视角联合观测中提取几何 token z^3D_v ∈ R^{L×D}，并重采样到 patch 级对齐。
- **Token-wise 残差融合**：用两层 MLP 构成的残差适配器 Γ: R^D → R^C 将几何特征映射到 VLM 隐空间，再做逐 token 相加：
  - `z^fuse_v = z^VLM_v + Γ(z^3D_v)`
- **设计要点**：残差相加保持 VLM 预训练表示空间不被破坏，同时注入细粒度几何线索；附录对比显示该方式优于 Concat Fusion 与 Cross-Attention Fusion。

### 2.3 Explicit Conditioning（显式条件化）
- **3D 语义场构建**：
  - 从头部相机 RGB-D 观测出发，用 Grounded-SAM 生成实例掩码（只保留机器人与被操作物体），用 DINOv3 提取密集特征图；
  - 按 D3Fields 方式将 2D 特征 lift 到 3D，得到点场 `F = {(p_i, f_i)}_{i=1}^N`；
  - 操作相关点与背景点分别降采样至 N_m = 1536、N_e = 256，最终表示 F ∈ R^{N×(3+D)}，把低层几何与高层语义绑定。
- **3D 条件化动作生成**：
  - 动作隐状态 f_act 与 VLM 特征融合后，双臂场景下分成两路，用末端执行器嵌入 e_arm 经 FiLM 调制：`ˆf_act = γ(e_arm) ⊙ f_act + β(e_arm)`；
  - 对 query/key 施加 **3D RoPE**：`Q = RoPE3D(ˆf_act, P_ee)`，`K = RoPE3D(F_pts, P)`，`V = F_pts`，其中 P_ee 与 P 分别是机器人坐标系下末端执行器与场景点云的三维坐标；
  - 通过 **spatial cross-attention** 让动作隐状态查询 3D 场点：`CrossAttn = Softmax(QK^T/√d)V`，从而把动作生成约束在度量 3D 工作空间内。

### 2.4 Layer-wise Linear Probing（逐层线性探测）
- 冻结 VLA backbone，在每个 DiT block 的隐状态上训练线性岭回归，预测机器人末端执行器的 3D 坐标；
- 探测结果显示：浅层误差低，**#7–#11 层误差急剧上升**，说明深层表示逐渐转向高层动作建模、几何感知退化；
- 因此仅在 **#7–#11 块**插入空间 cross-attention 模块，避免冗余并防止破坏语义一致性。

### 2.5 训练配置
- VLM backbone 冻结，仅优化残差适配器与 action expert；AdamW，学习率 1×10⁻⁴。

- **数据效率高**：约 **6.1× 更少训练样本**即可达到 74% 成功率，50 条演示下达 98%。
- **隐式与显式强耦合**：

- **隐式与显式强耦合（消融证据）**：
  - 组件消融显示，去掉 Implicit Fusion（w/o IF）或去掉 Explicit Conditioning（w/o EC）都会造成明显掉点，且两者叠加的完整模型收益大于任一单独模块，说明“3D 感知增强”与“3D 动作锚定”并非可互相替代的冗余设计，而是分别作用于感知侧与动作侧的两条互补通路。

  - 点语义消融显示，去除点级语义（仅保留低层几何）或替换为 PointNet++ 紧凑编码，都会降低成功率，支持“低层几何 + 高层语义绑定的 3D 语义场”这一设计选择。
- **插入层位置敏感**：层位置消融中，**#7–#11** 效果最佳，浅层（1,3,5）与更深处（23,25,27）均较差。这与逐层线性探测发现的“#7–#11 处几何信息急剧退化”相互印证，说明显式几何引导应施加在“几何尚未被高层动作语义淹没”的过渡层，过早会干扰底层视觉特征、过晚则无从挽救已丢失的空间信息。
- **注意力行为可解释**：可视化显示，动作 token 的空间 cross-attention 主要落在与被操作物体及末端执行器相关的点上，而非均匀铺满整个场景，说明 3D 语义场确实被用作“动作查询的几何索引”，而非被当作附加的全局上下文。

## 7. 局限与问题

- **对 3D 基础模型与外部感知模块的依赖**：方法强依赖 VGGT 提供几何 token、Grounded-SAM + DINOv3 构建 3D 语义场。这些模块的精度、泛化域（如透明、反光、可变形物体）与推理开销都会直接传导到策略上，论文未给出这些模块失效时的鲁棒性分析。
- **推理速度代价**：真实世界推理从 RDT 的 6 Hz 降到 3.46 Hz（约 1.7× 开销），对高频闭环或动态任务可能构成瓶颈；论文仅报告了 5 步 DPM-Solver++ 与 chunk=64 的配置，未讨论精度—速度权衡曲线或实时性优化（如缓存 3D 场、异步感知）。
- **真实实验覆盖有限**：仅 6 个桌面任务、单一主平台（XMAN-R1），且未报告多次随机种子下的方差与统计显著性检验，49.0% 的平均成功率虽相对提升显著，但绝对水平仍偏低，任务难度与失败模式的分解不足。
- **消融规模偏小**：部分消融（组件消融 5 个任务、点语义/编码器消融仅 2 个任务、数据效率仅 Grab Roller 单任务）样本较窄，结论的普适性有待更大规模验证；数据效率的“6.1× 更少样本”也主要基于单一任务的缩放曲线外推。
- **表述与可复现细节不足**：论文未给出总训练时长、各任务训练迭代数、真实数据采集与标注成本；部分表格数字（如不同任务子集下的“最高成功率”）在正文中缺乏明确说明，容易引起误读；PointVLA 在 Table 1 中大量任务缺项也削弱了横向对比的完整性。
- **几何条件化的形式限制**：3D RoPE 与 spatial cross-attention 目前以机器人坐标系下的点坐标为条件，隐含假设场景静态、点云在动作 chunk 内不发生变化；对接触式、遮挡变化剧烈的任务（如插拔过程中的物体位移）如何持续更新 3D 场，论文未展开讨论。

## 8. 整体评价与启发

- **问题定位清晰且有价值**：把“2D VLA 缺乏空间几何”拆解为感知瓶颈与动作瓶颈两个耦合子问题，并指出仅做隐式对齐或仅做显式注入都不足以修复通路，这一分析框架对后续“给 2D VLA 补 3D”的工作具有通用参考意义。
- **方法论上“冻结 + 轻量旁路”的工程范式务实**：不改动 VLM backbone、只训练残差适配器与 action expert，使方法能作为插件式模块迁移到 RDT、GR00T-N1.5 等不同 VLA 上，并在两个 backbone 上都取得一致增益，这一点比绝对精度提升更有推广价值。
- **逐层线性探测作为“该在哪里注入”的经验工具**：用线性探测定位几何信息退化层，再据此决定显式模块插入位置，是把“可解释性诊断”转化为“架构设计决策”的一个简洁范例，可迁移到其他需要跨层注入外部信息的场景。
- **隐式 + 显式的分工值得借鉴**：隐式融合负责在 token 层面补充细粒度几何线索，显式条件化负责在去噪过程中把动作约束到度量空间，两者在层次上（特征级 vs. 生成级）互补，而非简单堆叠。
- **尚待回答的问题**：3D 场是否能在长时序、动态场景中在线更新；推理开销能否通过异步/缓存降到实时；在更大规模真实数据上，几何先验与数据规模之间的替代关系如何变化——这些是该方向后续值得深入的方向。

## 9. 可复现性与复现建议

- **可复现的部分**：仿真 benchmark（RoboTwin 2.0）、本体（Aloha-AgileX）、演示数量（每任务 50 条）、评测协议（clean/randomized 各 100 trials）、优化器与学习率（AdamW，1×10⁻⁴）、硬件（4×RTX 4090 训练、单卡推理）、推理配置（DPM-Solver++ 5 步、chunk=64）均已明确，主要实验在给定代码与数据下具备复现基础。
- **信息缺口**：总训练时长、各任务迭代数、batch size、3D 语义场的降采样具体实现细节（N_m=1536、N_e=256 的选取依据）、VGGT 与 DINOv3 的具体版本/权重、真实任务的演示采集与成功判定标准，论文未完整披露，复现时需额外假设。
- **建议**：若要复现，应优先确认 VGGT 几何 token 与 VLM patch 的严格对齐方式、3D RoPE 中末端执行器坐标 P_ee 的坐标系定义与时序对齐（是当前帧还是动作目标位姿），以及双臂 FiLM 调制中 e_arm 的构造方式——这三点对结果影响最大，也最容易在实现中产生偏差。
