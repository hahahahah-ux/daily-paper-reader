## 摘要
灵巧操作需要长期前瞻与快速反应控制。Vision-Language-Action（VLA）模型虽擅长高层推理，却往往缺乏对物理动力学和空间感知的细粒度理解。相反，World-Action Models（WAMs）通常因迭代生成而受困于高推理延迟。这些缺陷导致关键的时间错位：模型意图无法适应快速的物理接触变化。为克服这一根本瓶颈，我们提出 LiMA——一种异步双系统生成框架，系统性地将意图规划与反应执行解耦。LiMA 将计算组织为多尺度层级：慢系统负责稀疏的长期时空意图生成，而快系统专注于密集的高频运动细化。为使稀疏意图预测与密集动作轨迹对齐，我们引入 Latent Schrödinger Bridge Coupling 机制，将细化建模为熵正则化的概率传输过程。通过异步解耦，LiMA 相比 Cosmos-Policy 将推理延迟降低了 45.8%。在涵盖多个时间范围的六项双臂灵巧操作任务上评估，LiMA 实现了 70.8% 的总体成功率和 78.9% 的平均子任务成功率，同时在未见场景中保持性能。项目网站为 https://ccdcs.github.io/LiMA_repo/

## Abstract
Dexterous manipulation demands long-term foresight and rapid reactive control. Vision-Language-Action (VLA) models, while proficient in high-level reasoning, often lack a fine-grained understanding of physical dynamics and spatial perception. Conversely, World-Action Models (WAMs) typically suffer from high inference latency due to iterative generation. These deficiencies result in a critical temporal misalignment where the model's intent fails to adapt to rapid physical contact changes. To overcome this fundamental bottleneck, we propose LiMA, an asynchronous dual-system generative framework that systematically decouples intent planning from reactive execution. LiMA organizes computation into a multi-scale hierarchy: a slow system handles sparse long-horizon spatiotemporal intent generation, while a fast system focuses on dense high-frequency motion refinement. To align sparse intent predictions with dense action trajectories, we introduce a Latent Schrödinger Bridge Coupling mechanism that formulates refinement as an entropy-regularized probabilistic transport process. LiMA reduces inference latency by 45.8% compared with Cosmos-Policy via asynchronous decoupling. Evaluated across six bimanual dexterous manipulation tasks spanning multiple horizons, LiMA achieves an overall success rate of 70.8% and an average subtask success rate of 78.9%, while maintaining performance in unseen scenarios. The project website is available at https://ccdcs.github.io/LiMA_repo/

## 2. 方法论

### 2.1 核心思想
- 采用**多尺度层级 + 双 DiT 架构**：慢系统负责稀疏长时程时空意图生成，快系统负责稠密高频动作精修；两者通过**隐空间薛定谔桥（Latent Schrödinger Bridge）**在噪声层面耦合，而非简单的特征拼接。

### 2.2 统一多模态表征
- 视觉：预训练 **Wan2.1 时空 VAE tokenizer** 压缩三视角（头部自中心 + 左右腕部）观测为视觉 token。

- 潜张量布局：`Z ∈ R^{B×C×Nslot×H×W}`，其中 C=16，Nslot=8，H=W=28；Dreamer 与 Refiner 使用**兼容的 slot 集合**，使意图潜变量可被直接消费，无需额外对齐网络。

### 2.3 Future Dreamer（慢系统）
- 从预训练 **Cosmos-Predict2-2B** 初始化以继承物理世界先验，再在任务示教上微调。
- **非对称条件化设计**：视觉 token 构成主去噪流，语言嵌入通过 **AdaLN** 调制 Transformer 激活。
- 输出长时程意图表征 `Z_int = [Z_vis_future, Z_act_future]`，包含想象的多视角视觉潜变量与粗糙宏动作先验。

### 2.4 Motion Refiner（快系统）
- 从零训练的 **1B 参数 Transformer**，专注细粒度运动协调。
- **解耦条件化**：分别处理想象视觉潜变量、粗糙动作先验与实时本体状态；粗糙动作先验沿动作时域复制以初始化精修轨迹。
- **时空自适应调制（Spatiotemporal Adaptive Modulation）**：对每个相机槽 i，将在线视觉 token 与想象视觉先验融合：
  `T_mod^(i) = γ(Z_vis_future^(i)) · LayerNorm(T_vis^(i)) + β(Z_vis_future^(i))`
  其中 γ、β 为由想象视觉先验预测的仿射缩放与偏移参数，从而在注入长时程视觉意图的同时保留对局部场景变化的敏感性。
- 输出联合执行潜变量 `Z_out = [Z_act_out, Z_vis_out]`（近端动作块 + 短时程自中心视觉潜变量）。

### 2.5 Latent Schrödinger Bridge Coupling（核心耦合机制）
- 采用 **I²SB** 框架，构建边界到边界的熵正则化最优传输路径。
- **边界定义**：结构化源边界 `X1 ≡ Z_int`（Dreamer 意图先验）；干净目标边界 `X0 ≡ Z_out^(0)`（Refiner 执行潜变量）。
- **中间态采样**（条件高斯后验）：
  `Z_out^(t) ~ q(Z_out^(t) | Z_out^(0), Z_int) = N(μ_t(Z_out^(0), Z_int), Σ_t I)`
  均值路径 μ_t 在两端点间插值，Σ_t 控制桥上的随机扰动；t=0 与 t=1 时随机项消失。
- **训练目标**：让 Refiner 直接从意图条件化的桥态预测干净执行潜变量：
  `L_refine = E[||Ẑ_out^(0) − Z_out^(0)||²]`，`Ẑ_out^(0) = G_θ(Z_out^(t), t, Z_int)`
- **推理初始化**：真实执行时干净边界不可得，改由意图条件化先验初始化：`Z_out^(1) ~ N(Z_int, σ₁²I)`，降低采样负担并保持与长时程意图一致。

### 2.6 异步双系统协调
- 引入周期执行间隔 `ΔT ∈ Z⁺`：
  - 当 `t mod ΔT = 0`：触发计算量大的 Dreamer 刷新战略意图先验 `Z_int,t`，Refiner 同步消费该先验生成执行块。
  - 当 `t mod ΔT ≠ 0`：Dreamer 冻结输出（旁路推理），轻量 Refiner 仍以全频率运行，持续融合最新观测与缓存的战略先验。
- 实现"**稀疏规划 + 稠密高频精修**"，在环境扰动下保持鲁棒反应性。

### 2.7 训练目标与正则化
- Dreamer 目标 `L_dream`：联合空间 score-matching 损失，监督长时程动作块与三视角未来视觉潜变量。
- **边界噪声注入（BNI）正则化**：以概率 p_bni 向 Refiner 接收的意图潜变量注入小幅噪声（`γϵ_noise`，γ≪1），提升 Dreamer–Refiner 接口在实时推理下的鲁棒性。
- 总目标：`L_total = L_dream + λ L_refine`。

## 3. 实验设计

### 3.1 硬件平台

### 3.2 任务与 Benchmark
- **6 项真实世界双臂灵巧操作任务**，每任务采集 **100 条专家遥操作示教**，每任务评测 **20 次试验**：
  - 短时程：Stack Cup（叠杯）、Roll T-shirt（折叠 T 恤）
  - 长时程：Cook Rice（煮饭）、Make Sandwich（做三明治）、Make Coffee（冲咖啡）、Assemble Package（组装包装）
- **评价指标**：
  - **SR（Success Rate）**：整体任务完成率（需按正确顺序完成全部目标）。
  - **PSR（Progress Success Rate）**：基于各任务预定义进度阶段（P1–P5）的子任务完成比例，用于细粒度失败定位。
  - **推理时间**：生成一个可执行动作块的平均耗时。

### 3.3 对比基线
- **VLA 模型**：GR00T N1.6、InternVLA-A1（后者扩展至 56-DoF 动作维度，从 InternVLA-A1-3B 初始化）。
