## 摘要
任务规划在长时程操作中连接高层指令与可执行行为，然而现代视觉-语言-动作（VLA）系统往往将这一中间结构隐式处理。现有的思维链（CoT）规划器也倾向于依赖粗粒度的任务级标注，或逐 token 串行化长推理轨迹。我们提出 X-Planner，一种规划前端，同时处理具身推理的监督与表示问题。我们的规划数据以分层粒度组合 Ego、UMI 和遥操作数据，并具有依赖于来源的标注深度。接管时刻标注和人工设计的失败用于监督进行中的错误识别。在模型方面，共享的 VLM 骨干网络提供两种事件结构化规划形式：离散接口输出可解释的事件状态，潜变量接口则通过 Staircase Decoding 在交错的 Transformer 深度间传递连续的 CoT 状态。冻结的潜变量到文本重建目标为潜表示提供语义锚点。离线两步规划评估中，X-Planner 在 BERTScore-F1 和基于评判器的 Overall 分数上均在四个被评估模型中位列第二。在真实机器人实验中，X-Planner 分别优于所评估的基线。这些结果刻画了规划文本质量与下游执行表现。

## Abstract
Task planning bridges high-level instructions and executable behavior in long-horizon manipulation, yet modern Vision-Language-Action (VLA) systems often leave this intermediate structure implicit. Existing chain-of-thought (CoT) planners also tend to rely on coarse task-level annotations or serialize long reasoning traces token by token. We present X-Planner, a planning front-end that addresses both the supervision and representation of embodied reasoning. Our planning data combine Ego, UMI, and teleoperation under a hierarchy granularity with source-dependent annotation depth. Takeover-time annotations and human-designed failures supervise ongoing error recognition. On the model side, a shared VLM backbone exposes two event-structured plan forms: a discrete interface that emits interpretable event states and a latent interface that relays continuous CoT states across staggered Transformer depths through Staircase Decoding. A frozen latent-to-text reconstruction objective provides a semantic anchor for the latent representation. Offline two-step planning evaluation places X-Planner second among four evaluated models on both BERTScore-F1 and a judge-based Overall score. In real-robot experiments, respectively, outperforming the evaluated baselines. These results characterize planning-text quality and downstream execution.

## 1. 核心问题与整体含义

- **研究背景**：具身基础模型（VLA）已能较好地把视觉观测与自然语言指令映射为可执行动作，但这一"观测→动作"的直连范式主要适用于短时程、指令明确的技能。
- **核心缺口**：长时程操作需要智能体在发出底层控制命令之前先选择并排序"接地的子目标"，而多数 VLA 系统把这一中间结构**隐式**处理。近期虽有工作引入思维链（CoT）推理，但具身任务规划仍在三个方面是碎片化的：
  - **数据缺口**：常用任务级描述或手写子目标清单，难以界定子目标的起止边界；抓取重试、接触失败、姿态微调等事件结构被一句 "pick up the object" 掩盖。
  - **粒度缺口**：规划器常固定在某一种外部强加的语义粒度（固定文本层级、或预测子目标图像/光流），固定长度分块可能切裂或合并行为。
  - **延迟缺口**：传统 CoT 逐 token 自回归解码，长 rollout 中反复处理重叠的视觉-语言上下文，串行关键路径长且易误差传播；潜空间 CoT 方法也大多保留潜步骤间的自回归依赖。
- **论文含义**：X-Planner 是一个**规划前端（planning front-end）**，在高层指令与下游 world-action 模型之间插入显式的、事件结构化的中间表示，把"具身规划"重新定义为以**动作接地的语义事件**为单位、且同时具备可解释接口与紧凑计算接口的问题。

## 2. 方法论

### 2.1 核心思想：以语义事件为规划单元 + 双规划形式

- 规划单元定义为**语义事件**：一段时间上连贯的可执行行为（伸手、抓取、抬起、放置等），其边界跟随**行为的变化**，从而兼顾语言可读、视频可观测、控制可实现。
- 共享同一个 VLM 骨干（Qwen 系列），暴露两种事件结构化规划形式：
  - **离散形式**：输出可解释的结构化事件状态（JSON 风格）。
  - **潜变量形式**：输出 $K_c$ 个连续推理状态 $\hat{y}_{1:K_c}$，避免规划器内部的逐 token 串行化。

### 2.2 事件结构化规划数据

- 融合三类数据源：**Ego（第一人称）、UMI、遥操作**，共用一套层级：
  - **L3 Task**（回合目标）/ **L2 Subtask**（语义阶段）/ **L1 Action**（可执行原语）/ **L0 Segment**（最细时间跨度）。
  - 遥操作数据含全部四级；Ego 与 UMI 仅到 L1–L3（运动更快，L0 边界难以可靠标注）。**缺失的标注层级不贡献监督，也不作为负标签。**
- **失败感知的进行中监督**：
  - 在干预回合中标注**接管时刻（takeover times）**，为执行中的错误识别提供时间监督。
  - 补充**人工设计的失败演示**，以缓解"单一策略失败分布偏置"问题。
- 结构化状态分三类：初始计划（执行开始）、进行中（当前/下一事件、归一化进度、继续状态、错误识别）、回合结束（最后可用媒体帧 + episode-end 标记）。

### 2.3 文本条件接口

- 令 $H_q$ 为 VLM 隐状态，边界掩码 $m_{txt}$ 选出文本 token 状态，经可学习投影 $P_Q$ 与下游原生文本 MLP $M_T$ 投影：
  - $c_\ell = M_T(P_Q(H_q[m_{txt}]))$
- 该序列与图像 token 一起进入 world-action 模型的交叉注意力层，使规划器能注入场景消歧、任务分解与进度感知的事件上下文，而**不替换下游文本通路**。

### 2.4 Staircase Decoding（阶梯解码）

- 在**中继深度 $N_r$** 处切分 Transformer：下层编码共享的视觉-语言上下文，上层跨推理步专门化。
- 第一个潜位置走完下层产生一个**被所有推理位置共享的中继表示**；上层块随后**并行**更新各潜状态，每个位置使用独立的因果缓存：
  - $\hat{y}_{1:K_c} = F_{stair}(x; N_r)$，其中 $x=(\{V^{(v)}_0\}_v, \ell, h)$
- 实现上是一个耦合到**冻结骨干**的轻量 Mixture-of-Transformers（MoT）分支，由微调后的 VLM 初始化。
- 论文明确声明：这一架构上的串行计算削减**本身并不证明端到端控制延迟更低**，后者还取决于整个执行栈。

### 2.5 冻结的潜变量到文本重建（语义锚点）

- 前缀投影器 $P_{pref}$ 把 $\hat{y}_{1:K_c}$ 映射为冻结轻量语言模型嵌入空间中的软前缀 $z_{1:K_c}$，条件于该前缀自回归重建文本 CoT 轨迹：
  - $P_\phi(r_{1:M_r} \mid z_{1:K_c})$，$L_{CoT} = -\sum_{m=1}^{M_r}\log P_\phi(r_m \mid z_{1:K_c}, r_{<m})$
- **只优化 staircase 推理分支与 $P_{pref}$**，重建模型保持冻结。目标是让潜序列保留高层语义，而非复制特定 token 级隐轨迹；冻结解码器还可把潜计划渲染为文本以供人工检视。

### 2.6 训练目标（三类，角色分离）

- **结构化计划状态监督（SFT）**：对**全部 assistant token** 自回归监督，$L_{SFT} = -\sum_{m\in A}\log p_\theta(y_m \mid x, y_{<m})$，而非只优化下一事件描述或把进度回归成独立标量；caption、进度、继续状态、错误识别在结构化响应中联合学习。
- **文本条件特征对齐**：$L_{align} = \lambda_{align}\|c^{VLM}_\ell - c^{ref}_\ell\|^2$，使规划器表示保持在下游固定接口所期望的特征几何中。
- **Staircase 蒸馏**：即 $L_{CoT}$ 的潜到文本重建，仅更新 staircase 分支与 $P_{pref}$。
- **下游 world-action 模型全程冻结。**

### 2.7 推理部署

- **event mode**：启动时给出初始计划，随新观测更新结构化事件状态；事件描述条件化 world-action 模型，进行中错误识别支持执行监控。
- **unified mode**：staircase 解码器产生 $K_c$ 个连续 CoT 状态，经同一交叉注意力接口条件化定长动作块推理。

- **总体判断（续）**：但论文同时指出，这些增益**不能被归因到 X-Planner 的任何一个具体组件**，因为实验是系统级的、下游 world-action 模型全程冻结、且缺乏消融与方差报告。因此更稳妥的表述是：事件接地的显式规划接口与"更强的长时程行为"之间存在**相关性证据**，而非因果证据。

## 7. 局限与批判性评价

### 7.1 论文自陈的局限

- **因果归因缺失**：无消融，无法区分错误监督数据、离散/潜变量表示、staircase 调度、三类训练目标各自的贡献。
- **架构削减 ≠ 端到端低延迟**：论文主动声明 staircase 的串行计算减少不能直接推断整体控制延迟下降，后者取决于完整执行栈（感知、world-action 模型、通信、控制器）。
- **统计不严谨**：真机无 trial 级数据、无误差棒、无显著性检验；跨任务均值可能掩盖任务级高方差。
- **数据统计的适用范围**：1500 回合分析子集只描述被分析的候选池，**不代表实际训练混合的规模与配比**。
- **算力信息完全缺失**：无 GPU 型号/数量、训练时长、参数规模、显存占用，阻碍成本评估与复现。

### 7.2 外部审视可补充的关切

- **评委—被评对象重叠**：离线 Overall 由 Doubao Judge 给出，而 Doubao 是被比较模型之一。即使评测协议固定，也存在系统性的偏好风险（如对自家输出风格、格式或冗长度的偏好）。论文未做评委一致性检验（如与人类评分或第二评委的对比）。
- **基线的同质性不足**：Qwen、Doubao、kimi3 是通用对话/推理大模型，未必针对具身事件结构化做过适配；与一个专门为事件规划设计、并在三源具身数据上微调的系统比较，优势部分可能来自**训练数据与输出格式适配**，而非方法论本身。理想的对照应包括：同一骨干的定长分块规划器、纯文本 CoT 规划器、以及无显式规划的直接 VLA。
- **指标语义边界**：BERTScore-F1 度量的是与参考标注的语义相似度，论文自己也承认它**不等于任务成功率**；同时"两步规划"的离线协议与真实长时程 rollout 之间的差距未被量化（例如离线分高但真机失败的模式是否常见）。
- **LingBot-VA 的 N/A**：泛化 suite 缺少该基线，使"超出最强可用基线 25.25 个百分点"这一表述的对比集不完整；若 LingBot-VA 在泛化上表现良好，结论强度会下降。
- **U-Scratch 的定位**：作者称其为"系统级参照"，这诚实地限制了归因，但也意味着真机提升只能说明"整条 X-Planner 流水线 + 下游模型"优于"从零训练的定长指令到动作系统"，**不能说明规划接口本身是关键变量**。
- **任务级结果的不一致性**：形状分类低于 U-Scratch（78% vs 82%）、物品配对显著低于 π0.5（36% vs 77%），说明 X-Planner 的优势**并非普适**，可能在需要精细空间关系或配对推理的任务上并不占优。论文未深入分析这些反例的成因（是规划粒度不匹配？还是下游策略的能力瓶颈？）。
- **可解释性与潜变量的张力**：潜变量形式（unified mode）本身不可读，其可解释性依赖一个**冻结轻量语言模型**的重建。重建文本与真实决策过程之间是否存在"合理化"（post-hoc rationalization）风险，论文未做验证（例如重建文本与实际执行事件的一致性度量）。
- **失败感知监督的伦理与偏差**：人工设计的失败演示只能覆盖作者设想的失败模式，真实部署中的长尾失败（传感器遮挡、物体滑落、人类干扰）可能仍未被覆盖；"接管时刻"标注也依赖遥操作者的主观判断，缺少标注者间一致性报告。

## 8. 对后续研究的启示

- **值得借鉴的设计**：
  - 把规划单元锚定在**行为边界**（语义事件）而非固定文本层级或固定时间分块，是一个在语言可读性、视频可观测性与控制可实现性之间取平衡的合理归纳偏置。
  - **双形式接口**（离散 JSON 事件状态 + 连续潜状态）共用同一骨干与同一文本条件接口，使得"可解释模式"与"低延迟模式"可以共享大部分训练信号，这一思路具有工程价值。
  - **冻结下游 + 只训规划前端**的分离式训练，降低了与 world-action 模型耦合带来的不稳定性，也便于把规划器作为即插即用模块替换。
  - **缺失层级不贡献监督、也不作负标签**的处理，是对异构多源数据（Ego/UMI/遥操作）标注深度不齐这一现实问题的务实解法。
  - 用**冻结语言模型重建**来给潜变量加语义锚点，避免潜空间塌缩为无意义向量，是一种低成本的表示正则化。
- **需要补上的实验**：
  - 组件消融：去掉失败监督、改用固定分块、去掉 staircase、去掉 $L_{align}$、去掉 $L_{CoT}$，逐一测量对离线与真机指标的影响。
  - 受控形式比较：离散 vs 潜变量在同一 backbone、同一数据、同一推理预算下的头对头比较（含延迟与成功率）。
  - 端到端延迟测量：从观测到动作的完整时延分解（规划器、通信、world-action 模型、控制器），验证 staircase 的实际收益。
  - 统计规范：多随机种子、trial 级记录、误差棒与显著性检验；评委一致性检验（多评委 + 人类评分相关性）。
  - 更同质的基线：同骨干的 CoT 规划器、定长分块规划器、以及无规划的端到端 VLA。
- **开放问题**：
  - 语义事件的**自动边界发现**：当前依赖标注层级，能否从无标注视频中自监督地发现事件边界？
  - 规划粒度是否应随任务与下游策略能力**自适应**变化，而非固定为事件级？
  - 潜变量的可解释性与忠实性如何验证？
  - 规划器在分布外场景（新物体、新指令组合、人类协作）中的泛化边界在哪里？

## 9. 一句话总结

X-Planner 把具身长时程规划从"隐式 CoT 或固定粒度子目标"重新表述为**以行为边界定义的语义事件为单元、并同时提供离散可读与连续紧凑两种接口**的规划前端；其设计动机清晰、接口设计与数据层级工程扎实、对自身局限的陈述坦诚，但**实验规模小、无消融、无方差报告、算力信息缺失、且评委与被评对象存在重叠**，因此当前证据只足以支持"事件接地规划值得进一步研究"这一较弱结论，尚不足以支撑任一组件有效性的因果主张。
