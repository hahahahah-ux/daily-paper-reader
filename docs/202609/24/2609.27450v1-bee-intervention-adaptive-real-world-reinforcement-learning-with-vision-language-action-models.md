## 摘要
视觉-语言-动作（VLA）模型能够处理长时程操作任务，但其成功往往取决于少数对精度至关重要的阶段，在这些阶段中，毫米级的误差便会使此前取得的全部进展付诸东流。在线强化学习（RL）恰好可以优化这些动作，但在真实机器人上进行自由探索的代价过于高昂，因此人类纠正不可或缺。然而，现有的面向VLA的在线RL方法要么无法纳入此类纠正，要么将其混入不加区分的监督信号之中。然而，人类纠正并非均匀地带有噪声：它们在部分动作维度上是可靠的，而在另一些维度上则存在变化。基于此，我们提出BEE——一个面向冻结VLA的真实世界强化学习的干预自适应框架，使策略能够超越专家模仿（BEyond Expert imitation）。我们将人类纠正不视为需要复现的动作，而是视为关于某一约束的证据：纠正模型（Correction Model）预测人类会如何纠正给定的VLA提议，以及该纠正沿每个动作维度的一致性程度。这种预测出的一致性设定了策略优化中约束在各维度上的紧度：在纠正一致的维度上，策略保持贴近人类；在纠正存在变化的维度上，约束则相应放宽。我们在三个真实世界操作任务和一个LIBERO-Pro仿真任务上，在匹配的在线数据预算下评估BEE。BEE在每项任务上均取得最高成功率，平均达91.2%，而RLT为57.5%、DSRL为42.1%；并在所有真实世界任务上取得最低的人工干预率。

## Abstract
Vision-language-action (VLA) models handle long-horizon manipulation, yet success hinges on a few precision-critical phases where millimeter-scale errors undo all prior progress. Online reinforcement learning (RL) can optimize exactly these actions, but free exploration is far too costly on real robots, which makes human corrections indispensable. However, existing online RL methods for VLAs either cannot incorporate such corrections or fold them into undifferentiated supervision. Yet human corrections are not uniformly noisy but reliable along some action dimensions and variable along others. Building on this, we introduce BEE, an intervention-adaptive framework for real-world RL on a frozen VLA that lets the policy go BEyond Expert imitation. We formulate human corrections not as actions to reproduce but as evidence about a constraint: a Correction Model predicts how a human would correct a given VLA proposal and how consistent the correction is along each action dimension. This predicted consistency sets the per-dimension tightness of a constraint on policy optimization. Where corrections are consistent the policy stays close to the human, and where they vary, the constraint relaxes. We evaluate BEE on three real-world manipulation tasks and one LIBERO-Pro simulation task at a matched online-data budget. BEE attains the highest success rate on every task, 91.2% on average against 57.5% for RLT and 42.1% for DSRL, and the lowest human intervention rate on all real-world tasks.

## 1. 核心问题与研究动机

- **背景痛点**：VLA（视觉-语言-动作）模型具备长时程操作能力，但任务成败往往只取决于少数"精度关键阶段"（如对齐、插入），毫米级姿态误差会让此前所有进展归零。这种脆弱性使在线 RL 极具吸引力——它可以直接优化决定成败的动作。
- **真机约束**：真实机器人上每次 rollout 都消耗时间与硬件寿命，稀疏奖励 + 高维动作块使无约束探索不可行，因此**人类纠正成为稀缺但关键的学习资源**。
- **现有方法的两类缺陷**：
  - DSRL 通过搜索 VLA 隐噪声空间进行引导，**完全没有人类输入接口**。
  - RLT 将人类干预存入共享 replay buffer，并在干预样本上用纠正动作**替换** VLA 提议作为 actor 训练目标，但部署时输入仍来自 VLA——相当于把纠正当作不加区分的模仿监督。
  - SiLRI 虽用状态级不确定性调节模仿强度，但**对所有动作维度一视同仁**（单一标量约束）。
- **核心洞察**：人类纠正并非均匀噪声，而是**在某些动作维度上高度一致、在另一些维度上波动较大**。因此需要"逐维度"而非"逐状态"的约束几何。BEE 的立意是让策略 **BEyond Expert imitation**（超越专家模仿）。

## 2. 方法论

### 2.1 核心思想
- 将人类纠正**不视为要复现的动作，而视为关于约束的证据**：训练一个纠正模型预测"人会怎样改 VLA 提议"以及"该改法在每个维度上有多一致"，用预测一致性设定策略约束在各维度上的松紧。
- 在冻结 VLA 之上只训练一个轻量**残差策略**，既保留 VLA 的长程能力，又允许 RL 在纠正一致的维度上紧跟人类、在波动的维度上放开探索。

### 2.2 关键结构与接口
- **冻结 VLA 双输出**：Extractor 将 VLA 内部特征映射为隐 token $z_t$；Action Expert 输出动作块提议 $\tilde{a}_t$。
- **RL 状态**：$s_t = [z_t \parallel p_t]$（隐 token 拼接本体状态），接口对 $(s_t, \tilde{a}_t)$ 固定不变，梯度不回流 VLA。
- **残差策略**（确定性）：$a_\theta = \tilde{a}_t + \Delta\pi_\theta(s_t, \tilde{a}_t)$。
- **块级 Critic** $Q_\psi(s_t, a_t)$：以 $K$ 步 Bellman 目标做 off-policy TD，目标为 $y_t = R_t + \gamma^K(1-\delta_t)\bar{Q}_\psi(s_{t+K}, a_{t+K})$。

### 2.3 纠正模型（Correction Model）
- 建模纠正残差分布：$q_\phi(\Delta^H_t \mid s_t, \tilde{a}_t) = \mathcal{N}(\mu_\phi(s_t,\tilde{a}_t),\ \Sigma_{\phi,t}=\mathrm{diag}(\sigma^2_\phi))$。
- 仅在演示缓冲区 $B_H$ 上以负对数似然训练：$\mathcal{L}_{corr}(\phi) = -\mathbb{E}_{B_H}[\log q_\phi]$。
- **关键设计**：把 VLA 提议作为显式输入保留，使纠正模型无需从紧凑 RL 状态中"恢复"高维动作，只需建模残差。
- 预测纠正动作 $\hat{a}^H_t = \tilde{a}_t + \mu_\phi$ 作为约束中心。

### 2.4 逐维度不确定性约束与原始-对偶优化
- 归一化马氏偏差：$\rho_\phi = \frac{1}{D}(a_\theta - \hat{a}^H_t)^\top \Sigma_{\phi,t}^{-1}(a_\theta - \hat{a}^H_t)$——一致性高的维度权重被放大，波动大的维度权重被压低。
- 约束优化问题：$\min_\theta \mathbb{E}_B[-Q_\psi(s_t,a_\theta) + \eta\|a_\theta - \tilde{a}_t\|_2^2]$ s.t. $\rho_\phi \le \varepsilon$。
- 引入状态相关乘子 $\lambda_\omega(s_t)\ge 0$（softplus 输出），得鞍点问题 $\min_\theta \max_{\lambda\ge 0} \mathcal{L}$；actor 损失经 $1+\lambda_\omega(s_t)$ 归一化以稳定大乘子更新：
  $\mathcal{L}_\pi(\theta) = \mathbb{E}_B\left[\frac{-Q_\psi + \eta\|a_\theta-\tilde{a}_t\|_2^2 + \lambda_\omega(s_t)\rho_\phi}{1+\lambda_\omega(s_t)}\right]$
- 乘子由对偶上升训练：$\mathcal{L}_\lambda(\omega) = -\mathbb{E}_B[\lambda_\omega(s_t)(\rho_\phi - \varepsilon)]$。
- 注意：人类纠正**塑造的是约束方式，而非直接作为策略目标**。

### 2.5 训练流程（Algorithm 1）
1. 预训练 $q_\phi$；用 20 个预采集纠正回合播种 $B_H$。
2. 每个 chunk 边界：得到 $(s_t,\tilde{a}_t)$，计算 $a_\theta$；有人干预则执行 $a^H_t$，否则执行加探索噪声的 $a_\theta$。
3. 全量 transition 存入 $B_R$，被纠正的额外复制进 $B_H$（保留 $\tilde{a}_t$ 与 $a^H_t$ 的配对）。
4. 从 $B_R$/$B_H$ **等比例**采样，更新 critic、actor、乘子；**每 M 个新纠正样本**才对 $q_\phi$ 做 $N_M$ 步更新（保守调度以缓解小缓冲区上的方差坍塌）。
5. 部署/评估时关闭干预与噪声，仅残差策略 + 冻结 VLA，**无额外推理成本**。

## 3. 实验设计

### 3.1 任务与 Benchmark
- **三个真实世界双臂任务**（每个 30–60 秒，约 900–1800 控制步 @30 Hz）：

  - **零食悬挂**（Snack Hanging）：可变形包装袋挂上架子，抓取形变导致目标位姿逐回合漂移；8 维动作，$K=20$。
  - **布料对齐**（Cloth Aligning）：布料形变使最终接触与释放成为决定性步骤；16 维动作，$K=10$，使用基于 SAM3 的视觉稠密奖励。
