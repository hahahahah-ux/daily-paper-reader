## 摘要
长时程操作要求机器人在响应移动物体的同时，记住已不在视野中的线索。然而，视觉-语言-动作（VLA）策略通常依赖最新观测，而刷新其视觉上下文通常需要另一次昂贵的视觉-语言模型（VLM）前向计算。我们提出 D$^2$-VLA，在预训练 VLA 的 KV 缓存接口处结合双记忆与双频控制。D$^2$-VLA 使用分块因果 KV 缓存来增量编码观测，并在不同时间注意力模式的引导下，为 VLM 和动作专家构建各自独立的历史 KV 读取视图。在周期性的 VLM 更新之间，一个门控适配器将新鲜视觉特征融入最新的、以历史为条件的 KV 块，同时一个短的快速记忆队列支持动作重规划。我们提出 DOMINO-Long，一个包含十项任务的基准，要求机器人在操作移动物体时利用更早的视觉线索。D$^2$-VLA 在 DOMINO 上取得 29.3% 的完整任务成功率，而 $π_{0.5}$ 为 9.6%，PUMA 为 17.2%；在 DOMINO-Long 上为 60.0%，而二者分别为 35.4% 和 20.6%。它在八项真实机器人任务上提升了成功率，并在 LIBERO-Long 上达到 97.5%，在 RoboTwin 2.0 上达到 74.3%。

## Abstract
Long-horizon manipulation requires robots to remember cues that are no longer in view while responding to moving objects. Yet vision-language-action (VLA) policies often rely on the latest observation, and refreshing their visual context typically requires another costly vision-language model (VLM) pass. We present D$^2$-VLA, which combines dual memory and dual-frequency control at the KV-cache interface of a pretrained VLA. D$^2$-VLA uses block-wise causal KV caching to encode observations incrementally and, guided by distinct temporal attention patterns, constructs separate historical KV read views for the VLM and action expert. Between periodic VLM updates, a gated adapter incorporates fresh visual features into the latest history-conditioned KV block, while a short fast-memory queue supports action replanning. We introduce DOMINO-Long, a ten-task benchmark requiring robots to use earlier visual cues when manipulating moving objects. D$^2$-VLA achieves complete-task success rates of 29.3\% on DOMINO, compared with 9.6\% for $π_{0.5}$ and 17.2\% for PUMA, and 60.0\% on DOMINO-Long, compared with 35.4\% and 20.6\%, respectively. It improves success rates on eight real-robot tasks and reaches 97.5\% on LIBERO-Long and 74.3\% on RoboTwin 2.0.

# D²-VLA 论文总结

## 1. 核心问题与整体含义

- **研究动机**：长时程动态操作要求机器人同时具备两种能力——(1) 记住已离开当前视野的任务线索（如物体初始位置、演示顺序、颜色指令）；(2) 对持续移动的物体做出快速响应。
- **现有 VLA 的缺陷**：以 π₀.₅ 为代表的现代 VLA 推理循环是"无记忆 + 频率耦合"的——每次动作预测主要依赖最新观测，刷新动作专家的视觉上下文需要再次执行完整的 VLM 前向，代价高昂。
- **核心矛盾**：保留更长的 VLM 历史上下文会增加注意力计算成本；频繁刷新 VLM 又非常昂贵。因此需要回答：能否在预训练 VLA 的原生 KV 接口上协同设计记忆访问与更新频率？
- **关键发现**：论文通过实验观察到明显的时间注意力不对称性——VLM 依赖更广泛的历史进行语义推理，而动作专家主要关注近期观测中携带运动信息的少量 token 子集（token 集中现象）。这一发现直接催生了"双记忆、双频率"的设计。

## 2. 方法论

### 2.1 核心思想

- 在 π₀.₅ Base 的 KV 缓存接口上，将**记忆选择**与**更新频率**解耦：VLM 与动作专家各自拥有独立的历史 KV 读取视图；VLM 低频刷新，动作专家高频重规划。
- 三大组件：**分块因果 KV 缓存**（增量编码观测）、**双记忆**（消费方特定的历史 KV 选择）、**双频率控制**（慢速 VLM 刷新 + 快速门控适配器重规划）。

### 2.2 关键技术细节

- **分块因果时序建模**：将当前观测与最多 N−1 个历史观测组成观测块序列，块内双向注意力、块间因果注意力。推理时仅编码最新观测块，复用历史 KV（`K_t = K_{<t} ⊕ K_c`），每个历史块只编码一次。
- **双记忆（Dual-Memory）**：
  - 基于在线注意力统计，VLM 和动作专家使用独立的 `Read_VLM` 和 `Read_act` 从完整存储块中选择历史视觉 token，保留指令 token。
  - 选择仅在推理时进行，训练使用未压缩 KV；存储块保持完整，仅临时读取视图被压缩。
  - 每个消费者维护独立的注意力重要性分数，按层取最大值得到跨层共享的选择索引；按块和相机分别执行 Top-K 选择，默认保留比例 0.7。
- **双频率（Dual-Frequency）**：
  - VLM 每 V 个环境步刷新一次，动作每 E 步重规划一次，V 为 E 的整数倍（主配置 V=3E，E=H=25）。
  - **动态特征适配器**：在两次 VLM 刷新之间，将当前图像特征与归一化时间偏移 δ_t 编码后，通过 32 个可学习查询池化，读取最新慢速锚点 KV 块，预测全块 K/V 残差，经门控（初始化为 arctanh(0.1)，即初始为恒等更新）加回锚点，生成完整精炼 KV 块。
  - **快记忆队列**：容量 N_fast=2，存储最近的精炼块；每次慢速刷新时清空并重置其分数。
  - 专家条件：慢速步使用 `Read_act(Q_slow) ⊕ K_c`；中间步使用 `Read_act(Q_fast) ⊕ Z̃_t`，两个队列从不拼接。
- **训练**：从 π₀.₅ Base 全量微调，仅使用 flow-matching 损失，无辅助适配器损失；每个样本含 1 个慢锚点分支 + 2 个后续快分支，共 3 条动作分支；在线 KV 选择在训练时禁用。

### 2.3 算法流程（文字概述）

1. 每步观测当前图像、状态与指令，计算是否到达慢速刷新时刻 `t = V⌊t/V⌋`。
2. 若为慢速刷新：保留最多 N_slow−1 个完整慢块，用 `Read_VLM` 选择历史后编码当前块，更新慢队列与前缀分数；专家条件使用慢速读取。
3. 否则：用适配器从慢锚点生成精炼块，插入快 FIFO；专家条件使用快速读取。
4. 固定 KV 条件执行 flow-matching 去噪（10 步 Euler），生成动作块并执行前 E 个动作。
5. 用本次前向的注意力统计更新对应消费者的重要性分数；慢速刷新后清空快 FIFO 及其分数。

### 3.2 对比方法

- **DOMINO**：OpenVLA、RDT-1B、π₀、π₀.₅、InternVLA-M1、VLA-Adapter、π₀-FAST、OpenVLA-OFT、StarVLA-OFT、PUMA。

### 3.3 评价指标

- **Complete-task Success Rate (SR)**：仅当全部任务要求满足（对象身份、顺序、最终构型）才计成功。
- **Manipulation Score (MS)**：DOMINO 协议下的操作质量指标，惩罚越界、碰撞等行为。

## 4. 资源与算力

- 论文明确提到 DOMINO-Long 训练使用 **8 张 A100 80GB GPU**，采用 8 路 FSDP、20 个 dataloader worker、prefetch factor 2、BF16 参数精度 / FP32 计算精度。
- 训练预算：**DOMINO 75,000 次优化更新**；**DOMINO-Long 与真实世界任务 50,000 次更新**；全局 batch size 为 40 个 anchor 组（对应 120 条动作分支）。
- 优化器为 AdamW，峰值学习率 2.5×10⁻⁵，cosine 衰减，1000 步 warmup，EMA 系数 0.99。
- **训练时长未明确说明**（论文只给出更新步数与硬件配置，未报告 wall-clock 时间或总 GPU 小时数）。
- 推理侧使用 10 步 Euler flow 积分；未报告推理 GPU 型号（推测与训练环境一致）。

## 5. 实验数量与充分性

### 5.1 实验规模

- **主实验**：DOMINO（35 任务逐项报告）、DOMINO-Long（10 任务逐项）、LIBERO-Long（10 任务）、RoboTwin 2.0（50 任务逐项）、真实机器人（8 任务，4 静态 + 4 动态）。
- **消融实验**：
  - 组件消融（DOMINO）：π₀.₅ → +Causal Training → +Dual-Frequency，SR 9.6% → 16.1% → 29.3%。
  - 历史 KV 保留率扫描：1.0、0.9、0.8、0.7、0.6、0.5、0.4、0.3（DOMINO）。
  - 更新频率消融：(V,E) = (50,25) 与 (75,25)，对比无高频路径。
  - 精度–内存–延迟权衡：与单帧 π₀.₅、Full KV Cache 在三个基准上比较。
  - 注意力模式可视化分析（LIBERO、RoboTwin 各两个 chunk）。

### 5.2 充分性与公平性评价

- **充分性**：覆盖动态仿真、长时动态、静态长时程、真实机器人和 50 任务双臂基准，任务类型多样；消融实验覆盖了核心组件、压缩率和更新频率，较为系统。
- **客观性**：对比方法均为公开代表性工作；DOMINO 的 π₀.₅ 和 PUMA 基线数据转录自原论文，D²-VLA 使用统一 retention ratio 0.7。
- **公平性**：静态基准上禁用高频路径、保留完整 KV 训练与在线选择，使比较聚焦于记忆机制本身；真实机器人任务报告 complete-task SR 而非中间成功率，标准严格。
- **潜在问题**：部分对比方法（如 MemoryVLA）仅在真实机器人子集和 LIBERO-Long 上比较，未在 DOMINO/DOMINO-Long 上全面对比；DOMINO 上部分任务成功率绝对值很低，方差可能较大。

## 6. 主要结论与发现

- **DOMINO**：D²-VLA 达到 **29.3% SR / 40.6 MS**，比 π₀.₅ 高 19.7 个百分点 SR、14.4 点 MS，比 PUMA 高 12.1 点 SR、5.6 点 MS。
- **DOMINO-Long**：平均 **60.0% SR**，超过 π₀.₅（35.4%）24.6 点、PUMA（20.6%）39.4 点；在 Motion Memory（80%）、Color Memory（86%）、Screen Cue（90%）等任务上优势显著。
- **真实机器人**：在 8 个任务上均优于 π₀.₅ 和 MemoryVLA；静态任务平均 SR 71.25% vs. π₀.₅ 51.25% vs. MemoryVLA 40%。
- **静态基准**：LIBERO-Long **97.5%**（π₀.₅ 92.4%、MemoryVLA 93.4%）；RoboTwin 2.0 **74.3%**（π₀.₅ 57.0%）。
- **效率**：相比 Full KV Cache，D²-VLA 在三个基准上均以更低延迟和峰值显存取得更高 SR（如 LIBERO-Long 延迟 184.69→174.92 ms，显存 10,738→9,654 MiB）；相比单帧 π₀.₅，显存仅增加约 1–2%。
- **消融结论**：双记忆带来 +6.5 点，双频率进一步带来 +13.2 点；高频路径在两个设置下均优于无高频路径（27.6%/29.3% vs. 16.1%）。

## 7. 优点

- **问题定位精准**：首次明确提出 VLM 与动作专家在历史上下文需求和更新频率上的"时间不对称性"，并据此设计统一框架。
- **方法优雅且非侵入**：完全在预训练 VLA 的 KV 缓存接口上操作，不改变模型主体结构，兼容 π₀.₅ 生态。
- **双记忆设计巧妙**：存储块保持完整、仅压缩临时读取视图，兼顾信息保留与计算效率；在线注意力统计无需额外前向或离线先验。
- **双频率机制实用**：门控适配器初始化为恒等更新，训练稳定；快 FIFO 容量小（2 块），开销可控。
- **基准贡献**：DOMINO-Long 填补了"长时程记忆 + 动态物体操作"联合评估的空白，任务设计明确分离信息获取与执行阶段。
- **实验覆盖广**：从 35 任务动态仿真到 50 任务双臂基准、再到真实机器人，证据链较完整。

## 8. 不足与局限

- **绝对成功率仍偏低**：DOMINO 上 29.3% 的完整任务成功率意味着多数任务仍失败；DOMINO-Long 60% 也有较大提升空间。
- **高频路径的适用范围受限**：在 LIBERO-Long 和 RoboTwin 2.0 上高频路径被禁用，说明该机制主要针对动态场景，静态基准上贡献有限。
- **算力报告不完整**：仅给出 GPU 型号、数量与更新步数，未报告实际训练时长、总 GPU 小时数或推理硬件细节。
- **对比公平性有改进空间**：MemoryVLA 未在 DOMINO 系列上对比；部分基线数据直接转录自原论文，训练/评估配置可能存在差异。
- **在线选择的额外开销**：虽然论文声称选择不增加额外前向，但 Top-K 选择、分数维护与跨层聚合仍带来实现复杂度和潜在延迟；论文中 Full KV 与 Ours 的延迟差异部分归因于此。
- **泛化性验证有限**：真实机器人仅 8 个任务、单一 Unitree G1D 平台；DOMINO-Long 为仿真环境，未验证真实动态场景下的长时记忆。
- **任务随机化不完全**：论文自述某些环境属性（目标布局、相机配置）保持固定，可能残留未控制的视觉或行为线索。
- **适配器设计复杂**：包含编码器、池化器、两阶段 editor、逐层门控等，超参数较多（查询数、editor 宽度、门控初始化等），复现和调参成本较高。
- **对慢锚点的依赖**：快路径的所有精炼块均从同一慢锚点生成，若慢锚点质量差或 V 过大，中间步的视觉条件可能退化。
