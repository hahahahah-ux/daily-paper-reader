## 摘要
视觉-语言-动作（VLA）模型提供了一个统一框架，可将高层语义信息落地为底层机器人动作，从而支持跨多样任务的可扩展机器人操作。然而，现有VLA模型缺乏显式机制来解耦双臂的状态与意图，导致非预期的跨臂干扰，从而降低任务执行成功率。为解决这一问题，我们提出一种对称的双臂专家（DAE）架构，构建于共享的视觉-语言模型（VLM）主干之上，并采用解耦的、臂特定的专家塔。专家选择通过两阶段双臂意图路由方案进行，其中第一阶段依据显式语言指令路由专家，第二阶段则依据隐式视觉语义路由专家。此外，我们引入一个轻量级任务进度预测模块，利用分块前时序特征与本体感觉和视觉观测的语义表示之间的交叉注意力，准确估计逐帧任务完成进度。该模块促进任务进度同步，以支持协作多机器人任务的协调调度。实验结果表明，我们的模型在双臂意图路由和跨臂干扰解耦方面有效，并进一步提供了从单臂任务到双臂任务（以及反向）的涌现技能泛化的初步证据，以及跨臂运动域技能迁移的证据。

## Abstract
Vision-Language-Action (VLA) models provide a unified framework for grounding high-level semantic information into low-level robot actions, enabling scalable robotic manipulation across diverse tasks. However, existing VLA models lack explicit mechanisms to disentangle the states and intents of the two arms, leading to unintended cross-arm interference that degrades task execution success. To address this issue, we propose a symmetric Dual-Arm Expert (DAE) architecture built upon a shared Vision-Language Model (VLM) backbone with decoupled, arm-specific expert towers. Expert selection is carried out through a two-stage dual-arm intent routing scheme, in which experts are routed either by explicit language instructions in the first stage or by implicit visual semantics in the second stage. Moreover, we introduce a lightweight task progress prediction module that leverages cross-attention between the pre-chunk temporal features and semantic representations of proprioceptive and visual observations to accurately estimate frame-wise task completion progress. This module facilitates task progress synchronization to support coordinated scheduling for collaborative multi-robot tasks. Experimental results demonstrate the effectiveness of our model in dual-arm intent routing and the disentanglement of cross-arm interference, and further provide preliminary evidence of emergent skill generalization from single- to dual-arm tasks (as well as the reverse), together with cross-arm motion-domain skill transfer.

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体架构（TAO-DA）

- **输入**：多视角视觉观测（1 张自视角 + 2 张可选的左右腕部末端视角）、语言指令、本体感觉状态。
- **编码**：每张图像由同一预训练 SigLIP 视觉编码器编码；视觉 token 与语言 token 拼接后送入**冻结的 Eagle-2.5-VL 主干**，得到融合表示 `E_VL ∈ R^{N×D}`。
- **关键设计**：`E_VL` 作为 DAIR 使用的**未掩码**多模态表示；路由完成后，在 VLM 输入端**掩掉非活动臂的末端视角 token**，构造用于动作条件的表示。自视角在所有模式下始终保留。本体感觉特征单独编码，臂专属状态与动作 token 由对应动作通路处理。
- **训练细节**：每个任务的指令从语义等价表达池中随机采样。

### 2.2 DAIR：语言与视觉引导的双臂意图路由

- **意图表示**：`r = [r_L, r_R] ∈ {0,1}²`，合法类别为仅左 `[1,0]`、仅右 `[0,1]`、双臂 `[1,1]`；作为三分类问题训练，交叉熵损失 `L_route = -log p_c`。三分类接口可**避免推理时出现非法的"无臂"向量 `[0,0]`**。
- **第一阶段：规则式语言意图解析**
  - 识别显式臂相关表达（"left arm"、"right arm"、"both arms"、"left hand"、"right hand"），映射为 `r̂_rule`；当同时出现双臂表达时，**双臂意图优先**，返回 `[1,1]`。
  - 不使用空间表达推断臂意图；若无显式臂相关表达，返回内部**无匹配码 `[0,0]`**，用于触发第二阶段，而非作为合法意图。
- **第二阶段：模型式多模态意图预测**
  - 对 `E_VL` 做 LayerNorm，用可学习 query 做池化：`f = MHA(q, E_norm, E_norm)`；MLP 输出 3 个 logits，取 argmax 映射回二值接口得到 `r̂_model`。
- **进度保持机制（hold）**：推理时，当任务已推进到一定程度后可保持先前意图。规则为：若 `r̂_rule ≠ [0,0]` 则用规则结果；否则若上一时刻意图不可用或预测进度 `p̂_t ≤ τ_hold` 则用模型结果；否则保持 `r̂_{t-1}`。该机制用于稳定路由决策，**与部署层任务调度器相互独立**。

### 2.3 DAE：双臂专家模块（三种变体对比）

- **Single-Tower（统一式）**：两条臂的状态与动作 token 拼接进同一个 DiT。
- **Dual-Mask（弱解耦）**：共享 DiT 参数，但通过**臂模式注意力掩码**限制信息流。输入含四组臂专属 token `X_in = [X^L_state, X^R_state, X^L_action, X^R_action]`；对每个执行模式 `m ∈ {left, right, dual}` 定义二值掩码 `M^(m)`，在自注意力 logits 上叠加 `log M^(m)`（零项抑制对应注意力 logit）。左臂模式下仅左臂状态与动作组可互相注意，右臂对称，双臂模式允许跨组注意；多模态任务表示仍共享。
- **Dual-Tower（强解耦）**：两条**参数独立**的分支 `T_L`、`T_R`，各自拥有状态编码器、动作 tokenizer、DiT 与动作解码器。`X^k_state = Enc^k_state(s_k)`，`X^k_action = Tok^k_action(a^k_α)`，两条输入序列 `X^L_in`、`X^R_in` 独立处理并以路由后的多模态上下文为条件。训练时由标注 `r` 选择 `T_L`、`T_R` 或两者，推理时替换为 DAIR 的 `r̂`。臂级组件参数量约翻倍，但冻结 VLM 与 DAIR 共享。单臂执行时只有被选中的塔参与；双臂执行时两塔均接收共享任务上下文。
- **路由条件动作生成与监督**：`L_act = r_L·L^L_FM + r_R·L^R_FM`，其中 `L^k_FM` 为第 k 臂的流匹配目标；单臂样本仅一项激活，双臂样本两项均用，非活动塔不接收动作监督。
- **臂条件视角掩码**：设 `V = [V_ego, V_L, V_R]`，则 `Ṽ(r) = Mask(V, r)`，`Ẽ_VL(r) = VLM(Ṽ(r), E_lang)`。`r = [1,0]` 时掩掉右腕视角，反之对称；`r = [1,1]` 时两视角均保留；自视角在所有模式下均可用。

### 2.4 任务进度预测模块

- 用 GRU 编码 DiT 时序特征 `H = [h_1,…,h_T]` 得 `S = GRU(H)`；再以交叉注意力融合 VLM 表示 `Z = MHA(S, E_VL, E_VL)`；回归头预测 `p̂_t`，**监督目标为归一化的轨迹时间**而非语义完成度。
- 推理时该估计同时支撑 DAIR 的 hold 机制与部署层调度器，促进任务进度同步以支持协作多机器人调度。

## 3. 实验设计
