## 摘要
世界动作模型（WAMs）将预测性视觉建模与动作生成耦合起来，通常依赖固定去噪步数的迭代去噪。然而，操作任务包含对生成误差敏感度各异的动作块：关键动作要求精确，而敏感度较低的动作则允许以更少去噪步数更快生成。在此，我们提出 AnyStep World Action Model，一个用于可调预算预测和场景依赖计算分配的通用框架。我们的预算对齐教师轨迹蒸馏利用显式冻结教师转移和共享低秩适配器训练区间条件流映射，支持从一步预测到多步细化的动作生成。基于这一能力，一个轻量级风险-收益调度器从单次一步预览中预测基于教师曲率的难度和特定预算下的学生-教师保真度，选择预测能满足风险自适应保真度要求的最小预算。我们在 RoboTwin 2.0 上，在三种广泛使用的 WAM（Motus、FastWAM 和 LingBotVA）上评估了我们的框架。我们的方法分别将平均去噪步数减少了 60.2%、49.8% 和 85.28%，同时保持基线任务成功率。特别地，我们的 AnyStep 训练在一步去噪预算下显著提升了模型性能，在 Motus、FastWAM 和 LingBotVA 上分别将任务成功率提高了 7.07%、12.08% 和 8.94%。在六个真实世界操作任务上的实验进一步验证了其有效性。

## Abstract
World-action models (WAMs) couple predictive visual modeling with action generation, typically relying on iterative denoising with a fixed denoising steps. However, manipulation tasks contain actions chunks with varying sensitivity to generation errors: critical actions require precision, while less sensitive actions allow faster generation with fewer denoising steps. Here we introduce AnyStep World Action Model, a general framework for tunable-budget prediction and scene-dependent computation allocation. Our budget-aligned teacher-trajectory distillation trains interval-conditioned flow maps using explicit frozen-teacher transitions and shared low-rank adapters, supporting action generation from one-step prediction to multi-step refinement. Building on this capability, a lightweight risk-benefit scheduler predicts teacher-curvature-based difficulty and budget-specific student-teacher fidelity from a single one-step preview, selecting the smallest budget predicted to satisfy risk-adaptive fidelity requirements. We evaluate our framework on three widely used WAMs Motus, FastWAM, and LingBotVA using RoboTwin 2.0. Our method reduces average denoising steps by 60.2%, 49.8%, and 85.28%, respectively, while maintaining baseline task success rates. In particular, our AnyStep training substantially improves model performance under a one-step denoising budget, increasing task success rates by 7.07%, 12.08%, and 8.94% on Motus, FastWAM, and LingBotVA, respectively. Experiments on six real-world manipulation tasks further validate its effectiveness.

## 二、方法论

### 2.1 核心思想

- 用**冻结教师轨迹的显式位移**作为有限区间监督信号，替代对演化学生求导/有限差分的流映射监督，从而在一次适配中支持多个去噪预算。
- 训练一个轻量**风险-收益调度器**，从**单次一步预览**中同时预测难度（风险）与各预算下的学生-教师保真度（收益），据此选最小可行预算，并把该预览**回收复用**到选定轨迹中，避免额外去噪、在线教师调用与候选 rollout。

### 2.2 预算对齐积分流映射蒸馏（Budget-Aligned Integral Flow-Map Distillation）

- **流映射参数化**：把去噪分支改造为区间条件形式 `f_θ(x_t, t, r; c) = x_t − (t − r)·u_θ(x_t, t, r; c)`，其中 `u_θ` 为区间平均速度，条件同时含起点 `t` 与终点 `r`，因此单模型可支持不同转移区间与推理预算。
- **教师积分目标**：对冻结教师用细粒度参考求解器跑出轨迹 `x^T_t`，定义区间 `[r, t]` 上的教师平均速度 `v^T_{t,r} = (x^T_t − x^T_r)/(t − r)`。该目标由教师两端点决定，**与学生在参数上无关**，不需要对学生做 Jacobian-vector product（MeanFlow）或中心有限差分（AnyFlow）。
- **预算对齐区间采样**：先采样候选预算 `K ∈ K`（本文 `K = {1,2,…,10}`），再采样区间索引 `i`，取 `(t, r) = (t^(K)_i, t^(K)_{i+1})`，使训练区间与推理调度 `S_K` 完全一致。
- **四项损失（均用按模态维度归一化的回归形式 R）**：
  - `L_int`：预算对齐的教师区间监督（核心项），权重 λ_int = 0.30；
  - `L_FM`：标准流匹配的瞬时速度监督（`r = t`），保留局部预测能力，λ_FM = 0.20；
  - `L_end`：到 `r = 0` 的端点监督，含专门的 `(t, r) = (1, 0)` 一步预览监督，λ_end = 0.50；
  - `L_rec`：从**分离梯度**的学生生成状态 `x̄_t` 出发的纠正性续推监督；对每个 `K > 1`，从该回收状态重新启动冻结教师并积分到 0，得到预算专属参考轨迹，纠正目标为 `(x̄_t − x^{T,K}_r)/(t − r)`，λ_rec = 0.20。
- **适配方式**：仅优化 LoRA（rank = 128，加在注意力、前馈、时间条件投影上），原始骨干与 VLM 权重全部冻结，**同一组适配器跨任务、跨预算共享**；对仅在推理时去噪动作的模型（FastWAM）只保留动作损失。

### 2.3 自感知风险-收益预测（Self-Aware Risk-Benefit Prediction）

- **风险监督（预算无关的难度代理）**：沿教师原始轨迹统计两种速度变化量——方向不一致 `κ_dir`（1 − 相邻速度余弦相似度）与相对速度变化 `κ_rel`（RMS 差 / RMS 速度，带数值保护 ε）；对每模态取两项统计在训练集上的**百分位秩均值** `ρ_m = ½[F_dir(κ_dir) + F_rel(κ_rel)]`，代表相对去噪难度，而非任务失败概率。
- **收益监督（预算相关保真度）**：对每个候选预算 `K`，离线执行与部署一致的"预览回收"路径，得到学生执行速度 `v^exec_{K,i}`；对第一区间与教师原始轨迹的 `v^T_{1,t^(K)_1}` 比较，后续区间与"从回收状态重启一次"的教师纠正目标比较。用 `ψ(p,q)` 结合方向一致（余弦）与归一化速度一致（指数 RMS 项），再以指数衰减权重 `w_i = 2^{−i}/Σ2^{−j}` 加权（更重视早期去噪区间），得到 `S_{K,m} ∈ [0,1]`。
- **调度器结构与训练**：输入为一步预览的隐藏特征摘要（视频/动作末块特征、视频/动作预测速度、归一化机器人状态、池化指令嵌入）；经特征投影成上下文 token，与一个风险查询和 `B = |K|` 个预算查询一起送入**4 层共享 Transformer**；风险头（MLP + sigmoid）输出 `ρ̂_m`，收益头（共享 MLP + sigmoid）输出 `B × |M|` 矩阵 `Ŝ_{K,m}`；两个头均用 Smooth L1 损失对离线标签监督，权重各为 1.0。教师与学生在此阶段均冻结。

### 2.4 风险条件自适应推理（Risk-Conditioned Adaptive Inference）

- **单次预览**：一次评估得到 `u_pre = u_θ(x_1, 1, 0; c)`、`x̂_0 = x_1 − u_pre` 及调度器特征。
- **风险条件阈值**：对每个活跃模态，`τ_m = τ^easy_m + (τ^hard_m − τ^easy_m)·ρ̂_m`，即预测难度越高，保真度要求越严格。默认阈值取离线训练集视频相似度的第 10/20 百分位、动作相似度的第 20/80 百分位。
- **预算选择**：选满足所有活跃模态 `Ŝ_{K*,m} ≥ τ_m` 的**最小** `K*`；若无预算达标，则取预测收益总和最大的预算。
- **预览回收**：若 `K* = 1` 直接返回 `x̂_0`；否则用原始噪声把 `x̂_0` 重噪到第一个中间时刻 `t^(K*)_1`，再执行剩余 `K* − 1` 次区间更新——**总去噪 NFE 恰好为 K***，无在线教师、无候选 rollout，调度器仅增加约 2.5–3.0 ms 开销。
