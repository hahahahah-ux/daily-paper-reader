## 摘要
预测下一状态是世界模型建模物理动力学的核心范式，强调预测保真度。随着世界模型演变为世界-动作模型（WAMs），现有方法在训练前仍将下一状态固定为 RGB、单一潜在特征或预定义目标的静态组合，从而将动作学习限制在某一特定表示所保留的归纳偏置内。为解决这一局限，我们提出 CF-WAM，一种动态下一状态预测框架，它对同一未来的视觉、语义、几何和交互投影进行采样，将其标准化为统一的视频形式，并基于这些投影监督一个统一的 WAM。这些投影所揭示的与动作相关的约束会在训练步骤中累积，迫使 WAM 捕获能够支撑同一动作条件未来的多种投影的底层状态转移结构。这种动态机制还为人类与机器人学习提供了自然的跨具身动力学参考框架。通过在不同下一状态参数化之间联合学习，异构的人类和机器人经验可以绕过外观差异，直接促进共享的状态转移学习，从而提升跨具身泛化能力。实验表明，CF-WAM 既提升了训练效率和最终控制性能，又能将人类经验有效转化为策略收益。CF-WAM 在 RoboCasa-GR1 上取得了最先进的性能，平均成功率为 82.50%，同时在 LIBERO-Plus 上达到 82.65%，在真实世界评估中最高达到 84.00%。

## Abstract
Predicting the next state is a core paradigm of World Models for modeling physical dynamics, emphasizing prediction fidelity. As World Models evolve into World-Action Models (WAMs), existing methods still fix the next state before training as RGB, a single latent feature, or a static combination of predefined targets, thereby constraining action learning to the inductive biases preserved by a particular representation. To address this limitation, we propose CF-WAM, a dynamic next-state prediction framework that samples visual, semantic, geometric, and interaction projections of the same future, standardizes them into a common video form, and supervises a unified WAM across these projections. The action-relevant constraints exposed by these projections accumulate across training steps, forcing WAM to capture the underlying state-transition structure that supports multiple projections of the same action-conditioned future. This dynamic mechanism also provides a natural cross-embodiment dynamics reference frame for Human and Robot learning. By jointly learning across different next-state parameterizations, heterogeneous Human and Robot experience can bypass appearance differences and directly contribute to shared state-transition learning, improving cross-embodiment generalization. Experiments show that CF-WAM improves both training efficiency and final control performance, while translating Human experience effectively into policy gains. CF-WAM achieves state-of-the-art performance on RoboCasa-GR1 with an average success rate of 82.50%, while reaching 82.65% on LIBERO-Plus and up to 84.00% in real-world evaluations.

## 1. 核心问题与研究动机

- **背景**：预测下一状态是世界模型（WM）建模物理动力学的核心范式，强调预测保真度；世界-动作模型（WAM）进一步把未来预测与动作生成耦合，使策略能基于"预期未来"行动。
- **角色转变**：在 WM 中未来状态只需忠实预测演化；在 WAM 中它还必须强调"可被动作改变或直接影响动作选择"的动态因素。因此，单纯由预测保真度驱动的状态未必最适合动作学习。
- **核心问题**：**当未来预测开始服务于动作时，下一状态应当表示什么？**
- **现有做法及其局限**：
  - 主流方法在训练前就把下一状态固定为未来 RGB 观测、单一潜特征，或预定义目标的静态组合。
  - 不同表示各有偏置：视觉保留大量与动作弱相关的细节；语义弱化空间关系；几何丢失物体身份与交互进程；交互丢失全局上下文。对某任务有效的状态未必对另一任务最优。
  - 静态多目标组合需在每步维持多个预测空间，增加容量与计算，并让模态特征竞争有限的动作条件容量，稀释真正与动作相关的状态变化。
- **人类数据带来的放大效应**：人类数据是可扩展经验的重要来源，但人机在视角、外观、具身、动作空间上差异巨大；固定未来表示容易被具身特定外观主导，导致只能用"人类预训练+机器人后训练"或配对数据，限制了人类数据的有效利用。
- **总体含义**：论文主张下一状态不应是预定义的监督模态，而应是**同一动作条件未来在不同抽象层级上的动态描述**（借鉴 Platonic Representation Hypothesis），据此提出 **CF-WAM（Confluent Foresight WAM）**。

## 2. 方法论

### 2.1 核心思想

- 视觉、语义、几何、交互四种状态是同一未来状态流形 $s_{t+\Delta}\in\mathcal{M}$ 的不同投影 $y^k_{t+\Delta}=\phi_k(s_{t+\Delta})$，描述同一物理转移但保留互补的动作相关信息。
- **"固定学习世界动力学的模型，而不固定描述未来状态的坐标系"**：表示选择由固定的设计决策变为动态的训练变量。

### 2.2 三项关键设计

1. **动态未来状态参数化**
   - 每个训练样本仅从投影集合 $\mathcal{R}=\{\text{Vis, Sem, Geo, Int}\}$ 中采样一个 $k\sim p_{\mathcal{R}}(k)$（实现中为均匀 $1/4$）。
   - $k$ 不是独立预测任务，而是"描述同一未来转移所用的坐标系"；不同投影的互补约束在训练步之间累积，共同塑造同一个 WAM。
2. **生成作为统一建模接口**
   - 四种投影均表述为**视频形式的生成目标**，经**同一个冻结 VAE**（Wan2.2 VAE）编码，由同一个 WAM 预测，不引入表示专用分支或额外预测头（几乎无额外参数）。
   - 多样性放在监督侧，统一性留在生成模型侧。
3. **无配对人-机世界-动作学习**
   - 人机经验无需 episode / 任务 / 时间层面的配对，直接在**转移层级**共享监督。

### 2.3 世界-动作建模（MoT 架构）

- **混合 Transformer（MoT）**：世界专家（Wan2.2-TI2V-5B 视频扩散 Transformer）+ 动作专家（ActionDiT）。
- 每层两专家各自计算 Q/K/V，沿序列维拼接做混合注意力：
  - $Q=[Q_w;Q_a],\ K=[K_w;K_a],\ V=[V^w;V^a],\ H=\mathrm{Attn}(Q,K,V;M)$
  - 注意力后按序列边界切分回各自专家，参数不共享。
  - **非对称掩码**：视频 query 只看视频 KV；动作 query 看全部视频+动作 KV（动作可读当前观测与预测状态，噪声动作 token 不扰动视频生成）。
- **流匹配**：世界与动作分支各自独立的流时间与调度器，仅通过 MoT 混合注意力耦合：
  - $z_\tau=(1-\sigma_\tau)z_0+\sigma_\tau\epsilon_z$，$a_\tau=(1-\sigma^a_\tau)a_0+\sigma^a_\tau\epsilon_a$
  - 速度目标 $v^*_z=\epsilon_z-z_0$，$v^*_a=\epsilon_a-a_0$
  - 总损失 $L_{\text{WAM}}=\lambda_w L_{\text{world}}+\lambda_a L_{\text{action}}$（实现中均为 1.0）
- **时间调度**：$\sigma(u)=\frac{5u}{1+4u},\ u\sim U(0,1)$；训练时间离散为 1000 个位置，损失权重按高斯形（中心 500）加权。

### 2.4 动态未来状态预测

- **投影实例化**：RGB 视频、DINOv3-PCA 语义视频、深度视频、手-物分割视频。
- **投影条件化生成**：$c^k=c_{\text{task}}\oplus c^k_{\text{rep}}$，其中 $c^k_{\text{rep}}$ 形如 "Predict the depth video."，经既有语言条件通路注入，无需模态专用路由模块。
- **所有投影共享同一当前 RGB 帧作为首帧条件**（严格时间对齐），保证起点世界状态一致，仅"未来如何表示"不同。
- **动态生成目标**：
  - $p_\theta(y^k_{t+1:t+H},a_{t:t+H_a}\mid o^{\text{RGB}}_t,c^k),\ k\sim p_{\mathcal{R}}(k)$
  - $L_{\text{dyn}}=\mathbb{E}_{k\sim p_{\mathcal{R}}(k)}\mathbb{E}_{D_k}[\lambda_w L_{\text{world}}(E_{\text{VAE}}(\tilde{y}^k),c^k)+\lambda_a L_{\text{action}}(a\mid o^{\text{RGB}}_t,c^k)]$
  - 关键不是每步增加更多预测目标，而是**持续改变监督同一未来转移的坐标系**。

### 2.5 无配对人-机联合学习

- 采样 $(d,k)\sim p_D(d)\,p_{\mathcal{R}}(k\mid d)$：$d$ 决定经验来源，$k$ 决定监督坐标系。
- **动作空间分解** $a=[a_{\text{EE}},a_J]$：人类腕部与机器人末端执行器映射到同一 18 维 EE 空间（双手各 3 维位置 + 6 维连续旋转），关节维度仅由机器人轨迹监督。
- **源相关动作掩码** $M^d_a=\mathrm{diag}(I_{\text{EE}},\,0\,/\,\mathbb{1}[d=R]I_{J})$，损失 $L^d_{\text{action}}=\mathbb{E}\big[\|M^d_a r^d_a\|_2^2/\mathrm{tr}(M^d_a)\big]$；人类样本缺失关节维**被掩码而非置零**，避免伪监督。
- 联合目标：$L_{\text{HR}}=\mathbb{E}_{(d,k)}\mathbb{E}_{D_{d,k}}[\lambda_w L_{\text{world}}+\lambda_a L^d_{\text{action}}]$。

### 2.6 关键实现细节

- 视频专家：30 层，残差宽度 3072，24×128 注意力头，FFN 14336，3D RoPE(t,h,w)，约 5.000B 参数。
- 动作专家：30 层，残差宽度 1024，FFN 4096，1D RoPE，约 1.021B 参数；动作输入为 16 步 × 47 维 chunk，每步一个 token。
- 注意力空间统一为 3072 维，两专家无需特征适配器；总参数约 6.021B（不含冻结 VAE 与文本编码器）。
- Token 预算：0.8 s 窗口、20 Hz、17 帧观测；取 5 个关键帧 {0,4,8,12,16}，224×224；VAE 潜变量 48×2×28×28，patchify (1,2,2) → 392 视频 token + 16 动作 token = **408 联合 token**；语言上下文（umT5-XXL，≤128 token，4096 维）+ 1 个本体感知 token 经交叉注意力注入。
- 推理：20 步 Euler 求解器（shift=5），每步把当前 RGB 潜变量重新写回第一时序位置。

### 2.7 数据构建要点

-

- **机器人数据**：保留原始 RGB 观测、动作 chunk、本体感知与语言指令，作为"源内配对"监督的基础；其动作标签同时覆盖 EE 与关节维度。
- **人类数据**：仅使用 RGB 视频与可提取的手部/腕部运动，经重定向映射到统一 18 维 EE 空间；因缺乏机器人关节遥测，关节维在损失中被掩码，不参与梯度。
- **投影视频的离线生成**：语义（DINOv3 特征 PCA 投影）、深度、手-物分割三类未来视频由现成模型在原始 RGB 上离线预计算，作为监督目标 $y^k$，训练时仅做 VAE 编码，不引入额外在线模型。
- **首帧一致性**：所有投影共享同一当前 RGB 帧 $o^{\text{RGB}}_t$ 作为条件与生成起点，确保不同坐标系描述的是同一物理转移，而非不同时间片段。
- **采样策略**：$p_{\mathcal{R}}(k\mid d)$ 对机器人数据可覆盖全部四种投影，对人类数据受可用标注限制（如深度/分割缺失时退化为可用子集），从而在不强制配对的前提下扩大有效监督面。
- **数据规模与配比**：人机样本按转移层级混合，未做 episode/任务/时间对齐；配比作为超参调节，用于平衡两类具身对动作条件的贡献。

## 3. 实验设计与主要结果

### 3.1 评估设置

- **任务与基准**：在机器人操作任务上评估策略成功率与泛化性，覆盖分布内与分布外（新物体、新视角、新指令）设置。
- **对比基线**：固定未来表示（RGB 预测、单潜特征、静态多目标组合）的 WAM/WM 变体，以及"人类预训练 + 机器人后训练"的配对式两阶段方案。
- **消融维度**：投影集合大小与组合、投影采样是否动态、是否加入人类数据、动作掩码设计、是否共享冻结 VAE 与统一生成接口。

### 3.2 关键发现（按论文主张组织）

- **动态坐标系优于固定坐标系**：在所有对比中，动态采样单一投影的 CF-WAM 与静态多目标组合性能相当或更优，且参数量与每步预测空间不随投影数增长，说明"改变坐标系"比"堆叠预测目标"更高效。
- **互补性可跨训练步累积**：语义与几何投影在空间关系与物体身份上互补，交互投影补充手-物接触进程，四者共同约束同一 WAM；去除任一投影均带来不同程度退化，且退化模式与其偏置一致。
- **统一生成接口的必要性**：将四类投影统一为视频形式并共享冻结 VAE，避免了模态专用分支与特征竞争，验证"多样性在监督侧、统一性在模型侧"的设计。
- **无配对人-机学习的增益**：在无 episode/任务配对条件下引入人类数据，仍能提升泛化与鲁棒性；关节维掩码避免了人类样本的伪监督，是稳定联合训练的关键。
- **具身差异的缓解**：由于未来表示不再被固定为具身特定外观，人类数据不再仅作为"预训练初始化"，而能持续参与转移层级的联合优化。

### 3.3 效率与实现分析

- **参数与计算**：除冻结 VAE 与文本编码器外，总参数约 6.021B；动态投影不增加预测头，额外开销主要来自离线生成投影视频与 VAE 编码。
- **注意力与 token 预算**：408 联合 token（392 视频 + 16 动作）在 MoT 中实现跨专家信息流，动作专家可读取预测状态而不扰动视频生成，兼顾耦合与稳定。
- **推理一致性**：20 步 Euler 求解、每步回写当前 RGB 潜变量，保证闭环执行中条件与预测的时间对齐。

## 4. 贡献与定位

- **概念贡献**：提出"当未来预测服务于动作时，下一状态应表示什么"的问题，并给出以动态、多坐标系描述同一动作条件未来的答案。
- **方法贡献**：CF-WAM 将下一状态从预定义监督模态变为训练变量，通过投影采样、统一生成接口与转移层级人机共享，实现无配对联合世界-动作学习。
- **工程贡献**：基于 MoT 的非对称掩码与双流匹配耦合、统一 VAE 接口、动作空间分解与源相关掩码，为可扩展的人机联合训练提供可复现路径。

## 5. 局限与未来方向

- **投影集合的完备性**：当前四类投影（视觉、语义、几何、交互）是人为选定，未必覆盖所有与动作相关的动态因素；如何自动发现或扩展投影空间仍待研究。
- **离线投影的依赖**：语义、深度、分割目标依赖现成模型离线生成，其质量与偏差会传导至 WAM；在线或自监督投影生成值得探索。
- **人类数据标注限制**：人类侧仅能可靠提供 EE 与部分交互信息，关节与精细力觉等维度缺失，掩码虽避免伪监督，但也限制了可学习信号。
- **评测范围**：主要在操作任务上验证，向更复杂、长时序、多具身场景的推广需进一步验证。
- **与 Platonic 假设的关系**：方法借鉴"同一底层状态存在多投影"的假设，但其在具身数据上的成立程度与边界仍需理论与实证检验。

## 6. 总体评价

CF-WAM 的核心洞见在于把"下一状态表示"从静态设计决策重新表述为随训练动态变化的坐标系选择：同一动作条件未来在视觉、语义、几何、交互等抽象层级上被交替监督，使世界模型学到的是跨投影共享的动态结构，而非某一模态的偏置。配合统一的视频生成接口与转移层级的人机共享，该方法在不增加预测分支、不要求配对数据的条件下，将人类经验从"预训练素材"提升为"联合监督来源"。其价值不仅在于具体性能，更在于为世界-动作模型的状态设计与人机联合学习提供了一个可扩展、可检验的新范式。
