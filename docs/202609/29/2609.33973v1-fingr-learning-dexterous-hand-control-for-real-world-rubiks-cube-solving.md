## 摘要
用单只灵巧手操控魔方是对持续、富接触控制的一项具有挑战性的测试：手必须在保持魔方稳固的同时连续执行层转动。每次转动都要求一些手指支撑魔方，而另一些手指推动转动层、释放接触，并为下一步复位。为学习这种协调，我们提出 FINGR（Future-supervised Interaction Network with Geometric Representations），这是一种将手指相对几何与未来交互预测相结合的策略。一个共享点编码器以每个指尖为参照表达魔方，并在不依赖小方块索引的情况下聚合其点。学习到的未来 token 共享观测编码器，并在多个时间尺度上接受接触力变化、层转动进度和手指关节位移的监督。由此得到的表示条件化一个流策略，直接生成手指动作。在真实灵巧手上，我们的策略在 300 次转动尝试中达到 99.0% 的成功率，而基础流策略为 79.7%。与抓取和桌面辅助重抓取相结合，该策略求解了全部十个打乱的 $2\times2\times2$ 魔方，平均完整系统时间约为 137 秒。项目网站见 https://www.lyt0112.com/projects/FINGR

## Abstract
Manipulating a Rubik's Cube with a single dexterous hand is a challenging test of sustained, contact-rich control: the hand must execute successive layer turns while keeping the cube secure. Each turn requires some fingers to support the cube while others push a moving layer, release contact, and reset for the next move. To learn this coordination, we introduce FINGR (Future-supervised Interaction Network with Geometric Representations), a policy that combines finger-relative geometry with future interaction prediction. A shared point encoder expresses the cube relative to each fingertip and aggregates its points without depending on cubie indexing. Learned future tokens share the observation encoder and receive supervision for contact-force changes, layer-turn progress, and finger joint displacement at multiple time scales. The resulting representation conditions a flow policy that directly generates finger actions. On a real dexterous hand, our policy achieves 99.0% success over 300 turn attempts, compared with 79.7% for the base flow policy. Integrated with grasping and table-assisted regrasping, the policy solves all ten scrambled $2\times2\times2$ cubes in a mean complete-system time of approximately 137 seconds. The project website is available at https://www.lyt0112.com/projects/FINGR

  - **空间结构**：某根手指可执行的动作取决于转动层与支撑面相对于它的位置。全局编码魔方 + 各手指独立编码，会让策略自己去推断这些关系。
  - **时间结构**：一次转层中接触会变化（加载表面 → 推进层 → 释放 → 回位），而单纯的动作模仿并不会显式训练观测编码器去捕捉接触与运动的演化。
- **整体含义**：论文提出 FINGR（Future-supervised Interaction Network with Geometric Representations），把"指尖相对几何"与"多时间尺度未来交互预测"结合，条件化一个流策略直接生成手指动作；在真实灵巧手上把转层成功率从基线 79.7% 提升到 99.0%，并进一步与抓取、桌面辅助重抓取结合，完成真实魔方求解，说明几何表征与未来监督可显著提升富接触灵巧操作。

## 2. 方法论

### 核心思想
- 空间上：把魔方点云平移到每根指尖为原点，用共享点编码器 + 对称聚合得到"手指相对几何特征"，直接加到该手指的状态 token 上。
- 时间上：引入 3 个可学习的未来 token（多时间尺度），在共享观测编码器中与观测 token 交互，并监督它们预测接触力变化、转层进度与手指关节位移。
- 二者共同训练一个输出关节动作块（action chunk）的流匹配（flow）策略：预测头仅训练时使用，未来 token 在部署时直接条件化动作生成。

### 任务与策略接口
- 对象为 2×2×2 魔方，学习技能为当前抓握下 U、L 两层的 90° 转动；手臂保持姿态，拇指与中指维持抓握，策略只控制食指、无名指、小指共 13 个关节。
- 观测（10 Hz）：五指的数值特征（关节位置/速度/力矩、6 个触觉力/力矩通道、指尖位置）、3 个受控指的触觉形变图像、32 个魔方点（24 个面中心 + 8 个外角，由 8 个小方块位姿重建，无小方块身份与颜色标签）、移动标签 m_t ∈ {U, L}、归一化剩余角度 r_t。
- 动作：预测 H = 20 步、相对当前受控关节构型 q_t ∈ R¹³ 的关节位置偏移；至少执行 5 步后才更新 chunk，命令与观测时间戳对齐以补偿推理延迟。

### 关键技术一：手指相对几何（式 1）
- 对第 i 根手指与第 j 个魔方点定义 d_{t,ij} = (p_{t,j} − f^i_t)/ℓ，其中 ℓ = 0.05 m 为固定长度尺度；原点随指尖移动、坐标轴与手掌对齐，因此保留了从特定手指到某个魔方面点的**方向与距离**。
- 用共享两层点网络 φ: R³ → R⁶⁴ 逐点编码，对 32 个点做**均值池化**，再经 W_g、b_g 投影到 Transformer 宽度得到 g^i_t，加到手指 i 的数值特征投影上。
- 均值池化对点序不变，故特征不依赖小方块索引；同时相对几何已显式写入对应手指 token，便于策略选择"推、撑、脱离"。
- 其余编码：手指身份嵌入与模态嵌入区分五根手指及数值/触觉/全局魔方三类信息；触觉图像用共享 CNN + 手指特定的 feature-wise scale/shift 编码；另用一套点网络 + max pooling 产生一个全局魔方 token；任务嵌入与 r_t 的投影加到全部 9 个观测 token 上。

### 关键技术二：未来交互预测（式 2–4）
- 3 个可学习 query 对应 h ∈ {1, 5, 10} 控制步（约 0.1 s / 0.5 s / 1.0 s）；Transformer 联合编码 [观测 token, z₁, z₅, z₁₀]，每个编码后的未来 token 经共享预测头 D_ψ 输出预测。
- 监督目标 y_{t,h} = [c_{t+h} − c_t, r_t − r_{t+h}, q_{t+h} − q_t] ∈ R²³：分别对应接触力加载/卸载、目标层角度进度、推层与复位期间的关节位移。
- 目标按 horizon 与坐标分别用经验标准差标准化（不减去均值，最小尺度 1e-6）；仅当前帧与未来帧位于同一连续跟踪转动片段时该目标有效。
- 损失先在各目标组内求均方误差，再对接触、进度、运动三组等权平均（式 4），避免不同维度导致权重失衡。
- 动作模仿只用成功且对齐良好的转动，未来预测还使用被动作模仿排除的连续交互片段，从而扩大接触与动力学监督范围；两个目标更新同一个观测编码器。

### 动作学习与训练目标（式 5–6）
- 流策略：训练输入 X_τ = (1−τ)A_t + τϵ（A_t 为归一化演示动作块，ϵ 为高斯噪声），网络预测干净动作 Â_θ，速度场 v_θ = (X_τ − Â_θ)/τ；动作头交替执行动作自注意力、对 M_t 的交叉注意力与前馈层，并由噪声水平调制每个子块。
- 推理用 4 步 Euler 积分（步长 −0.25，在 τ = 1、0.75、0.5、0.25 处求场）从噪声积分到动作块。
- 联合目标 L = L_act + λ(k)·L_pred，λ(k) = 0.003·max(0, 1 − k/(0.5K))：预测监督只在前半训练塑造表征，之后由动作目标继续优化同一编码器与动作头；部署使用 EMA 参数。
- 动作归一化用训练集偏移的第 1/99 百分位（b_j 取中点、s_j 取半范围，最小 0.01 rad），损失以 s²_j 在关节空间加权，并用二值掩码排除超出转动片段的目标。

### 完整魔方求解系统
- 多视角编码标记估计小方块位姿 → 重建魔方姿态 → 规划预抓取 → 合拢支撑指并抬起到操作位姿。
- 离散求解器在正 U/L 四分之一转上搜索：先最小化四分之一转数量，其次降低重复同层的代价。
- 若当前抓握下无法完成，则先构造一个"已解的两小方块块"，把魔方按指定朝向放到桌面，再抓取该块并完成第二段 U/L 序列（桌面辅助重抓取，含运动规划与碰撞检查）。
- 每段序列后验证魔方状态，必要时做额外对齐动作并从观测状态重规划；全部小方块方向一致后放到桌面并返回初始姿态。
