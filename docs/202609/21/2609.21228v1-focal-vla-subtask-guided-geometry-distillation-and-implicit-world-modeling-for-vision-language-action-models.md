## 摘要
基于预训练视觉-语言模型构建的视觉-语言-动作（VLA）模型已在多样化的机器人操作任务中展现出强大性能。然而，直接将当前二维观测映射为动作的VLA模型往往缺乏足够的空间与时间理解能力，限制了其在精细和长时程操作中的表现。近期方法通过在整个场景上进行几何监督和未来状态预测来增强VLA模型。然而，这些方法可能受到冗余场景信息的干扰，使模型偏离学习与当前交互相关的几何和动态。为解决这一问题，我们提出FOCAL-VLA，一个将子任务引导的几何蒸馏与隐式世界建模相结合的框架，用于学习当前空间结构和未来交互动态的表征。为使几何学习聚焦于当前子任务，我们通过将几何隐变量与子任务相关图像区域的特征对齐，将VGGT中的几何知识迁移到VLA模型。为捕捉当前交互的未来三维演化，我们引入隐式世界建模，利用来自当前与未来演示帧的Track4World特征。这两种互补表征共同引导动作生成，且在推理时无需运行VGGT或Track4World。实验表明，FOCAL-VLA在仿真基准和真实世界操作任务上均优于基线。项目网站：https://zhiyuan-gao.github.io/FOCAL-VLA/。

## Abstract
Vision-language-action (VLA) models built on pretrained vision-language models have demonstrated strong performance across diverse robotic manipulation tasks. However, VLA models that directly map current 2D observations to actions often lack sufficient spatial and temporal understanding, limiting their performance in precise and long-horizon manipulation. Recent methods enhance VLA models through geometric supervision and future-state prediction across the entire scene. However, these methods can suffer from redundant scene information, distracting the model from learning the geometry and dynamics relevant to the current interaction. To address this issue, we propose FOCAL-VLA, a framework that combines subtask-guided geometry distillation with implicit world modeling to learn representations of current spatial structure and future interaction dynamics. To focus geometric learning on the current subtask, we transfer geometric knowledge from VGGT to the VLA model by aligning geometry latents with features from subtask-relevant image regions. To capture the future 3D evolution of the current interaction, we incorporate implicit world modeling using Track4World features from current and future demonstration frames. The two complementary representations jointly guide action generation without running VGGT or Track4World at inference time. Experiments show that FOCAL-VLA outperforms baselines on both simulation benchmarks and real-world manipulation tasks. Project website: https://zhiyuan-gao.github.io/FOCAL-VLA/.

# FOCAL-VLA 论文深度总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型将预训练视觉-语言模型扩展到机器人控制，在多样化操作任务上表现强劲。
- **核心痛点**：直接由当前 2D 观测映射到动作的 VLA 模型缺乏充分的空间与时间理解能力，在**精细操作**和**长时程操作**中性能受限。
- **现有方法的不足**：
  - 几何监督方法（如 Spatial Forcing、GLaD）对整个图像的所有视觉 token 做对齐，包含与当前操作无关的场景区域。
  - 未来预测方法（如 Track4Action）对整个场景做运动特征池化，同样引入冗余信息。
  - 冗余场景信息会**分散模型注意力**，使其难以学习与当前交互真正相关的几何结构与动态。
- **关键观察**：动作生成所需的信息随交互进程而变化。例如"把物体放进抽屉"需要理解物体-抽屉的空间关系，而"关闭抽屉"则需要预判抽屉的运动。因此，几何与未来运动监督应围绕**当前交互涉及的实体**构建。

## 2. 方法论

### 2.1 核心思想
- 基于 π0.5 构建，引入两组可学习查询 token：**几何查询 Qg** 与**未来运动查询 Qm**。
- 两条互补监督分支：
  - **子任务引导几何蒸馏**：迁移 VGGT 的几何知识到 VLA。
  - **隐式世界建模**：通过 Track4World 特征学习未来交互动态。
- 两种表征共同条件化动作专家，且**推理时无需运行任何教师模型**，也无需子任务标注与相关性掩码。

### 2.2 子任务引导几何蒸馏
- 使用冻结的 VGGT 处理当前多视角图像，得到每视角 patch 特征 $G^v_t \in \mathbb{R}^{P_g \times d_g}$（$d_g=2048$）。
- 用离线 VLM（Qwen3-VL-8B-Instruct）将人工指定的子任务描述与演示帧对齐，识别涉及的实体，生成二值相关性掩码 $M^v_t$（实体级掩码并集，不含夹爪）。
- 计算掩码在 patch 上的覆盖权重 $w^v_{t,p}$，仅在子任务相关区域内池化，并在有效视角上平均：
  $$y^g_t = \frac{1}{|V_t|}\sum_{v\in V_t}\frac{\sum_p w^v_{t,p}G^v_{t,p}}{\sum_p w^v_{t,p}}$$
- 预测头对 Qg 输出做归一化、均值池化与线性投影得 $\hat{y}^g_t$，用掩码 MSE 对齐标准化后的目标：
  $$\mathcal{L}_{geo} = \frac{1}{|B_g|d_g}\sum_{t\in B_g}\|\tilde{\hat{y}}^g_t - \tilde{y}^g_t\|^2_2$$

### 2.3 隐式世界建模（未来运动蒸馏）
- 使用冻结 Track4World 处理当前 agent 视角帧与 $K$ 个未来时间戳帧（在动作 chunk 区间内均匀采样，跨子任务边界不截断）。
- 教师输出的时序全局 3D 流特征 $D_{t,p} \in \mathbb{R}^{d_m}$（$d_m=256$，源网格 45×45=2025 patch）。
- 用当前相关性掩码映射到教师网格得权重 $u_{t,p}$，掩码池化得到运动目标：
  $$y^m_t = \frac{\sum_p u_{t,p}D_{t,p}}{\sum_p u_{t,p}}$$
- 用标准化特征空间中的掩码 Smooth L1（β=1）监督 $\hat{y}^m_t$：
  $$\mathcal{L}_{motion} = \frac{1}{|B_m|}\sum_{t\in B_m}\text{SmoothL1}_{\beta=1}(\tilde{\hat{y}}^m_t, \tilde{y}^m_t)$$

### 2.4 动作生成与训练
- 注意力模式：上下文 token 保持原生路径；几何查询、运动查询各自独立关注上下文与组内 token；动作专家同时关注上下文、Zg 与 Zm：
  $$C_t \leftarrow C_t,\quad Z_g \leftarrow C_t + Z_g,\quad Z_m \leftarrow C_t + Z_m,\quad Action \leftarrow C_t + Z_g + Z_m$$
- 额外训练原生 LM 分支自回归预测子任务文本，提供子任务级语义引导：
  $$\mathcal{L}_{sem} = -\frac{1}{L_s}\sum_{k=1}^{L_s}\log p_\theta(s_k \mid C_t, s_{<k})$$
- 总目标：
  $$\mathcal{L} = \mathcal{L}_{action} + \lambda_g\mathcal{L}_{geo} + \lambda_s\mathcal{L}_{sem} + \lambda_m\mathcal{L}_{motion}$$
  其中 $\lambda_g=0.05$、$\lambda_s=0.01$、$\lambda_m=0.05$。
- 推理时仅用当前观测、指令与本体状态计算 Zg、Zm 来条件化动作专家。

## 3. 实验设计

### 3.1 数据集 / 场景
- **LIBERO**：含 Spatial、Object、Goal、Long（LIBERO-10）四个套件，各 10 个任务；使用 agent 与 wrist 双视角，预测并执行 10 步动作块；每任务评估 50 回合。
- **RoboCasa**：Atomic-24 under Human-50（每任务 50 条演示），使用左 agent、wrist、右 agent 三视角；预测 50 步 chunk，执行 25 步后重规划；报告不加权平均任务成功率。
- **真实世界**：Franka Emika Panda + 固定 Orbbec Astra Pro RGB 相机，四项任务：双水果重排、抽屉打开、抽屉存储（放入香蕉并关闭）、关闭微波炉；每任务 50–150 条 SpaceMouse 遥操作演示，共 350 条，10 Hz、640×480；每任务 20 次试验。

### 3.2 对比方法
- **LIBERO**：OpenVLA、π0、π0.5、OpenVLA-OFT、GR00T N1.7、SpatialVLA、DreamVLA、GeoPredict、Track4Action。

## 8. 不足与局限

- **离线标注依赖**：需要人工指定子任务描述、子任务起止时间，并依赖离线 VLM 与 Grounded-SAM-2 生成实体掩码，数据准备成本与计算成本较高。
- **标注误差敏感**：子任务边界或实体掩码的错误会直接影响蒸馏目标质量，进而影响策略性能。
- **评估覆盖有限**：仅在两个仿真基准与单一真实机器人平台（Franka Panda + 单固定相机）上验证，未探索其他本体、其他任务族及多相机配置的泛化性。
- **真实实验样本量小**：每任务仅 20 次试验，成功率的统计置信区间较宽，难以支撑强结论。
- **相机遮挡问题**：真实世界中抓取失败部分源于单固定视角下目标物体被遮挡，方法本身未专门处理遮挡。
