## 摘要
让机器人适应新物体和新任务需要交互经验，而获取这些经验可能代价高昂。我们提出 WorldContact，这是一种用于可变形物体操作的以接触为中心的世界模型；它基于有限的高质量轨迹构建，以高效生成额外的训练数据。与源数值模拟器相比，它使用更大的时间步预测物体动力学，而源模拟器需要很小的积分步长来解析快速运动并防止相互穿透。我们在 16 个购物袋操作任务上评估了 WorldContact。在单块 H100 GPU 上进行状态推演测量时，除去渲染和磁盘 I/O，其速度比源模拟器快 10 倍。我们使用生成的数据微调现有的视觉-语言-动作策略，并将其直接部署到真实机器人上。在提袋任务中，同一策略仅在源仿真数据上微调时单次尝试成功率为 65%，而在用 WorldContact 扩展后的数据集上微调时达到 95%。这些结果支持使用 WorldContact 高效生成数据以进行机器人策略适配。

## Abstract
Adapting robots to new objects and tasks requires interaction experience that can be costly to obtain. We present WorldContact, a contact-centric world model for deformable-object manipulation, constructed from a limited set of high-quality trajectories to generate additional training data efficiently. It predicts object dynamics using larger time steps than the source numerical simulator, which requires small integration steps to resolve rapid motion and prevent interpenetration. We evaluate WorldContact across 16 shopping-bag manipulation tasks. State-rollout measurements on a single H100 GPU show a $10\times$ speedup over the source simulator, excluding rendering and disk I/O. We use the generated data to fine-tune an existing vision-language-action policy and deploy it directly on a real robot. In bag lifting, the same policy achieves 65% single-attempt success when fine-tuned on source simulation data alone, compared with 95% when fine-tuned on the dataset expanded with WorldContact. These results support efficient data generation with WorldContact for robot policy adaptation.

## 2. 方法论

### 2.1 核心思想
- 将场景拆分为两部分：**物体状态** $S_t$（待预测对象）与**规定状态** $B_t$（机器人运动与外部几何，作为输入）。
- 学习物体状态在接触作用下的演化：$(\Delta X_t, \Delta V_t) = F_\theta(S_t, B_{t+\Delta t})$，再更新 $\hat X_{t+\Delta t} = X_t + \Delta X_t$，$\hat V_{t+\Delta t} = V_t + \Delta V_t$。
- 关键区别：物体若被机器人刚性握持则归入 $B_t$（运动由机器人规定），若被释放则归入 $S_t$（需预测其后续运动）。

### 2.2 状态表示
- 物体状态：$S_t = [X_t, V_t, E, C]$，$X_t, V_t \in \mathbb{R}^{N\times3}$ 为顶点位置与速度，$E$ 为静止拓扑，$C\in\mathbb{R}^{N\times3}$ 拼接物体身份标签与静止态 $(u,v)$ 坐标。
- 规定状态：$B_t = [a_t, G, X^E_t, V^E_t, C^E_t]$，其中 $a_t\in\mathbb{R}^{14}$ 为双臂关节旋转（各 6 维）与夹爪开合，$G$ 为固定运动学结构与几何，$X^E_t, V^E_t$ 为环境几何（如桌面）采样点位置与速度，$C^E_t$ 拼接环境标签与表面法线。

### 2.3 接触中心顶点 Tokenizer（四类接触）
对每个目标顶点 $i$ 编码局部几何与运动，聚合四类邻居：

- **空间接触 $N^S_i$**：欧氏空间中邻近的顶点（跨物体/跨部位，如袋带与袋身）。
- **拓扑接触 $N^T_i$**：静止拓扑 $E$ 中邻近的顶点（UV 空间，捕捉物体内在拓扑的局部交互）。
- **可控接触 $N^C_i$**：机器人连杆、夹爪及被刚性握持物体的邻近采样点（直接接触或经工具介导的接触）。
- **环境接触 $N^E_i$**：环境几何（如支撑袋子的桌面）的邻近采样点。

采用紧凑支撑的学得核聚合邻居特征：$g^k_i = \sum_{j\in N^k_i} W^k(r^k_{ij}) u^k_{ij}$，其中 $r$、$u$ 分别为位移与特征（含速度、标签、法线等）。最终顶点 token 为：
$$h_i = \text{MLP}([x_{t,i}, v_{t,i}, c_i, g^S_i, g^T_i, g^E_i, g^C_i])$$

### 2.4 分层 Token 编码器
- 可变形物体的物理现象存在**长程耦合**（如拉动布料一处，远处顶点运动相似），需自注意力传播信息，但全分辨率注意力计算昂贵。
- 沿用 WorldParticle 的**分层 token 合并**：每层先以带 3D RoPE 的多头自注意力交换全局上下文，再将 token 交替划分并配对合并（$N^{(\ell)} = \lceil N^{(\ell-1)}/2\rceil$），用多重度 $m_i$ 做加权平均，最终得到 $N_g \ll N$ 个全局 token。

### 2.5 全局 Token 解码器
- 原始顶点 token 绕过压缩作为 query 初始化 $H^{(0)}_d$；全局 token 做自注意力捕捉长程依赖。
- 顶点分辨率 token 通过**交叉注意力**查询全局表征，保留局部几何与接触信息。
- 逐点输出头预测修正量：$(\Delta x_{t,i}, \Delta v_{t,i}) = \text{MLP}_{out}(h^{(L_d)}_{d,i})$。

### 2.6 训练
- 采样长度 $W$ 的轨迹段，自回归 rollout，损失覆盖所有 rollout 步的位置与速度误差：$L = \frac{1}{N(W-1)}\sum_n\sum_i(\lambda_x\|\hat x - x\|^2_2 + \lambda_v\|\hat v - v\|^2_2)$，梯度贯穿全部 rollout 步以抑制误差累积。
- **可微拓扑投影**：在自回归循环内加入投影 $P$，$\hat X_{t+\Delta t} = P(\tilde X_{t+\Delta t}, E)$，$\hat V = (\hat X_{t+\Delta t} - \hat X_t)/\Delta t$，平滑位移场并限制拓扑边畸变，提升长时程稳定性，梯度可穿过投影迭代与完整 rollout。

### 3.1 数据与场景
- **数据采集**：由 GPT-5.6 Sol（xhigh reasoning effort）驱动的自动化仿真智能体，在 SimWeaver 的物理模拟器中配置并执行任务，监控轨迹并剔除失败样本。
- **资产量化**：购物袋离散为 **20,274 个顶点**，刚性球体 951、立方体 465 个顶点；夹爪 1,114 个采样点，桌面 16,900 个采样点。物理时间步 **0.002s**；物体级参数（摩擦、阻尼、杨氏模量）固定。
- **任务集**：**16 个购物袋操作与碰撞任务**（轻触、与固定球碰撞、单臂抓取提升、与可移动球碰撞、按压提升、双臂抓取提升等），覆盖空间、拓扑、可控、环境四类接触及同时交互。
- **数据规模**：每任务 25 条训练轨迹（共 400 条），每任务 2 条验证 + 2 条测试。
- **质量校验**：物理检查（NaN/Inf、求解器失败、相互穿透、自交、夹爪-袋虚假粘连）与视觉检查（袋子移出工作空间或相机视野），状态机 RESET→EXECUTE→VALIDATE→ACCEPT，智能体维护失败记忆避免重犯。

### 3.2 Benchmark 与对比方法
- **神经动力学对比**：与 RoboCraft、RoboCook、AdaptiGraph 在相同数据集与划分下对比，报告自回归测试 rollout 的顶点位置 MSE、速度 MSE、穿透率（穿透超 1cm 的布料接触面积占比，按顶点面积加权聚合）。
- **效率对比**：与源物理模拟器对比完整状态 rollout（单张 H100，排除渲染与磁盘 I/O）。
- **消融实验**：① 接触中心顶点 tokenizer（移除 $g^S, g^T, g^C, g^E$，改用线性投影 + 最近邻环境/可控采样特征）；② 分层 token 压缩（替换为全分辨率自注意力，相同层数，比较 $W=5,10,15$ 的单步训练时间）。
- **真实机器人应用**：用 WorldContact 从 25 条高质量仿真轨迹扩展至 150 条策略训练轨迹，微调现有 VLA（从 Pi05/π0 检查点），部署到真实机器人做单臂提袋（抓取、举过桌面、保持 2 秒），20 次单次尝试试验。

## 4. 资源与算力

- **训练算力**：两个训练阶段（基础训练 + 含可微拓扑投影的继续训练）均使用 **8 张 NVIDIA H100 GPU**。
- **训练规模**：基础训练 93,240 优化步，峰值学习率 $1\times10^{-4}$，8,000 步线性 warmup 后余弦衰减至 $5\times10^{-6}$；继续训练 31,080 步，峰值学习率 $2\times10^{-5}$。使用 AdamW（$\beta=(0.9,0.999)$，权重衰减 $5\times10^{-4}$），rollout 段长 5 步，时间步 0.04s，位置/速度损失权重均为 $10^4$。
- **效率测量**：单张 H100 上，WorldContact 每秒墙钟时间模拟 0.4s 动力学，源模拟器为 0.04s，即 **10× 加速**。
- **模型规模**：总计约 **2.00M 参数**（tokenizer 57,993 + 编码器 782,784 + 解码器 1,116,480 + 预测头 42,502）。
- **策略微调**：AdamW（$\beta=(0.9,0.95)$，$\epsilon=1\times10^{-8}$，权重衰减 $1\times10^{-2}$），初始学习率 $2.5\times10^{-5}$，1,000 步 warmup 后余弦衰减至 $2.5\times10^{-6}$，共 30,000 步；全模型微调，每 chunk 预测 50 步动作。
- **未明确说明**：论文未给出各阶段训练的具体墙钟时长（仅给出优化步数），也未给出真实机器人实验的硬件算力开销。

## 5. 实验数量与充分性评估

- **实验组数概览**：
  - 1 组神经动力学定量对比（3 个基线 + 本文方法，4 项指标）。
  - 1 组定性 rollout 可视化对比（GT / RoboCraft / RoboCook / AdaptiGraph / 本文）。
  - 1 组计算效率对比（10× 加速）。
  - 2 组消融实验（接触 tokenizer、分层 token 压缩，后者含 3 个段长）。
  - 1 组真实机器人策略对比（65% vs 95%，各 20 次试验）。
  - 覆盖 16 个任务的训练与测试划分。
- **充分性评价**：
  - **优点**：消融设计直接验证了核心模块（接触特征、分层压缩）的必要性；定量 + 定性 + 效率 + 下游策略多维度验证；真实机器人端到端验证增强了说服力。
  - **可改进处**：神经动力学对比仅在单一物体类型（购物袋）上进行，未覆盖其他可变形物体；基线方法均非专为"接触中心"设计，对比的公平性受各自超参调优程度影响；真实机器人试验仅 20 次/条件，统计置信区间未报告；未报告不同随机种子或多次训练的方差。
  - **客观性**：对比方法在同一数据集与划分下训练，指标定义明确（含穿透率这一物理合理性指标），总体较为客观。

## 6. 主要结论与发现

- **动力学保真度**：WorldContact 在位置 MSE（0.0002）、速度 MSE（0.0002）、穿透率（0.35%）上均显著优于 RoboCraft（0.0598 / 0.0106 / 13.88%）、RoboCook（0.0575 / 0.0105 / 10.28%）和 AdaptiGraph（0.0323 / 0.0098 / 24.84%）。
- **计算效率**：状态推演比源数值模拟器快 **10×**（单张 H100，排除渲染与磁盘 I/O），得益于 20× 的更大时间步与 GPU 高效推理。
- **真实机器人收益**：同一 VLA 仅在 25 条源仿真轨迹上微调时单次提袋成功率为 **13/20（65%）**；用 WorldContact 扩展至 150 条后提升至 **19/20（95%）**。
- **模块有效性**：移除接触中心 tokenizer 会导致顶点穿透桌面与夹爪、rollout 不稳定；分层 token 压缩在保持顶点级输出的同时降低单步训练时间（如 $W=15$ 时从 15.873s 降至 14.493s）。
- **总体结论**：以接触为中心的世界模型能从有限高质量数据高效扩展训练经验，有效适配机器人控制策略到新的可变形物体操作场景。

## 7. 优点与亮点

- **接触建模的系统化**：显式区分空间、拓扑、可控、环境四类接触，并给出统一的核聚合与 token 化表示，兼顾物体

内在拓扑（UV 空间）与外部物理空间的交互；
- **物理一致性导向**：将穿透率作为核心评价指标之一，并在训练循环内引入可微拓扑投影，直接约束拓扑边畸变，使长时程 rollout 的物理合理性显著优于纯数据驱动的基线；
- **效率与保真度的平衡**：通过 20× 更大时间步 + GPU 批量推理获得 10× 墙钟加速，同时保持顶点级位置/速度预测精度，避免了"加速即失真"的常见权衡；
- **模型轻量**：约 2.00M 参数即可完成 20,274 顶点的可变形物体动力学预测，相对于同类神经动力学方法规模较小，易于训练与部署；
- **数据效率与下游闭环**：以 25 条高质量轨迹为起点扩展至 150 条用于策略微调，把"世界模型"从离线预测工具变成了策略数据放大器，并用真实机器人实验完成端到端验证，闭环完整；
- **数据质量工程化**：由自动化智能体驱动采集，配合物理检查（NaN/Inf、求解器失败、相互穿透、自交、虚假粘连）与视觉检查，以及带失败记忆的 RESET→EXECUTE→VALIDATE→ACCEPT 状态机，为"少量高质量数据"这一前提提供了可复现的保障机制。

## 8. 局限与不足

- **物体类型单一**：定量对比与真实机器人验证均围绕购物袋展开，未涉及布料、绳索、颗粒、流体等其他可变形体，方法在更一般可变形物体上的泛化性未经验证。
- **接触类别依赖人工定义**：空间/拓扑/可控/环境四类接触是人为划分的先验结构，对于接触语义模糊或类别重叠的场景（如多物体相互支撑、物体间既非刚性握持又非自由），归类规则可能需要额外启发式。
- **刚体/可变形体统一建模有限**：物体被机器人刚性握持时归入 $B_t$（视为规定状态），这是一种"硬切换"；抓取与释放的过渡瞬间如何平滑处理，论文未充分讨论。
- **长时程稳定性仍依赖投影**：可微拓扑投影是稳定性的关键组件，但投影本身引入了额外的计算与归纳偏置，若拓扑 $E$ 本身在任务中发生变化（如袋子撕裂），该假设会失效。
- **基线公平性存疑**：RoboCraft、RoboCook、AdaptiGraph 均非以接触为中心的架构，在同一数据集上的超参调优程度、输入特征对齐程度未必对等，可能放大本文方法的相对优势。
- **统计显著性缺失**：真实机器人仅 20 次/条件，未报告置信区间或多种子方差；动力学指标也未给出多次训练的均值±标准差，难以判断性能差异是否稳健。
- **未报告训练墙钟时长**：仅给出优化步数（93,240 + 31,080 步，8×H100），缺少端到端训练成本，不利于实际复现与成本评估。
- **模拟器内循环风险**：训练数据与验证均由同一物理模拟器（SimWeaver）产生，模拟器自身的偏差（接触模型、摩擦参数固定）可能被世界模型继承，向真实世界的 sim-to-real 差距未量化。

- **可复现要素较完整**：状态定义、网络结构（tokenizer / 分层编码器 / 解码器 / 输出头）、损失函数、优化器超参、学习率调度、rollout 段长、时间步、损失权重、参数量分解均有明确给出。

- **评测可复现性中等**：指标定义清晰（位置/速度 MSE、穿透率按顶点面积加权的定义），16 个任务类别有描述，但轨迹划分的具体随机种子未说明。

## 10. 对后续研究的启示

- **"接触即表示"的思路可迁移**：将接触按来源分类并作为显式特征通道，而非让网络从原始几何中隐式学习，这一设计可推广到刚体堆叠、多机器人协作、工具使用等场景。
- **可微物理约束嵌入自回归循环**是提升长时程稳定性的有效手段，可与其他约束（体积守恒、不可压缩、能量耗散）结合。
- **世界模型作为策略数据放大器**的范式值得进一步研究：如何选择"最有信息量"的扩展轨迹、如何避免世界模型偏差被策略放大，是开放问题。
- **分层 token 压缩在顶点级任务中的适用性**得到初步验证，但其与更高效的稀疏注意力/图神经网络路线的对比尚缺。
- **评价体系**建议扩展：除 MSE 与穿透率外，可引入接触力一致性、能量漂移、任务成功率等多层次指标。

## 11. 总体评价

WorldContact 在方法层面提出了一个结构清晰、物理动机明确的接触中心神经模拟器：以 Lagrangian 粒子为状态载体，显式建模四类接触并统一为核聚合 token，配合分层 token 压缩与可微拓扑投影，在购物袋操作这一具有代表性的可变形物体任务上同时实现了高保真度（位置 MSE 0.0002、穿透率 0.35%）与 10× 的推演加速。其最具说服力的部分是将世界模型接入真实机器人策略学习闭环，把 25 条仿真轨迹扩展为 150 条后使单臂提袋成功率从 65% 提升至 95%。主要短板在于物体类型与场景多样性不足、基线对比的公平性未充分论证、统计显著性缺失，以及复现所需的代码与数据未公开。总体而言，这是一项在"接触建模 + 世界模型 + 机器人策略数据扩展"交叉方向上具有明确贡献与启发价值的工作，其结论在购物袋这一设定内可信，向更广泛可变形物体与真实场景的泛化仍需后续验证。
