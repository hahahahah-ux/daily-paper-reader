## 摘要
世界动作模型（WAMs）联合建模动作生成与环境动态，且大多构建在预训练视频扩散模型（VDMs）之上。在基于 VDM 的 WAM 中，观测首先由 VAE 编码，随后得到的压缩潜变量由大型视频扩散骨干网络处理，以提取用于动作生成的有效特征。然而，这一范式将 WAM 的性能与训练成本绑定于大规模视频生成预训练，限制了 WAM 的效率与可扩展性。本文从理论和实证两方面研究视觉表征如何影响 WAM 中的动作生成。结果表明，来自联合嵌入预测架构（JEPA）编码器的预测嵌入比压缩 VAE 潜变量更能支持动作生成，在我们的编码器比较中 I-JEPA 表现最佳。基于这些发现，我们提出 LeWAM，它以 JEPA 嵌入为条件进行动作生成，并通过在同一空间中预测未来嵌入来建模环境演化，而不依赖视频扩散骨干网络。我们进一步发现，模仿学习能够匹配演示动作，但不能区分更好与更差的动作，即便很小的动作偏差也可能极大影响任务成功率。为在不增加环境交互、也不依赖重置与安全所需人工监督的情况下解决这一局限，我们引入演示引导的 DPO（DemoDPO），这是一个离线偏好精炼阶段，直接从演示中导出偏好监督。LeWAM 仅有 0.4B 可训练参数，在 RoboTwin 2.0 上取得 92.28% 的平均成功率，与最先进的 VLA 和 WAM 相当，并在真实世界操作任务上保持实用有效性。

## Abstract
World Action Models (WAMs) jointly model action generation and environment dynamics and are mostly built on pretrained Video Diffusion Models (VDMs). In VDM-based WAMs, observations are first encoded by a VAE, and the resulting compressed latents are then processed by large video diffusion backbones to extract effective features for action generation. However, this paradigm ties WAM performance and training cost to large-scale video generation pretraining, limiting WAM efficiency and scalability. In this paper, we theoretically and empirically investigate how visual representations affect action generation in WAMs. Our results show that predictive embeddings from Joint-Embedding Predictive Architecture (JEPA) encoders better support action generation than compressed VAE latents, with I-JEPA performing best in our encoder comparison. Based on these findings, we propose LeWAM, which conditions action generation on JEPA embeddings and models environment evolution by predicting future embeddings in the same space, without relying on a video diffusion backbone. We further find that imitation learning matches demonstrated actions but does not distinguish better actions from worse ones, even though small action deviations can greatly affect task success. To address this limitation without additional environment interaction or the human oversight required for resets and safety, we introduce Demonstration-Guided DPO (DemoDPO), an offline preference refinement stage that derives preference supervision directly from demonstrations.With only 0.4B trainable parameters, LeWAM achieves an average success rate of 92.28\% on RoboTwin 2.0, comparable to that of state-of-the-art VLAs and WAMs, and maintains practical effectiveness on real-world manipulation tasks.

## 2. 方法论

### 2.1 理论分析（动机支撑）

- **命题 1（动作相关性差距）**：在动作充分性假设 $p(A|X,c)=p(A|S,c)$ 下，额外动作不确定性 $\Delta E(A)=H(A|Z,c)-H(A|X,c)=I(A;S|Z,c)\ge 0$，表明应从"保留的动作相关因子信息"而非重建质量来评价表征。
- **命题 2（VAE 谱压缩）**：线性高斯 VAE 全局最优解下，后验均值有效维度 $r_{\text{eff}}=\min(k,\#\{i:\lambda_i>\beta_{\text{vae}}\sigma^2_{\text{dec}}\})$。当动作依赖被阈值截断的低方差方向（$B_c u_i\neq 0, i\notin J$）时，$\Delta E(A)>0$，即基于重建的选择不保证保留动作相关信息。
- **可用性分解**：最优超额对数损失 = 信息损失（仅取决于表征）+ 可用性缺陷（取决于表征与下游模型），并给出损失通道界，把重建误差与动作信息损失联系起来。
- **数据处理的限制**：下游模型对 (Z, c) 的确定性变换无法恢复已被表征与上下文共同丢弃的动作相关信息。

### 2.2 LeWAM 核心思想

- **统一预测器 + 结构化注意力掩码**：将当前观测嵌入 $Z_0$、含噪动作 token $A'_\tau$、干净动作 token $A_t$、未来查询 $Q_{1:N}$ 组成统一 token 序列，由单个预测器处理：
  - 含噪动作 token 只能关注 $Z_0$ 及自身因果含噪前缀 → 实现 $\pi_\theta(A_t|X_t,c_t)$；
  - 干净动作 token 因果；
  - 未来查询 $Q_i$ 只能关注 $Z_0$、自身查询网格与前 $\delta_i$ 个干净动作 → 实现 $p_\theta(Z_i|X_t,A_t^{(\delta_i)},c_t)$；
  - 该掩码防止干净动作泄漏到动作生成，也防止 $\delta_i$ 之后动作影响 $Z_i$ 预测。
- **AdaFuse（自适应层融合）**：冻结 JEPA 编码器多层嵌入 $E_\ell(X)$，学习通道维度的层融合 logits $\Gamma\in\mathbb{R}^{L\times d}$，按特征维度 softmax 归一化后加权求和，前后加 LayerNorm，融合权重跨 patch 与观测共享。
- **联合训练目标**：
  - 条件流匹配：$A'_\tau=(1-\tau)A_t+\tau\epsilon$，$v_\tau=\epsilon-A_t$；
  - 动作损失 $L_{\text{act}}=\mathbb{E}\|\hat v_\theta-v_\tau\|_2^2$；
  - 世界模型损失 $L_{\text{wm}}=\mathbb{E}_i\|\hat Z_i-\text{sg}(Z_i)\|_2^2$（stop gradient）；
  - 总损失 $L_{\text{LeWAM}}=L_{\text{act}}+\alpha L_{\text{wm}}$。
- **推理**：仅编码 $X_t$ 得到 $Z_0$，在 $Z_0$ 与 $c_t$ 条件下去噪生成动作块；省略干净动作与未来查询，未来嵌入预测只提供训练监督、不增加推理成本。

### 2.3 DemoDPO（演示引导的 DPO）

- 从监督 LeWAM 检查点初始化可训练策略 $\pi_\theta$ 与冻结参考策略 $\pi_{\text{ref}}$。
- 对每个条件 $x_t$，从 $\pi_{\text{ref}}$ 独立采样 $G$ 个候选动作块，用与演示的动作 MSE $d_i$ 排序，取最小/最大者构成偏好对 $(A_w,A_l)$。
- 引入对保留掩码 $M_{\text{pair}}=\mathbf{1}\{d_{i_l}-d_{i_w}\ge\varepsilon_{\text{pair}}\}$，过滤区分度不足的组。
- 由于流匹配策略无法直接计算动作似然，采用 Diffusion-DPO/Flow-DPO 的代理：定义归一化流匹配误差 $\bar\ell_\phi$，代理对数比 $s_\theta=-\frac{1}{2}[\bar\ell_\theta-\bar\ell_{\text{ref}}]$，最终损失 $L_{\text{DemoDPO}}=-\mathbb{E}\log\sigma(\beta[s_\theta(A_w)-s_\theta(A_l)]\,|\,M_{\text{pair}}=1)$。
- 候选生成噪声 $\{\eta_i\}$ 与训练噪声 $(\tau,\epsilon)$ 独立采样，两个候选共享同一 $(\tau,\epsilon)$。

## 6. 主要结论与发现

- **表征层面**：Wan2.2 VAE 表现最差（10.81%），I-JEPA-Huge 在冻结编码器中最佳（86.17%），且仅用 ImageNet-22K 预训练就超过 V-JEPA2-Huge（81.70%）；I-JEPA 在深度与分割探针上也最优，说明其几何与物体信息更易被下游访问。
- **注意力行为**：动作 token 对视觉 token 的注意力集中在目标物体与交互区域，并随操作进程在相关区域间转移，支持"动作生成依赖几何与物体信息"的判断。
- **世界模型形式**：直接回归未来嵌入（87.02%）优于流匹配（86.21%）与 Action Only（86.17%），推测因 JEPA 嵌入已具备丰富结构化语义，直接回归更充分利用该监督。
- **AdaFuse 有效且互补**：单独使用提升至 86.88%；与未来嵌入预测结合提升至 90.69%，提升幅度大于无 AdaFuse 时；探针指标也全面改善。
- **DemoDPO 有效**：将平均成功率从 90.69% 提升至 92.28%；同等步数的纯监督训练反而略降（73.31%→73.25%），说明增益不是单纯多训练；最佳配置为 $\varepsilon_{\text{pair}}=10^{-3}$、$\beta=5000$、$G=4$。
- **总体性能**：LeWAM 以 0.4B 可训练参数、无具身预训练、无视频扩散骨干，在 RoboTwin 2.0 达到 92.28%（clean 93.14%，randomized 91.42%），与最强基线（LingBot-VA 92.20%、LaWAM 91.22%、Fast-WAM 91.83%）相当；真实世界三个任务进度均最高（84.9%、60.7%、53.0%），超过 π0.5、LingBot-VLA-v2 与 FastWAM。
- **效率优势**：推理延迟与峰值显存均为对比模型最低。
