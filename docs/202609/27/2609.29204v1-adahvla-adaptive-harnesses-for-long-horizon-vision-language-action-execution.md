## 摘要
视觉-语言-动作（VLA）模型具备强大的局部控制和指令跟随能力，但往往难以应对需要持久记忆和规划的长时程任务。任务执行框架通过保留任务历史并跟踪各执行阶段的进度，为智能体推理提供持久上下文。为了将这些互补能力结合起来，我们提出 AdaHVLA，一种自适应执行框架，它通过机器人经验优化基于代码的协调策略，以更好地使智能体推理和记忆与 VLA 执行对齐。其解耦的多智能体自适应过程将证据分析、执行框架修订和行为评估分离到不同的工作上下文中，使用可检验的协调假设来指导修订，并通过后续 rollout 评估其预测效果。一个有状态的修订图将执行证据、假设、修订和观察到的效果联系起来，保留备选执行框架和自适应记忆，以指导多次尝试中的改进，以及跨任务和环境的持续自适应。在仿真中，AdaHVLA 将 NaVILA-LH 上的平均测试成功率从 22.5% 提升至高达 57.5%，并在三个 VLA 骨干模型上将操作测试成功率较初始执行框架提升最多 30.8 个百分点。真实世界部署进一步说明了自适应策略如何支持跨任务阶段的稳定执行。

## Abstract
Vision-language-action (VLA) models offer strong local control and instruction following but often struggle with long-horizon tasks requiring persistent memory and planning. Task harnesses provide persistent context for agent reasoning by retaining task history and tracking progress across execution stages. To bring these complementary capabilities together, we introduce AdaHVLA, an adaptive harness that refines code-based coordination policies through robot experience to better align agent reasoning and memory with VLA execution. Its decoupled multiagent adaptation process separates evidence analysis, harness revision, and behavioral assessment into distinct working contexts, using testable coordination hypotheses to guide revisions and subsequent rollouts to assess their predicted effects. A stateful revision graph links execution evidence, hypotheses, revisions, and observed effects, preserving alternative harnesses and adaptation memory to guide refinement across repeated attempts and continued adaptation across tasks and environments. In simulation, AdaHVLA raises mean test success on NaVILA-LH from 22.5\% to as high as 57.5\% and improves manipulation test success across three VLA backbones by up to 30.8 percentage points over the initial harness. Real-world deployment further illustrates how the adapted policies support stable execution across task stages.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型在视觉 grounding 和语言条件执行上进展显著，能提供良好的**局部控制**与指令跟随，但真实机器人任务很少是单步动作即可完成。
- **核心痛点**：长时程任务要求机器人**保留相关历史、跟踪剩余子目标、并在执行偏离计划时调整行为**；每个阶段还要为下一阶段创造可成功的条件。局部合理的动作并不保证整体任务推进。
- **既有方案的两条路线**：
  - LLM/VLM 智能体侧：可做更宏观的任务推理与规划修正（如 Inner Monologue、Code as Policies）；
  - 分层 VLA 侧：通过显式中间接口把任务推理连接到学习式局部执行（如 Hi Robot、HAMSTER）。
- **关键缺口**：即使采用"智能体推理 + VLA 执行"的分工，**协调规则本身**（保留哪些历史、何时推进阶段、纠偏持续多久）仍需随布局、执行器响应、中间状态变化而改变。仅靠技能选择或固定规则下的计划修订不足以保证成功。
- **论文主张**：应当**自适应地修改协调策略本身**（即可执行的代码化 harness），而不仅仅是固定规则下改计划。由此提出 **AdaHVLA**：通过机器人经验精炼代码化协调策略，使智能体推理与记忆更好地对齐 VLA 执行。

## 2. 方法论

### 2.1 核心思想

- 把"智能体推理/记忆"与"VLA 执行"之间的接口暴露为一组**可编辑、可执行的协调策略（code-based harness）**。
- 该策略决定：跨调用保留什么状态、向 VLA 传什么指令与观测上下文、何时提交任务进度、何时触发恢复或完成逻辑。
- 执行期间 harness 代码固定（同一 revision 内不重新生成源码）；**在两次 rollout 之间**由多智能体过程修订代码。
- VLA 参数与控制器**始终冻结**，改进完全来自"如何协调既有能力"。

### 2.2 问题形式化

- 任务实例记为 ξ = (x, E, s₀)：指令 x、环境 E、初始机器人/场景状态 s₀。
- 在决策边界 t，harness 依据交互历史 Hₜ = (x, o≤ₜ, a<ₜ) 与运行状态 mₜ 输出：
  - (qₜ, κₜ, mₜ₊₁, zₜ) ∼ H_c(· | Hₜ, mₜ)，其中 qₜ 为给 VLA 的指令，κₜ 为观测上下文，zₜ ∈ {0,1} 为终止标志；
  - aₜ ∼ π_θ(· | qₜ, κₜ)，π_θ 为 VLA 策略。
- 自适应目标：在已有 revision 集合 C 上最大化 E_{ξ∼D, τ∼P_c}[R(τ; ξ)]，R 为 benchmark 成功指示（0/1）。
- 关键约束：修订只使用有限的自适应集，机器人配置与 VLA 参数不变。

### 2.3 Harness-VLA 策略的具体职责

- **任务进度与引导**：有序子任务/目标给出可观测的进度判据；策略决定何时推进当前目标，以及向 VLA 传原始指令还是局部目标。
- **上下文与视觉刷新**：harness 选择哪些观测、进度记录、持续纠偏信息进入推理；并控制执行器接口的视觉刷新。不同用途的历史观测可有不同的保留规则（如转弯前的视觉缓冲对路径推理仍有用，但对局部执行已过时）。
- **恢复与完成**：决定纠偏何时开始、持续、结束；完成检查对照剩余目标，局部停止信号不等于整体任务终止。

### 2.4 多智能体解耦的自适应流程

- **三个分离的工作上下文**：证据分析（evidence analysis）、harness 修订（harness revision）、行为评估（behavioral assessment），彼此通过**结构化记录**交换信息，而非共享一段对话。
- **从证据到修订**：
  - 按 request ID 对齐相机观测、日志、轨迹片段，并关联到 harness 源码 revision；
  - 分析智能体区分"观察到的事件"与"解释"，产出**可检验的协调假设**：疑似机制、支持证据、预期效果、可观测指标；
  - 修订智能体检视源码与相关尝试，提出 c′ = c ⊕ Δ（Δ 为代码补丁）；
  - 另有独立的源码与接口审查确认可执行资格。
- **效果评估与归因门（attribution gate）**：
  - 独立评估智能体在全新上下文中对比父/子 rollout，分别评估目标效果、整体行为与最终成功；
  - 定义 û 表示被修改机制是否被触发，v̂ 表示轨迹在该触发前是否已分歧，取值 {1, 0, ⊥}；
  - **归因门 χ = 1{û = 1 ∧ v̂ = 0}**：只有 χ = 1 的对比才更新假设支持度（目标改善→增强支持；无变化或退化且候选被弃→减弱支持），否则保留原支持度；
  - 强调**可重复性需多次 rollout**，不能凭单次成功下结论。

### 2.5 修订图与记忆

- **任务内策略探索**：维护修订图 G，连接代码版本、假设、rollout 证据与行为评估；候选按"任务成功 → 目标效果 → 整体效果"优先级排序。设 W 为最大活跃候选叶数、D 为当前任务焦点内的最大修订深度。

- 测试阶段两者的源码均固定；**测试结果不参与修订或候选选择**。

- **真实世界验证**：Unitree Go2 实机部署一段轨迹，展示 R59 偏离 → R67–R72 持续纠偏 → R75 达成 Goal 2 的过程。
- **客观性与公平性**：
  - 优点：测试实例留出、测试结果不反馈到修订或候选选择、VLA 参数与控制器冻结、报告 SD、多次重启。
  - 局限：**每格仅 3 次运行**，样本量偏小；作者自己也指出 L1 上若干接近的均值（如 56.7% vs 55.8%）"不足以确立可靠排序"；自适应模型与执行器能力本身可能混杂（如 π0.5 优于更大的 OpenVLA-OFT，说明该对比并未隔离模型规模因素）；L1 与 L2 的工作流长度与阶段依赖同时变化，二者效应无法分离。

## 6. 主要结论与发现

- **引入协调本身即有效**：Initial Harness VLA 已把导航平均测试 SR 从 2.5% 提升到 22.5%（+20.0 点）。
- **自适应进一步带来增益**：AdaHVLA 在 6 个自适应模型上达到 **31.7%–57.5%**，相对初始策略再提升 **9.2–35.0 个百分点**；不同自适应模型端点间差距达 25.8 点，说明改进幅度依赖自适应模型能力。
- **操作任务同样成立**：6 个"骨干×层级"组合中，Initial Harness 全面优于 Single VLA，自适应又在全部设置上进一步提升，L1 达 **25.8%–55.8%**，L2 达 **10.8%–38.3%**。
  - π0.5 上：L1 从 20.0% → 25.0% → **55.8%**（自适应再加 30.8 点）；L2 从 10.0% → **38.3%**（+28.3 点）。
- **L2 更难**：所有骨干的绝对增益与最终 SR 在 L2 上均低于 L1。
- **消融要点**：
  - 导航对**完成检查**（57.5%→29.2%）与**紧凑记忆**（→33.3%）最敏感；操作中**去掉视觉刷新**使 L1 降幅最大（55.8%→37.5%）；**去掉恢复**对 L1 几乎无影响但使 L2 从 38.3% 降到 23.3%，说明长工作流更依赖恢复与上下文保留。
  - **W/O Graph** 使导航降到 42.5%、L2 降到 26.7%（L1 仅降到 50.8%）；**SR Select** 降到 38.3%/48.3%/25.0%；**Shared Context** 降到 49.2%/55.0%/30.0%。综合支持"修订证据需组织化持久、各智能体上下文需独立作用域与生命周期"。
- **执行稳定性**：仿真导航与操作轨迹在自适应后呈现更明显的目标导向推进；实机案例显示 harness 在 VLA 执行纠偏动作期间**保持待完成目标不重启**，且整段 episode 内源码不变。
- **最终 harness 仅凭自适应证据选择**，其源码在留出任务上保持固定。
