## 摘要
操作策略必须知道哪些物体重要以及它们在哪里，然而当前机器人基础模型所依赖的预训练骨干网络——从视觉-语言-动作模型（VLA）中的语言，到世界-动作模型（WAM）中的视频生成——并不直接要求这种度量接地，而是将其留待从机器人演示中隐式学习。我们提出Grounded Action Models（GAM），一种以3D Grounding构建的机器人基础模型新范式。GAM可以以语言、点或框提示为条件，这些提示首先被转换为所选对象的共享对象中心表示。该表示捕获以目标为中心的视觉特征和度量物体几何，并通过多流Transformer与机器人状态历史混合，以预测动作块。尽管GAM可以自主运行，它们也可以作为低级控制器，由高级规划器利用其各种输入模态进行控制，从而实现长时程和依赖记忆的操作。在RoboTwin 2.0上，GAM在50项任务中取得55.3%的平均成功率（Spatial Forcing为52.0%），其中在场景随机化下为47.6%（Abot-M0为30.4%），而其动作策略仅在干净场景演示上训练。在LIBERO-PRO上，它在16种扰动设置中取得61%的最优平均成功率（$π_{0.5}$为53%），当目标被重新定位或新指定时增益最大。在两台真实机器人上，GAM在双臂YAM的视觉偏移下保持17/20的成功次数，而$π_{0.5}$为4/20；其与Molmo2规划器在Franka上的组合在长时程和依赖记忆的任务中实现64.7%的ID和49.8%的OOD步骤完成率。

## Abstract
Manipulation policies must know which objects matter and where they are, yet the pretrained backbones that current robot foundation models build on, from language in vision-language-action models (VLAs) to video generation in world-action models (WAMs), do not directly require this metric grounding, leaving it to be learned implicitly from robot demonstrations. We propose Grounded Action Models (GAMs), a new paradigm of robot foundation models built with 3D grounding. GAM can be conditioned using language, points, or box prompts, which are first transformed into a shared object-centric representation of the selected objects. This representation captures target-focused visual features and metric object geometry, which is mixed with robot state history through a multi-stream transformer to predict action chunks. Although GAMs can be run autonomously, they can also serve as a low-level controller that a high-level planner controls using its various input modalities, allowing for long-horizon and memory-dependent manipulation. On RoboTwin 2.0, GAM achieves an average success rate of 55.3% across 50 tasks (vs. 52.0% for Spatial Forcing), including 47.6% under scene randomization (vs. 30.4% for Abot-M0), with its action policy trained only on clean-scene demonstrations. On LIBERO-PRO, it achieves a state-of-the-art average success rate of 61% (vs. 53% for $π_{0.5}$) across 16 perturbation settings, with the largest gains when targets are relocated or newly designated. On two real robots, GAM retains 17/20 successes under visual shift on a bimanual YAM versus 4/20 for $π_{0.5}$, while its composition with a Molmo2 planner on a Franka achieves 64.7% ID and 49.8% OOD step completion on long-horizon and memory-dependent tasks.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：当前机器人基础模型主要建立在两类预训练骨干上——VLA 依赖语言/视觉-语言预训练，WAM 依赖视频生成预训练。这两类目标都不直接要求**显式的度量级 3D 定位**（metric grounding），即“哪些物体重要、它们在哪里、占据什么几何形状”。
- **后果**：物体定位与空间关系只能从机器人演示中隐式学习。当演示覆盖的环境和布局有限时，策略容易依赖视觉相关性；一旦物体移动、背景变化或目标被重新指定，性能会显著下降。
- **论文主张**：应把**可提示的 3D grounding** 作为机器人动作学习的基础，提出 **Grounded Action Model（GAM）**。其核心假设是：一个在预训练阶段就显式暴露“目标物体 + 度量 3D 几何”的骨干，比语言生成或视频生成骨干更直接地支持可泛化的操作学习。
- **整体含义**：GAM 不仅是新模型，更代表一种新范式：动作策略不再直接观察整幅场景，而是条件化于被 grounding 的任务物体；语言、点、框三种提示统一映射到同一对象中心表示。GAM 既可自主运行，也可作为低层控制器，由高层 VLM 规划器通过点接口驱动，完成长时程和记忆依赖任务。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 使用一个**冻结的、可提示的 3D grounding 骨干**（WildDet3D）解析任务物体，将其输出转换为对象中心的图像 token 和检测 token。
- 动作头只学习“如何操作已被 grounding 的物体”，而不必从零学习“物体在哪里”。
- 所有提示模态（语言、2D 点、2D 框）统一到同一对象表示，便于人机交互和与高层规划器组合。

### 2.2 从提示到检测
- 输入：RGB 图像 \(o_t\) 与任务指定 \(\ell\)。
- 语言输入：用 span-tagging head（基于冻结 Flan-T5）抽取任务相关物体短语，例如“pick up the sponge and place it in the bowl”得到 *sponge* 和 *bowl*，分别作为 grounding query。
- 点/框输入：直接指定物体。
- 对每个物体 \(i\)，WildDet3D 输出：2D 检测框 \(u_i\)、度量 3D 框 \(b_i\)、稠密度量深度图 \(\hat D_t\)，以及视觉骨干的密集特征 \(F_t\)。

### 2.3 从检测到观测
- **图像 token**：将 \(F_t\) 平均池化为 \(G\times G\) 网格（\(G=16\)）。只保留与任务物体 2D 框重叠面积 \(\ge 30\%\) 的格子，或与机器人手臂轮廓重叠 \(>10\%\) 的格子；其余置零。经共享线性 adapter 得到 \(G^2=256\) 个图像 token。
- **检测 token**：利用深度图反投影得到场景点云，裁剪每个 3D 框内点云并采样 \(P=512\) 个点。点云编码器 \(\phi\) 使用共享逐点 MLP，再经全局最大池化、全局平均池化、以及围绕质心的 8 个八分圆内最大池化，得到 512 维形状特征。物体描述符为  
  \[
  z_i=[\tilde u_i,\ c_i,\ \gamma(c_i),\ \phi(P_i),\ e_i,\ r_i]
  \]
  其中 \(\tilde u_i\) 为归一化 2D 框，\(c_i\) 为中心，\(\gamma(c_i)\) 为 8 频率 Fourier 特征，\(e_i\) 为尺寸，\(r_i\) 为 6D 旋转。经线性 adapter 得到每个物体 \(M=8\) 个检测 token；未检测槽位使用可学习 null token。
- **状态历史 token**：拼接当前与前一帧关节位置，投影为单个 token。
- **条件融合**：图像、检测、状态历史 token 加模态嵌入，经共享自注意力层融合，得到条件序列 \(C\in\mathbb R^{L\times d}\)，其中 \(L=G^2+MN+1\)。

### 2.4 从观测到动作
- 动作头为 **MM-DiT**，12 个 block，处理四条流：图像段、检测段、状态历史段、以及嵌入为 \(H\) 个动作 token 的噪声动作块 \(A_t^\tau\)。
- 每个 block 对每条流使用独立的 query/key/value/output projection/FFN/adaLN 参数；通过联合注意力交换信息。
- **语言条件**：句子嵌入 \(e_s\in\mathbb R^{768}\) 经线性投影加入流时间步嵌入：  
  \[
  h_{\tau,s}=\mathrm{TimeEmbed}(\tau)+W_\ell e_s+b_\ell
  \]
  其中 \(W_\ell\in\mathbb R^{576\times768}\)，零初始化。该向量通过自适应层归一化注入每个 block。
- **训练**：只优化动作头（图像 adapter、检测 adapter、点云编码器、条件融合层、语言投影、MM-DiT），grounding 骨干冻结。使用 flow matching：  
  \[
  A_t^\tau=\tau A_t+(1-\tau)\epsilon,\quad 
  \mathcal L=\mathbb E\|\ v_\theta(A_t^\tau\mid \tau,C,e_s)-(A_t-\epsilon)\|_2^2
  \]
  推理时从高斯噪声出发，用 \(K\) 步 Euler 积分生成动作块。
- **部署**：用 CoTracker3 在初始检测框内跟踪点，跨帧保持物体关联；每个策略查询时重新构建 grounded observation。长时程任务中，高层规划器在子任务切换时用当前图像和记忆选择新目标，通过点提示重新初始化跟踪器。

## 3. 实验设计：数据集、Benchmark 与对比方法

### 3.1 RoboTwin 2.0
- **场景**：50 个双臂操作任务，每个任务有干净（Easy）和随机化（Hard）两种设置。
- **协议**：按官方单任务协议，每个任务用 50 条干净场景演示训练一个 GAM 策略，每任务 100 次 rollout，Easy/Hard 各评一次；训练阶段未见随机化场景。
- **对比方法**：DP、ACT、RDT、DP3；VLA 类：starVLA、\(\pi_0\)、GalaxeaVLA、Xiaomi Robotics-0、EventVLA、Abot-M0、X-VLA、\(\pi_{0.5}\)、Spatial Forcing；WAM 类：AHA-WAM、FastWAM、X-WAM。
- **注意**：GAM 为单任务训练，部分基线为 50 任务联合训练；官方 leaderboard 按 Easy/Hard 平均排名。

### 3.2 LIBERO-PRO
- **场景**：保留 LIBERO 固定布局训练数据，测试时沿四个轴扰动：物体外观与尺寸（Obj）、物体位置（Pos）、指令措辞（Sem）、目标物体/目标（Task）。
- **协议**：在四个 suite 的全部 LIBERO 演示上训练单一 GAM 策略，在 16 种扰动设置下评估。
- **对比方法**：NORA、MolmoAct、\(\pi_0\)、X-VLA、OpenVLA、Flex-\(\pi\)、\(\pi_{0.5}\)。多数数字取自官方 leaderboard，Flex-\(\pi\) 由作者自行评估。

### 3.3 真实机器人
- **双臂 YAM**：两臂拾放任务，每侧 3 个同色物体，每臂将一个指定物体放入共享容器；评估 4 种目标组合，每组合 5 次，共 20 次。GAM 用点击或 2D 框指定目标，\(\pi_{0.5}\) 用语言接口；均无规划器和记忆，每组合 25 条演示微调。评估 ID 与视觉偏移。
- **单臂 Franka**：4 个任务，2 个长时程（Sort objects into three bowls、Clear the table），2 个记忆依赖（Uncover the R, G, B blocks in order、Restore original layout）。Molmo2 规划器通过 2D 点选择物体，语言指定操作；每任务 50 条演示微调。对比 \(\pi_{0.5}\) 和 MolmoAct2 的语言接口，无外部规划器。报告 ID 20 次、OOD 10 次试验的步骤完成率。

### 3.4 消融实验
- 在 10 个 RoboTwin 2.0 任务上，每任务 20 次 rollout，Easy/Hard 各评，保持骨干、动作头、训练数据和调度一致。
- 变体：完整 GAM；去掉图像 masking；去掉点云裁剪；两者都去掉；仅检测 token；仅图像 token。
