## 摘要
视觉-语言-动作模型为通用机器人控制提供了坚实基础，但绝大多数策略不会保留和利用当前观测之外的回合级信息。这一局限在依赖仅存在于过去观测中的信息的历史相关操作任务中尤为关键。将过去观测保留在上下文中有助于恢复这类信息，但代价是上下文不断增长、臃肿，并带来推理延迟。因此，我们提出 MemBodied，一种固定大小的回合记忆，包含两个互补组件：记录跨策略调用交互的联想状态，以及保留初始场景紧凑表示作为参考的回合锚点。在每次策略调用时，模型基于当前输入和记忆组件来条件化动作生成，而不是直接使用过去观测。在五个需要记忆的 RMBench 评测任务中，MemBodied 的平均成功率分别达到无状态策略的 7.81 倍和普通循环记忆的 2.98 倍，同时其表现是最强记忆增强基线的 1.3 倍，而新增参数少 10 倍。在完全可观测的 LIBERO-Long 套件上，它达到 90.6%，相比无状态 π0 策略提升 5.4%。这些发现支持 MemBodied 作为面向历史相关操作任务、扩展策略上下文的一种实用替代方案。

## Abstract
Vision-Language-Action models provide a strong foundation for general-purpose robot control, yet a vast majority of policies do not preserve and leverage episode-level information beyond the current observation. This limitation is consequential in history-dependent manipulation tasks that depend on information available only in past observations. Retaining past observations in context can aid in recovering this information, but at the significant cost of ever-growing, bloated context and inference latency. We thus introduce MemBodied, a fixed-size episodic memory with two complementary components: an associative state that records interactions across policy calls and an episode anchor that preserves a compact representation of the initial scene as a reference. At each policy call, the model conditions action generation on the current input and the memory components, rather than directly using past observations. Across five evaluated RMBench tasks requiring memory, MemBodied achieves $7.81\times$ the mean success rate of a stateless policy and $2.98\times$ of vanilla recurrent memory, while outperforming the strongest memory-augmented baseline by $1.3\times$ with $10\times$ fewer added parameters. On the fully observable LIBERO-Long suite, it reached 90.6%, a 5.4% improvement over the stateless $π_0$ policy. These findings support MemBodied as a practical alternative to expanding the policy context for history-dependent manipulation.

# MemBodied 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型（如 RT-2、OpenVLA、Octo、π0、π0.5）已成为通用机器人控制的重要基础，但绝大多数策略在每次调用时**仅以当前观测和语言指令为条件**预测动作块，丢弃了历史信息。
- **关键问题**：在**历史相关（history-dependent）操作任务**中，当前观测可能无法提供完成任务所需的信息。论文将此定义为**时间状态混叠（temporal state aliasing）问题**——相同或相似的当前观测，因过去经历不同而需要不同的动作。例如机器人把物体移走后需归位，但当前位置已无法揭示正确目标。
- **直接保留历史的代价**：将完整历史放入策略上下文会导致上下文长度、显存占用和推理成本随回合持续增长；固定观测窗口虽能限制成本，但任务相关信息一旦移出窗口即丢失。相关信息可能是与当前决策相隔许多中间观测的**短暂事件**。
- **研究目标**：设计一种**在线更新、大小固定、能根据策略当前状态检索信息**的情景记忆，在不扩展策略上下文的前提下提升历史相关操作任务的表现，同时不损害完全可观测任务上的性能。

## 2. 方法论

### 2.1 核心思想

MemBodied 是一种**固定容量的情景记忆**，由两条互补通路组成：

- **联想状态（Associative State）**：以逐层矩阵形式记录跨策略调用的交互历史，通过门控 delta 规则在线更新。
- **情景锚点（Episode Anchor）**：保留回合初始场景的紧凑视觉表示，防止反复更新覆盖早期细节。

每次策略调用时，动作生成以**当前输入 + 记忆读出**为条件，而非直接使用过去观测。记忆状态 $M_t = \{S^{(l)}_t\}_{l=1}^L$，其中 $S^{(l)}_t \in \mathbb{R}^{B \times r \times r}$，实验中 $r=128$，状态大小在回合内保持不变。

### 2.2 关键技术细节

**（1）写入值的构造（Write-Value Construction）**

- 动作块执行后，用投影后的机器人状态 $s_{t+1}$ 作为查询，对下一观测的视觉 patch token 做注意力，得到各相机编码并平均池化，记为 $e^{\text{vision}}_{t+1}$。
- 将其与前一因果动作块的聚合拼接：$y_t = [e^{\text{vision}}_{t+1}; \sum_{h=1}^H a_{t,h}]$，再经逐层投影得到写入值 $v^{(l)}_t$。
- 视觉 patch token 处**停止梯度**。该设计使写入值表示**动态交互转移**，而非孤立观测。

**（2）门控 Delta 规则写入**

- 写入键由层输出变换并做 L2 归一化：$k^{(l)}_t = \text{L2Norm}(\tanh(W^{(l)}_k h^{(l)}_{t,\text{out}}))$。
- 写入门 $\beta^{(l)}_t$ 与保留门 $\alpha^{(l)}_t$ 由层输出和写入值经 sigmoid 得到。
- 更新公式：$S^{(l)}_t = \text{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1} + \text{Diag}(\beta^{(l)}_t)(v^{(l)}_t - \text{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1}k^{(l)}_t)(k^{(l)}_t)^\top$。第一项保留现有状态，第二项通过比较新值与已关联值施加 delta 修正，避免不加区分地累积所有值。

**（3）联想检索与记忆令牌注入**

- 读出查询由进入层前的状态表示构造：$q^{(l)}_t = \text{L2Norm}(\tanh(W^{(l)}_q h^{(l)}_{t,\text{in}}))$，读出 $r^{(l)}_t = S^{(l)}_{t-1}q^{(l)}_t$。
- 论文比较三种条件化变体：**注意力引导（-AS）**、**层级记忆（-H）**、**记忆令牌（主方法）**。
- 主方法将动作网络后缀组织为 `[state token, memory token, H noisy action tokens]`；记忆令牌为每次调用插入的学习向量，不跨调用持久化（持久化的是联想矩阵）。读出经线性变换并缩放 $\alpha_{\text{mem}}/r$（实验中 $\alpha_{\text{mem}}=256$，检索乘数为 2），再由当前状态表示导出的标量门控调制后加入记忆令牌，参与自注意力，使检索内容作为**上下文内容**可用。

**（4）固定情景锚点记忆**

- 取策略前缀中冻结的视觉 token，将每相机 $16\times16$ patch 网格平均池化为 $4\times4$ 并跨相机拼接，得到锚点 $A \in \mathbb{R}^{N_A \times D}$（$r_A=64$）。
- 当前机器人状态对当前视觉 token 做池化得到 $z_t$，通过 rank-$r_A$ 跨注意力查询锚点，得到 $c_t$，投影到动作网络宽度并按动作视野重复，通过输入条件函数 $f_{\text{cond}}$ 融合进动作表示。
- 锚点不追加首帧或其完整 token 序列到策略前缀，**不改变前缀长度、token 位置和注意力掩码结构**。

**（5）读写因果协调与序列训练**

- 延迟写入调度：先用 $M_{t-1}$ 读取并生成 $a_t$，执行后获得 $I_{t+1}$，再写入 $M_t$，确保存储值包含动作的观测后果而不将该未来观测暴露给造成它的动作。
- 训练需**序列级反向传播**：每个样本包含 $N$ 个观测-动作对，相邻对间隔一个动作视野 $H$；图像编码与策略输入在 batch 和序列维度并行，记忆状态沿序列串行传播，梯度贯穿整个序列，使后续动作损失优化早前记忆操作。记忆参数**仅通过策略原生动作目标学习，无单独记忆预测损失**。

## 6. 主要结论与发现

- **RMBench 五项任务**：MemBodied 平均成功率 **50.0%**，比 π0-Stateless（6.4%）高 43.6 个百分点（**7.81 倍**），比 π0-FrameStack（14.8%）高 35.2 点，比 π0-Vanilla Recurrent Memory（16.8%）高 33.2 点（**2.98 倍**）。
- **对比压缩历史方法**：NativeMEM 单独 38.4%，NativeMEM + MemBodied 45.2%，均低于独立 MemBodied 的 50.0%；MemBodied 推理延迟低 **91.9%**（129.2 ms vs. 1593.7 ms），峰值显存低 9.5%，新增参数 **40M（π0 的 1.26%）**，约为 NativeMEM（415M，12.81%）的十分之一。
- **骨干迁移**：π0.5 骨干上 MemBodied 达 48.0%，基线仅 12.4%（**3.87 倍**），Rearrange Blocks 从 13.0% 提升至 94.0%。
- **真实机器人**：平均成功率从 3.33% 提升至 26.67%（**8.0 倍**），三个任务均有改善。
- **LIBERO**：四套件均值 95.1%，与 π0 的 94.2% 相当；**LIBERO-Long 达 90.6%，超过 π0 的 85.2% 达 5.4 个百分点**，提升偏向长视野任务。
- **消融发现**：记忆令牌注入（37.6%）优于层级记忆（23.2%）和注意力引导（20.8%）；加入锚点后提升至 50.0%（Swap Blocks 从 16.0% 升至 56.0%），但锚点在 Block Ranking 上反而从 32.0% 降至 22.0%，说明锚点效果**任务依赖**；写入值中视觉与动作互补，二者结合在三个任务上均最优。
- **定性分析**：增益集中在需要过去信息的**混叠决策点**（归位目标选择、物体选择、交换完成判定、电池方向重试、排列是否已验证），剩余失败多为运动执行错误或长程跟踪错误。

## 7. 优点

- **方法设计精巧**：固定大小记忆在回合内不增长，同时通过"联想状态 + 初始锚点"双通路分别解决交互历史与初始场景两类信息需求，二者角色分工清晰。
- **参数与效率优势显著**：仅新增 40M 参数（π0 的 1.26%），推理延迟和显存均低于压缩历史方法，验证了"固定容量记忆优于扩展上下文"的论点。
- **训练简洁**：记忆参数仅通过策略原生动作目标联合学习，无需辅助记忆预测损失或额外监督。
- **因果一致性**：延迟写入调度保证训练与推理使用相同的交互事件因果解释，避免未来观测泄漏。
- **实验覆盖面广**：仿真 + 真实机器人、两种骨干、记忆依赖 + 完全可观测基准、多类消融与细粒度失败模式标注，验证较立体。
- **客观性较好**：作者主动澄清 π0-μVLA 适配失败的解读边界、π0-Hint 为特权参考而非上界、NativeMEM 训练流程不可比等，减少了误导风险。

- **读出机制的机理阐释不足**：论文比较了三种注入方式，但对"为何记忆令牌优于层级记忆与注意力引导"缺乏机制层面的分析（如梯度流动、注意力熵、记忆矩阵利用率等），结论偏经验性。
- **延迟写入的时序假设**：延迟写入依赖"动作块执行后才获得下一观测"的因果结构，对于异步控制、连续流式动作或人机干预场景是否仍成立未讨论。
- **固定容量记忆的遗忘策略不明确**：门控 delta 规则虽通过 $\alpha$、$\beta$ 控制保留与写入，但论文未分析长期回合中哪些信息被覆盖、是否存在系统性遗忘关键事件的失败案例。
- **跨回合携带仅为探索性**：作者将其标注为探索性测试，未给出跨任务、跨场景迁移的定量结论。

## 9. 可复现性评估

- **有利因素**：方法描述较完整，写入值构造、门控 delta 规则、读出注入方式、锚点池化尺寸（$r=128$、$r_A=64$、$\alpha_{\text{mem}}=256$）等超参明确；训练步数、batch size、序列长度、LoRA 配置均给出；评测协议（任务数、rollout 数、检查点选择）清晰；RMBench、LIBERO 为公开基准。
- **不利因素**：未报告学习率、优化器、权重衰减、门控初始化、记忆矩阵初始化方式等关键训练细节；未说明随机种子数量与方差；真实机器人硬件与演示采集流程描述较简，缺少相机外参与控制频率等复现所需参数；代码/权重是否开源未在总结信息中体现。
- **结论**：方法层面可复现性中等偏上，训练超参与硬件细节的可复现性中等偏低，算力层面不可复现（信息缺失）。

## 10. 总体评价与启示

- **核心贡献定位**：MemBodied 将"情景记忆"从"扩展上下文/堆叠历史帧"的范式转向**固定容量、在线更新、按当前状态检索**的联想记忆范式，并用门控 delta 规则与初始锚点双通路分别覆盖"交互历史"与"初始场景"两类互补信息需求。这是一个在**参数效率、推理效率、因果一致性**三个维度同时占优的设计，其 40M 新增参数（π0 的 1.26%）与 91.9% 的推理延迟下降，直接回应了"长上下文不可持续"的痛点。
- **实证价值**：在 RMBench 上相对最强本地基线约 3 倍、相对无状态基线约 7.8 倍的提升，加上 π0.5 骨干上的可迁移性（3.87 倍），以及 LIBERO-Long 上超过 π0 的 5.4 个百分点，说明增益并非以牺牲完全可观测任务为代价——这是"记忆增强是否损害通用能力"这一常见质疑的有力反证。
- **方法启示**：写入值中"视觉 + 动作"互补、锚点效果任务依赖、记忆令牌优于其他注入方式等消融结论，为后续记忆增强 VLA 的设计提供了可复用的经验规则；延迟写入调度则为"训练-推理因果一致性"提供了一个简洁而通用的工程范式。
- **适用边界**：该方法最适合**存在时间状态混叠、且相关信息为短暂事件或初始场景**的操作任务；对纯进度追踪型任务（如 Block Ranking），固定首帧锚点可能产生干扰，提示未来需要**自适应或任务条件化的锚点机制**。
- **待解问题**：记忆容量的自适应分配、遗忘机制的可解释性、跨回合/跨任务记忆迁移、以及在异步或人机协作控制下的时序适配，是该方法走向更通用机器人记忆系统的关键开放方向。
- **综合判断**：在"固定容量情景记忆增强 VLA"这一细分方向上，MemBodied 提供了方法设计、效率论证与多基准验证较为完整的一套证据链，主要短板集中在**算力透明度、真实机器人统计功效、以及读出机制的理论阐释**三处；总体属于**方法贡献明确、实证较为扎实、但复现细节与理论深度仍有提升空间**的工作。
