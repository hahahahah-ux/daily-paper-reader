## 摘要
尽管视觉-语言-动作（VLA）模型在机器人操作中展现出令人印象深刻的能力，但其无记忆特性使其在测试时环境偏移下表现脆弱，尤其是由磨损或校准不完善引起的硬件偏移。使这些模型在部署期间能够自适应，而无需持续进行现场重新校准，仍是实现现实世界可扩展性的关键瓶颈。在这项工作中，我们提出了 Self-Adaptive VLA，一种新颖的后训练方案，使策略能够利用自身的 rollout 作为上下文，迭代地适应部署时的硬件偏移。为此，我们首先在刻意注入的硬件偏移下收集策略 rollout。然后，我们通过对专家动作针对这些已知偏移进行预补偿，将基础策略的训练数据转换为偏移条件化的专家示范。接下来，我们引入一个轻量级、可插拔的上下文编码器，将偏移环境中的上下文（包括视觉观测、本体感觉和动作）压缩为潜在上下文 token。该 token 通过自适应层归一化（AdaLN）调制策略。此外，我们发现上下文 token 可以被集成，从而使策略能够逐步迭代地自我纠正并缓解失败。在四个精度关键的双臂和灵巧操作任务上的大量实验表明，Self-Adaptive VLA 在硬件偏移（如执行偏置和关节编码器偏移）下恢复了基础策略超过 80% 的性能。此外，与基础策略相比，Self-Adaptive VLA 能够更鲁棒地部署到新的工作站。我们的方法为稳健的大规模真实世界机器人部署和更轻松的维护提供了一条路径。视频见 https://icefoxzhx.github.io/self-adaptive-vla。

## Abstract
While Vision-Language-Action (VLA) models demonstrate impressive capabilities in robotic manipulation, their memoryless nature renders them brittle to test-time environment shifts, particularly hardware shifts caused by wear or imperfect calibration. Enabling these models to self-adapt during deployment without requiring continuous on-site recalibration remains a critical bottleneck for real-world scalability. In this work, we introduce Self-Adaptive VLA, a novel post-training recipe that enables the policy to iteratively adapt to deployment-time hardware shifts leveraging its own rollouts as context. To do so, we first collect policy rollouts under deliberately injected hardware shifts. We then transform the base policy's training data into shift-conditioned expert demonstrations by pre-compensating the expert actions for these known shifts. Next, we introduce a lightweight, plug-in context encoder that compresses the context, including visual observation, proprioception, and actions in the shifted environment, into a latent context token. This token modulates the policy through adaptive layer normalization (AdaLN). Furthermore, we find that context tokens can be ensembled, allowing the policy to iteratively self-correct and mitigate failures step by step. Extensive experiments across four precision-critical bi-manual and dexterous manipulation tasks show that Self-Adaptive VLA recovers over 80% of the base policy's performance under hardware shifts, such as actuation bias and joint encoder offsets. Moreover, Self-Adaptive VLA enables more robust deployment to new workstations compared to the base policy. Our approach provides a pathway for robust large-scale real-world robot deployments and easier maintenance. See videos at https://icefoxzhx.github.io/self-adaptive-vla.

- **研究动机**：视觉-语言-动作（VLA）模型在机器人操作中表现优异，但其**无记忆（memoryless）特性**使其对测试时环境偏移极度脆弱，尤其是由硬件磨损或标定误差引起的**硬件偏移（hardware shift）**。
- **现实痛点**：制造公差与长期磨损使部署硬件难以与训练配置完全对齐，而持续现场重标定在大规模部署与维护中不现实，构成规模化落地的关键瓶颈。
- **整体含义**：论文提出一种**后训练（post-training）方案 Self-Adaptive VLA**，让策略利用自身失败 rollout 作为上下文，在部署期间迭代适应硬件偏移，无需人工重标定，也**不增加推理开销**，为大规模真实机器人部署与便捷维护提供路径。

## 二、方法论

### 2.1 核心思想
- 将策略自身的**次优 rollout 作为上下文**，让无记忆的 VLA 通过上下文 token 调制实现“记忆”，从而推断并补偿硬件偏移。
- 建模两类硬件偏移：**执行偏置（actuation bias）** 与 **关节编码器偏移（joint encoder offset）**。
  - 执行偏置：动作执行偏移 δ，但状态感知准确：$\hat{q}_{t+1} \approx a_t + \delta,\ q_t = \hat{q}_t$。
  - 关节编码器偏移：动作执行与状态感知同时偏移 δ：$\hat{q}_{t+1} \approx a_t + \delta,\ q_t = \hat{q}_t - \delta$，此偏移只能从视觉观测推断。
- 目标：学习自适应策略 $\pi(A^*_t \mid l, o_t, q_t, \xi_s)$，条件化于次优行为 $\xi_s$ 以输出**硬件偏移补偿后的动作块**。

### 2.2 关键技术流程

1. **偏移条件化专家数据构建（自动化管线）**
   - 采样随机硬件偏移 δ，在注入偏移下 rollout 冻结的基础策略，收集次优轨迹数据集 $\mathcal{D}_{shift}$ 作为上下文。
   - 将基础专家数据 $\mathcal{D}_{base}$ 通过**预补偿专家动作**转换为偏移补偿后的专家轨迹 $\xi^*$（若偏移含传感器偏移则同时变换本体感觉 $q^*$）。
   - 关键约束：补偿目标**仅来自高质量人类专家数据**，绝不来自次优 rollout，保证数据质量。

2. **可插拔上下文编码器**
   - 输入：长度 T、时间分辨率 R 的多模态上下文（3 路视频、本体感觉、动作，30Hz）。
   - 视频以 1/R fps 下采样，ViT 提取每相机 M 个视觉 token；本体感觉与动作经共享 MLP 投影为单 token，共 2M token。
   - 加入可学习**类型嵌入**区分模态，经**两个自注意力块 + 时序 1D RoPE** 融合。
   - 最后经**可学习查询注意力池化**压缩为单一上下文 token $c \in \mathbb{R}^d$，维度与 DiT 时间步条件一致。
   - 该 token 与扩散时间步条件**相加**后送入 DiT 块的 AdaLN（自适应层归一化）调制策略。
   - 训练时冻结 VLM 主干，上下文编码器用与基础策略相同的**条件流匹配损失**优化。

3. **上下文 token 集成实现迭代自适应**
   - 多轮 trial 的上下文 token 直接**线性求和**：$\text{ensemble}(c_1,\dots,c_m) = c_1 + \dots + c_m$。
   - 由于不同硬件偏移可能坍缩为相似失败模式，单次 rollout 不足以定位偏移；多轮集成可逐步隔离并补偿残余偏移，并纠正自身过/欠补偿。
   - 推理时上下文编码器仅在失败 trial 后执行一次，生成静态 token 后**零额外计算开销**。

## 三、实验设计

- **任务场景（4 个精度关键任务）**：
  - Transport Corn（6-DoF Piper/Piper-X 臂 + 平行夹爪）
  - Insert Tube（同上）
  - Cap Marker（同上）
  - Assemble Ring（两台 7-DoF Marvin 臂 + 20-DoF Wuji 灵巧手）
  - 每台机器人配 1 个 ego 相机 + 2 个腕部相机；任务时长约 10–15 秒。
- **Benchmark 设置**：
  - 每个方法测试 **20 个 episode**，每 episode 采样一个未见的硬件偏移（相当于 20 个未标定部署环境）。
  - 每 episode 最多允许 **6 次 trial**，任一次完成即判定成功；trial 之间完全重置场景。
  - 指标：成功率 $s$ 与性能恢复比 $\rho = \frac{s - s_{base,misaligned}}{s_{base,nominal} - s_{base,misaligned}}$。
- **对比方法**：
  1. 无记忆基础策略（Base）；
  2. Base + Shift Data（仅用偏移 rollout 微调，无上下文编码器）；
  3. Gated Memory Policy (GMP)（跨 trial 记忆，用相同上下文数据训练）；
  4. Self-Adaptive VLA（本文）及其集成变体（Ours + Ensemble）。
- **实现细节**：基础 VLA 采用 Qwen-3.5-0.8B 作为 VLM 编码器，8 层 DiT（340M 参数）作为动作去噪器；上下文编码器使用预训练 DINO v3 视觉主干；上下文窗口 T = 15。

- 仅披露了模型规模相关参数：Qwen-3.5-0.8B VLM 编码器、8 层 DiT（340M 参数）、DINO v3 视觉主干，以及上下文窗口 T = 15。

## 五、实验数量与充分性

- **主要实验**：4 个任务 × 3 种条件（标称、执行偏置、关节编码器偏移）× 5 种方法（含集成变体），共约 60 组成功率评估，每组 20 次 episode 取平均。
- **消融实验**：在 Cap Marker 任务上对上下文编码器做两组消融——移除本体感觉（-Proprios）与使用全部 patch token（All Patch Tokens）。
- **上下文结构分析**：计算各偏移轴均值 token 的两两余弦相似度（热力图），并进行 PCA 分析，验证潜空间维度与偏移轴数量一致（6 个分量占 99.8% 方差）。
- **新工作站部署实验**：在训练工作站与两个新工作站上评估 Assemble Ring 任务（最多 2 次 trial 上下文）。
- **迭代曲线实验**：绘制 Cap Marker 任务成功率随 trial 数（0–5）的变化，对比 GMP。
- **充分性与公平性评估**：
  - 覆盖 4 种任务、2 类硬件偏移、多种机器人本体（6/7-DoF 臂 + 20-DoF 灵巧手），多样性较好。
  - 所有基线均从**同一基础策略**后训练，比较公平。
  - 但每个任务每条件仅 20 个 episode，统计样本偏小；未报告方差/置信区间；硬件偏移的采样分布未详细说明。

## 六、主要结论与发现

1. **基础策略在硬件偏移下崩溃**：标称成功率近 100%（平均 88.8%），但执行偏置下平均仅 7.5%，关节编码器偏移下仅 5.0%，几乎完全失效；仅用偏移数据微调（Base + Shift Data）也无法解决。
2. **Self-Adaptive VLA 单次 trial 即可大幅恢复**：执行偏置下平均成功率 45.0%（恢复 46%），关节编码器偏移下 46.3%（恢复 49%）。
3. **上下文集成带来显著提升**：集成最多 6 次 trial 后，执行偏置恢复至 80%（平均 72.5%），关节编码器偏移恢复至 84%（平均 75.0%）；Transport Corn 任务从 0–20% 完全恢复到 100%。
4. **上下文 token 具有良构潜空间**：同一偏移轴正负号 token 余弦相似度约 −0.987 至 −0.991，不同轴间接近 0；潜空间维度精确等于偏移轴数量（6 个分量解释 99.8% 方差），解释了线性求和的可行性。
5. **本体感觉对执行偏置尤为关键**：移除本体感觉后两种偏移均下降，但执行偏置下下降更严重；使用更密集的 patch token 无显著增益，CLS token 已足够。
6. **新工作站部署更鲁棒**：基础策略从 95% 降至 70% 与 10%，Self-Adaptive VLA 用 2 次 trial 上下文恢复至 90% 与 50%。
7. **优于 GMP**：GMP 受固定注意力窗口限制，超过 2 次 trial 后难以继续改善；Self-Adaptive VLA 可持续迭代提升。

## 七、优点

- **方法设计亮点**：
  - 将“失败经验”作为上下文的后训练范式新颖，直接利用策略自身 rollout，无需额外人工采集。
  - 自动化数据合成管线（预补偿专家动作）保证补偿目标始终来自高质量专家数据，避免次优数据污染。
  - 可插拔上下文编码器与 AdaLN 调制设计，**推理时零额外开销**，工程实用性强。
  - 上下文 token 线性集成简洁有效，且被潜空间结构分析所解释，具备一定可解释性。
- **实验设计亮点**：
  - 覆盖双臂与灵巧手、多种机器人本体，任务均为精度关键的抓取与插入。
  - 统一从同一基础策略后训练，基线公平。
  - 除成功率外，还提供迭代曲线、潜空间可视化、消融与新工作站部署验证，论证较立体。

## 八、不足与局限

- **方法适用范围有限**：仅覆盖可在机器人配置空间内建模的偏移（关节编码器偏移、执行偏置），**未涉及相机标定误差**等更广泛的环境差异。
- **无 trial 内自适应**：将次优轨迹编码为静态 token 虽消除推理开销，但也排除了推理过程中的在线更新，无法实现 trial 内即时纠正。
- **安全性假设较强**：假设环境允许安全收集次优 rollout，对安全关键任务（首次失败可能造成不可逆损坏）不适用。
- **实验统计不足**：每条件仅 20 个 episode，未报告方差或置信区间；硬件偏移分布、注入范围等细节披露有限，可能影响可复现性与结论稳健性。
- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，难以评估方法的总计算成本与可扩展性。
- **基线覆盖有限**：未与更多通用测试时自适应方法（如 TTT、其他长上下文策略）做对比。
